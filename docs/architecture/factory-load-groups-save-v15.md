## 增量权威字段

schema 15 每个已放置 `grid_buffer` 必须包含且只包含以下 `load_group` 对象。储能原有整数电量、启停、归网字段继续沿 E2；未装配构件和其他实体不得带此对象。成员实体不另存反向组 ID，以免两份事实冲突。

| 字段 | 类型与合法值 |
| --- | --- |
| `enabled` | 严格布尔值，表示控制启停，与储能本机 `enabled` 分开 |
| `member_ids` | 按 ID 严格升序、无重复的数组，长度 `0..8`；每项为正精确整数，小于 `next_id` |
| `reserve_j` | 精确整数、1000 J 倍数，范围 `0..3600000`，默认 `100000` |
| `latch` | `pending`、`allow` 或 `block` |
| `evaluation_ticks_left` | 精确整数 `0..19`；0 表示下一权威步尝试评估 |

整数沿现有有限 / 非负 / JSON 精确整数校验，不能把布尔、字符串或浮点截断成合法值。默认对象为 `enabled=false, member_ids=[], reserve_j=100000, latch=pending, evaluation_ticks_left=0`。未知 / 缺字段均拒绝，不静默补默认。

### 规范组合与引用

- 未研究 `load_management` 时，所有储能只能有完整默认对象。已研究的配置须满足核心 III 与 C2 研究 DAG；新增成本由已完成研究及版本定义重建，不保存“已付款”或“允许控制”副本。
- `enabled=false` 必须为 `latch=pending`、`evaluation_ticks_left=0`，可保留合法成员和自定义保留量。`member_ids=[]` 必须关闭；已研究后的空组允许保留自定义保留量，来自清空配置或末成员移除。启用组必须有 1–8 个成员。
- 每个成员必须存在，类型为 `refinery / assembler`，当前配方非 `cell_assembly`；全世界所有组（含关闭组）的成员集合两两不交。引用不存在 / 错类型 / 电芯配方、重复归属均为损坏，拒绝；正常回收和切电芯配方必须先原子清引用。
- 启用时三种 latch 均合法。刚启用或修改配置后可在下一模拟步之前保存 `pending / 0`；因失效或无候选不能评估时，`pending` 可与 `0..19` 任一倒计时共存。`allow / block` 同样允许任意合法倒计时，不用当前需求或电量反推上次决定。
- 储能本机停用 / 孤立、成员分网、合网后多个启用组属于**合法运行失效状态**，均可存读。读档须恢复为整组禁止新批并展示原因，不因冲突拒绝文件、不自动关闭组或选择胜者。每网一个启用组是配置提交约束，不是拓扑变化后的存档拒绝条件。
- 本机手动停机和在制均是合法成员状态；原实体的 `enabled`、批次 ID、投入、进度、输入 / 输出严格保留。不能根据组的阻断决定把在制标为空闲，或擅自把本机重新启用。

`evaluation_ticks_left` 记录步初相对倒计时，取代早期草案中未定义的“下次评估 tick”；不同时保存绝对与相对两份时钟。启用组每步 `0 → 尝试评估 → 19`，非零则减一。评估失效 / 无候选时不改变 latch；关闭状态不计时，暂停和离线不补步。应用、启用、关闭和成员变化的重置按实施合同执行，读档本身不重置。

不持久化：网络编号、冲突标记、有效性 / 原因文案、实时预算、候选集、窗口工时、供需余量、上次样本读数、最终开工许可、成员反向索引和 UI 草稿。它们从原实体、拓扑、组配置和当前状态派生；`latch` 与倒计时是需要精确恢复的历史决定和节奏，不能由这些派生数据替代。

## 恢复与事务边界

1. Store 先验证世界 ID、完整身份和定义摘要，再取得单写会话；未知 / 未来身份和错摘要不走备份降级。构造 schema 15 模型并恢复世界时钟、研究、实体、物料 / 构件、固定燃烧、E2 能量账及 C1 / C2 原字段。
2. 校验每个 `load_group` 的精确白名单、数值和组合，再在全部实体完成恢复后验证正向引用、成员配方与全局唯一归属。重建端口、自动电图与派生成员索引；合法失效只产生原因，不写回清空 / 改组。
3. 在第一模拟步之前，所有组的启停、成员、保留量、latch、倒计时、本机启停和在制都必须与快照一致；UI 与保存不得补一次评估。场景重建成功才接纳会话，失败释放锁并保留原档。
4. 第一步先做当前有效性检查，再按恢复的倒计时决定是否评估；不是所有读档都立即采样。随后 C3 许可参与新批工时请求，原电力、在制与物流继续。同样的快照和输入必须得到同样的后续开批 / 能量轨迹。
5. 研究扣料、应用配置、启停组、移除成员、切换配方并清引用、回收成员 / 储能并清理组及 C2 引用，分别在单条命令事务内完成。失败保留完整前态，禁止快照半扣料、半清引用或反向索引过期状态。

复用现有临时写入、严格读回、主档序号 / 哈希、单写锁、三槽备份和原子发布。仅同 world ID、同完整身份和摘要的备份可恢复；不支持的主档不能被较旧备份掩盖。写 / 读回 / 备份 / 发布失败暂停并保留内存及原文件，不能伪造保存成功。

C3 没有新的能源来源、损耗或离线收益。研究不新增电芯消费；在制和原库存按既有总账校验，组等待本身不算物料消费或电力请求。实际待机、在制用能、G 释能、充放 / 损耗继续入原统计；不能增加一份“节省能量”计数替代可核对的账。
