## 身份与职责

| 字段 | 固定值 |
| --- | --- |
| `world_kind` | `factory_3d` |
| `save_schema_version` | `7` |
| `ruleset_id` | `factory_expansion_e2_v1` |
| `map_id` | `factory_expansion_yard_64_v1` |
| `supply_id` | `factory_expansion_energy_starter_v1` |

`energy_model.gd` 继承 E1 的多原料 / 多产物、构件制造及物料账，增加工业电芯、发电机和本机启停；初始仍为 165 构件、零物料，G 预配为零，总拥有量上限 326。地图不变，R12 和 G 制造由已持久化的首次扩建事实解锁。新建是菜单第四项，默认仍为基础工厂；原 E1 新建 / 继续保留。

`power_grid.gd` 只计算分配。每网先使用封装电源，再按各机本步实际可供上限均分缺口。启用额定能力决定自动接网偏好，燃料变化不重建电图；停用或无燃料 G 仍是导通节点。旧世界不存在 G，沿原分配与接网规则。

固定步先开始统计桶，再由 `energy_model._commit_power` 扣实际输出所需能量，然后推进加工、物流与统计。新到电芯下一步才能发电；查询、HUD、拓扑重建和解码不扣料。基础供电、实际电芯供能及启用额定积分由 `energy_statistics.gd` 记录；消费者共用同一网内满足率。

## 权威字段与严格校验

V7 复用全部 E1 状态，并增加：

- 用电设备的布尔 `enabled`，默认启用；停机保存输入、在制、输出、进度与批次，被动物流继续。
- G 的布尔 `enabled`、仅含 `industrial_cell` 的 `fuel` 映射（合计 0–5）与有限 `remaining_kj`（0–7,200）。拒绝加工、输出、消费者连接等不属于 G 的字段。
- `completed_by_recipe.cell_assembly`、`assembly_counts.cell_generator` 及对应物品 / 构件类型；不放宽旧 codec 的白名单。
- 统计累计量、当前桶和最近 600 秒桶中的 `enabled_kj`、`base_supplied_kj`、`cell_supplied_kj`、`discarded_kj`、整数 `cells_activated`。
- `energy_origin`：新建为 `{}`；复制为严格的 `source_id`、`source_sequence`、`source_sha256`，来源身份必须不同于自身。

`codec_v7.gd` 先确认完整身份，再复用 V6 的状态重建与实体 / 制造账校验。能源校验器显式验证新增字段后才投影旧统计字段交给共同时间轴校验；不吞掉未知字段，不以默认值修复坏档。装机上界由原 240 kW 与累计合法制造 G 数推导，请求上界由合法消费者推导。

整数物料和制造计数精确校验，浮点能量沿共同容差：

```text
完整电芯持有量 = R12 完成数 − 累计激活数
7,200 × 累计激活数 = 电芯实际供能 + 回收余能损失 + 现存余能
总实际供电 = 基础供电 + 电芯实际供能 = 实际用电
当前可供积分 ≤ 启用额定积分 ≤ 装机额定积分
```

激活当步只记一次物料消费，耗完不再扣一次。回收先校验全部返料的背包容量，成功移除后才登记余能损失；取消或容量不足保持整个状态。历史累计制造不会因回收被扣减。R12 完成或 G 制造早于首次扩建、伪造消费 / 余能 / 损失、非有限数、过大缓冲及错误字段组合均拒绝。

## E1 显式复制事务

菜单显示原 E1 的“复制为能源世界”，确认页说明两份进度独立和原世界保留，捕获所选主档 ID、序号与 SHA-256。取消不写文件。V1–V5、工程身份、坏主档待恢复或被占用的来源不直接复制。

Store 在创建锁下取得源世界写锁，严格读取有效 V6 主档并比对所选序号 / 哈希。`energy_copy.gd` 生成新 ID，在根目录下不可列为世界的 `.energy-copy-<id>/<id>/` 中建立副本。复制人物、布局、全部物料 / 在制、发现事实、时钟余量、制造账与统计历史；仅新增零能源计数、零 G 构件和默认启用标志。旧供能及历史桶归入基础供电，旧可用积分归入启用额定积分。

副本经原 Store 的临时写、严格读回及发布后，再检查源哈希与锁，原子重命名整个新世界目录。新世界写锁随目录移动，再转交进入会话；此前不出现在世界列表。失败保留未发布诊断，原 E1 字节不变；成功后两者独立继续。发布已成功但源锁释放失败时明确显示警告，不谎报整个复制失败。

会话身份阻止 E2 原位覆盖 E1，也阻止 E1 / E2 与普通、工程身份相互写入。以后保存继续沿三槽备份、外部主档修改拒绝覆盖、未来身份阻断回退等共同规则。复制不代表任意存档编辑、通用世界克隆或静默迁移。
