# Image Generation And Review Workflow

更新时间：2026-08-22

## 用途

本文定义 AI 图像生成、候选落盘、批次交接和图像读取的稳定工作流。仅在生成或密集审阅图像时按需读取；像素网格、调色板、尺寸和风格合同仍以 [Pixel Art And Grid Standard](../reference/pixel-art-and-grid-standard.md) 为准，具体素材目标仍以当前功能专题和提示词库为准。

## 会话拆分

- 单个图像生成会话默认只负责一个素材类别的生成与落盘，例如角色、设备、地表或 UI 目标稿不在同一生成批次混做。
- 候选审阅、裁切、atlas 组装、代码 / 场景接入、Godot 验证和提交默认交给独立执行会话；萝卜SAMA明确指定当前会话继续某个命名阶段时，才在原会话切换。
- 前一类别完成落盘并更新 manifest 后，萝卜SAMA若明确点名切换到下一素材类别，可在原会话继续；新类别必须重新读取真相源，使用独立批次目录和 manifest，并从自己的首轮 `0 / 3` 开始计数。
- 切换授权只覆盖被点名的类别或阶段，不自动扩展到后续类别、接入、Godot 验证、提交或无限续跑。

## 生成轮次

- 单个会话默认先执行至多 `3` 次图像生成调用，每次只生成 `1` 张图。
- 每达到一轮 `3` 次调用后必须停手，报告累计调用数、已落盘候选、当前结论和继续生成的必要性，并更新本批 `_manifest.md`。
- 萝卜SAMA明确批准当前会话继续后，可追加一轮至多 `3` 次；每轮结束仍须重新停手并取得下一轮授权。
- 这组限制是稳定性护栏，不由执行 Agent 自行放宽。预计需要大批量生成时，优先拆分任务，或由萝卜SAMA单独批准只返回文件路径的受控 API / CLI 批处理方案。

## 候选落盘

- 项目用生成结果必须在继续下一次生成前保存到 `$CODEX_HOME/generated_images/`，并复制到忽略提交的 `assets/art-intake/YYYY-MM-DD-batchNN/`。
- 候选使用可辨识素材类别、方向和版本的语义化文件名；不要只保留工具默认名称。
- 明确属于一次性预览或头脑风暴、不会进入项目审阅链的图片，可以只保留在 `$CODEX_HOME/generated_images/`。
- 每个批次维护 `_manifest.md`，至少记录素材类别、真相源、调用计数、候选文件、关键参数或提示、哈希 / 尺寸（适用时）、当前选择与淘汰原因、是否允许继续。
- 生成结果尚未落盘和更新 manifest 时，不开始下一轮，也不依赖旧会话图像上下文代替文件真相源。

## 中断恢复

- 图像生成会话发生中断、重连或超时后，先清点 `$CODEX_HOME/generated_images/<thread-id>/`、对应 `assets/art-intake/` 批次目录和工作区状态。
- 只有确认目标结果确实缺失后才补生成；不得在未检查文件和工具结果时原样重试。
- 恢复图像密集型旧会话时，优先用会话列表确认状态并读取批次 manifest 与落盘文件；读取旧会话默认设置 `includeOutputs: false` 并限制在必要的最近轮次，除无替代方案外不载入完整图像工具结果、截断工具输出或重复正文。

## 图像读取稳定性

- 图像读取不设单会话累计张数上限；限制以单次调用的分辨率、像素量、文件体积和视觉密度为准。
- 默认使用 `detail: "high"`。只有检查像素边缘、小字、透明度、锚点或局部瑕疵时才使用 `detail: "original"`。
- 单次调用最多读取 `9` 张 `high` 图片。使用 `original` 前先检查尺寸与文件体积；单次原图合计不超过 `8 MP` 且不超过 `4 MB`，超过时拆分、裁切或改用 `high`。
- 长边超过 `2048 px` 或总像素超过 `2 MP` 的 `original` 图片默认一次只读 `1` 张，并在继续下一张前形成文字判断。
- 联系表、拼图和包含多个画面的截图只用 `high` 做总览；需要精查时读取被选中的单图或裁切区域，不在同一次调用中同时送入联系表和对应原图。
- 图片调用完成后超过 `90` 秒没有新的推理、消息或工具动作，可视为疑似停滞。恢复时先确认工具结果与落盘文件，再减少批量、改用 `high`、裁切局部或拆分任务。

## 审阅与交接

- 大规模视觉审阅按素材类别拆分，把选择、淘汰原因和关键观察写入 manifest 或专题记录；后续任务读取文字真相源，不依赖旧会话中的图片记忆。
- 审阅先判断素材是否满足玩家结果、介质、网格、方向、尺寸和家族一致性，再判断局部色彩与装饰；不以局部调色掩盖介质或结构失败。
- 联系表用于快速导航，不替代对入选单图、透明度、锚点、像素边缘和原生比例的必要精查。
- 批次收口时明确列出：入选候选、未入选原因、仍需人工判断的项目、下一阶段名称、落盘目录和 manifest 路径。
- 进入 Godot、场景接入或玩家可见验证后，遵循 [Godot Runtime Verification Guide](../reference/godot-runtime-verification-guide.md) 和当前专题，不把生成成功写成接入或视觉验收通过。
