# Demo Main Path Continuity V1

更新时间：2026-06-16

## 目标

建立首版 Demo 主路径连续性契约，确认玩家从 `S0` 新档到 `S21` 核心稳定站入口，再到 `quest.write_demo_stabilization_core` 完成反馈之间，世界、角色、库存、建筑、任务、区域、敌人、HUD / 地图和关键整备状态不会断档。

本专题承接 [Demo Save State Contract V1](demo-save-state-contract-v1.md) 之后的阶段推进；重点不是继续扩写存档字段，而是把首版 Demo 主路径的“下一步能走、关键状态能读、终点能完成”固定成可检查契约。

## 范围

覆盖：

- `S0`、`S1`、`S2`、`S5`、`S13`、`S19`、`S21` 等代表性开发基线的当前区域、当前任务、已完成任务、关键建筑、关键库存和回投锚点状态。
- `S21` 到核心稳定站的真实运行路径：进入核心区域、整备核心稳压缓冲包、守卫战消耗缓冲、回收核心写入校验片、写入核心稳定数据。
- HUD 当前目标、关键资源、路线段标题和 Demo 完成读法在上述路径中的连续性。
- `slice_01_complete` 只在核心写入任务完成后出现，不能在进入核心站或整备阶段提前出现。

不覆盖：

- 不新增资源、配方、区域、任务链、完整背包、完整装备栏或自动化物流。
- 不继续加厚资源链状态、非核心区域场景身份、功能 / 过渡路线支撑、工具打击校准、防护响应、主线完成感或工业主干同类读法点。
- 不把当前推进切到试玩准备、修 bug、发布准备或纯基线复核。

## 主路径契约

| 段落 | 必须保持的连续性 |
| --- | --- |
| `S0` 新档 | 当前任务是恢复前哨，角色和世界都在前哨平台，HUD 能读出当前目标和关键资源。 |
| `S1` 处理点就绪 | 处理点扩建已完成，污染过滤器存在，当前任务进入污染边界。 |
| `S2` 外圈已确认 | 封锁遗迹外圈主段完成，当前任务回收封锁回波匣，角色处在遗迹外圈。 |
| `S5` 回投上线 | 前线回传锚点部署完成，当前任务要求从基地回投台重返前线。 |
| `S13` 稳场锚核带回 | 背包中有稳场锚核，当前任务回基地解析稳场锚核，回投锚点保持可用。 |
| `S19` 巡线反馈归档 | 基地行动选择入口激活，三类选择任务同时存在，巡线反馈产物留在背包。 |
| `S21` 核心站开放 | 核心稳定站区域已解锁，当前任务进入核心稳定站，锚定桥回投锚点仍是当前落点。 |
| 终点写入 | `quest.write_demo_stabilization_core` 完成后出现 `slice_01_complete` 和 Demo 完成反馈。 |

## 验收

- 新增 `client/scripts/checks/demo_main_path_continuity_check.gd`，通过 `DevelopmentBaselineBuilder` 验证主路径代表性基线状态，通过真实 `GatherSystem`、`ProcessingSystem`、`EnemyCounterattackRuntime` 和 `QuestRuntime` 推进 `S21` 到 Demo 完成。
- 新增 `scripts/check-client-demo-main-path-continuity.py` / `.ps1`，作为窄职责静态护栏，确认文档、运行时检查和入口接线同时存在。
- `sh ./scripts/check-client.sh` 默认执行静态护栏；`sh ./scripts/check-client.sh --with-godot` 执行运行时主路径连续性检查。

## 退出条件

- 代表性基线能验证当前任务、区域、库存、建筑、回投锚点和 HUD / 地图读法不脱节。
- 从 `S21` 出发，真实运行事件能完成核心稳定站四段路径，并且守卫缓冲消耗、核心写入校验片、Demo 完成反馈和 `slice_01_complete` 都落在正确阶段。
- 未新增内容型资源、配方、区域、任务链或完整系统。
- 新检查保持窄职责，不继续推高既有大检查、地图或 HUD 脚本复杂度。
