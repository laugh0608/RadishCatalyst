# Demo Resource Chain State V1

更新时间：2026-06-16

## 用途

本文定义首版 Demo 资源链状态第一包。它承接已落地的工业主干读法，把“设备和配方能说明用途”推进到“玩家能判断当前核心资源处在哪条链路、下一步该回哪个设备、加工结果如何进入外勤整备或核心站准备”。

本专题服务 [Demo Definition V1](demo-definition-v1.md) 中「资源 / 生产链」「污染与防护」「UI / HUD」「存档 / 状态」和「自动检查」规格。它不新增资源、配方、设备、完整背包或复杂化工仿真。

## 玩家价值

- 玩家看到晶体矿物时，能知道它会进入基础反应器并转成基础零件。
- 玩家看到污染沉积物时，能知道它会进入污染过滤器并产出抗污染药剂和污染浆液。
- 玩家看到污染浆液时，能判断它是留给核心 / 遗迹组装，还是回收成基础零件。
- 玩家看到修复凝胶、抗污染药剂、基础零件和核心稳压缓冲包时，能判断当前是否已接近核心站整备。

## 与整体规划的关系

- 服务长期核心：“基地服务冒险，冒险反哺基地”。
- 承接 `Demo Industrial Tech Spine V1` 的设备 / 配方主干读法，但不继续加厚同一设备说明。
- 承接角色成长、防护响应、工具校准和主线完成感，不新增装备栏、随机词条或长期成长系统。
- 复用现有库存、配方、设备状态和存档结构，不新增稳定 ID 或迁移口径。

## 当前已有基础

- `ProcessingSystem` 已能消费输入、写入设备加工中状态、完成后发放产物 / 副产。
- `IndustrialTechSpineFormatter` 已说明基础反应器、污染过滤器和出发整备台的工艺主干。
- `HudStatusPresenter`、`HudDevicePanelPresenter` 和 `HudLogPresenter` 已有基地摘要、设备面板和加工结果入口。
- `CharacterState` / `InventoryState` / `WorldState` 已能序列化库存、设备状态、任务状态和角色状态。

## 本轮范围

- 新增资源链状态 formatter，统一 8 个核心资源 / 产物的链路判断。
- HUD 基地摘要在前哨显示当前资源链状态和核心资源快照。
- 设备面板在基础反应器和污染过滤器显示当前配方所在链路。
- 加工完成日志补充资源链去向，说明产物或副产如何进入下一段。
- 新增专项检查，覆盖核心资源口径、HUD、设备面板、加工结果和状态序列化 round-trip。

## 当前不做

- 不新增资源、流体、配方、设备、敌人、区域或任务链。
- 不改背包 UI、快捷栏结构、设备队列、自动化物流、电网或管线。
- 不继续加厚路线支撑、非核心场景身份、工具校准、防护响应、主线完成感或核心场景识别同一读法点。
- 不把本专题扩成试玩准备、集中修 bug、全量存档迁移或静态审计。

## 玩家操作路径

1. 玩家从晶体矿脉区带回晶体矿物，HUD 读出固体加工链，基础反应器面板说明它会转成基础零件。
2. 玩家从污染边界带回污染沉积物，HUD 读出污染处理待加工，污染过滤器面板说明药剂和污染浆液的不同去向。
3. 玩家拿到污染浆液后，HUD 说明它可保留给核心 / 遗迹组装，或回收成基础零件。
4. 玩家准备核心稳压缓冲包时，HUD 能读出修复凝胶、抗污染药剂、污染浆液和基础零件是否已经齐备。
5. 加工完成后，日志补充资源链去向，玩家能判断下一步是回设备、回出发口还是去核心稳定站。

## 运行时、存档与数据边界

- 本轮只读取 `CharacterState.inventory`、`WorldState.quest_state` 和 `WorldState.base_structures`。
- 资源链 formatter 只负责展示和判断，不消费库存、不推进任务、不新增存档字段。
- 状态验证通过既有 `to_dict` / `from_dict` round-trip 覆盖库存、设备和任务状态是否保持。
- 新检查独立为专项文件，不继续推高 `vertical_slice_flow_check.gd`。

## HUD / 设备 / 结果反馈

- HUD 基地摘要：显示资源链状态和核心资源快照。
- 设备面板：基础反应器和污染过滤器显示当前配方属于固体加工、污染处理、副产回收或核心整备链。
- 加工日志：完成后显示资源链去向，避免产物和副产只停留在库存数字。
- 检查：专项 check 覆盖 formatter、HUD、设备面板、加工完成日志和状态序列化。

## 验收条件

- 8 个核心资源 / 产物有统一资源链口径。
- HUD、设备面板和加工结果日志至少各有一处能读出资源链状态。
- 状态 round-trip 后仍能读出核心整备原料齐备或污染处理状态。
- 未新增资源、配方、设备、任务链、完整背包或自动化系统。

## 风险与后续决策

- 风险：资源链状态容易退化成又一层长文案；本轮只覆盖链路判断、设备去向和状态保存。
- 风险：HUD 基地摘要已有多个优先级；实现时只在前哨和资源相关状态下显示，避免压过任务关键提示。
- 后续若资源链仍不可读，应优先补真实操作点、设备状态或任务节奏断点，而不是继续堆说明。
