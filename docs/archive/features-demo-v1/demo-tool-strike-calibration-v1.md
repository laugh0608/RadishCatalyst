# Demo Tool Strike Calibration V1

更新时间：2026-06-15

## 用途

本专题定义首版 Demo 第三个角色套件 / 装备状态开发包：把基础多用工具、基础反应器、出发整备台和基础零件收束成一次可确认、可触发、可复测的工具打击校准状态。

它不是武器栏、技能树或长期装备系统，而是让玩家读懂“回基地加工材料后，下一趟外勤战斗输出会更稳”，并在战斗结果里看到工具校准降低本次敌方反击压力。

## 玩家价值

玩家应能理解：

- 基础多用工具不只是采集背景，而是可以由基地整备校准为下一趟战斗收益。
- 晶体矿和残骸废件经基础反应器转成基础零件后，可在出发整备台确认工具打击校准。
- 下一次外勤反击触发后，战斗日志说明本次输出压制来自工具校准，而不是防护响应挡伤。
- 触发后回基地重新加工零件、复查整备台，可以再次整理下一趟外勤收益。

## 与整体规划的关系

覆盖 [Demo Definition V1](demo-definition-v1.md) 中这些规格项：

- 角色成长：玩家获得一种可持续读出的外勤能力提升。
- 技能 / 操作：基础攻击 / 工具动作之外，补足由基地整备支撑的战斗增强。
- 装备 / 模块：工具来源服务基地制造和外勤准备。
- 战斗压力：战斗验证准备差异，而不是只做路障。
- UI / HUD、存档 / 状态和自动检查：关键状态可读、可保存、可检查。

本专题承接 `Demo Character Kit V1` 的基础工具方向，但不继续加厚战术扫描；承接 `Demo Protective Response V1` 的整备台状态形态，但不继续堆同一防护响应。

## 当前已有基础

- `equipment.basic_multitool` 已作为角色基础工具存在。
- `item.basic_parts`、`item.crystal_ore` 和 `item.salvage_scrap` 已通过基础反应器、晶体侧路和后勤补料形成既有来源。
- `building.field_outfitting_station` 已能装配模块、校准过滤模块、确认后勤维护和防护响应。
- `EnemyCounterattackRuntime` 已统一处理敌方反击，可消费一次性整备状态并输出战斗反馈。
- HUD、前哨核心、出发口和出发整备台已有出发准备摘要。

## 本轮范围

- 在出发整备台对象状态上新增一次工具打击校准状态。
- 条件只使用既有内容：基础多用工具、出发整备台和基础零件。
- 确认时消耗基础零件，不新增材料、科技或装备栏。
- 出发整备台提示显示工具校准可确认、已待命或已触发。
- HUD / 前哨核心 / 出发口读出工具校准待命或触发后的回基地价值。
- 下一次外勤反击触发工具校准，降低生命和防护承压，并写入已触发状态。
- 战斗反馈说明本次收益来自基础多用工具、基础零件和出发整备台校准。
- 新增专项检查覆盖确认条件、HUD / 对象提示、反击触发、状态字段和反馈文本。

## 当前不做

- 不新增武器栏、完整装备栏、完整 `loadout`、随机词条、职业树或等级曲线。
- 不新增资源、敌人类型、区域、任务链、科技树或新 UI 面板。
- 不继续加厚战术扫描、防护响应、工业主干、污染边界后勤维护或遗迹外圈同一压力点。
- 不把本专题扩成试玩准备、集中修 bug 或全量平衡阶段。

## 玩家操作路径

1. 玩家已有基础多用工具，并通过外勤带回晶体矿、残骸废件或已有基础零件。
2. 玩家用基础反应器加工或整理基础零件。
3. 玩家操作出发整备台，确认工具打击校准待命。
4. HUD、出发口、前哨核心和整备台提示显示下一次外勤战斗会读取工具校准。
5. 玩家进入外勤战斗，下一次反击触发工具校准，生命 / 防护承压下降。
6. 触发后反馈提示回基础反应器加工零件并复查整备台，以便重新整理下一趟外勤。

## 运行时、存档与数据边界

- 真相源放在 `map_object_instance.field_outfitting_station` 的对象状态里。
- 只新增轻量布尔字段，不扩 `CharacterState`、装备 schema 或存档格式。
- 旧存档没有该字段时默认为未确认，不影响既有模块、维护和防护响应状态。
- 反击触发后写入已触发状态；重新消耗基础零件可再次待命。

## HUD / 场景 / 对象反馈

- 基础反应器：说明基础零件可服务工具校准和下一趟战斗输出。
- 出发整备台：显示可确认、待命、已触发和缺基础零件状态。
- 前哨核心：显示出发准备中是否已有工具校准待命。
- 外勤出发口：显示下一次外勤反击是否会读取工具校准。
- HUD 基地摘要：读出工具校准待命 / 已触发。
- 战斗反馈：触发时明确说明承压下降来自工具打击校准。

## 验收条件

- 玩家通过真实整备台交互确认工具打击校准，不靠调试状态。
- 工具打击校准能在下一次反击中触发，并降低生命 / 防护承压。
- 触发后状态可持久读取，HUD 和对象提示能说明需要回基地加工基础零件并复查整备台。
- 未新增当前冻结事项。
- 默认客户端检查和 Godot 专项检查通过。

## 风险与后续决策

- 风险：整备台交互已有多种状态，工具校准必须排在模块装配、模块校准、核心归档维护、后勤维护和防护响应之后，避免抢走已有流程。
- 风险：战斗反馈过长会降低日志可读性；本轮只补一段来源说明。
- 后续若继续做角色套件，应切到新的动作或装备状态，不继续围绕同一工具校准堆倍率。
