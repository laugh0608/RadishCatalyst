# Demo Industrial Tech Spine V1

更新时间：2026-06-15

## 用途

本文是「首版 Demo 体验主干建设：角色成长与战斗第一版」下的可执行细专题，定义基础反应器、污染过滤器和出发整备台之间的工艺主干读法收束。

本专题服务 [Demo Definition V1](demo-definition-v1.md) 中「工艺 / 科技解锁」「工业基建模块」「资源 / 生产链」和「UI / HUD」规格，但只做首版 demo 可验证的一条轻量主干。

## 玩家价值

玩家回基地加工材料时，需要看懂三件事：

- 当前设备服务哪条外勤能力。
- 当前材料会转成什么整备收益。
- 污染副产、基础零件、过滤模块、药剂和整备台如何支撑下一趟外勤。

这不是完整科技树，而是把已经存在的资源和设备读成一条清晰链路：外勤带回材料，基地加工成模块 / 药剂 / 基础零件，出发整备台把收益接到下一趟污染、遗迹或核心站承压。

## 与整体规划的关系

- 服务长期核心：“基地服务冒险，冒险反哺基地”。
- 承接 [Demo Combat Progression V1](demo-combat-progression-v1.md) 已完成的模块、整备台和承压差异。
- 复用 `building.basic_reactor`、`building.pollution_filter`、`building.field_outfitting_station` 和既有材料 / 配方。
- 不改变 12 区域封顶，不新增第 13 区域或新任务链。

## 当前已有基础

- 基础反应器已处理晶体矿物、回收污染浆液、制造过滤介质、组装基础过滤模块、调制修复凝胶和整备核心稳压缓冲包。
- 污染过滤器已把污染沉积物处理成抗污染药剂，并产出污染浆液。
- 出发整备台已能装配基础过滤模块、做模块校准、接入核心归档维护和后勤维护。
- HUD、加工设备面板、对象提示和结果日志已有入口，但同一条“材料 -> 设备 -> 整备收益 -> 下一趟外勤”的读法还不够集中。

## 本轮范围

- 新增共享的工业主干读法 formatter，让 HUD、设备面板、对象提示和结果日志复用同一套链路说明。
- 让基础反应器面板明确：晶体矿物 / 污染浆液 / 基础零件会进入过滤模块、药剂补给、修复凝胶或核心稳压缓冲包。
- 让污染过滤器面板明确：污染沉积物会转成抗污染药剂，污染浆液是基础零件回收或后续组装输入，不是废料。
- 让出发整备台对象提示明确：模块、药剂、后勤维护分别服务污染采集、遗迹外圈反击或核心站复测。
- 让加工完成日志补一句当前产物对下一趟外勤的作用。
- 增加自动检查，覆盖 HUD、设备面板、对象提示和加工完成日志的关键文本。

## 当前不做

- 不做完整科技树、科技 UI、研究点或长期解锁系统。
- 不做复杂自动化、电网、管线、物流或新资源体系。
- 不新增第 13 区域、完整装备栏、完整 `loadout`、随机词条或多角色系统。
- 不继续加厚战术扫描、污染边界后勤维护口袋或遗迹外圈同一压力点。
- 不把本专题扩成所有配方的百科面板；只覆盖首版 demo 主干中最常被玩家误读的设备和产物。

## 玩家操作路径

1. 玩家从晶体、污染、遗迹或核心站路径带回材料。
2. 玩家靠近基础反应器或污染过滤器，提示和设备面板显示当前配方服务哪项整备收益。
3. 玩家启动并完成加工，结果日志说明产物和副产会进入哪条下一趟外勤准备。
4. 玩家靠近出发整备台，提示显示模块、药剂和维护状态如何接到污染 / 遗迹 / 核心站承压。
5. HUD 在基地摘要里用短句说明当前主干读法，避免玩家只看到库存数字。

## 运行时、存档与数据边界

- 本轮优先从现有 `WorldState`、`CharacterState`、库存、设备状态和配方状态推导读法，不新增存档字段。
- 工业主干 formatter 只负责文案和链路判断，不直接消费材料、不推进任务、不写状态。
- 加工完成仍由 `ProcessingSystem` 和任务运行时写入真实产物、设备状态和任务进度。
- 若后续需要新的可持续整备状态，必须另起细专题并同步存档校验。

## HUD / 场景 / 对象反馈

- HUD：在基地摘要中显示当前最关键的工艺主干，例如“沉积物 -> 药剂 + 污染浆液 -> 基础零件 / 缓冲包”。
- 设备面板：显示当前设备服务的外勤能力、当前配方的整备去向和副产用途。
- 对象提示：靠近加工设备或出发整备台时，能读到下一步应该去处理材料、补药剂还是确认维护。
- 结果日志：加工完成后短句回指下一趟污染、遗迹或核心站外勤。

## 验收条件

- 玩家能通过 HUD、设备面板、对象提示和结果日志读懂基础反应器 / 污染过滤器 / 出发整备台的主干关系。
- 基础零件、污染浆液、抗污染药剂、基础过滤模块和核心稳压缓冲包都有至少一处明确去向说明。
- 实现不新增资源体系、科技树 UI、完整装备栏或新区域。
- 自动检查覆盖工业主干 formatter 的关键输出，并能随 `check-client` 执行。

## 验证计划

- 客户端默认检查：`sh ./scripts/check-client.sh`。
- 文档检查：`./scripts/check-docs.sh`、`./scripts/check-text-files.sh`、`git diff --check`。
- 本轮不要求启动 Godot；若后续触及运行时场景复测，再按需执行 `sh ./scripts/check-client.sh --with-godot`。

## 风险与后续决策

- 本专题第一包只收束现有主干读法；如果玩家仍读不懂工艺价值，下一包应补真实设备流程或任务节奏断点，而不是继续堆提示密度。
- 若后续要做完整工业解锁，应另建专题，先定义阶段、资源数量、UI 范围和存档边界。
