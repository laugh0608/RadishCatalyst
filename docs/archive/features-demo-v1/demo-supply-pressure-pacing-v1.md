# Demo Supply Pressure Pacing V1

更新时间：2026-06-18

## 用途

本文定义首版 Demo 补给节奏与承压价值第一版。它不新增资源、配方、区域、任务链、UI 面板、目标箭头或同类 HUD 提示，只验证现有修复凝胶和抗污染药剂是否在玩家遇到关键压力前后真实可获得、可消耗，并能改变生命 / 防护承压结果。

## 玩家价值

玩家不应只知道快捷栏里有补给，还应能在真实路线中确认：

1. 修复凝胶能在治疗点战斗压力后恢复生命，让玩家继续推进。
2. 抗污染药剂能从污染过滤器产出，并在门前污染压力和终点写入压力中降低损耗。
3. 消耗后的抗污染药剂能通过前哨核心 / 基础储存箱补回，不让主线因为关键补给断档。

## 与整体规划的关系

本专题覆盖 [Demo Definition V1](demo-definition-v1.md) 的「装备 / 模块」「战斗压力」「污染与防护」「UI / HUD」和「自动检查」规格。

它承接已收束的 [Demo Quick Slot Supply Readability V1](demo-quick-slot-supply-readability-v1.md)。快捷栏短状态已经能读出补给数量、可用和回补设备；本轮不继续加 HUD 文本，而是检查补给获得节奏和压力价值是否支撑主线理解。

## 阶段入口判断

`Demo Quick Slot Supply Readability V1` 已通过退出判断：HUD 快捷栏、补给成功 / 失败反馈、缺口恢复路线和专项检查均满足当前阶段要求。下一步选择补给节奏与承压价值，避免继续围绕同类短状态加厚。

## 当前已有基础

- `recipe.repair_gel` 已通过基础反应器产出修复凝胶，快捷栏 `1` 可恢复生命。
- `recipe.cleanse_residue` 已通过污染过滤器把污染沉积物处理为抗污染药剂，并产生污染浆液副产。
- `EnemyCounterattackRuntime` 已让门前污染压力敌人自动消耗抗污染药剂并降低反击损耗。
- `GatherSystem` 已让核心稳定设备写入时读取抗污染药剂，降低生命 / 防护承压。
- 前哨核心已能在基础储存箱与污染过滤器条件满足后补回抗污染药剂。

## 本轮范围

## 玩家操作路径

1. 晶体矿脉推进后，玩家能回基础反应器调制修复凝胶。
2. 治疗点扰动体造成生命压力后，玩家按 `1` 使用修复凝胶，生命回到可继续承受压力的状态。
3. 污染处理点开放后，玩家把污染沉积物放入污染过滤器，得到抗污染药剂和污染浆液。
4. 门前污染压力战斗会自动消耗抗污染药剂，并显著降低生命 / 防护损耗。
5. 药剂消耗后，回前哨核心整备可经基础储存箱补回抗污染药剂。
6. 核心稳定设备写入时，抗污染药剂继续参与排压，降低终点写入损耗。

## 运行时、存档与数据边界

- 不新增存档 schema；继续读取库存、建筑、任务进度、敌人状态和关键地图对象状态。
- 不新增数据 ID；只验证现有 `item.repair_gel`、`item.resistance_vial_t1`、`recipe.repair_gel` 和 `recipe.cleanse_residue`。
- 压力消耗继续记录在敌人或交互状态中，避免同一压力点重复消耗。

## HUD / 场景 / 对象反馈

- HUD：复用已完成的快捷栏补给短状态，不新增提示行。
- 战斗反馈：门前污染压力必须读出抗污染药剂自动接入排压。
- 前哨核心：补给整备必须读出抗污染药剂补回。
- 核心设备：写入结果必须读出药剂参与排压并降低承压。
