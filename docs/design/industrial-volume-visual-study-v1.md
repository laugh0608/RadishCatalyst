## 开工五问

1. **玩家结果**：不用箭头、标签或解释，就能看出机器有厚度、管道架离地面，管体与支撑具有明确前后关系。
2. **实现介质**：内置图像工具生成一张局部像素体积候选；这一阶段只判断空间关系，不把整张候选裁成精灵或当作游戏截图。
3. **成功证据**：同一画面中设备顶面最大、侧壁可读；圆管有顶部亮面、侧向中间调与暗部；支脚接地，管下露出地面并有与高度一致的投影；前景部件遮挡后方结构，所有物体采用同一投影。最后仍须用户确认。
4. **失败判据**：管体仍像平面色条、靠加粗边框假装厚度、机器与管道视角不一致、支架悬浮，或只能靠写实连续光照 / HD 细节建立体积。若失败，先记录具体结构原因，不用装饰或提高生成分辨率掩盖。
5. **文档落点**：本文件记录局部合同与判断；来源、提示词、调用计数和候选哈希进入 art-intake manifest，周志记录反馈与过程，Current / Daily 只指向当前动作。

## 局部构图合同

- 一台匿名低矮加工设备与一条接入侧面接口的透明管道，连接关系只作视觉研究，不对应已有固体端口或新设备能力。
- 管道从设备侧面伸出，在两个可见支撑上方转弯；支撑、管底和地面之间保留清楚的负空间，前端管段遮挡后方支撑的一部分。
- 设备采用明亮漆面顶壳、中间调侧壁、暗色下部承重结构和独立接地基座；不能仅把底板加厚当作机身高度。
- 透明圆管保留弧面亮带、侧向厚度、内壁与少量内容色，金属环须有前后表面；内部颜色不能填满成等亮平面色块。
- 平台是铺在地上的连续低纹理平面，外围少量砂岩；不做悬空展示底座，不用密集地砖缝与裂纹抢占体积读法。
- 左上单一光源；接触阴影紧贴承重点，架空管段投影与管体分离。光影用克制、可数的像素色阶表达。
- 设备和管路轴线服从同一个矩形地面坐标，不改成钻石等距构图；保留顶面主导与清楚侧壁高度带。
- 可加入一名工程师作比例参照；没有 HUD、解释标签、标题、大型外部箭头或额外设备阵列。

## 独立素材与原生比例实施合同

1. **玩家结果**：在既有角色、常态相机 `2.0` 和建造相机 `1.5` 下，看到一台有顶侧面层次的设备，与一条有支撑、管下空隙和分离投影的管道；体积不依赖概念图放大。
2. **实现介质**：以 v2 为体积参考，用内置图像工具重出独立设备、水平玻璃管、支撑和对应地面阴影。各图经确定性像素块采样与色板归一后独立装配为 `Sprite2D`；不裁取概念整景中的地面去假装运行时场景。
3. **成功证据**：查看归一原图；正式 `Boot` 创建独立存档，取得正常 / 建造倍率、实际角色前后遮挡、分层开关对照及保存 / 重载证据。自动检查只保证引用、尺寸、锚点、隔离和操作状态，用户评价仍决定体积是否保住。
4. **失败判据**：归一后顶侧面合并成色块、管道重新变成平条、支脚 / 阴影脱离，或必须放大设备与改变相机才能接近候选，则记录原生尺度复现失败，不继续扩成完整模块族或产线。
5. **落点**：素材与场景位于既有 `visual_studies/` 下的独立体积目录；稳定复核入口在 `tools/`，一次性诊断在忽略目录。结果进入本合同与本周周志。

| 元素 | 初始目标 | 边界 |
| --- | --- | --- |
| 设备 | 管体约 `96px`，画布允许 `128×128` 容纳端口与脚部，视觉足印参考 `3×3` | 匿名样板，不替换反应器，不新增正式建造 / 碰撞规则 |
| 水平管 | `96px` 长，约 `16px` 外径，内部保留顶部清玻璃与下部内容色 | 本轮只做一段水平样板，不扩成四向网络 |
| 支撑 | `32×32` 以内，同一支撑重复两次 | 独立于管体，保留承重与前后遮挡 |
| 地面投影 | 设备 / 管体 / 支撑各自的像素轮廓，置于地面层 | 源图生成后归一；不靠程序几何代替主体美术 |
