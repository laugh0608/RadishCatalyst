# Resources And Process Chain - 当前原型链路

返回：[Resources And Process Chain](resources-and-process-chain.md)

更新时间：2026-06-19

## 当前阶段结论

资源链的重点不是数量，而是关系。

首版之前应先确定一条能闭合的链路：

**外出采集或战斗获得资源 -> 基地加工和治理污染 -> 产出探索/战斗能力 -> 解锁更危险区域 -> 获得更高价值资源。**

这条链路稳定后，再进入具体 MVP 配方和数值拆分。

当前加工已经从即时命令推进到最小 `in_progress` 运行状态：启动时消耗输入，设备记录当前配方和加工进度，完成后才发放产物 / 副产并记录最近完成结果。基础反应器和污染过滤器已有设备面板雏形，能显示当前配方、输入、产出、副产、耗时、进度、缺料、最近完成和下一步建议；基础反应器会按当前任务自动优先选择目标配方，并在核心稳压缓冲包需要最后一份污染浆液时避免误把它推荐去回收基础零件，降低后期配方变多后的摩擦。

设备加工按“同一设备同一时间只运行一条配方”解释。加工中时，HUD 交互提示和基地摘要显示同一条进度条并提示 `Q` 打开设备面板；设备面板列表只有实际运行配方显示进度，其他配方显示设备忙碌，避免玩家误以为所有配方都在同步制造。左下短条只承担短反馈，优先显示“下一步”和关键按键，完整输入 / 产出 / 完成去向继续交给设备面板。当前 8 个核心资源 / 产物已经要求在基地摘要、设备面板、加工结果和保存读取校验中读出链路位置，避免资源只表现为库存数字。

资源链读法不只看库存数字。晶体采集应指回基础反应器和基础零件分流，污染沉积应指回污染过滤器和药剂 / 浆液双收益，核心准备对象应指回核心稳压缓冲包、守卫缓存和写入承压；当至少两类外勤处理结果可读时，出发整备台可以登记任务差异，让下一趟出发从 HUD、对象提示和设备面板里读出该回哪个设备处理。

2026-05-28 首小时制造读法已补当前 / 推荐配方用途说明和目标里程碑提示：拿到导电废件、异常残留物、修复凝胶、污染沉积物或抗污染药剂等关键节点时，日志会说明为什么回基地加工或再次外出；制造目标已完成后，基地摘要会把玩家重新指回外出推进，而不是继续要求留在基地。2026-05-31 已进一步把处理点清障、地基施工、污染过滤器上线、首趟抗污染药剂和遗迹门前压力串成一段：修复凝胶先服务清障，地基材料服务过滤器落地，污染沉积物处理出药剂后先指向补第二批沉积物和清敌，再指向门前压力。

当前这些链路的价值已经不只是“做出一个新物品”，而是会继续落到：

- 更东侧区域解锁。
- 新敌人和新采集点的进入许可。
- 回基地再出发的补给和过滤准备。
- 更晚期的前线回投落点前移与裂相脊后半生存曲线承接。
- 副产物转主输入，以及“把基地产物带回前线部署”这种新的任务结构。
- 基地平台基建收益不只增加储存名目；基础储存箱建成后会进入前哨核心整备，玩家外出耗尽修复凝胶后回基地可补到 1 份。
- 出发整备台把基础过滤模块装配、战术扫描、防护响应和工具打击校准都变成基地操作；过滤模块、抗污染药剂、核心稳压缓冲包、终点前补给和一次性整备状态会直接降低污染战斗、遗迹外圈守卫、核心阶段守卫或最终设备写入造成的承压。
- 污染边界侧翼、浆液副产回收口袋和封锁入口准备反馈已经把沉积物补给、药剂排压、浆液回收和进门判断接成同一条可操作路径。
- 功能 / 过渡区的现场对象处理不再停在“看见区域职责”：继电残片、回波匣、裂相读数、泄压阀、盐壳硬壳、碎晶 / 风蚀 / 锁相 / 锚定桥断面等代表性对象会把现场结果指回基地解析、稳定、组装或整备。
- 完成态读数和稳窗相位序校准把前线稳定窗口变成可回访回充点，并进一步承接三轮轻量前线行动、第一轮基地行动选择、出发整备确认、风险收益快照和同一前线窗口反馈；补给反馈会变成带稳相垫片的下一次出发补给包，测绘反馈会变成带回波透镜的路线提示、目标显形和风险预告，清障反馈会变成带防护涂层的防护补给。相位回投只消耗行动台确认过的完整快照，随后稳相缓存样本、透镜校准读数或涂层样本会回到行动台影响下一轮计划预告和候选保留 / 替换判断；压力清障窗口还会被清障扰动守卫压制，未击退时不能直接结算。两轮窗口复盘后，三类模块收益会合并为高压窗口三模块联锁，带回高压窗口稳定数据，并进一步开放核心稳定站写入链路，而不是只增加库存纪念物。
- 核心写入后的复测链不新增资源类别：核心复测读数缓存只回收基础零件和修复凝胶，后勤维护复测沉积仍回到污染过滤器，后勤维护状态继续绑定出发整备台和基础过滤模块。

`S0` 新档冷启动已于 2026-05-28 验证可从 0 玩到当前主线终点。基础零件后段供给不再依赖有限晶体簇，短期由关键前线阶段的前哨核心回收 / 阶段补给批次承接；`晶体矿物 -> 基础零件` 保留为早期教学和应急加工，不作为后段主线预算的唯一来源。晶体矿脉区北侧 `富晶残脉` 和新增残骸缓存作为可选兜底，相位中继锚点后的 `回收基础零件` 可把污染浆液低效率转回基础零件。后段解析类配方已移除固定基础零件税，装配类配方继续消耗基础零件，但主线会把装配件并入整备包，避免回基地只做一个零件。`scripts/check-client-data.ps1` 已新增主线资源预算检查，并随默认 `check-client.ps1` 执行，覆盖新档初始库存、主线采集、采样、中间加工、建筑消耗、任务件部署和 3 个基础零件误用缓冲。

当前原型也验证了一条重要约束：即使内容一路扩到锚场回稳窗口、三轮轻量前线行动、第一轮基地行动选择、出发整备确认、行动候选轮转、风险收益确认、轻量整备模块、同一窗口反馈、高压窗口、核心稳定站终点、基地后勤设施、污染边界回访口袋和核心站复测，短期仍可以继续复用污染过滤器、基础反应器、基础储存箱、出发整备台、前线行动台和相位回投台，而不急着为了“像工厂游戏”临时引入复杂设备群。当前仍不包含管线、电网、储罐、自动物流、完整背包转移、多设备管理或复杂设备调度；后续新增基地设施应像基础储存箱和出发整备台一样先提供清楚的外勤收益，再考虑更重的工艺链。
