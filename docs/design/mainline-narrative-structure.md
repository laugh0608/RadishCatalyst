# Narrative And Quest Framework - 主线叙事结构

更新时间：2026-05-26

返回：[Narrative And Quest Framework](narrative-and-quest-framework.md)

## 文档目的

这份文档用于定义 RadishCatalyst 首版叙事、主线任务、支线任务和教程任务的组织方式。

它不是完整剧本，也不是任务表。它只回答：

- 首版故事为什么开始。
- 主线如何服务核心循环。
- 支线任务承担什么功能。
- 教程任务如何自然融入世界。
- 叙事如何避免拖累原型开发。

## 叙事定位

首版叙事应是“工业现场任务记录 + 异星异常调查”，而不是长篇剧情演出。

玩家应通过行动理解世界：

- 修复前哨。
- 采集资源。
- 分析样本。
- 处理污染。
- 遭遇受扰生态。
- 解锁更危险区域。

文本应短、明确、带工程语气。首版不需要大量角色对白、复杂阵营或多分支剧情。

## 首版主线一句话

玩家抵达或苏醒在一座受损的异星化工前哨中；为了恢复生存能力并调查周边异常污染，玩家必须外出采集晶体资源和异常样本，重启基础加工链，制造防护与过滤产物，最终进入污染边界并发现遗迹或深层异常入口。

## 首版 Demo 主线问题

首版 demo 收束时，主线不需要解释完整星球真相，但必须让玩家开始追问三件事：

1. 这个星球为什么不稳定：晶体、污染、裂相地貌和异常能量不是孤立资源点，而是同一套失衡机制的外显。
2. 人类前哨为什么失败：前哨不是单纯缺料停机，而是被污染、旧设施残留、生态扰动和稳定工程失效共同拖垮。
3. 遗迹或旧设施到底在稳定什么：封锁遗迹、锁相框架、锚定桥和核心稳定站应暗示这里曾经有系统试图压住星球异常，但现在需要玩家用基地工艺重新接管。

这三个问题是地区命名、任务目标、地图标记和结尾钩子的共同依据。首版不靠长对白回答它们，而是通过“外出发现异常 -> 回基地解析 / 制造 -> 再进入对应地区验证”的闭环让玩家逐步看见。

## 主线阶段

### 阶段一：恢复前哨

目的：

- 让玩家认识基地是安全区和后勤核心。
- 交代前哨受损、能源不足、加工链中断。
- 引导玩家恢复基础库存和设备。

任务目标示例：

- 检查前哨核心。
- 打开基础库存。
- 重启基础加工设备。
- 查看当前缺失资源。

系统教学：

- 基地 UI。
- 库存。
- 设备状态。
- 当前目标。

### 阶段二：勘探晶体矿脉

目的：

- 让玩家第一次离开基地。
- 让资源采集、战斗和撤离成为一组动作。
- 说明晶体矿物是基础工艺链的关键。

任务目标示例：

- 前往晶体矿脉区。
- 扫描晶体节点。
- 采集晶体矿物。
- 击退原生小型生物。
- 带回资源。

系统教学：

- 移动。
- 采集。
- 基础战斗。
- 背包和撤离。

### 阶段三：分析异常样本

目的：

- 把采样与主线调查关联起来。
- 让玩家知道样本不是普通材料。
- 打开污染边界和受扰生态线索。

任务目标示例：

- 采集异常晶体碎片。
- 回基地分析样本。
- 解锁污染残留处理配方。
- 标记污染边界区。

系统教学：

- 采样。
- 样本分析。
- 配方解锁。
- 地图标记。

### 阶段四：建立污染处理能力

目的：

- 让污染从背景变成系统。
- 让基地生产直接反哺外勤。
- 引入地基、平整和建造前置。

任务目标示例：

- 清理一处可建造地块。
- 平整地面或铺设基础地基。
- 建造或启用过滤 / 处理设备。
- 制造过滤模块、净化剂或抗性药剂。

系统教学：

- 可建造 / 不可建造。
- 清理和平整。
- 地基。
- 制造远征产物。

### 阶段五：进入污染边界

目的：

- 验证玩家是否理解装备、药剂和模块准备。
- 让污染区成为第一个危险层级提升。
- 通过受扰生态和污染源点承接战斗压力。

任务目标示例：

- 装备过滤模块。
- 携带抗性药剂或净化剂。
- 进入污染边界。
- 采集污染沉积物。
- 击败受扰污染体。

系统教学：

- 环境危险。
- 防护消耗。
- 快捷物品。
- 敌人掉落样本。

### 阶段六：治理污染源点

目的：

- 给切片一个小型高潮。
- 让战斗、补给、污染治理和样本分析合并。
- 打开后续区域悬念。

任务目标示例：

- 定位污染源点。
- 清理周边敌人。
- 使用净化剂或稳定剂。
- 击败精英节点。
- 回收关键样本。
- 解锁遗迹入口或深层污染读数。

系统教学：

- 精英挑战。
- 区域目标。
- 解锁新入口。
- 切片结束反馈。

## 当前原型主线延伸结构

截至 2026-05-24，当前 Godot 原型的主线已经不再停在“进入污染边界并发现遗迹入口”，而是沿着单张向东切片继续验证了多轮“基地整备 -> 更深外勤 -> 新区域解锁”的结构。前线回传锚点之后，主线开始刻意打破同构模板；稳窗相位序校准后，轻量前线行动已经验证三轮短回访，并在基地行动选择、行动候选、轻量整备模块、风险收益确认、出发整备槽和同一前线窗口反馈里体现行动前取舍与下一趟出发准备。

当前已验证的主线收益锚点依次是：

```text
封锁回波匣 -> 裂相样块 -> 裂相读数矩阵 -> 内层故障轨迹
-> 相位井定位器 -> 相位井芯样本 -> 相位井心核
-> 相位井纺核 -> 相位井织核 -> 相位井结核
-> 相位井锚核 -> 相位井余响片 -> 相位井稳窗读数
-> 稳窗相位序校准 -> 三轮轻量前线行动
-> 基地行动选择 -> 补给 / 测绘 / 清障反馈
-> 风险收益确认出发 -> 低风险补给 / 信息侦测 / 压力清障计划
-> 稳相垫片 / 回波透镜 / 防护涂层改变同一窗口结果
-> 稳相缓存样本 / 透镜校准读数 / 涂层样本反馈基地
-> 完成态收益影响下一轮预告和候选判断
-> 高压窗口三模块联锁 -> 高压窗口稳定数据
```

前线回传锚点之前，这些后续任务包大多保持统一：

1. 先把上一跳带回的关键样本或遗迹件带回基地解析。
2. 再沿更东侧推进，击败一个新敌人并回收两处关键资源。
3. 回基地或处理点完成必要加工。
4. 带着新产物返回更东侧终点，勘验后拿到下一跳推进锚点。

前线回传锚点之后，当前主线已经开始把“单件门禁制造”改成整备包任务形态：

1. 带回一组现场材料或样本。
2. 回基地解析上一跳成果，回处理点稳定现场材料。
3. 在同一个整备任务内完成过滤中间件和装配件。
4. 下一趟外勤直接进入现场校准、开锁、勘验或短守场，不再插入一个独立组装任务。

相位井锚核之后，锚场回稳、稳窗校准、轻量前线行动、基地行动选择和高压窗口进一步验证了另一种后段任务形态：

1. 回基地把锚核解析成归谱片和锚核落尘。
2. 完成锚场整备，把锚核落尘稳定成稳场滤囊，并组装井系校锚桩。
3. 带着基地产物返回锚定桥东侧，先部署，再清理压力钉、压住井系守脉体，最后完成回稳交互。
4. 把局部稳定窗口和相位井余响片作为现场收益，再回基地解析成相位井稳窗读数，把叙事收益落成可回访的前线回充点。
5. 返回现场按西侧、中央、东侧顺序校准稳窗相位序，说明基地解析结果正在反向整理前线异常。
6. 回基地确认前线行动，再去稳窗回波探点读数并带回前线行动回报，形成第一条“基地确认 -> 前线短目标 -> 回基地反馈”的轻量行动。
7. 后续补给回执和巡线信标继续复用这个短循环，证明模板可重复但不应继续横向堆同构行动。
8. 巡线反馈归档后，基地行动选择把“确认下一趟行动”推进为稳场补给 / 相位测绘 / 压力清障三选一；补给叙事偏低风险物资回收，测绘叙事偏侦测路线和下一趟提示，清障叙事偏高风险压力处理和防护收益。
9. 补给、测绘或清障反馈归档后不会只停在文本奖励：反馈进入统一前线行动台的当前计划槽，玩家按目标、收益、风险和代价确认后才随下一次相位回投执行。确认时会锁定风险收益快照；补给会带 `稳相垫片` 并装入基础零件和修复凝胶缓冲，测绘会带 `回波透镜` 并载入锚定桥前线目标显形和风险预告，清障会带 `防护涂层` 并装入修复凝胶和抗污染药剂；本次执行后下一计划候选晋升为新的当前计划。
10. 已确认计划执行后继续落到同一个前线异常窗口：稳相垫片、回波透镜和防护涂层分别改变窗口目标、处理结果和完成态收益；补给带回稳相缓存样本，测绘带回透镜校准读数，清障带回涂层样本。压力清障窗口会先被清障扰动守卫压制，未击退时不能直接结算，确保高风险分支至少包含一次短战斗。行动台会把这些完成态收益写成当前计划预告和下一候选说明，方案终端可保留或替换下一计划候选，但只影响下一轮，不改动当前已经确认的出发整备槽。相位回投只执行带完整目标、收益、风险、代价和模块快照的确认计划。
11. 连续两轮窗口复盘后，行动台会把三类模块归档收益合并成一次 `高压窗口` 目标。玩家仍需确认 `三模块联锁` 整备槽，再通过相位回投处理更危险窗口并带回 `高压窗口稳定数据`；它用于验证三类模块收益能否支撑更高压目标，不扩成第四个常规行动分支。

这种结构让当前原型的叙事仍保持“工业现场任务记录 + 异星异常调查”口径，而不是突然切成大段剧情演出：

- 基地解析负责解释当前异常物为什么值得继续向东推进。
- 新敌人和新区域负责给风险升级一个可玩的现场原因。
- 整备包负责把“为什么回基地”解释成一次可执行准备，而不是只回去做一个门禁件。
- 行动选择负责让“下一趟为什么这样出发”变成玩家可见取舍，而不是只由任务链自动指定。
- 出发整备槽、风险收益快照、轻量整备模块、方案终端和同一前线窗口负责把上一趟反馈落成下一趟计划，而不是让补给、测绘或清障收益停在日志说明里。
- 高压窗口负责把三类模块收益收束成一次更危险目标，证明闭环可以从单变量反馈推进到组合压力，而不是继续横向堆行动候选。
- 新产物负责把收益落成下一次外勤许可或现场收益，而不是只落成一条文本说明。
- 前线回传锚点和基地相位回投台负责在晚段维持节奏，不让主线退回长距离空跑。
- 稳窗读数和相位序校准负责说明“这段前线已经被基地校准过”；它们不是继续向东扩一段新门禁，而是把完成态前线变成可短回访、可产出行动回报的基地-前线循环入口。

短期叙事约束保持不变：文本仍应短、明确、带工程语气；当前不需要长对白树、阵营分支或复杂角色演出，优先把“为什么回基地、为什么还能继续向东”解释清楚。
