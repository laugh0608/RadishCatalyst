# Onboarding And First Hour - 基线、UI 与验收

返回：[Onboarding And First Hour](onboarding-and-first-hour.md)

## 首小时之后的延伸约束

- 后段主线仍应服务“外出获得资源 -> 回基地加工 -> 下一次外勤被改变”，但不应继续用完全同构的门禁、战斗和收集模板机械拉长。
- 若继续扩新的后段功能区，至少要改变 1 个维度：外勤目标结构、风险与战斗关系、资源获取模式、基地加工决策，或前线锚点 / 回投节奏。
- 当往返开始重复时，优先压缩无决策空跑，不把“基地有价值”建立在纯移动时间上。

不应在首小时同时解锁：

- 完整管线。
- 多设备自动化。
- 多天气。
- 多角色 Build。
- 大型任务日志。
- 复杂技能树。
- 联机入口。

## 开发复测基线

为了避免首小时和后续第二闭环内容扩展后每次人工复测都从空档重打，当前原型已把这条链拆成 `S0` 到 `S21` 二十二个开发基线。

- `S0`：新档起点，保留完整冷启动链。
- `S1`：处理点已就绪，直接进入污染边界段。
- `S2`：封锁遗迹中继已确认，直接进入封锁回波与裂相坐标链。
- `S3`：裂相脊入口门禁已开，直接进入相位纤丝与覆写栓链。
- `S4`：裂相样块已回收，直接进入第二轮阵列解析链。
- `S5`：前线回传已上线，直接观察回投后的裂相尖塔链与裂相脊往返节奏。
- `S6`：内层故障轨迹已回收，直接观察故障轨迹解析到裂相锁位的后续链路。
- `S7`：回声定位器已带回，直接观察定位器解析到回声台地的更东侧新链路。
- `S8`：回声芯样本已带回，直接观察回声芯样本解析到盐壳浅滩的更新后链路。
- `S9`：碎晶心核已带回，直接观察碎晶心核解析到碎晶沟谷的更新后链路。
- `S10`：风蚀张力核已带回，直接观察风蚀张力核解析到风蚀管廊的更新后闭环。
- `S11`：锁相织构核已带回，直接观察锁相织构核解析到锁相框架的更新后闭环。
- `S12`：锚定结核已带回，直接观察锚定结核解析到锚定桥的更新后闭环。
- `S13`：稳场锚核已带回，直接观察稳场锚核解析到锚场回稳和稳窗余响片的非同构后续闭环。
- `S14`：锚场回稳已完成，直接回归完成态收益和余响片解析入口。
- `S15`：稳窗读数已解析，直接验证锚场回访回充和三处稳窗节点现场校准入口。
- `S16`：稳窗相位序已校准，直接验证前线行动台入口和第一条轻量前线行动。
- `S17`：前线行动回报已归档，直接验证第一条基地-前线-基地短闭环和补给短行动入口。
- `S18`：短行动反馈已归档，直接验证第二条轻量前线行动完成态和巡线短行动入口。
- `S19`：巡线反馈已归档，直接验证基地行动三选一入口。
- `S20`：相位测绘反馈已归档，直接验证第一轮基地行动选择完成态、出发整备确认、信息侦测计划、风险收益快照、同一前线窗口反馈和完成态收益预告。
- `S21`：高压窗口已归档，核心稳定站已开放，直接验证核心稳定站入口、阶段守卫、核心设备写入和 demo 完成反馈。

这套基线是开发内部工具，不是正式玩家存档流程。详细设计与使用方式见 `docs/design/development-retest-baselines.md`。

## UI 引导

首小时 UI 应优先包含：

- 当前目标。
- 生命、防护和快捷栏。
- 小地图或方向标记。
- 设备缺料提示。
- 配方输入输出。
- 建造失败原因。
- 污染危险提示。
- 返回基地提示。
- 常驻 HUD 不遮挡关键推进区域。

当前阶段的 UI 推进判断：

- 当前阶段是“首版 Demo 场景、UI 与交互成型”，先把原型草稿整理到可读、可操作、交互边界清楚，再继续堆首小时内容。
- 这不是正式美术包；不引入外部素材、不重做完整菜单、不追求最终视觉风格。
- 开局场景对象层、通用交互、设备面板、HUD 重排和对象反馈第一包已落地；后续只按实机读法回补 HUD 裁切、短条、加工进度、建造阻塞和设备面板断点。
- HUD 应从横向格子堆叠改为稳定分区，目标、资源、基地摘要、角色状态各自承担职责。
- 地图资源、敌人、设备和区域标签不能全部常驻挤在一起；优先显示当前目标、附近对象和当前危险。
- 当前可交互对象必须比其他对象更明确，玩家能判断按 `E` 会操作谁。
- 资源、敌人、设备、建造点的摆位应支撑首小时路线判断，避免标签、碰撞和交互范围互相遮挡。
- HUD / 交互 / 核心区摆位两轮收束后，后续只按短跑取样结果补关键断档，不继续以 UI 或摆位 polish 阻塞内容推进。

可延后：

- 完整生产统计。
- 复杂地图图层。
- 全资源图鉴。
- Wiki 入口。
- 官方工具入口。

## 原型落地顺序

首个 Godot 原型的引导实现应先做“能完成目标”的最小链路，不先做完整教程系统。

优先实现：

1. 当前目标文本。已在原型 HUD 中显示目标、进度和阶段短提示。
2. 地图或方向标记。已用临时地图色块、区域文字、正式小地图 / 地图标记雏形表达当前目标方向与关键区域状态。
3. 交互提示。已在靠近交互对象时显示提示。
4. 设备缺料提示。已在靠近加工设备时显示当前配方输入、产出、加工进度和缺料状态，并可用 `Q` 打开设备面板；加工中只让真实运行配方显示进度，其他配方显示设备忙碌。
5. 建造失败原因。已接入最小清理、地基和污染过滤器建造失败提示。
6. 污染危险提示。已在污染采集、当前区域污染状态、低防护进入污染边界和撤离补救中起步。
7. 回基地提示。已在样本返回、撤离补救和方向提示中起步。

暂缓实现：

- 完整教程弹窗框架。
- 大量语音或剧情演出。
- 可回看的教学百科。
- 完整键位自定义引导。

只有当玩家能不依赖开发者说明完成第一条闭环后，再扩展教程表现。

当前原型中，玩家已经能看到目标、目标进度、小地图 / 区域标记、任务驱动短提示、生命、防护、当前区域污染状态、当前模块、快捷栏、关键资源摘要、基地摘要、交互提示、交互日志、补给使用短反馈、任务完成反馈和撤离结果反馈。常驻 HUD 已改成分散式结构：左上区域地图、左侧目标 / 关键资源卡、右上基地 / 角色状态卡和左下提示 / 日志分离显示，不再把主线信息强塞进单列；区域方向、设备详情、长提示和运行反馈分别交给小地图、设备面板、交互提示、任务完成面板、撤离面板和日志承担。2026-05-26 UI baseline 第一包已把主 HUD 标题、目标追踪、运行时提示和任务完成反馈切到新区域口径；2026-05-27 第二包已把关键资源、基地摘要和角色状态拆成更清楚的分组，并通过核心稳定站人工读法复核。世界相机也已锁定玩家跟随，封锁遗迹和裂相脊推进不会再因为静态舞台摆位而丢出视野。

2026-05-28 首小时引导可玩第一轮已补里程碑提示和基地制造读法；交互标签只显示当前交互 / 攻击目标，核心区摆位第二轮已把基地、晶体、污染三段拆成更清晰的外出采集、回基地制造和更高风险污染推进。2026-05-31 已把处理点清障、施工、过滤器上线、沉积物处理、抗污染药剂和遗迹门前压力接成更明确的二次外出节奏；2026-06-03 已启动首版 demo 场景层、通用交互提示和缺料 / 阻塞下一步提示。2026-06-04 已完成设备面板、HUD 重排、首小时对象表现、开局场景对象层、对象反馈和交互一致性第一包，并补 HUD 裁切、加工进度和设备面板配方列表串读断点。后续验证应看设备面板、HUD 和对象表现是否能支撑实际操作，而不是只看主线任务是否能跑通。

后段前线行动不把同一套长说明复制到所有面板：前线行动台负责完整显示当前计划、模块、收益、代价和风险拆解；方案终端只显示下一候选的紧凑预告、窗口反馈承接和保留 / 替换判断；相位回投台只显示已确认计划的执行摘要，并且只执行已锁定的风险收益快照；小地图只在测绘计划生效时追加目标显形和“测绘预告”。这条分层用于避免补给 / 测绘 / 清障三类方案在 HUD、候选槽、回投台和同一前线窗口里重复堆字，同时避免未确认或缺快照的整备状态被误当成已出发计划。

实现边界上，上述 HUD 信息已经拆到独立 presenter：状态摘要由 `HudStatusPresenter` 生成，小地图 / 区域标记由 `HudMapPresenter` 生成，任务短提示由 `HudHintPresenter` 生成，设备面板由 `HudDevicePanelPresenter` 生成，任务完成 / 撤离 / 补给反馈由 `HudFeedbackPresenter` 生成，日志格式化由 `HudLogPresenter` 生成。后续若继续调整首小时提示，应优先改对应 presenter 和流程检查，不把文案重新堆回 `PrototypeHud` 或 `GameRoot`。

区域标记会显示基地、晶体、污染、封锁遗迹、裂相脊、锚定桥、核心稳定站和后段关键地区的相对方向、解锁状态与当前目标。污染状态会显示当前区域是否稳定、污染强度、过滤模块是否生效、防护消耗倍率和低防护建议。靠近基础反应器或污染过滤器时，HUD 交互提示和设备面板会显示设备名、当前配方输入、产出、副产、耗时、加工进度、当前目标推荐配方、最近完成配方、产物 / 副产入库去向、下一步建议和可加工 / 缺料 / 未解锁状态；加工完成日志也会说明产物进入背包以及后续行动。

靠近粗糙地块、基础地基建造点或污染过滤器建造点时，HUD 会显示地块是否阻挡建造、清理后续、建造材料、基础地基数量、缺料或前置原因，以及可建造时的 `E` 键提示。交互、攻击、配方切换、加工、建造和区域门槛失败时，日志会按失败类型、原因和下一步建议提示补救方向。

当前目标、任务完成反馈和场景完成态已经覆盖恢复前哨、晶体采集、异常样本、处理点扩建、污染边界推进、封锁遗迹入口、封锁遗迹和中继台这条首小时到第二闭环的关键链。裂相脊、回声台地、盐壳浅滩、碎晶沟谷、风蚀管廊、锁相框架和锚定桥等后段进度不再在本文逐段展开；具体后段进度与验证范围统一转到 `docs/planning/current.md`、`docs/planning/vertical-slice.md`、`docs/design/development-retest-baselines.md` 和最新周志维护。

晶体矿脉区会要求先恢复前哨核心，污染边界深处会要求先扩建处理点并启用基础过滤模块，封锁遗迹深处会要求先回基地组装稳相信标并稳定抖动雾幕，中继台之后则继续把裂相收益指回基地分析。被挡回时，日志会补充处理点扩建、启用过滤模块、补给防护或回基地加工等具体原因；生命或防护耗尽会自动撤回前哨，并通过 HUD 撤离反馈面板提示撤离原因、恢复结果和再尝试建议。完成污染边界目标后会激活污染残核压制，压制后地图东侧封锁遗迹入口会转为封锁遗迹入口；确认中继台后 `slice_01_complete` 会先解锁以保留第一切片终点。

玩家可用 `1` 使用修复凝胶、用 `2` 使用抗污染药剂，主动补充生命或防护；处理点补给准备段会先要求调制修复凝胶，再进入两处清障战斗，让玩家看到“回基地加工补给”对下一次外勤的价值。恢复前哨后，前哨核心本身也会提供基地整备：回基地可直接恢复生命和防护，保证旧图材料耗尽后仍能继续验证后段推进，而修复凝胶的价值继续保留在前线续战。污染边界段会提示抗污染药剂来自过滤器处理沉积物；首趟药剂完成后会先指向带药剂补第二批沉积物并清敌，沉积物目标满足后再指向遗迹门前压力点。使用成功时会显示恢复量、当前生命 / 防护和剩余数量，满状态、缺少物品或空槽时会显示保留补给、回基地加工或重新绑定的短提示。HUD 左侧调试面板可把两个快捷栏槽位切换为修复凝胶、抗污染药剂 I 或空槽；三槽位存档调试面板支持保存、读取、清空和从新档重置，`K` / `L` 仍保留为默认槽位快捷键。

仍未接入：

- 更完整的建造面板、建造预览和正式地块状态表现。
- 更正式的污染危险 UI、返回基地提示表现和死亡 / 撤离演出；当前只有面板雏形。
- 更完整的补给面板、物品冷却和正式消耗品表现；当前只有快捷栏与短反馈。
- 正式存档 / 快捷栏管理界面；当前仍是原型调试面板。
- 完整教程弹窗或可回看教学。

## 失败与补救

首小时允许玩家失败，但必须可恢复。

推荐规则：

- 战斗失败后回到基地或撤离点。
- 关键任务资源不要永久丢失。
- 防护不足时给出明确提示。
- 背包满时提示返回基地。
- 建造失败时说明原因和解决方式。
- 污染区失败后提示需要过滤模块、药剂或更多补给。

不推荐：

- 第一次死亡损失大量进度。
- 让玩家因为没读文本而卡关。
- 天气、污染或敌人随机阻断主线。

## 文案和提示风格

提示应短而具体。

推荐：

- “设备缺少晶体矿物。”
- “污染浓度升高，防护消耗加快。”
- “地面不平，先平整或铺设地基。”
- “过滤模块可降低污染区防护消耗。”
- “样本分析完成：污染边界已标记。”

避免：

- 长段教程说明。
- 专业公式。
- 含糊提示，例如“条件不足”。
- 只用颜色表达危险。

## 首小时验收标准

首小时体验可用时，应满足：

- 玩家能在无开发者口头解释下完成第一闭环。
- 玩家知道为什么要回基地。
- 玩家至少制造一次能改变外勤结果的产物。
- 玩家理解污染、防护和区域推进的关系。
- 玩家理解地块为什么不能建造，以及如何修正。
- 玩家完成一次小型战斗挑战。
- 玩家看到后续区域或主线悬念。

## 当前阶段结论

RadishCatalyst 的首小时不是把所有系统展示给玩家，而是让玩家完成一次可信闭环。

首小时必须保护一件事：

**玩家先理解“基地和外勤互相需要”，再逐步理解化工、污染、地形、天气和长期成长。**
