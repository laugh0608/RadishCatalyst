# Combat And Interaction Prototype - 玩家战斗与工具

返回：[Combat And Interaction Prototype](combat-and-interaction-prototype.md)

更新时间：2026-06-18

## 文档目的

这份文档用于把首版 MVP 中的外勤、战斗、地图交互和建造前置条件拆成 Godot 原型可执行边界。

它不是完整战斗设计，也不是完整建造系统方案。它只回答：

- 首版原型里玩家能做哪些动作。
- 地图上的资源、建筑、地形和敌人如何被交互。
- 哪些对象可破坏，哪些对象不可破坏。
- 建造为什么需要考虑地形高低差、平整和地基。
- 原型阶段哪些内容必须做，哪些只做预留。

## 原型目标

首版战斗与交互原型应验证：

**玩家从基地出发，在地图上移动、探索、采集、采样、战斗、清障、撤离，并把带回的资源交给基地加工。**

它的目标不是做出完整动作游戏手感，也不是做复杂地形工程，而是确认玩家在外勤过程中始终有清楚判断：

- 这里能不能走。
- 这里能不能采。
- 这里能不能破坏。
- 这里能不能建。
- 这里危险来自敌人、污染、地形，还是资源准备不足。
- 我现在应该继续深入、清障、采样，还是撤回基地。

## 玩家基础动作

原型必须支持：

- 移动。
- 面向或瞄准。
- 基础攻击。
- 使用工具。
- 采集资源。
- 采样调查。
- 拾取掉落物。
- 使用快捷物品。
- 与基地设备或地图节点交互。
- 回到基地或撤离点。

可选支持：

- 闪避或短距离冲刺。
- 简单击退。
- 简单蓄力工具动作。
- 临时扫描。

首版不要求复杂连招、空中动作、格挡反击或高精度动作取消。

## 战斗最小边界

必须实现：

- 一种通用武器或工具攻击。
- 一种近程或远程基础敌人。
- 一种更危险的精英、巢穴或小型首领挑战。
- 生命、防护和能量 / 体力中的至少两个压力来源。
- 受击反馈、死亡 / 失败反馈和撤离后保留成果的规则。
- 敌人掉落样本、部件或污染残留，而不是主要掉完整装备。

推荐首版敌人类型：

- 原生小型生物：用于验证基础移动、攻击和采集干扰。
- 受扰污染体：用于验证污染区、样本掉落和防护压力。
- 精英节点守卫：用于验证装备、药剂、特殊弹药或模块准备。

暂不做：

- 大量敌人类型。
- 复杂 Boss 阶段。
- 职业技能循环。
- 大规模弹幕。
- PvP。
- 多人同步战斗。

## 工具与武器关系

首版可以把武器和工具先做成少量可复用交互能力。

推荐：

- 工程步枪：通用攻击，验证远程战斗。
- 切割 / 冲击工具：可攻击，也可破坏部分障碍或采集矿物。
- 扫描器：标记资源、样本、危险边界或可破坏对象。
- 投放器：使用净化剂、特殊弹药或稳定剂处理污染节点。

工具不应只为战斗服务。它们应同时连接：

- 资源采集。
- 环境清障。
- 样本调查。
- 基地制造产物。
- 区域通行门槛。

## 当前原型落地口径

截至 2026-06-18，当前战斗收益已经开始接回基地和资源链：

- 基础过滤模块会降低污染采集的防护消耗，也会缓冲污染敌人反击造成的生命 / 防护压力。
- 出发整备台把模块装配变成基地操作；只制造模块但没有装入时，污染区仍按未装配状态给出承压提示。后续晶体侧路材料可在整备台校准模块，核心稳定设备写入完成后可在整备台接入核心归档维护。
- 基础多用工具已经接入 `C` 战术扫描：建成出发整备台后，玩家可主动标记敌人或污染采集点，下一次反击或采集承压会下降，并在反馈中说明扫描被消费。
- 出发整备台新增防护响应和工具打击校准两类一次性整备状态：前者读取基础防护服、过滤模块和补给，后者消耗基础零件强化下一次外勤反击处理；两者都通过战斗日志说明承压下降来源。
- 晶体侧路、污染侧翼、副产回收口袋和归档维护回访口袋把额外资源、受扰敌人和回基地处理理由放在同一条可操作路线里。
- 污染浆液缓冲罐把过滤副产接入前哨补给，使抗污染药剂整备目标从 1 份提升到 2 份；战斗压力反馈会读出药剂余量和回前哨补满的去向。
- 快捷栏补给已形成可读状态：修复凝胶和抗污染药剂会在 HUD 中显示数量、可用 / 暂存和缺口回补设备；修复凝胶用于处理点战斗后的生命恢复，抗污染药剂会在门前污染压力和核心写入压力中自动参与排压。
- 封锁遗迹入口门前确认会读取基础过滤模块、抗污染药剂和污染浆液状态，决定提示玩家补药剂、回收副产或直接确认入口。
- 污染脊守卫、核心缓冲补料守卫和归档维护回访守卫不只是挡路敌人；清掉后会打开沉积物回收、过滤副产、补给整备和基地维护收益。
- 核心稳压缓冲包会在核心阶段守卫第一次回写压力中被消耗，降低终点战斗承压。
- 核心阶段守卫败退后会暴露回写缓存，回收校验片和补给后才能写入核心稳定设备；首次写入会读取侧向补给、守卫回写校准和抗污染药剂，完成后的回访复测会继续读取核心归档维护状态。
- 外勤出发口负责把前哨核心补给、整备台模块状态、归档维护回访处理和下一趟目标方向合成一次出发前读法，避免玩家在基地各设施之间猜下一步。

后续战斗设计应继续优先验证“基地准备改变外勤承压，外勤战斗反过来给基地加工理由”，而不是只增加敌人血量或掉落数量。
