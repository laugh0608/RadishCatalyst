# Factory Representative Asset Brief V1

更新时间：2026-11-01

状态：R1 新核心及代表材质的制作需求候选，**未制作、未导入、未冻结最终美术或预算**。顺序 / 交互与验收见[样板方案](../features/factory-camera-and-representative-scene-v1.md)；既有来源见[资产映射](../reference/asset-source-and-export-map.md)。本篇不改变核心等级、库存、端口或供电合同。

## 视觉目标与制作范围

以清楚的工业结构、材料层次、地表与接地光影形成有角色在场的工厂。轮廓 / 口 / 流向先于微小刻线；青灰结构、浅色壳体与少量琥珀维护点为候选家族，具体色值和材质粗糙度经同场景确认。

首轮只新增一件核心模型、一件代表反应器的 UV / 材质候选、一套共享工业材质与两种可平铺地面。其他设备、角色、货物与图标沿现有资源，不进行整套模型、人物或 UI 翻新；研究 / 固定燃烧实现另包。

## 新核心：身份与轮廓

建议主体为**低层仓储 / 供配能基座、中心工程调度舱与竖向维护脊柱、周边低矮物流托盘**。从普通镜头首先读成基地中枢，次级能看出存储、工程管理与基础供能用途。仓储容量以 UI 数量账解释，不堆砌 99,999 个实体货箱；顶部高亮不作为输出功率或等级数值的替代。

候选高度包围 `0..3.6` 世界单位：外围托盘低于 `0.7`，中心主体主要收在 `3.6×3.6` 内；保留周边约 1.2 单位低位带口视线。高度由镜头 / 遮挡样板校正，不形成新的碰撞墙。北口需有朝上可读的接带托盘 / 槽口，不以背面竖门作为唯一识别。

I / II 共用相同基座、足印、外包围与全部端口。II 通过主体内部加装的调度 / 工艺模块和等级铭牌变化表现，不增加占格、库存上限或免费功率；III 模型未纳入首轮。升级结构不得封住现有接带路径。

## 核心几何与导出合同候选

- 沿逻辑格 1 单位；核心候选 6×6，导出原点为足印中心 / 地面 `Y=0`，X 向东、Z 向南。局部占地 `[-3,3]×[-3,3]`；模型缩放应用后为 1，禁止用非均匀缩放临时修接口。
- 12 个端口位置来自[布局预算](../reference/factory-integrated-demo-layout-and-budget.md)，不另造美术端口。口内中心与足印边界口沿不同，见下表；后续定义变化必须同步模型与布局复算。
- 带面接驳高度先取 `Y=0.31`，依据现有带面几何约 0.30–0.31；货物渲染中心现为 0.53，不能把它当设备带面。正式值需导入后同屏对齐。
- 建议根节点 `BaseCore`；保留 `Structure`、`LogisticsRing`、`TierModules/I`、`TierModules/II`、`StatusMounts` 与 `Ports/Port_<角色>_<ID>`。命名是新模型合同候选，不代表客户端已绑定这些节点。
- 端口锚点是定位标记，不另持物料 / 供能状态；升级装饰只在已声明包围内变化。碰撞与物流沿权威足印 / 定义，不从装饰网格自动反推新规则。

| 锚点（口沿） | 中心原点下 `(X,Y,Z)` | 外法向 `(X,Z)` |
| --- | --- | --- |
| `IN_N0..N3` | X=`-1.5/-0.5/0.5/1.5`，Y=`0.31`，Z=`-3` | `(0,-1)` |
| `IN_W0 / IN_W1` | `(-3,0.31,-1.5)` / `(-3,0.31,1.5)` | `(-1,0)` |
| `OUT_E0..E3` | X=`3`，Y=`0.31`，Z=`-1.5/-0.5/0.5/1.5` | `(1,0)` |
| `OUT_W0 / OUT_W1` | `(-3,0.31,-0.5)` / `(-3,0.31,0.5)` | `(-1,0)` |

端口局部格中心由 `格坐标 + 0.5 − 3` 得到，口沿再沿外法向移 0.5；角色前缀必须保留，避免输入 W0 与输出 W0 同名。所有出入口保留几何区别与方向标识，颜色只辅助。外部整段带与货物不能烘焙进模型，空口不显示假连接。

首件轮廓模型用真实可导入网格验证；R1-A 的占地框仅是测量辅助，不作核心模型交付。初始核心预算候选 ≤12,000 三角形、≤4 材质表面，实际纹理 / 发光与拆分共享后的成本单列；这是首轮工作边界，性能或轮廓需要变化时先更新预算。

## 材质与贴图需求

现有 GLB 使用材质参数而无贴图。抽查本次 17 项样板输入均有 `TEXCOORD_0`，均无已导出的 `TANGENT`；存在 UV 不证明可用于独占烘焙、无重叠或 texel density 一致。代表反应器基于 refinement 几何另出候选，保留原模型，先复核 / 重排 UV 再做细节。

| 材质族 / 首轮对象 | 表现需求 | 贴图候选上限 |
| --- | --- | --- |
| 新核心专用 | 浅色涂层板、深色结构、局部裸金属、有限能量 / 状态标识；接缝、检修盖和磨损服从实际结构 | BaseColor / Normal 各 2048²，ORM 1024²，Emission mask 512² |
| 代表反应器 | refinement 承压腔 / 环箍 / 检修口的层次；细槽与螺栓用法线，轮廓与接口用几何 | BaseColor / Normal / ORM 各 1024²；发光优先共用已有遮罩或参数 |
| 共享工业 trim | 涂层板、钢、橡胶 / 密封件与少量维护色；供节点 / G / 带候选后续复用 | 一套 BaseColor / Normal / ORM 各 1024²；不能未经 UV 核对直接铺到所有旧机 |
| 岩土地表 | 一种颗粒岩土，方向性和明暗适中，角色 / 货物可辨 | 一套 BaseColor / Normal / ORM 各 1024²，可无缝平铺 |
| 压实工作面 | 一种与岩土同家族的压实地面 / 工业承载面，接地关系清楚 | 一套同规格 1024²；A 阶段先沿旧 yard，不同时换场地 / 灯 / 镜头 |

以上为最多 16 张候选图的上限分配；某通道为常量就用材质参数，不生产无意义空图。按每图 RGBA8、完整 mip 链且不压缩估算约 **113.33 MiB**，仅是贴图资源算例，未含帧缓冲、深度 / 阴影、模型、其他资产或上传副本，不能当实际显存 / 性能成绩。先核对下采样到 1024 / 512 是否保持普通视距品质，再决定是否保留核心 2K。

## 技术交付要求

- BaseColor 使用颜色语义，Normal / ORM 使用数据语义；ORM 明确 R=AO、G=Roughness、B=Metallic，导入时核对通道，不把颜色转换施加到数据图。
- Normal 采用切线空间 OpenGL 方向（+Y），记录生成 / 烘焙来源与导入设置；UV、平滑法线、硬边和切线一并校验，不以法线图替代真实轮廓或碰撞。
- 灯光方向、投影与 AO 不烘成彩色投影贴在 BaseColor 上；只允许材质局部 AO，避免与场景 AO 叠黑。涂漆为非金属，裸金属区单独表达，避免全壳镜面；通电与故障灯由权威状态驱动。
- 首轮以不透明材质为主体；玻璃 / alpha、强发光、体积雾与更多动态灯作为独立后续对照，不为细节引入全局后处理改造。
- 建议交付几何 / UV / 稳定材质槽的 GLB、独立 PNG、候选材质定义与可编辑源。贴图文件保持一份来源，避免 GLB 内嵌和外置各藏一份不同版本；最终采用外置材质绑定或嵌入方式须在样板导入时记录并核对依赖。

Godot 的 [Camera3D](https://docs.godotengine.org/en/stable/classes/class_camera3d.html)、[标准材质 / ORM / Normal](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)和[glTF 导入](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html)为接口参考；当前固定引擎构建的实际导入与表现仍需运行复核，网页能力说明不代签工程通过。

## 制作与发布材料

先建立独立候选批次，建议在获制作授权后使用 `assets/art-intake/<date>-factory-representative-assets/<batch>/` 放可编辑源 / 烘焙源与候选 GLB / PNG，不覆盖正式路径。若采用自有离线网格制作，导出工具进入 `tools/factory-content/` 的独立新入口；若采用 DCC，先说明软件、已有安装与源文件落盘，不在本轮安装或预选付费工具。

每件清单记录：来源 / 许可、版本与制作命令、工具版本 / 依赖、几何 / UV / 材质槽、原点 / 足印 / 端口与节点、贴图通道 / 色彩语义 / 尺寸、源与产物 SHA-256、导入设置、审阅状态。候选状态写清“轮廓 / 材质试验 / 获认可”，不能把导出成功写成美术定稿。

先走 R1 样板；获认可并有功能接入授权后，再决定正式 `client/assets/` 发布路径、导入配置与清单。旧 GLB、二维锚点、实验副本和历史源均保留，不以新核心制作顺手迁删。
