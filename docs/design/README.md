- [Web Style Comparison Demo V1](web-style-comparison-demo-v1.md) — Web Canvas 手绘 / 像素对照。
- [Web Topdown 3D Demo V1](web-topdown-3d-demo-v1.md) — Web 七机视觉样场、局部 Three.js 依赖及后续 `/play/` 路由。
