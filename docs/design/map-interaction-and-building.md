# Combat And Interaction Prototype - 地图交互与建造

返回：[Combat And Interaction Prototype](combat-and-interaction-prototype.md)

更新时间：2026-06-13

## 地图对象交互分类

地图上的对象至少应分成以下几类：

### 可采集

玩家使用工具或交互键获得资源。

示例：

- 晶体矿脉。
- 浅层矿物。
- 植被或菌毯样本。
- 污染沉积物。

### 可采样

玩家获得样本、线索或解锁信息，不一定直接获得大量资源。

示例：

- 异常反应点。
- 污染边界。
- 受扰生态残留。
- 遗迹入口装置。

### 可破坏

玩家可以通过武器、工具、爆破或特定装备移除。

示例：

- 小型晶体簇。
- 脆弱岩块。
- 受污染的生物膜。
- 已废弃的轻型设施残片。
- 可清理的障碍物。

可破坏对象应带来至少一种结果：

- 打开路径。
- 获得资源。
- 降低危险。
- 触发敌人或污染反应。
- 暴露样本或入口。

### 不可破坏

玩家不能通过常规手段移除。

示例：

- 大型地貌边界。
- 深坑、峭壁或主地形骨架。
- 主线遗迹核心结构。
- 基地平台关键锚点。
- 用于限制原型范围的区域边界。

不可破坏对象不是失败设计。它们用于保护地图可读性、关卡节奏、存档稳定和后续任务结构。

## 当前交互可读性规则

当前原型不再把所有可交互物和敌人名称常驻铺在地图上。玩家靠近或瞄准对象时，HUD 和场景优先突出“当前会被操作的对象”：

- 当前可交互对象显示名称、交互提示和高亮，帮助玩家判断按 `E` 会操作谁。
- 当前攻击目标显示名称和更明显的状态，高亮对象应比周围低压敌人更清楚。
- 小地图和区域标签保留方向判断，但避免和资源、敌人、设备名称互相遮挡。
- 基地、晶体矿脉区和污染边界的对象摆位应让玩家先读出路线层次，再读单个节点名称。
- 采集、采样和检查提示采用“对象、用途、产物或样本、状态、操作”结构；已处理对象也要显示完成态，避免玩家反复尝试。
- 地图对象完成态需要稳定可见：已采集、已部署、已稳定和已校准对象应保留完成态标签或视觉差异，避免成功操作后看起来像还没处理。
- 设备、建造点和清障点如果被阻塞，提示必须显示“状态”和“下一步”，明确是缺料、前置未完成、地块未清理、地基不足还是等待加工完成。
- 加工中状态必须在 HUD 交互提示、基地摘要、短条和设备面板之间读成同一件事：当前设备正在跑哪条配方、进度到哪里、下一步是等待或按 `Q` 看面板。
- 污染过滤器完成抗污染药剂后，设备面板、加工完成短条、HUD 当前目标 / 基地摘要、污染沉积物提示和门前压力点必须统一指向同一条链：处理药剂 -> 带药剂回污染边界 -> 清理受扰敌人 / 门前压力点；若当前任务已进入稳相信标、深段回波解析或核心缓冲包整备，完成去向应按当前任务分流。
- 遗迹外圈相位守卫败退后暴露的污染回波沉积，必须先通过对象启用、交互提示和设备缺料提示读成“处理副产后再解析回波”，不能让玩家误以为回波匣可直接完成整段链路。
- 核心稳定站侧向补给、守卫回写缓存和核心设备写入提示应连续说明：补给可提供药剂，缓冲包削弱守卫回写，最终写入会读取回写校准并自动接入药剂排压。
- 基地平台基建设施不能只显示“可建造”；基础储存箱这类后勤设施要在建造提示、完成态、HUD 基地摘要和前哨核心交互里说明实际补给收益。
- 污染浆液缓冲罐必须读成“过滤副产接入前哨补给”：建造提示说明前置、缺料和双药剂收益，完成态对象、HUD 基地摘要和前哨核心整备都要显示抗污染药剂目标变成 2 份。
- 出发整备台提示需要覆盖模块未装、已装、可校准、已校准、核心归档维护待接入和已接入六种状态；其中校准和归档维护都要能被污染采集、污染战斗和核心站复测反馈读取。
- 外勤出发口不是传送说明牌。它应汇总前哨核心补给、整备台模块状态、归档维护回访处理和下一趟目标方向，并把“先补给 / 先维护 / 可以出发”的判断交给同一条提示。
- 设备面板列表不能把当前进度复制给所有配方；只有运行配方显示进度，非运行配方显示设备忙碌，玩家按 `R` 切换时也不应误读为多配方并行。
- 左下日志短条只显示短反馈和关键操作，不承载完整说明；完整去向、输入 / 产出、副产和完成后建议留给交互提示或设备面板。

### 可建造

玩家可以放置地板、地基、设备、储存、管线或电力设施。

可建造性应由地形、空间、污染、坡度、高低差和已有对象共同决定。

### 不可建造

玩家不能直接建造。

原因可以包括：

- 地面不平。
- 高低差过大。
- 被资源、建筑残骸或敌对巢穴占据。
- 污染过高。
- 属于保护区域、遗迹区域或任务区域。
- 缺少地基、支撑或前置清理。

## 地形与高低差

用户补充的“地形高低差、平整土地和地板 / 地基单元”非常适合进入建造交互边界。

推荐首版采用离散层级，而不是连续地形模拟：

- 地图格或地块可以有高度等级，例如低地、平地、高地。
- 同一设备占地范围内需要高度一致。
- 管线、地板和设备不应跨越过大的高度差。
- 玩家可以通过平整、填平、架高地板或放置地基来获得可建造区域。
- 高低差可影响移动路径、敌人路径和基地扩建方向。

这样既能让地形参与玩法，又不会把首版拖进复杂体素、真实土方或物理施工系统。

## 平整与地基

首版建议保留四种建设前置动作：

1. 清理  
   移除小型障碍、资源残留、污染膜或废弃设施。

2. 平整  
   把指定地块整理为可建造状态，消耗基础材料或工具时间。

3. 铺设地板 / 地基  
   创建稳定建造面，允许放置轻型设备、管线、储存和工作台。

4. 强化地基  
   作为可选扩展，用于支持重型设备、储罐、反应器或高风险工艺。

MVP 必做不应超过：

- 简单清理。
- 简单平整。
- 一种基础地板或地基单元。
- 建造时显示能否放置以及失败原因。

当前原型中的处理点扩建已经验证了这组前置动作的最小链路：玩家需要先带修复凝胶清理处理点北缘两处掠行体，再清理两块粗糙地面，铺设两块基础地基，最后建造污染过滤器。建造反馈应明确说明当前卡在清障、粗糙地面、地基数量、材料不足还是过滤器上线；第二块地基完成后，短条和对象完成态应立即把读法转到“现在可以建造污染过滤器”。

当前建造 / 清障提示读法：

- 粗糙地面：显示它正在阻挡建造，并提示清理后可铺设基础地基。
- 基础储存箱建造点：显示建造材料来自基础零件；可建造时说明建成后接入前哨核心，修复凝胶耗尽后回基地可补到 1 份。
- 基础地基建造点：若地块未清理，提示先清理粗糙地块；若缺材料，提示回晶体区采集资源并用基础反应器补齐建造材料。
- 污染过滤器建造点：若基础地基不足，提示先铺设两块基础地基；若材料不足，提示回基地补齐过滤器材料。
- 可建造状态才显示 `E` 建造操作；不可建造状态不应把玩家诱导成反复按键。

可选扩展：

- 不同地基等级。
- 斜坡、桥梁或支架。
- 污染地块需要先净化再建造。
- 大型设备需要强化地基。
- 地形改造会影响污染扩散或敌人路径。

暂不做：

- 真实土方体积计算。
- 大规模地形雕刻。
- 多层建筑。
- 复杂结构承重。
- 完整水体、流沙、坍塌或滑坡模拟。

## 建造放置规则

首版建造放置至少检查：

- 是否在允许建造区域。
- 占地范围是否为空。
- 地面是否已清理。
- 高低差是否满足要求。
- 是否有地板 / 地基或天然稳定地面。
- 污染是否低于设备允许阈值。
- 是否拥有材料。
- 是否与已有管线、设备或电力连接规则冲突。

失败提示应明确，例如：

- 地面不平。
- 缺少地基。
- 污染过高。
- 被障碍物占据。
- 距离基地核心过远。
- 材料不足。

这些提示是首版 UI 的一部分，因为它们能让玩家理解地形、资源和基地扩建的关系。

## 当前处理点规则

处理点不是独立区域或完整建造模式，而是首小时里验证“外出清障 -> 回基地制造 -> 回现场施工 -> 解锁污染处理”的固定样例。

当前顺序：

```text
调制修复凝胶
-> 清理两处处理点掠行体
-> 清理两块粗糙地面
-> 铺设两块基础地基
-> 建造污染过滤器
-> 处理污染沉积物
```

这条链路用于证明建造前置不是纯文本门槛：敌人压力、补给消耗、地块清理、材料制造和设备上线都会改变后续污染边界推进。

污染过滤器第一次完成抗污染药剂不是链路终点。玩家应从设备完成反馈、HUD 当前目标、污染沉积物提示和遗迹门前压力点读到同一个下一步：带药剂回污染边界，补齐第二批沉积物，清理受扰敌人和门前压力后再检查封锁入口。后续同一过滤配方继续服务稳相信标、深段回波解析和核心稳压缓冲包时，完成去向必须随当前任务切换，而不是重复首小时门前提示。

封锁入口确认不是单纯开门按钮。门前受扰敌人清掉后，入口 prompt 和确认反馈应读取基础过滤模块、抗污染药剂和污染浆液携带状态：有多余污染浆液时指回基础反应器回收基础零件，缺药剂时提示回过滤器补药剂，未装模块时提示后续污染承压更高。

## 当前基地平台基建规则

基地平台基建用于证明“基地设施改变外勤准备”，不是完整自由建造模式。

当前顺序：

```text
制造基础零件
-> 建造基础储存箱
-> 外出消耗修复凝胶
-> 回前哨核心整备并补到 1 份修复凝胶
-> 污染过滤器跑通首支药剂后，回前哨核心可补到 1 份抗污染药剂
-> 建造污染浆液缓冲罐
-> 回前哨核心把抗污染药剂补到 2 份
-> 建造出发整备台
-> 把已制造的基础过滤模块装入防护服
-> 消耗晶体矿和残骸废件校准基础过滤模块
-> 核心写入完成后，把核心归档维护接入基础过滤模块
-> 从外勤出发口复测核心稳定站或回污染边界验证承压
```

这条链路的检查重点是：建造点可见、建造结果写入基地结构、完成态对象可读、HUD 基地摘要显示补给或装配收益、前哨核心 / 整备台 / 外勤出发口交互实际改变库存、装备或出发判断并写入日志。储存箱和过滤器的协同补给必须读取已跑通首支药剂的任务进度，不能凭空提前发放抗污染药剂。污染浆液缓冲罐必须读取真实建筑状态后再提升药剂目标；核心归档维护必须读取核心写入完成和模块装配状态后再开放。后续新增基地平台设施应沿用这组要求，把设施收益接入真实操作和存档来源，而不是只增加建筑名或说明文本。
