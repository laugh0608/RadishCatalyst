## 玩家目标与范围

承接 [Industrial Volume Visual Study V1](industrial-volume-visual-study-v1.md) 与 `6264e17d` 的建造态分层。萝卜SAMA同意下一步制作可拼接体积管道，以当前体积方向继续推进；该授权不代替最终视觉验收。

1. **玩家结果**：一台设备接出连续横管，转弯后沿地面纵向延伸；接缝、高度与光向一致，管下可见支撑和投影，白色双箭头沿管壁流动，停流与空管可区分。
2. **实现介质**：内置图像工具生成独立模块板，确定性归一到 `32px` 网格；复用现有设备、支撑、地面与阴影素材。主体使用 Sprite2D，材质掩码与动态流向使用 shader，按接地深度排序。
3. **成功证据**：原生资产机械检查、重复拼接与接缝对照，正式 Boot 隔离存档的正常 / 建造倍率截图，流动 / 停流 / 空管与转角连续性检查，真实角色前后移动及保存重载。
4. **失败判据**：模块拼合破坏离地体积、管径或光向，转角需要强行拉伸才能连接，或动态内容盖掉圆管层次，则记录具体失败，停止扩模块；不靠放大相机和加装饰弥补。
5. **落点**：本合同记录装配约束与结果，art-intake manifest 保留源图、完整提示词与哈希，本周周志记录验证事实。

## 有限模块合同

| 项目 | 本包约束 |
| --- | --- |
| 网格 | 32px；模块画布 32×32，管轴通过边中点 |
| 管径 | 管体目标 16px，接头外径目标 20px，留出高光、侧面与暗部 |
| 高度 | 管轴平面相对地面上移 16px；支撑采用同一接地锚点规则 |
| 模块 | 横直管、纵直管、西入南出弯头、朝东设备接口各一款；有限 L 形链，不声称完整四向网络 |
| 光向 | 保持左上；纵管单独出稿，不旋转横管的烘焙光照 |
| 支撑 | 复用当前独立支撑，直线每两格及转角附近布置，支撑与管体分别排序 |
| 接缝 | 对接边的轴线、轮廓与金属环材质一致；归一允许用同源端面像素对齐，记录映射，不重绘主体 |
| 动态 | 复用管壁双箭头语义；内容色青 / 琥珀可切，流动推进、停流保持、空管隐藏内容与箭头 |
| 显示 | 默认低纹理地面与已验证的建造分层，保持既有相机 2.0 / 1.5 和真实角色比例 |

## 执行结果

- 内置 `image_gen` 生成 v1，再以其为编辑目标纠正直管长度和弯头长尾，得到 v2。第三轮使用 `2 / 3` 次，管道类别累计 `8` 次，当前停止追加。两个 `1254×1254` 源稿、完整提示词和原件路径在本批 `_manifest.md`；v2 SHA-256 `25548eb4ffd497819b4ed15b98360845aea480bb6035d2ba49e96caa89577997`。
- v1 的横纵长宽比与弯头轴线不满足装配目标，作为失败对照；v2 用于归一。源图是带不透明棋盘背景的独立部件板；`tools/normalize_raised_pipe_modules.py` 固定源块锚点、去底、共享色板并复用同源对接端面像素，未从整景裁取素材。
- 四种部件各有主体、动态内容掩码和地面投影，均为 `32×32`。横纵管体 `16px`、接头目标 `20px`，共享 `16` 色主材质；玻璃保留原稿亮面与侧面色阶，并使用 `96 / 210` alpha。首次机械检查发现管壁外轮廓超出目标宽度，修正源边界后 `12` 项检查通过；输出参数及哈希见 `client/assets/sprites/visual_studies/raised_pipe_v1/manifest.json`。
- 新场景装配九段 L 形链：设备接口、四格横管、一格弯头、三格纵管。管轴整体上移 `16px`；按接地深度排序，复用设备 / 支撑并独立放置投影。纵管支撑使用同一素材在两侧装配，避免脚部全部被管身遮住。正常 / 建造相机与角色比例保持原值。
- 继承上一管道样板的路径距离和相位逻辑，新增可选分层内容材质：下部内容色与管壁双箭头叠在空玻璃底层。共用 shader 默认分支保持旧效果，新增分支显式接收建造主体透明度；停流保持相位并降低箭头显著度，空管同时隐藏内容与箭头。
- 正式 `Boot` 定向窗口验证 `78` 项通过，日志 `tools/runtime-intake/2026-09-06-raised-pipe-validation/logs/review-20260906T065512Z-25422.log`；最终存档 `tools/runtime-intake/check-runs/raised-pipe-modules/run-1788677713-473482/`。`runtime-preview/run-1788677713/` 保留 `14` 张状态截图及 `7` 张受控相位帧。首轮 `71` 项验证与截图另存，覆盖未重复累加。
- 已直接审阅正常 / 原生流动、停流、空管、琥珀反向、角色前后、建造两种尺寸、建造停流 / 空管及转角相位原图。`motion-comparison.json` 记录相邻相位帧的管路变动像素数 `715 / 787 / 842 / 874 / 821 / 813`、弯头 `24 / 75 / 115 / 159 / 163 / 135`，地面和金属接头对照区域均为 `0`。这些是每次 `4px` 的受控相位截图，不冒称连续录像；真实 process 推进与暂停另有运行断言。
- 本次还执行旧管道窗口回归 `91` 项、Godot 导入 / 解析及客户端静态检查；未重跑完整客户端 Godot 套件。素材 / 动画只负责视觉表达，正式菜单通过信号进入，场地由夹具准备，样板按钮使用鼠标输入，遮挡通过真实移动复核；未声称真实铺管或流体运输通过。

## 人工复核与保留限制

用 `sh tools/run-raised-pipe-modules.sh` 进入独立复核世界。底部可切换流动、停流、空管、内容色、方向、演示暂停、投影与地面；`WASD` 查看前后遮挡，左上按钮切换建造倍率。每次入口重建视觉节点，存档仅保存真实地板和角色状态。

默认入口已实际创建并进入 `tools/runtime-intake/review-worlds/raised-pipe-modules/`，窗口保留供用户复核；文档、文本、差异空白与仓库治理检查通过（`1563` 文件）。

本轮观察是：连续管路仍能辨认金属接头、玻璃上亮下暗、架空支撑与投影，常态流动 / 空管可区分。建造态细管与箭头更淡，原生精细度弱于生成参考图；纵向末端只是有限样板出口，尚无完整终端或四向模块族。当前交用户评价连续装配是否保住体积，不自动扩成真实输送系统。
