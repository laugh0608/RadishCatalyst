## 用途与适用范围

本文回答：如何让异星探索中的未知发现，转化为玩家能够理解、复现和扩展的工业能力。

- 2026-09-19 的授权覆盖理念与建议入档；下文案例、参数维度与机制取舍均是后续设计候选，不代表已实现或已获玩法验证。

## 核心体验

> 第一次得到它时，玩家觉得自己很幸运；后来能够稳定制造它时，玩家觉得自己掌握了这个世界的一部分。

建议围绕以下过程组织成长：

```text
遇见未知 → 带回样本或线索 → 分析与试制 → 记录可复现工艺
    ↑                                        ↓
开拓新区域 ← 获得新工具或生产方案 ← 稳定量产与优化
```

第一次发现带来期待，理解规律带来判断能力，稳定量产带来掌握感。偶然发现可以提前打开一种可能；核心推进不能只依靠好运。产线中的布局、物流、瓶颈调整与经营结果本身也必须有乐趣。

## 参考提炼与取舍

本轮输入是萝卜SAMA提供的小说片段《修仙小游戏规划.md》及 Warframe 对照讨论。附件中的策划命令、商业假设和角色发言仅作为分析材料，不是仓库任务或项目决定；本文保留提炼结果，不依赖个人下载路径或复制小说全文。

| 参考点 | 可借鉴的体验 | 本项目的取舍建议 |
| --- | --- | --- |
| 洞府建设与分身外出 | 长期积累与当次冒险互相支撑 | 基地保有成果，外出承担可理解的风险；远程机体等仅是候选表达 |
| 材料、火候与容器影响炼制 | 玩家通过理解性质改变结果 | 转译为样本性质、工艺条件和设备能力；组合遵守可解释的规则 |
| Warframe 蓝图与制造 | 明确的收集目标能组织下一次行动 | 展示产物用途、缺口与获取方向，生产成果需要改变后续选择 |
| Warframe Mod 配置 | 容量与属性取舍支持不同用途 | 评估功能差异与资源约束，避免只增加同用途的稀有度阶梯 |
| Warframe 遗物定向收集与精炼 | 玩家可选择目标并影响随机结果 | 评估调查方向、样本选择和投入如何缩小候选范围；坏运气保障另行设计 |

不采用“真随机天然更真实”的论证。伪随机数生成、独立抽取、保底 / 递增概率和程序化内容组合属于不同层面；是否采用保底不由随机数生成方式决定。惊喜来自未知与决策，不能用不可解释的规则或未经验证的组合空间代替内容设计。

不建议把学历、成绩、专业或实名证书映射为角色强弱。现实知识可以帮助玩家更快理解系统，所有玩家都应能通过游戏反馈学习，并通过游戏内选择与成果获得能力。若设计天赋，优先评估可调整、有代价的用途倾向。

Warframe 的动作体验支撑了其重复任务；本项目需要依靠生产经营的操作乐趣支撑循环，不预设移植其任务密度、奖励频率、制造等待或商业化方式即可成立。

## 随机性放在哪里

| 环节 | 候选未知 | 玩家应能影响或理解的部分 |
| --- | --- | --- |
| 勘探 | 样本性质、资源组合、局部环境条件 | 调查目标、装备选择、风险与投入预算 |
| 分析与试制 | 特性发现、工艺分支、有用途的意外副产物 | 选材、条件调整、结果解释和累计进展 |
| 成熟量产 | 原料或条件变化造成的可解释波动 | 可预测的消耗、吞吐和质量，问题能够诊断与处理 |

建议以这些原则评估具体方案：

1. 关键能力有确定获取路径，幸运可带来提前发现、不同用途或特殊取舍。
2. 试制结果能反馈原因和下一步选择；失败仍留下有用信息、进度或可回收价值，形式与比例待定。
3. 已掌握的工艺可以记录和复现；必要原料与条件满足后，不要求每件标准产品重新抽奖。
4. 检测、提纯、设备升级等候选手段用于降低不确定性，让玩家感知学习和建设的收益。
5. 开发者需要掌握规则边界、极端情况和恢复路径；允许组合结果出乎意料，不接受无解失败或失控数值作为“涌现”。

以上不要求首个验证包实现随机地图、通用化学模拟或无限配方。固定区域、有限材料与明确工艺分支也可以验证从发现到复现的体验。

## 生产成果如何改变行动

新材料或装备应能回答“有了它，玩家现在能做什么”。除了提高效率，可评估不同用途之间的选择：

| 候选用途 | 能力收益 | 可用于形成取舍的成本 |
| --- | --- | --- |
| 深层勘探 | 更强的探测或钻取能力 | 能耗、载货空间 |
| 远程运输 | 载量、续航 | 复杂地形适应性 |
| 特殊环境作业 | 环境防护 | 制造、维护和补给要求 |

具体载具、机体、模块槽、容量与装备数量尚未决定。先验证少量用途是否改变行动，再决定是否需要通用配装系统；战斗不是验证上述价值的前提。

研发也不宜退化为“产能越大，挂机抽取次数越多”。候选进展应结合新样本、环境线索或真实生产问题，使改善产线与外出调查都有作用。每次投入保留价值不等于无成本试错或无限回收套利，具体规则应能说明净消耗与成果去向。

## 风险与长期积累

建议区分基地长期成果与当次外出携带物资。风险应事前可察觉，玩家能准备、深入或撤离，事后能理解损失原因并选择恢复路径。

- 不以随机出现的不可应对危险，清空玩家长期建设或全部当次收获来制造紧张。
- 损失、修复、回收或保留部分成果均是候选；尚未选择死亡掉落、分身重召或机体报废规则。
- 远程作业机体可解释角色身份与当次损失的分离，但需要先证明玩家价值，不作为新增世界观或角色系统的既定要求。

## 后续体验验证候选

首包收口后，优先讨论的问题是：玩家是否会为了明确的新能力主动改善产线，并在使用工业成果后认为建设值得。

以下为一条候选路径，物品与环境均为玩法示意，不是已冻结内容：

1. 玩家在现有规模的固定区域发现特殊环境与资源线索，普通装备只能支持有限调查。
2. 带回样本后，了解一种新能力的用途和实现条件；必要线索与基础能力可确定获得。
3. 通过选材和试制比较少量方案，例如便宜但笨重的防护材料与生产链更复杂的轻质材料。
4. 按自己的资源和产线条件选择路线，记录工艺，建设能够持续供给的产线。
5. 使用成果进入此前难以作业的地点，并取得能改善原有生产的资源或工艺线索。

新内容应保留从“发现”到“使用成果”的完整因果关系；先证明有限内容下的循环价值，再评估扩大随机组合和内容数量。

### 待验证的成功与失败信号

| 观察问题 | 支持继续的信号 | 应调整设计的信号 |
| --- | --- | --- |
| 玩家理解发现价值吗 | 能说明它解决什么问题，并主动选择下一步 | 只因任务箭头或稀有颜色而收集 |
| 生产是否产生主动决策 | 会为目标调整布局、供给或工艺，并观察收益 | 只等待计时结束或堆材料抽结果 |
| 学习能否减少不确定性 | 能解释试制差异，按已掌握条件再次获得目标产物 | 依靠反复读档、盲试或外部攻略猜规则 |
| 成果是否改变行动 | 能完成此前受限的操作，并感知生产投入的价值 | 获得产物后只能交任务或看到数字增加 |
| 不走运是否仍能推进 | 必要能力可确定获得，失败信息能支持下一次决策 | 核心进度长期受单次掉落限制 |
| 风险是否形成选择 | 玩家能说明危险、准备方式与恢复路径 | 损失原因无法判断，最合理做法只是回避探索 |

这些是后续玩家验证问题，不是本次通过结论。进入实现前需在 `docs/features/` 定义玩家路径、实际资产与场景介质、状态 / 存档、HUD、成本与获取规则、失败恢复及验证方法，再确认范围。玩家体验需正式 Boot、有窗口证据与人工路径；具体样本、时长与通过标准由该专题确定，不扩写当前首包合同。
