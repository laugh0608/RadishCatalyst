# Factory Playtest Refinement Proposal

更新时间：2026-09-29

状态：2026-09-29 萝卜SAMA已确认圆润、机械结构与化工质感方向，验证阶段控制投入，记录决策并制作小 demo。设备面板、接口、范围供电与逐步引导方向已接受；本轮执行范围见[交互样板 V1](../features/factory-refinement-demo-v1.md)。以下全量建议不等于全部进入本轮，正式存档版本与地图平衡仍待后续接入设计。

## 玩家问题与本轮目标

亲测世界为 `tools/runtime-intake/review-worlds/factory-discovery-v1/d4-playtest-20260929-a/`。萝卜SAMA报告：缺少可视化设备面板、放置时看不清传送带接口、期望电源节点显示范围并自动无线连接、任务需要逐步操作引导，以及 UI / 设备 / 人物希望更精细并讨论《异星探险家》参考。

目标是让玩家在建造前看懂设备作用、接口和供电，建造后能直接看懂生产及阻塞，并由具体操作提示完成首条产线。既有自动路径和短性能结果保留为工程证据，不等于这些体验问题通过。

## 设备面板与接口预览

- 将建造选择与已放置设备详情分清：建造卡显示设备缩略图、名称、作用、足印、剩余构件和供电需求；选中设备后显示对应设备详情。
- 反应器详情使用输入物料格 → 当前配方与进度 → 输出物料格，并列实际供电、生产状态和明确阻塞原因；仓库显示按物料库存，电源 / 节点显示覆盖、电网供需与接入设备。
- 在设备详情内提供对应操作，不再要求玩家在“工艺、物料与矿道”通用弹窗里寻找所有动作。远程查看与近身取放 / 切配方权限区分，受限操作说明距离原因；是否继续暂停生产沿现有合同，不能顺手修改。
- 建造预览同时显示真实设备外形、占地网格、输入 / 输出的准确接入格、方向箭头和短标签；不能仅用颜色区分。
- 铺带和选中设备时仍可查看邻近接口；端口位置取自同一权威定义，镜头旋转后保持正确。暂不因接口预览额外加入设备旋转能力。
- 成功证据：不用先放下设备试错即可判断带从哪里接入 / 接出；能从设备面板解释缺料、缺电、回压及产物去向。

## 覆盖范围自动供电提案

这是从现有显式接线转为自动建图的规则调整，需先确认电力与保存合同，不能只隐藏接线按钮。

建议的玩家规则：

1. 电源 / 节点放置预览显示覆盖范围，高亮将接入的设备、节点和电源，并预告新增负荷与供电不足。
2. 合法范围内的电源 / 节点自动连接并形成电网；范围内的用电设备自动接入。使用一个可解释的覆盖半径起步，具体格数结合现有地图、节点预算与跨区路线复核，不直接照搬原 12 / 6 格双距离。
3. 覆盖只解决连接，有限功率和缺电按比例降速保留；仓库与带仍不耗电。用电设备不承担电网中继，不能借重叠覆盖暗中合并两个网络或重复获得功率。
4. 多网覆盖时优先有启用电源的网络，同级按距离和稳定实体 ID 选择；不按每帧剩余功率反复跳网。断电 / 拆除后重算并在面板说明归属变化。
5. 未开放矿壳继续阻断跨区供电；范围预览区分有效覆盖与地形阻挡。放置、回收、电源启停、开路和加载时更新派生图，不每帧全图搜索。
6. 无线连接用选中 / 建造时的临时关系提示解释，避免常驻满屏连线。拆除预览显示将失电或改接的设备。

保存方面：现有 schema 2 保存显式 `power_links` 与设备接入点。自动图是否完全派生、新规则身份与版本保护、旧世界继续显式规则或明确升级，需作为独立合同决策；不静默重解释已有存档，不自动迁移用户试玩世界。

成功证据：预览覆盖与实际接入一致，先设备后节点 / 先节点后设备结果一致；多源不重复计量，跨封闭矿壳不能提前接电，拆除 / 停复电 / 保存重进一致。

## 首线逐步引导

- 将阶段说明拆为“当前动作、操作方法、目标对象、完成反馈”；每次突出一个动作，支持折叠与查看完整目标。
- 建议路径：找到矿点 → 选择并放采集器 → 建立供电 → 看见首件原料 → 放反应器 → 从出口铺带至入口 → 生产催化剂 → 放仓与接出料 → 调查拾样 → 在设备面板试制 → 量产制剂 → 首次开路 → 富集回流 → 第二次开路。
- 根据世界事实识别玩家已完成的操作，允许先拾样或先建线，不让任务要求拆掉重建或重复消耗唯一样本。
- 缺电、缺料、出口未接通时指出具体对象并提供定位；提示建造栏按钮、目标格位或设备接口，不靠不断增加整段说明。
- 引导不得代建、赠送物料、直接解锁或改变真实生产规则。细步骤设计依赖确定后的面板及供电交互，避免先写一套即将失效的按键教程。
- 成功证据：玩家不用外部说明完成首条可持续产线，能说明当前阻塞以及下一步；记录理解与等待时间，不以点击任务按钮计完成。

## 视觉方向与制作取舍

推荐讨论方向为圆润、模块化、色块清晰的风格化工业科幻。保留 Godot 3D、现有高斜角视图与化工生产辨识，通过体块、倒角、材质层次、统一接口和动画提高完成度。

- 设备：统一外壳 / 深色结构件 / 功能强调色；保留反应容器、管路、阀件与接口等化工特征。先做好远处轮廓和操作部位，细节必须在正式视角有价值。
- 人物：强化头盔、服装和背包比例，补待机 / 行走 / 操作姿态；绑定和动画的制作维护成本需单列。
- 场景：地形和矿物用较简洁的大体块与受控色彩，让设备和接口更容易识别；不借视觉提案引入可变形地形、球形世界或新玩法。
- UI：统一字体层级、留白、图标、按钮状态和面板结构；仍以适合工厂比较 / 操作的屏幕面板为主，不把所有信息做成世界内实体界面。

| 方向 | 相对成本判断 | 适用性 |
| --- | --- | --- |
| 保留现有资产，只统一 UI / 配色 / 光照 | 低至中 | 改善一致性快，但设备和人物造型上限明显 |
| 重做少量核心资产，统一圆润模块化造型与 UI | 中；人物动画单列较高 | 推荐，用小样验证完成度与可持续制作成本 |
| 全套高细节模型、复杂贴图和大量动画 | 高 | 当前不建议直接展开，返工与资产维护成本大 |

先做一张正式视角可交互样板：采集器、反应器、电源节点、短传送带、人物，以及建造卡 / 设备面板 / 引导条；沿现有模型导入流程落地。概念图只用于方向交流，最终判断以实机可读性与制作成本为准。样板认可后再扩展资产，不先全量替换。

参考：[Astroneer 官方早期美术文章](https://blog.astroneer.space/p/the-art-of-astroneer-low-poly/)将低多边形、简化材质与降低内容制作负担联系起来；[开发团队访谈](https://www.unrealengine.com/developer-interviews/inspired-space-inside-the-development-of-astroneer)讨论大体块 / 鲜明色块及直接可见的状态信息。两者是早期制作理念，不能当作当前游戏全部实现或本项目工期承诺。以上方案与成本判断为本项目建议，不复制其具体资产或图标。

## 完整接入候选与本轮决定

1. 已确认低投入样板方向；样板认可后，进一步冻结正式电力 / 保存版本与地图平衡。
2. 用同一个小样确定建造卡、设备面板、接口、覆盖圈、引导条及模型关系。
3. 实施设备面板与接口预览、自动供电，再按最终操作补逐步引导；每个可分割步骤做最小验证。
4. 回到空世界亲测主循环，再决定资产扩展与规模工程；既有性能短测无需无改动重跑。

已确认：采用范围自动供电方向，选择圆润但保留机械结构和化工质感的小样；验证阶段限制投入。本轮仅制作独立 demo，不全量替换资产。旧试玩世界继续保留，正式规则接入与迁移后续明确。
