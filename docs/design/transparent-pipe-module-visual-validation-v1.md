## 目标与授权

承接 [Small Chemical Factory Visual Target V1](small-chemical-factory-visual-target-v1.md) 已认可的透明管段、金属接头和管壁动态双箭头方向。本包只回答“能否在原生游戏比例下装配、辨认和连续表达流向”，不实现可建造管道或液气输送。

萝卜SAMA已同意本包包含模块规格、有限像素样板与 Godot 隔离视觉验证；不再把本轮接入试验视为待授权。整体工厂 v2 的规模与气质评价仍独立保留。

## 开工五问

1. **玩家结果**：看到一段包含直线、转弯和端接头的管路，在不额外放大的情况下辨认两种示例物质、输送方向、停流与空管。
2. **实现介质**：生成像素模块经既有工具机械归一，管体使用 `Sprite2D`；内容与双箭头为动态状态层。试验场景独立于正式设备目录和生产逻辑。
3. **成功证据**：原生尺寸模块及接缝检查、正式 `Boot` 隔离世界截图、常态 / 建造倍率对照和状态切换操作；移动连续性另以时序帧与运行时参数验证，单张截图不替代动态证据。
4. **失败判据**：原生尺寸看不清内容或箭头、金属占比吞没透明段、弯头接缝错位或箭头跳变，均不能以放大截图或新增文字解释为通过。两轮同类失败时停手复盘。
5. **文档落点**：本文件承载本包规格与结论；原专题保留视觉评审，周志记录过程和证据，当前规划与 Daily 仅路由到本包。

## 模块合同

沿用 32px 网格、高斜角、顶面主导、左上光、nearest 采样与现有世界色板管线。以下都是视觉装配坐标，不是新玩法占用或碰撞规则。

| 模块 | 输出画布 | 视觉连接合同 |
| --- | --- | --- |
| 水平直管 | `32×32` | 左右中点 `(0,16)` / `(32,16)`；相邻模块中心距 32px |
| 竖直直管 | `32×32` | 上下中点 `(16,0)` / `(16,32)`；独立光照画稿，不直接旋转横管冒充 |
| 左入下出弯头 | `32×32` | 左中点进入、下中点离开；本包只做这一代表方向 |
| 设备端接头 | `32×32` | 金属端座与水平管对齐；连接视觉样板端座，不接入现有固体设备端口 |

- 透明段内径目标为约 8–12px，管壁总厚度约 14–18px；按归一结果收敛具体像素值并记录，不能更改 32px 单位掩盖不合格素材。
- 接头宽度保持克制，普通直管优先让透明段占多数；接缝必须在重复装配下复核，不能只审单张放大 sprite。
- 静态素材分别承担管壁 / 金属；内容层与箭头裁剪到内部通道，不能覆盖金属接头或越出玻璃轮廓。
- 两种内容色仅为匿名 A / B，沿用青色、琥珀色示例；白色双箭头是独立中性动态标识，不新增物质或重定义全局状态色。
- 运行时演示使用同一条连续路径的距离推进，弯头沿切线改变朝向；停止时保留内容与方向，空管隐藏内容和运动标识。演示速度不等于流量。
