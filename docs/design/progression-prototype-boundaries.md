# Character Progression And Equipment - 原型状态与边界

返回：[Character Progression And Equipment](character-progression-and-equipment.md)

## 当前原型成长状态

截至 2026-06-10，Godot 原型还没有接入完整经验值、职业分支或技能树；当前成长主要通过“任务里程碑 + 基地供给 + 区域适应 + 出发整备判断 + 基地设施收益”五条线体现。

当前已经落地的成长表现是：

- 过滤模块、修复凝胶和抗污染药剂承担早期的环境适应与续战能力；过滤模块已经同时降低污染采集防护消耗和污染敌人反击承压。
- 基础储存箱已作为第一项基地平台后勤设施接入：它不增加角色面板属性，但会让前哨核心在修复凝胶耗尽后补到 1 份，形成“基地建设提高外勤续战稳定性”的早期成长收益。
- 出发整备台已作为第二项基地平台后勤设施接入：它不新增完整装备栏，只把已制造的基础过滤模块装入防护服，让基地基建直接改变外勤污染承压。
- 污染边界门前准备确认已接入：封锁入口会读取基础过滤模块、抗污染药剂和污染浆液携带状态，让玩家在进门前判断是否先回基地整理副产或补药剂；这仍是 demo 级准备反馈，不是完整 loadout。
- 裂相脊之后的每一包推进都要求先把上一跳产物带回基地处理，成长更接近“工业后勤升级”而不是刷怪堆经验。
- 前线回传锚点与基地相位回投台会在裂相脊里程碑后接入，碎晶沟谷前还会增加第二前线锚点，直接降低晚期纯跑图成本。
- 锚定桥东侧的锚场回稳窗会把最新一轮成长收益落成“基地产物改变前线目标结构”，稳窗读数还会把完成态转成可回访的生命 / 防护回充点。
- `S20` 后的基地行动系统已经把补给、测绘、清障、轻量整备模块、风险收益快照和同一前线窗口反馈纳入出发前判断；稳相垫片、回波透镜和防护涂层分别把窗口结果转成稳相缓存样本、透镜校准读数和涂层样本，压力清障还要求先击退清障扰动守卫，连续两轮窗口复盘后还会合并成高压窗口三模块联锁，并进一步开放核心稳定站写入链路，验证基地整备如何改变战斗、探测、防护或回收目标并收束成 demo 终点。
- 核心稳定站段已把终点前整备接到污染边界补料、污染浆液、核心稳压缓冲包、守卫回写缓存和最终设备写入：基地整备会削弱核心阶段守卫第一段压力，守卫败退后的缓存把战斗收益转成写入校验片、基础零件和补给，核心设备还会读取守卫回写校准和抗污染药剂排压来降低最终反冲。

当前生命 / 防护成长也已经从固定基础值改成按裂相脊后半里程碑逐步提高：

- 基础生命 / 防护上限从 `100 / 100` 起步。
- 完成裂相样块、裂相尖塔、裂相锁位、回声台地、盐壳浅滩、碎晶沟谷、风蚀管廊和锁相框架等关键里程碑时，每次生命上限与防护上限各 `+15`。
- 以当前已接入的成长里程碑计算，晚期角色最高可成长到 `220 / 220`，不再让更东侧战斗长期建立在早期基础耐久上。

这意味着当前原型里的成长收益已经不只是“做出更高阶物品”，而是会同时改变：

- 玩家能否继续进入下一段区域。
- 玩家能否在晚期战斗里保有足够容错。
- 玩家是否需要把基地设施、基地整备、回投和补给当成有效策略，而不是只靠有限旧图材料硬撑。
- 玩家是否能把装备 / 模块选择理解为基地生产和外勤目标之间的取舍，而不是传统刷怪掉装。

当前仍未进入正式范围的内容包括：

- 完整技能树或职业体系。
- 大量随机词条装备。
- 系统化经验条和刷怪成长主轴。
- 完整装备 loadout、队员、随机成功率或新成长货币。

短期设计目标仍然是先把“基地生产出的补给、模块、加工产物、可建设施、回投能力和少量装备 / 模块变量会真实改变远征结果”这件事验证扎实，再决定是否继续扩成更重的 RPG 成长系统。

## 数据字段预留

未来角色、装备、技能和模块应结构化，至少预留：

- 稳定 ID。
- 显示名。
- 类型。
- 标签。
- 描述文本。
- 装备槽位。
- 基础属性。
- 环境抗性。
- 技能或效果引用。
- 制造配方。
- 升级材料。
- 解锁条件。
- 适用区域或危险类型。
- 公开等级。

这些字段应能被游戏、Wiki 和官方工具共同使用。

官方工具未来可以支持：

- 装备材料反查。
- 区域推荐装备。
- 药剂和特殊弹药查询。
- Build 方案记录。
- 技能、模块和资源链之间的反查。

## 设计边界

- 不把角色成长做成脱离基地的传统刷怪升级。
- 不把基地科技树做成自动替代角色选择。
- 不用复杂词条堆叠掩盖核心循环不清。
- 不让装备门槛变成无提示的硬墙。
- 不让首版 RPG 系统规模超过原型验证需要。

## 当前阶段结论

角色成长、装备、技能和 Build 的核心任务，是把基地生产和外出冒险紧密咬合。

首版应优先验证：

**基地生产补给和装备 -> 玩家形成远征 Build -> 进入危险区域 -> 带回样本和材料 -> 解锁更强装备与工艺 -> 推进更深区域。**

只要这条关系成立，后续才值得扩展更完整的技能树、装备词条、职业差异和终局 Build。
