# Factory Conveyor Combination Layout V1

更新时间：2026-10-17

## 用途与证据范围

供 [C 组合专题](../features/factory-conveyor-combination-v1.md)的检查驱动共用；坐标是设备足印左上格 `(x,z)`，方向 `0/1/2/3` 分别为东 / 南 / 西 / 北。固定设备不旋转端口，带与附件按方向连接。主代理用正式 V5 模型构造几何夹具，检查了落位、实际端口、同网接电及步长 0.05 的角色碰撞采样：2,726 项通过，84 实体，其中 63 带 / 4 节点。此证据不含正式 Boot、自然行走 / 生产或截图。

夹具与最终日志位于 `tools/runtime-intake/2026-10-17-factory-combination-layout/` 的 `probe.gd`、`layout-report.json`、`probe-b.log`。首次日志使用相对路径被 Godot 按 user 路径解释，创建日志目录失败；该次不作为完整通过，改绝对仓库路径重跑。仅已知系统证书 `ret != noErr` 噪声被单列，其他错误不能忽略。

共用布局已落实为 `client/scripts/checks/factory_combination_layout.gd`；正式 `geometry` 入口的主代理独立批次 `c-layout-independent-20261017-a` 为 3,611 项通过，另验证普通供给数、保留 / 搬迁集合和每个实际输出目标。初探与正式检查的计数不同，不相加作为自然运行断言。

## 起步布局与改接差异

C0 沿 B 起步：保留 collector / basic / solvent / solvent_store / g4 / source_a，以及本表 node_a / node_b；g1 暂放 `(-18,0)`，g3 暂放 `(-10,0)`；起步带为 `x=-17..-14,z=0` 及 `x=-9..-7,z=0`，共 7 带。g3 初始催化剂 2 件、试制后不限量；g4 在试制首件之前配置并启用 4 件。

外矿道后，按专题隔离旧线残料，再回收起步 g1 / g3 及上述 7 带；反应器、主仓、电源和两节点保留。新增催化剂仓临时承接返料，按本表重新放 g1 / g3、其余附件与 63 带。不得把 `place` 的位置覆盖当搬迁，不得直接清货或改实体坐标。第二电源、跨廊节点、富集采集与富集配方仍通过正式建造 / 近身操作取得。

旧件回收统一使用初始服务廊：`(-3.5,5) → (-3.5,1.5) → (旧件 x+0.5,1.5)`，返回严格逆行。它位于机器末端 `z=1` 和新催化剂仓顶 `z=2` 之间；不得从各自 `x` 沿主通路直接北上，否则可能撞 node_a，或在 `z=1.8` 擦入仓库碰撞半径。主代理独立补验该初始布局服务廊 2,235 项通过，日志 `transition-probe.log`；它只在旧布局改接时使用，最终布局的 g2 会占用此横廊。

## 电力与通行

实际自动图唯一链为 `source_a → node_a → node_b → node_c → node_d → source_b`；五台用电设备均接入该网。正常全部工作需求 220 kW、供给 240 kW；不能用该峰值预算代替自然运行需求采样。连线穿外矿道只经过开放格，内矿道未开也成立。

以下点均为人物世界坐标，不是实体足印坐标。检查驱动应沿已验证折线路径自然 WASD 行走；不能在两个已验证端点之间擅自取穿设备的直线。到点仍按正式近身 / F / Tab 权限打开目标，路径采样不能替代实际行走验收。

| 目标 | 从主通路开始的折线点 |
| --- | --- |
| 主通路 | 出生 (-3.5,5.7) → (-3.5,5) ↔ (-18,5) |
| g1 | (-18,5) → (-15.5,5) → (-15.5,1.8) |
| g2 | (-18,5) → (-18,2.6) → (-17.6,2.6) |
| m1 | (-18,5) → (-18,1.8) |
| s1 | (-18,5) → (-21,5) → (-21,-2) → (-17.5,-2) → (-17.5,-1) |

路径返回沿原折线逆行到主通路，再去下一个目标。取样在建线前由出生点自然走到 (2.5,2.5) 并手动确认；起步 g1 / g3 的操作点及实际输入容差由正式驱动补验。紧邻节点 / 设备的路径必须保留角色半径与方向输入偏差余量，实际受阻即停并记录，不传送人物绕过。

C 检查入口沿既有设备交互检查，先设镜头 `yaw=0`，使轴向通道对应真实 WASD 轴向输入；这只改检查镜头，不改人物坐标或碰撞。首个主机自然批次使用默认斜向镜头，自动转向偏离旧件服务廊而失败，保留批次并以新世界重验。外矿道开路前操作点再由 `(2,0.5)` 向前走到 `(2.7,0.5)`，避免停点容差落到近身权限边缘之外。

## 实现前后的复核

主代理已独立执行构造几何检查；后续 C 共用布局模块需按上述坐标复现同一实体集合，状态检查覆盖布局、每个输出目标和人物到点权限。正式 Boot 再证明施工时人物不占位、改接返料、两物料自然生产、缺口 / 修复以及保存接续。布局变更须同时更新本表和检查数据，按实际差异重验；不把文档中的 2,726 项当成新改版证据。
