# Factory Camera Study Layout And Framing

更新时间：2026-11-01

状态：[R1 方案](../features/factory-camera-and-representative-scene-v1.md)的坐标与镜头核算；R1-A 已运行并获萝卜SAMA选择 C2 / 21 格 / 跟随角色，作为后续基线。原作资料见[银河破裂者研究](riftbreaker-camera-and-visual-study.md)；此处数值全部为本项目参数，不是原作参数。

## 控制变量与首轮候选

先同一场景、同模型 / 光照 / 材质 / 实际 3D 视口对照，人物 / 地格不缩放补偿。当前 `view.gd` 的正交 size 在常用宽屏为 21、pitch=50°、yaw=25°、目标斜距 40；它是 C0 来源，不是已认可的最终取景。首轮固定目标 `T=(0,0.25,1)`，保留三张主候选，必要时再进 C3 / C4。

| ID | 投影 | 俯角 / yaw | 垂直 FOV / span | 斜距候选 | 回答的问题 |
| --- | --- | --- | --- | ---: | --- |
| C0 | 正交 | 50° / 25° | span=21 | 40 | 现行镜头参数的局部板基线；目标点为样板固定值 |
| C1 | 正交 | 50° / 0° | span=21 | 40 | 只改变水平朝向，检验过强菱形构图是否主要原因 |
| C2 | 透视 | 50° / 0° | vFOV=35°，中心 span=21 | 33.3017 | 以 C1 为同尺度对照，检验轻度透视观感 |
| C3 备用 | 透视 | 50° / 0° | vFOV=25°，中心 span=21 | 47.3624 | 仅在 C2 近远变化过强时降低透视强度 |
| C4 备用 | 透视 | 45° / 0° | vFOV=35°，中心 span=21 | 33.3017 | 仅在 C2 顶面 / 侧面比例不合适时比较俯角；必须复核遮挡 |

角度约定沿现行相机：俯角从水平面向下算；yaw=0 时相机从 +Z 望向目标，正 yaw 向 +X 转。相机位置为 `T + d×(sin(yaw)cos(pitch), sin(pitch), cos(yaw)cos(pitch))`。近 / 远裁剪首轮保持现行 0.1 / 120，`KEEP_HEIGHT`；同一个 span 不保证所有远近物体占屏相同。

透视中心平面匹配用 `d=span/[2tan(vFOV/2)]`；匹配的是过目标点、垂直于视线的平面。地面倾斜、模型高度及近远变化仍不同，不能称完整画面等价。C2 高于目标约 25.511 单位是此算式结果，不是照抄原作 25 米高度。

萝卜SAMA已选择 C2 / span21：默认角色跟随，保留近身 span16、拉远 span28 与滚轮中间档。正交对照改 size；透视固定俯角 / FOV，沿视线按公式改变距离与相对焦点高度，不只垂直抬高后重新瞄准。21 格相对焦点高度约 25.51 个世界单位；16 / 28 格约 19.44 / 34.01。不是独立的俯角滑条，也不新增自动变焦或自由旋转；正式设置界面后续按同一距离参数接入。

## 主板 P：24×24 的局部现场

逻辑格范围 `-12≤x,z<12`，东 +X / 南 +Z。坐标是左上格，GLB 放在足印中心；整个板与 S1 自然生产布局分开，设备并非已经解锁或喂料。

| 对象 | 左上格 / 足印 | 用途 |
| --- | --- | --- |
| 核心预留 | `(-3,-3)` / 6×6 | A 阶段仅占地测量，B 阶段放新核心模型 |
| 采集器 | `(-9,-2)` / 2×2 | 小设备 / 矿点尺度 |
| 代表反应器 | `(5,-1)` / 3×3 | 主要材质与高度样本 |
| 终端仓 | `(1,6)` / 2×2 | 低矮轮廓与前景对照 |
| G | `(7,5)` / 2×2 | 不同设备家族、状态灯与体量 |
| 节点 | `(2,3)` / 1×1 | 细长结构与遮挡观察 |
| 角色脚点 | `(-1,5)`，沿现有角色尺寸 | 正常取景 / 行走起点，不是存档注入位置 |

核心北侧邻格短带为 `(x,-4)`、x=`-2/-1/0/1`；西侧 `(-4,z)`、z=`-2/-1/0/1`；东侧 `(3,z)` 同四行，共 12 段，只观察空口 / 接带关系，不宣称闭环物流。装配方向由逻辑端口法向决定，不能为取景旋转固定机器或重排核心口。

建议人工抵近路线：`(-1,5)→(-5,5)→(-5,-5)→(4,-5)→(4,5)→(-1,5)`；初步足印留空，但真实模型外伸、角色碰撞和点击路径仍须实机检查。角色与地面 / 设备不为镜头对照临时缩放；视口超边界时明确是局部构图，不承诺整张 24×24 板始终可见。

## 密集板 D 与光照 / 材质对照

另建 4×4 代表反应器阵列：各行 / 列左上坐标 `-8/-4/0/4`，每台 3×3，相邻留一格通路；角色从 `(0,9)` 抵近外围。D 替换 P 的摆件，不与核心主板重叠叠放。以固定少量带 / 货物检查遮挡和流向，列明实际实例数 / 动态状态，不冒充 1,000 台性能负载或完整产线。

L0 沿现有 `_build_lighting()` 参数作为可追溯基线：太阳方向 / 颜色 / 阴影、环境、ACES / 曝光 / SSAO 设置冻结，并记录真实渲染器和分辨率；不由候选相机顺手调整灯光。M0 / M1 比较同一几何 / UV 与灯；若要 L1 中性灯光，另记单独版本和理由，不同时改材质与灯来证明收益。曝光不能随视角 / 状态自动跳变，静态材质评价先冻结动画相位。

## 离线预检与读法风险

`python3 tools/design/audit-camera-study.py` 检查主板占格、12 口锚点 / 邻带、中心平面尺度与示例视锥包围，并读取 17 项候选 GLB 元数据。报告在忽略目录 `tools/runtime-intake/design-references/2026-11-01-camera-study/design-audit.json`，含脚本和资产 SHA-256、材质贴图估算；不改资产或调用 Godot。

首轮 45 项离线检查通过。以 1440×650 / 1100×480 的**示例 3D 视口**核算，主板对象包围落在 C0–C4 视锥内；这不是实际窗口 / 子视口测量，更不证明模型表面未被遮挡。普通窗口目标仍沿当前 1440×900 与最小 1100×720 请求，原生结果 / 实际 3D 像素另记。

在示例小视口，12 口中心最小间距约 C0=18.58、C1=17.51、C2=16.29、C3=16.62、C4=14.93 像素。18 像素级标记在部分候选上已没有足够裕量，因此必须验证近身 span=16；普通主镜头的常驻已配置输出图标仍必须可辨 / 不互遮，完整 ID 可按需显示，不能只放大截图或隐藏图标代签。

若真实最小窗口失败，先调整取景尺度 / 俯角与核心外围结构，再决定是否重算核心足印 / 端口候选；这会影响布局预算，应先更新合同。核心 6×6 / 12 口不因静态锚点合法而冻结。贴图约 113.33 MiB 为未压缩完整 mip 假设值，实际导入 / 显存 / 帧率继续待测。

R1-A 实测主板与密集板已运行，D 使用 16 台反应器 / 15 段直带，起点微调为 `(0,9.5)`，不含货物动画。常规 / 最小窗口实际 3D 为 1440×698 / 1100×533；同主板最小中心距 C0 / C1 / C2 在常规窗口为 27.02 / 25.46 / 23.68 像素，在最小窗口为 20.63 / 19.44 / 18.08 像素。输入为 8 UI 像素色块，输出为 18 UI 像素底框内的 16 UI 像素现有物品图标；随窗口拉伸缩放，不能把名义 UI 尺寸当最终物理像素。

以上为 R1-A 批次，逐图原图 / JSON、原生路径与限制见[R1-A 交付记录](../features/factory-camera-and-representative-scene-v1.md#r1-a-playtest)。三镜头固定同位置的密集对照显示 C0 角色局部遮挡较强；该批未导入新核心 / 贴图、运行物流或得出性能结论，不追改历史原图与测量。

后续 R1-B 已在同一 C2 下导入独立核心轮廓，额外工具栏使实际 3D 为 1440×659 / 1100×503，不能沿用 A 批视口 / 标记间距证明 B。其遮挡检查覆盖 11 个位置 × 3 个距离 × 2 个等级；每口取中心与四个偏移点，角色另取足 / 躯干 / 头部三点，均只检测核心本身的网格。11 月 1 日候选有 96 项端口边缘断言失败。11 月 7 日 `outline-04` 在同一 1,051 项中全部通过。亲测后新 `outline-05` 使用四面 16 口并复用相同采样组合，累计 1,360 项通过；198 个角色样点的结果限所采样点。最终 `outline-06` 调整南侧角饰，保持四面端口，1,360 项通过并获萝卜SAMA认可。各候选分别留证。见 [R1-B 记录](../features/factory-camera-and-representative-scene-v1.md#r1-b-outline-06)。
