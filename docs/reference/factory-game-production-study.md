# Factory Game Production Study

查阅日期：2026-10-17

## 用途与结论

按萝卜SAMA“扩大到官方 Wiki、其他资料与其他游戏，取其精华”的要求，对照六款游戏的生产组织与成品用途。本文补充[终末地社区工具研究](endfield-production-planning-study.md)，用于修订[生产内容扩展 V1](../features/factory-production-expansion-v1.md)，不直接解冻新系统。

建议保留当前“扩建、能源、开拓”三条用途，优先改善它们的关系：直接工艺承担起步和独立供料，混料工艺承担有条件的节材；持续消费与一次性项目分开计算；副产物必须在需求变化后仍有可解释的去处。物品数量本身不是深度指标。

## 六款游戏分别借什么

| 参考 | 可核对的机制 | 对本项目的提炼 | 当前不搬入的部分 |
| --- | --- | --- | --- |
| 终末地 | 官方通讯把探索、工业供货、地区建设及收益联系起来；配方页提供产线异常提示 | 成品应改变可行动范围或生产能力；在物品页显示用途和缺口，设备提示具体阻塞 | 地区货币、交易涨跌、在线共享、整套蓝图系统 |
| Factorio | 基础炼油先提供较简单输出，进阶炼油引入多产物；任一输出满会阻塞整批，裂解可改变产物比例 | 先让玩家完成直接工艺，再引导可选回用；看清“哪种产物堵住”，保留不依赖副产物消费的工艺 | 开局同时引入液气、裂解、控制电路和完整科技包 |
| Satisfactory | 替代配方可以改变原料和加工步骤；Cast Screw 省去铁棒中间步骤；Sink 销毁物品换积分 / 券 | 工艺价值既可以是节材，也可以是少机器、少运输；产物出口与生产配方必须一起设计 | 随机硬盘解锁、万能销毁换币、为保持全厂常转而强造需求 |
| Captain of Industry | 矿渣可粉碎后用于混凝土，多余矿渣可倾倒；贸易合同承担长期资源交换 | 区分“回用价值”和“剩余处置”；扩建停止后再看副产物是否堵住能源线 | 全地形倾倒、污染、居民需求和航运经济 |
| Astroneer | 化学实验室汇合多原料，部分配方使用气体；同一种燃料服务多种移动工具 | 化工产物最好能提升玩家工具能力，未来开拓品不必只是门票；少量共享中间品可服务多个终端 | 多星球、完整大气采集、飞行器和载具系统 |
| Oxygen Not Included | 资源可经不同过程转化，污水既可处理也可作冷却介质 | “废料”由上下游需求决定；未来化工深度可来自工艺条件和联产，而非单纯加长配方 | 热力学、气压、病菌和生存崩溃链；这些会明显扩大当前运行时 |

上表“提炼”为本项目判断，不是来源对 RadishCatalyst 的建议。来源强度不支持精确结论时，仅保留机制层面的候选，不以资料数量制造确定性。

## 对首版方案的实质修正

### 1. 配方应回答“何时值得换”

R05 不吃炭、无副产物，适合起步、炭紧缺和独立电芯线；R08 节省铁矿并给载体提供矿渣，但占用炭、粉碎设备、额外输出和回用能力。R10 在没有矿渣时独立生产载体；R09 利用现成矿渣。R03 与 R14 则在催化剂和载体余量之间选择。

按当前提案，生产 2 包构件的直接路线加工能耗为 3,680 kJ，混料回用路线为 2,840 kJ，后者还同时节约铁矿和晶体。因此不能虚称“混料更耗电”来制造取舍；它的真实代价是炭竞争、机器与布局、需求比例。配方页应显示这些条件，不简单标成低级 / 高级。

E1 的内容范围仍包含两条工艺，但首次目标先指向直接生产并扩建第二台炉，再展示混料回用收益；配方可提前查看，不增加研发树或硬解锁门槛。

### 2. 一个漂亮配平不能代表全厂永远闭环

R08 每 2 金属板副产 1 矿渣；R09 按批量平均把 1 矿渣转为 1 载体。构件包恰好需要 2 板 + 1 载体，所以这条用途能配平。电芯只吃板、不吃载体：如果板全走 R08，即使矿渣全部烧成载体，载体仍会积压。仓库只能延缓回压。

本包建议保留明确的需求分工：扩建包适合混料回用，持续电芯供板可用直接精炼；矿渣或载体积压时减少混料、回到直炼。玩家可混用两工艺，不要求自动策略控制。提示应直说“副产物满 / 载体需求不足”，不能让玩家误判为缺电。

若试玩表明频繁改配方明显破坏体验，再评估额外处置或载体的持续用途；新处置设备、毁料换币、污染和自动出仓均不因此自动加入 E1。

### 3. 成品需求必须区分时间形态

| 成品 | 需求性质 | 当前设计应如何说明 |
| --- | --- | --- |
| 构件包 | 扩建阶段性消费；受空间和实体预算限制 | 有真实建造目标时生产，扩建完成后允许停线；不能称无限需求 |
| 工业电芯 | 由实际同网功率缺口决定的持续消费 | 无缺口就不消耗；制造一件有净供能，不代表整张地图已经有充足的发电需求 |
| 破岩胶囊 | 当前固定支路只消耗 4 件 | 展示剩余需求，允许定量生产后停线；不能按无限每分钟产量计算长期资源压力 |

首版“2 包 + 2 电芯 + 2 胶囊 / 分钟需炭 5 件”的算例，只在胶囊仍需要生产时成立。支路打开后，同一组合剩余炭需求降至 3 件/分钟，恰好等于初始供给；而实际用电不足时电芯消费更低。这个算例不能证明高产炭矿存在长期价值。

因此初始 1 件/20秒、高产 1 件/5秒保留为待试玩的候选节拍，不冻结为已经合理的门槛。先在开路后的实际扩建负载下看炭缺口、发电消耗和等待，再调产能 / 消费；不靠放慢起步矿点强迫玩家等。高产矿接回后应实际缓解问题，否则调整回报或需求安排。

### 4. 通用构件包适合 Demo，但有表达上限

首包保留一个构件包以尽快验证“制造 → 扩建”。缺点是所有设备共享一种购买能力，设备之间的材料身份较弱。后续若能源、化工、物流出现不同经营目标，可让建造配方在基础构件之外分别消耗既有电芯、载体或金属板；先复用现有材料，再判断是否真的需要新增电路、密封件等物品。

这只是后续候选，不在本轮替换构件换算表。不要为了模拟现实，把每台机器拆成十几种一次性零件。

## 当前采用与后续候选

| 优先级 | 建议 | 价值与代价 |
| --- | --- | --- |
| 本提案采用 | 直接工艺先教；同品不同路线的条件说明；矿渣需求变化后的退路；阶段 / 持续 / 一次性需求分开；目标剩余量与具体阻塞提示 | 不增加物品 / 设备总数，使现有 15 物品 / 14 配方更有明确用途 |
| 下一内容包候选 | 固定勘探发现一条替代工艺；可消耗化工用品改善实际开拓工具；建设项目带来新的可用空间或资源能力 | 分别借鉴 Satisfactory、Astroneer、终末地；应按完整玩家结果挑一项，不一次拼齐 |
| 化工深化候选 | 固体吸附 / 分离 / 载体再生，让同一设备体系处理不同原料并回收部分介质 | 比继续堆矿粉名称更贴合定位；需另做物料回路、启动来源与损耗设计，不能将现有消耗型“催化剂”假装成已实现催化循环 |
| 暂缓 | 液气与热力学、污染 / 维护、居民需求、贸易货币、多星球、随机科技、万能垃圾兑换 | 都可能有价值，但会扩大状态、交互和存档边界，不能仅凭参考作品有此功能就加入当前 Demo |

下一步仍是核对修订后的内容方案，再实施 E1；广泛参考的成果应体现在更好的选择、用途和反馈上，不转化为更长的开工门禁。当前没有实现或试玩新链，研究不代替可玩性结论。
