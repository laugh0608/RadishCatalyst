## 科技 / 扩建材料核算

I 阶段先用同一炉直炼 / 直接烧结支付 B1 / M1 / X1，再升级 II；首次供给设置允许顺序启动，不要求开局立即建满全部并行设备。稳定电芯链建成后不应依靠持续切配方维持自举。

| 用途 | 直接成本候选 |
| --- | --- |
| B1 + M1 + X1 + E1 研究 | 金属板 11、载体 4、催化剂 1 |
| I→II | 2 构件包 |
| 首 G | 3 构件包 |
| 额外一炉、一组装 | 各 2 构件包 |
| 首颗工业电芯 | 金属板 1、炭粉 2、催化剂 1 |

9 包展开后全目标共金属板 30、载体 13、催化剂 2、炭粉 2；按 R05 / R10 / R01 / R07，净原料 **铁 60 / 晶体 43 / 炭 1**。对应炉工作 344 秒、反应 20 秒、粉碎 6 秒、构件与电芯组装合计 102 秒；这些是各设备工作总量，可以并行且有阶段前置，不直接求和为玩家时长。

未包含联产 / 回用研究、额外铺带制造、未消费尾货 / 缓冲、路程和配置成本。X1 只要求实际拾样，不消费样本或研究尚未解锁的催化剂，R02 留有唯一实物可用。M2 / M3 的成本依赖 M1 炭粉 / M2 矿渣，按 DAG 与材料可达性核对。

## 供电与供给节拍

| 场景 | 同时运行上界 | 候选核心的关系 |
| --- | ---: | --- |
| S0 双采集 + 炉 + 基础反应 | 140 kW | 基础足够，证明基础连接而非 G 收益 |
| 三采集 + 炉 + 粉碎 + 基础反应 + 电芯组装 | 220 kW | 完整电芯链 |
| 上述 + 载体炉 + 构件组装 | 320 kW | 至少保留这部分其他生产 |
| 核心候选 | 360 kW | 留 40 余量，等级不增功率 |
| 核心 + 一台固定燃烧 G | 480 kW | 增加 120 kW 可用能力；实际收益需自然有料负载证明 |

全待机对应能源七机 22 kW，加入一炉 / 一组装为 32 kW；运行值包含本机附属耗电，不再叠加待机。若增加采集、研究耗电或改配方功率，表格必须重算。

一电芯直接路线需铁 2 / 炭 1 / 晶体 2；纯加工 / 采集工作能 1,960 kJ，毛燃料能 7,200 kJ。G 候选每分钟烧 1 颗；普通炭为 3 件/分钟、R12 单机理论 5 颗/分钟，均不是全链持续产率。核心多口各 1 件/秒不比现有带更快；口和共享矿料的争用、输出空档、上游回压都须进入实际吞吐验证。

## 参数冻结前的剩余证据

1. S1-P 已补载体炉和构件组装的独立离线几何，实际操作量、共享原料分配及终端仓搬运需要在自然路径核验。
2. 用 320 kW 组合从零得到电芯，同时维持其他生产；验证初始研究与制造成本 / 操作量，按结果冻结核心功率。不能拿理论峰值当自然请求。
3. 在不关闭核心、不过量空转下，用后续明确制造目标得到真实 >360 kW 请求；同源比较 360 / 480 下实际完成时间，必要时调整设备目标或 G 参数。
4. 开拓高产炭矿的长期价值、III 材料 / 储能参数、动态负载 PWM 与控制周期后续另核算；旧 360 / 390 理想算例只是设计参照。
5. R1-B 样板已有核心模型及几何碰撞证据；本布局的多口真实物流、Boot / 存读和 Windows / 目标硬件均待后续代码授权与运行验证。本轮离线检查不宣称这些通过。
