# Factory Production Expansion E2 Energy Balance

更新时间：2026-10-23

## 用途与计算口径

支持 [E2 实施合同](../features/factory-production-expansion-e2.md)与[坐标布局](factory-production-expansion-e2-layout.md)。本页公式与表格是设计核算，**不是 Godot 运行成绩**。R12、发电机和设备启停已按确认合同实现；配方 / 矿点与当前代码一致。实际运行证据见文末及 [W43](../devlogs/2026-W43.md)。普通铁矿 / 晶体 1 秒一件，炭矿 20 秒一件；采集均 20 kW。无离线收益、免费燃料或任意变电效率。

区分四个量：额定合计是同时有料时的上界；实际请求由当前在制 / 原料 / 堵塞决定；供能是实际交给设备的 kJ；稳态平均是明确产出速率下的理想能量预算。平均不超预算不保证瞬时满速，能量为正也不证明玩家需要使用电芯。

## 产能与自举

C 有三采集器、一炉、一粉碎、一反应、一组装：`3×20 + 60 + 20 + 40 + 40 = 220 kW`。两套封装电源 240 kW 能承担全部同时请求，不需预放电芯或开路到富矿；G 无燃料仍是导通节点，E 可从同网基础电源获得电力。

普通炭供给上界 3 件/分钟，按一炭一电芯，电芯线原料上界为 3 件/分钟；R12 单机加工上界 5 件/分钟，物流出空会降低，不能把 5 当整线产量。3 电芯/分钟的理想生产负载为 98 kW、毛燃料能流 360 kW；**一台 G 的发电上限仍只有 120 kW**，产得多不会让单机超额输出。缓冲满后上游回压，停止过量生产，不自动焚烧。

单台 G 满输出每分钟消耗一电芯；补产这件电芯的平均负载是 32.667 kW，其余基础 / 电芯供能可供其他生产。两台满输出需两电芯/分钟，仍低于普通炭的理想 3 件上界，实际有限目标下的双机供电与耗尽恢复已验证，长时稳态速率仍不能由这一上界推定。

C 的首颗冷启动受炭矿 20 秒与长炭粉带约束；71 段总带中炭粉路径 48 段。即使加工完全供电也需等实体物料走完，不能把 R12 的 12 秒当作首颗产出时间。正式 Boot 已记录 C 就绪与两电芯到货阶段；它包含施工后行走和配额配置，未单独测量“第一件原料进入到首颗电芯产出”的纯冷启动时长。已有炭库存的恢复仍须单独标注。

## 构件产出与 D 的真实需求

一包直接工艺：4 铁矿 + 3 晶体 → 2 板 + 1 载体 → 1 构件包；加工 `2×480+480+400=1840 kJ`，目标采集 `7×20=140 kJ`，共 **1,980 kJ/包**。

P 的两炉分别做板与载体，单板炉加工上界 7.5 板/分钟，因此整线不超过 3.75 包/分钟；机器出空、长带和首次启动另扣。P 同时请求上限 `2×20+2×60+40=200 kW`，基础供电足够，适合自动备建，不证明能源短缺。

D 设三板炉、两载体炉、两构件组装机，另有一台电芯组装机、一粉碎、一反应、四采集器：

```text
加工设备额定：5×60 + 3×40 + 20 + 40 = 480 kW
采集额定：4×20 = 80 kW
全有料同时请求上界：560 kW
两基础源 + 一 G：最多 360 kW
两基础源 + 两 G：最多 480 kW
```

在恰好 560 kW 同时请求时，基础独供满足率 42.857%，一 G 为 64.286%，两 G 为 85.714%。这是条件算例，**不是 D 已测峰值**；空仓、缺料、目标配额和物流回压会降低实际请求。第二机有提升空间，但不能宣称两台就覆盖所有峰值。

三板炉的加工上界 22.5 板/分钟，必须分给构件与电芯：`2p+c ≤ 22.5`；两载体炉要求 `p ≤ 15`，两构件机 `p ≤ 12`，能源反应 `c ≤ 6`，R12 `c ≤ 5`，普通炭 `c ≤ 3`。铁需求 `4p+2c ≤ 60`，两晶体矿分担 `3p ≤ 60`、`2c ≤ 60`。这些都是加工 / 采集上界，尚未计单件出空、交接仲裁和路由分流。

### 不空耗条件下的平均自供收支

令 p 为构件包/分钟，g 为平均电芯发电 kW，c 为平均燃料消耗/分钟。在能源材料无库存变化且无损失的理想稳态，若构件负载超过基础容量并能连续满用基础电源：

```text
c = g / 120
构件负载 = 1980*p / 60 = 33p kW
补产燃料负载 = 1960*c / 60 = (49/180)g kW
240 + g = 33p + (49/180)g
g = (33p - 240) * 180/131  # 33p > 240
```

低于该阈值时，平滑负载可由基础电源按 `33p` 供电，取 `g=0`；不能仍把基础实际供电写成 240 kW。

| 构件目标 p | 构件平均负载 | 理想所需 g | 电芯 / 分钟 | 判断 |
| --- | ---: | ---: | ---: | --- |
| 6 | 198 kW | 0 | 0 | 平均不需燃料，仍可能有短时峰值 |
| 8 | 264 kW | 32.977 kW | 0.275 | 一机能量预算可承受，实际吞吐待验 |
| 9 | 297 kW | 78.321 kW | 0.653 | 一机仍可承受平均预算，峰值可继续缺电 |
| 10 | 330 kW | 123.664 kW | 1.031 | 超过单机 120 kW，不能承诺一机稳定达到 |

一机理想能量上限 `p ≤ (360 - 1960/60) / 33 = 9.919 包/分钟`，还须满足共同板材、物流与瞬时功率。基础独供的纯构件能量上界为 `240/33 = 7.273 包/分钟`。基础低负载时容量会空闲，不能存到后来抵峰；因此表中 g 是充分利用基础供电时的下界，脉冲负载的实际燃料消耗可能更高。

若离线 / Godot 实际线路只能跑到 6 包/分钟，不能据此声称存在上述 8 / 9 包稳态需求。D 的实施闸门是先记录真实缺口与同目标产出改善，再评价是否值得更长时间经营；本轮不把有限构件预算当作永久消费市场，也不提前宣称 E3 高产炭矿有长期价值。

## 有限制造成本与后续用途

D 最低累计制造 30 包，构件账见布局；E1 已制造第二炉计入其中，不能再收费。按纯直接工艺核算这 30 包，需 120 铁矿 / 90 晶体，目标用能 59,400 kJ；若其中两包已走 E1 回用，按实际配方账替换，不假装此前全为直炼。

从“已花两包造第二炉、现有两包未消费”的 E1 B 终点出发，缺少 26 包；使用 P 直炼需另投入 104 铁矿 / 78 晶体，目标用能 51,480 kJ。P 按加工上界至少约 416 秒，实际含出空、冷启动、走路、制造与铺设更长；这不是首次电芯的等待要求。

D 就绪后再做 4 包，实际制造第二 G 与一个分流器；3 段新增带来自首次十批带制造留下的库存，不再扣包。D+ 总拥有量 258、带全放 208 段、累计制造 34 包。更多构件需求由玩家选择，不自动产生无限订单。

| --- | --- |
| D=100，B=240，有完整电芯 | 基础供 100，G=0，激活数不变 |
| D=300，B=240，一 G | 基础 240，G=60；50ms 扣 3 kJ |
| D=500，B=240，两 G | 每 G=120，实际供 480，缺口 20 |
| D=300，B=240，两 G，一机余 0.5 kJ 无备料 | 一机本步最多 10 kW，另一机 50 kW；合计补 60，不把另一半缺口丢掉 |
| G 余 1 kJ + 一完整电芯，D=360，B=240 | 本步输出 6 kJ；激活一件后余 7,195 kJ，消费仅一次 |
| 孤网缺 60，另网有空闲 240 | 不抵消孤网缺口；只有实际并网才共享 |

数学脚本以有理数核对上表、配方净投入和公式，证据见 `tools/runtime-intake/design-references/2026-10-23-e2-contract/`。实现后的 C / P / D / D+ 已走自然材料与真实构件账。同一 D 检查点独立副本的四包目标，G 关闭 / 开启分别为 55.05 / 41.10 模型秒，后者实际电芯供能 4,634.88 kJ；完整起点一致，累计缺口与各自终点尾货留档。该起点已有上游在制，不能折算为稳态每分钟产量，也不能用它反推每包从零能耗。双机耗尽后基础电源自然恢复能源生产，半批 / 余能独立接续通过；玩家建线成本、5–10 分钟首次收益目标和长期经营价值仍待试玩。
