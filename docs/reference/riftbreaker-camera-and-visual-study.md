## 本次未能确认的参数

- 正式游戏相机的确切正交 / 透视投影、FOV、俯角、水平朝向及全部动态偏移规则：本次查阅的资料未给出足够证据，不填猜测值。
- 官方使用 `isometric` / `top-down` 描述游戏视角，不足以单独证明严格数学等轴测或正交投影；截图有空间感也不能单独证明透视投影。
- 约 25 米是开发者对自家相机高度的描述，不是可直接抄入 Godot 的镜头合同，也不证明用户两张截图恰好采用同一设置。
- 固定高度不等于镜头完全不移动，也不等于玩家一定不能缩放。动态模式、调试自由镜头与普通游玩行为须分开。

## 本项目的实现判断与候选验证

以下为项目建议，不是 The Riftbreaker 已披露的实现细节。

沿用 Godot 3D 是可行的技术路径：[Camera3D](https://docs.godotengine.org/en/stable/classes/class_camera3d.html)支持透视与正交，[标准 3D 材质](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)支持粗糙度 / 金属度及法线贴图。支持这些功能只说明具备实现基础，不承诺同等效果或规模性能。当前项目 `client/scripts/factory/view.gd` 为正交、俯角 50°、默认 yaw 25°，这些是现行实现事实。

| 应分别验证的变量 | 主要影响 |
| --- | --- |
| 水平朝向 | 建筑与网格在屏幕上的朝向，是否形成过强的斜菱形构图 |
| 俯角 | 顶面 / 侧面的占比、建筑前后遮挡与地面可见范围 |
| 投影与 FOV | 近远缩放、边缘形变和纵深；FOV 只在透视候选中讨论 |
| 相机距离 / 正交尺寸、目标点 | 人物与建筑的画面占比、可见地面、角色周围活动空间 |
| 资产与光照 | 轮廓、细节、接地感和地表层次，不能与镜头效果混成单一变量 |

先以两张参考的取景关系为目标，用同一处核心 / 设备 / 带 / 角色 / 地表样板，对齐取景中心与主要物体占屏比例；以轻度透视作为探索候选，与现行正交对照，再分别调整朝向、俯角与尺度，不预设哪项必胜。轻度透视是候选观感描述，不是第三种投影或已查明的原作参数。

样板须观察普通移动 / 停留、近身操作、密集产线、建造网格 / 端口、正常与最小窗口；记录实际镜头参数、原图、遮挡问题和可见规模。首次先识别是否需要局部消隐，方案与授权清楚后再实施，不直接迁入原作 stencil 系统或引入全套高级渲染。

本轮仅网页研究与文档补充，未启动 Godot / 原作、未修改客户端、未安装工具或导入资产；镜头与最终精细度继续待样板审阅。
