## 目标与确认范围

回答两个问题：同一条真实生产线在两个连续 12 分钟窗口内，节拍 / 反馈能否在保留交付的同时减少燃料消耗；断燃时 C3 能否降低缺口而不靠停掉产出获得好看的电力数字。结果服务于玩家用更少燃料维持基地材料生产，并在供燃异常时理解等待和接管。

正常供燃组与 v1–v4 故障组沿用 schema 15，v5 另用 [schema 16 联锁身份](../architecture/factory-load-interlocks-save-v16.md)。两种身份复用正式 Boot、设备面板和真实物流，沿用原配方、360 kW 核心、120 kW × 60 秒燃烧、E2、C1 和 C2。

“真实产线”指所有采集、加工、燃烧、充放电、运输和收货由现行权威模拟实际发生；主成绩由正式场景的单调活动时钟自然推进。预设分段生产命令仍是**诊断负载夹具**，不宣称玩家亲手完成布局、走位或周期操作，也不包装成新的自动排程功能。准备时的定步加速、边沿状态检查、自然时钟成绩、窗口合成输入和玩家亲测分别记录。

O4 / L4 和 O5 / L5 在九个断燃周期按[共用生产状态与采样节拍](#d2-c3-production-state-proposal)开放 A，原订单下达与期限继续沿用。各组“停止新工作”由检查驱动在固定步边界用现行 `set_device_enabled` 实现：到截止点，空闲设备先停用；已在制设备继续，第一次完工后的下个开工步前停用。不得冻结在制、取消返料、清空输入或覆盖 `work_spec`。同一边界先执行预定命令，再由产品 C2 / C3 采样和电力 / 加工 / 物流走原顺序。尾批可能跨到准备段，真实功率和完成时刻必须保留。

A 的 2 批上限是整批工作量，不用离线 25 秒除以 10 秒产生“2.5 个实收构件包”。本轮尚未开工的 A 在 85 秒后仍可等待 C3 放行；每周期最多两项新订单，旧欠单优先，所有组规则相同。每项订单记录下达、首次开批、完工、入仓和是否逾期，不能因缺料或控制等待删掉分母。其他机器按机会表自然开工，记录实际批数，不能强制满功率。

命令夹具可临时使用已校验的可达邻格执行近身命令并恢复人物位置；这类诊断定位、参数设置和瞬时多机操作显式标记，不冒充玩家走位或点击。计分段禁止注入物料、直接改能量 / 进度、改变采集周期、搬运成品、绕过近身 / 配方校验。若现有主循环一次处理多个 tick，需要最窄的检查专用步边界回调，默认关闭、不序列化，并先证明有 / 无观察器 600 步快照一致；不得引入第二套生产时钟或改追赶上限。

## 计量：交付、燃料和库存

### 产出与等待

- R08 主指标为 **F 混料批次所产金属板实际进入核心的累计件数**，通过带 / 端口实际交接和批次来源计数。R05 板材、P0 已有板材不得混入；核心随后输出不倒扣已交付，也不能把核心净库存差当实收。F→A 支路实际耗用另列，不能重复计入核心实收。
- R11 主指标为本窗新生产的构件包实际进入 T 仓的件数；同时记录订单完成 / 交付时间、周期末欠单和最大延迟。旧在途成品即使本窗到仓也按来源单列。
- Fd→Td 板材、矿渣实收与 F2 / R / E 实际生产单列。所有有预定工作的支路均比较；不能牺牲副支路来维持两个主指标。每窗各项实收与对应产出、期初 / 期末输出及在途残留相互校验。
- 每步记录控制阻断、人工分段停机、缺料、出口满、无电 / 比例缺电、在制的原因位图，可同时有多个原因；另给互斥主因展示规则，不把等待时间相加超过总时长。缺口从实际请求与供给积分，不从 C3 预估预算推算。

### 两种耗芯与期末能量修正

设一窗内 `A` 为激活颗数，`R0/R1` 为窗界全部 G 的燃烧余 tick 总和（每颗 1,200 tick），`S0/S1` 为全部 B 的储能 kJ。三项同时报告：

- 整颗激活数 `A`：真实从缓存转入燃烧的颗数，不能用节拍器已送数代替。
- 实际燃烧当量 `C_burn = A + (R0 - R1) / 1200`，与 `fuel_released_kj / 7200` 的增量一致。
- 库存能量修正当量 `C_adjusted = C_burn + (S0 - S1) / 7200`。消耗期初储能计入成本，期末可用储能计作留存；与 `C_burn` 一起达标，避免用第一窗存电装饰第二窗结果。每窗独立计算，不取整后比较。

另按世界全部物理位置清点未激活电芯 `W`（核心、背包、输入 / 输出、带 / 附件、仓和 G 缓存）及 R12 新产量 `P`。计分段无装配、研究、回收、外部输入输出，故必须满足 `W1 = W0 + P - A`；读档和报告不得把缓存、在途重复算一遍。活跃燃烧余能只由 `R` 计算，不再算完整电芯。

逐窗核对 `核心实际供能 + G 释能 + S0 = 实际用电 + 弃能 + 充电损耗 + 拆除损失 + S1`；拆除损失在本实验应为 0。充入、放出、损耗使用整数 J；历史浮点 kJ 差值按已有 1e-9 的快照比较规则处理，并单列账残差，长窗能量账容许的累计数值误差上限为 **0.001 kJ**，不可用于容忍真实缺电或整数物料差。

### 防止吃准备库存

每窗列所有原料、中间料、成品的期初 / 期末物理库存、在制投入、生产、消费与路由。中间料关键集合为铁粉、炭粉、催化剂、金属板、载体；任何一项连续两窗下降，或单窗净减少超过其下游一个配方批次的最大投入量，判定供料未稳定，不能发布长期节能通过。阈值从冻结配方表算出，不能为不同策略单独放宽。电芯和储能按上述完整公式另外处理。

不允许计分段手动清仓；预检证明 T、Td、Ts、余料仓在 24 分钟最坏产出及期初库存下不满。容量不足时重做共同布局 / 父档并重新确认影响，不能只在受阻组中途扩仓。全物料账及整数数量必须精确守恒。

C3 保留在制和待机，且预算不是供电优先队列，因此故障组**不设零缺口承诺**；必须同时报告剩余缺口、推迟时长与各支路交付。这个口径替代把离线“移动 A 的 25 秒工时后缺口为零”直接当实机结论，不修改 C3 产品行为。

结果分别标记 T 通过 / F 通过 / C3 通过、对照无效、产品错误或策略未达标。只通过 T 不能宣布 C2 收益通过，控制正确也不代表节能收益已通过；D2 长期验收要求三项均完成或由萝卜SAMA明确接受剩余项。即使三项通过，也只适用于本负载和本机，不代表最优调度、一般场景节能比例、玩家体验或目标平台通过。

## C3 故障对照 v3 · A 开工相位

**萝卜SAMA已确认 v3 时表、预检门禁和报告单位。** v1 断燃区间内 G 无燃料，C2 已因电量高处于阻断，B 仍覆盖最高 40 kW 的基础供电差额，两窗实际缺口均为 0。v2 的 G 真正燃尽，正式断燃至恢复供能期间，O2 两窗缺电量达到 0.374962 / 0.430785 kWh。故障压力成立，但工作开始的时点仍早于集中用电。旧证据见 [v1](../devlogs/2026-W46.md#d2-long-comparison-preflight)与 [v2](../devlogs/2026-W46.md#d2-c3-fault-v2-preflight)。

### 时表

故障对照采用 **O3 / L3**。两组沿用 v2 的供燃时表和 600 / 1320 秒恢复命令。每周期的两项 R11 订单仍在相位 60 秒下达，截止仍为相位 120 秒。只有正式断燃内的九个集中加工周期将 A 的**最早允许开工**从相位 60 秒移到 65 秒。其余设备从 60 秒按原合同工作，Fd 仍在相位 85 秒后只排空尾批。A 已开工的批次继续正常完工，旧欠单照原顺序保留。

| 24 分钟中的周期 | A 最早开工相位 | 用途 |
| --- | --- | --- |
| 1、6、12 | 60 秒 | 保留首次供燃和两次恢复窗口的原工作时表 |
| 2–5、7–11 | 65 秒 | 其余设备先加工 5 秒，随后两组同时开放 A，首个预期采样步为相位 65.05 秒 |

65 秒命令在固定步前走现有启停入口，之后 A 按原工作表保持开工机会，物流照常供料。L3 使用原有采样周期和迟滞，预算余量小于 0 kW 时阻断，已阻断后达到 20 kW 才放行。例如 360 kW 可持续供给遇到含 A 的 382 kW 候选需求时，余量为 −22 kW，A 被阻断会将其当步额定请求从 40 kW 降至 4 kW 待机。全窗能否减半仍取决于阻断时长、其他设备进度和后续开批。两组共用的五秒延后本身没有 C3 收益归属。

时表在执行前冻结，禁止根据各组瞬时需求、C3 状态或缺口移动 A 的开工相位，禁止重置 C3 倒计时。旧轨迹中的 65.05 秒只是选定相位的依据。前五秒 A 处于停机可能改变供电比例、加工进度和来料，必须由新样本确认 65.05 秒的候选及预算。

交付的主要风险是回差等待。v2 部分周期 Fd 尾批到相位约 93 秒才结束。如果 L3 要等到这附近才获得许可，距订单截止约 27 秒，其中 A 两批额定工时共 20 秒，还需留出来料、比例供电和入仓的时间。若提前放行又使第二批撞上峰段，也可能触发阻断而未达到全窗减半。两类结果均按原期限和收益线实测。

故障对照使用 **O4 / L4**。共同准备将 F2→A 的单格带换为位于 `(-13,13)` 的朝东分流器。东口继续接 A 西上口，北支路经 `(-13,12)`、`(-14,12)`、`(-14,11)` 接入锚点为 `(-13,10)` 的独立载体余料仓。原拟南支路中间带会同时连接 F2 第二物理出口，触发单入口校验，因此改用等长北支路。分流器与仓库合计装配成本 3 个构件包，支路占用 3 格库存带，替换带及其货物经正式命令回收并入账。按每周期 60 秒工作机会加一次尾批计算，24 分钟最多 108 件新增载体，计入期初 3 件后上界为 111 件，低于 200 件仓容。

正式断燃的原九个周期（第 2–5、7–11 周期）仍在相位 60 秒下达两单，周期末截止。A 的第一批开工机会取**订单下达后首个满足下列生产状态的常规采样步**。两组使用同一条件，先在步边界完成其他设备的原命令，再读取上一完整步留下的生产状态。

1. A 有待开订单、空闲、输出缓存为空，配方投入齐备。就绪检查仅忽略夹具当前的 A 停机开关和 C3 许可，实际启用走现有近身命令。
2. F2 已在本周期实际开出新批且仍在制。F、Fd、R、E 各自在制或按原生产规则已经可开批；I、Q、Kh 可采集，C / Ci 至少一台在制或可开批。按现有配方的 C3 名义功率口径，这组负载含 A 至少 380 kW，核心容量为 360 kW。实测的供给、预算和负余量继续由产品计算。
3. 取与 L4 原 C3 对齐的公共采样网格，两组均用相对固定步号判断。C3 自首步起按原每 20 tick 采样，核对 L4 当步确实评估。生产条件达成若落在采样间，保留 A 停机，在下一采样步重新检查全部条件。驱动不读取实时缺口、预算余量、C3 决定或对方组数据来选择开工时点。

达成后，两组各自启用 A，此后本周期两单按原工作表继续，允许在制正常结束。若条件未出现，记录原因和欠单，保留原订单及期限，禁止按另一个固定秒数兜底。第 1、6、12 周期仍用原工作表。保持 v2 的供燃命令、C1 相位、C2 阈值、A 单成员和 C3 保留量。

### 同源与验收

- 原 P0 继续供 N / B / T / F 使用。故障对照从它派生一次，依法装配并核账，重新核对空 G / 空 B、无计分在制、库存上限、路径及成本后冻结故障 P0。O4 / L4 从同一个新父档的字节副本开始，策略差异只有 C3 开关。这项调整需要将原六组共用同一份 P0 的约定改为共同祖先、各自组内同档。正常四组的 P0、产线、工作表和门槛沿用原合同。
- 每组在自己的真实产线上运行同一规则。C3 造成的后续生产和来料差异可能令开放 tick 不同。预先固定规则，按同一周期、同一订单和相同就绪条件记录触发，保留每个未触发和不同步的周期。每窗至少一对真实证据须显示 O4 的 A 开批、L4 的 A 在同类生产状态下采到负余量并被阻断，随后恢复并开出同一订单。成对证据核对两组 G 均已燃尽、当时 B 电量和实际缺口，排除首次点火等待。实际时刻和当时状态随结果披露，两窗成绩仍按原连续 720 秒整窗对比。F 继续作为正常供燃背景，C3 收益只用同线 O4 作分母。
- 确认后先用真实物流证明 A 满载体时 F2 能经余料支路清空并再开工，且 A 仍能补料；记录 F2 出料、带与仓交接、F2 开批、A 启用、C3 样本、A 扣料及入仓的相对 tick。再做完整 O4 / L4 成对固定步预检。原每窗故障归因缺电 ≥100 kJ（约 27.78 Wh）、减半、三项实收分别 ≥95%、无新增逾期、120 秒恢复、两种耗芯不增及账本门槛继续执行。任一门禁失败保留全量证据并停止。自然长测与跨进程恢复仍以完整预检通过为前提。

结论范围为具有独立载体出路、按生产状态开放 A 的故障产线。报告用 kW、kWh / Wh，原始账本保留现有精度。

### v4 复盘与错峰可行性方案

v4 样本有效。现有 C3 每秒按步初就绪状态给出许可，A 开批后保留在制，下一批可沿用上次决定。它能阻止 A 在首次峰值开工，但未把后续两批移出 F2、Fd 持续重叠的时段。负载设计使这个局限暴露出来：相位 85 秒只是 Fd 停开新批的命令，L4 的尾批实际延续到相位 92.90–93.10 秒。两窗放行后的缺电增量主要集中在 A 的第二批。逐步分解见 [W46](../devlogs/2026-W46.md#d2-c3-fault-v4-review)。

**萝卜SAMA已确认并完成错峰诊断。** 诊断验证同一条线是否有足够的真实错峰空间。沿用 v4 的故障父档、设备、配方、库存、供燃命令及原周期工作量，新增一组 C3 关闭的诊断对照。九个正式断燃周期用共用的 v4 条件记录 A 何时具备开工机会，再保持 A 停机，直至 Fd 已过原停开边界、实际排完尾批并停机。随后用现有命令开放 A 连做原有两单。首次供燃与两个恢复周期沿用原工作表，禁止取消 Fd 尾批、缩短其工作窗口或改 A 的订单期限。沿用 v4 原派生档的字节副本，与 O4 比较这项排程的效果，保留 L4 作为现行 C3 的成绩。正常 N / B / T / F 继续使用原 P0 和原工作表。

计算依据是 Fd 停机后的额定负载上界约 300 kW，A 开批后约 340 kW。v4 已见 L4 在 Fd 停机后还有 26.90–27.10 秒至订单截止，A 两批名义工时共 20 秒。新排程会改变负载和加工进度，须按实际尾批、载体与板材到料、R11 入仓验证。先核对首个诊断周期的 Fd 真正停机及 A 两单交付，再完成连续两窗的固定步诊断。用 O4 同窗作为参考，继续核对缺电量减半、R08 / R11 / Fd 实收各 ≥95%、无新增欠单、恢复期限、两种耗芯、仓容和账本。原 C3 的故障资格与收益验收线继续适用于未来 C3 成对验证，手动错峰诊断单独记录。

若诊断在两窗都达到缺电与交付目标，说明原产线有可用的错峰时段，可据此另审给 C3 增加明确的开工前置条件或玩家可配置的联锁，让两批 A 等到 Fd 真的停机。若诊断未达标，先按真实到料、可用工时和交付结果判断产线调度是否可行。任一结果都保留 v4 的策略未达标结论。C3 规则调整和自然长测等待萝卜SAMA确认，跨进程恢复仍停在现有门禁。
