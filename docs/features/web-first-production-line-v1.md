# Web First Production Line V1

更新时间：2026-09-06

状态：有限实现、模型检查与浏览器操作路径已完成；等待萝卜SAMA亲测理解、操作与继续建设意愿。

## 授权与玩家结果

萝卜SAMA在视觉与引擎探索后表示迷茫；执行会话建议暂定当前 Web 三维画面，下一包验证“第一条亲手搭起来的三维产线”。用户回复“好，就按照你的建议做”，授权本专题、对应规划切换与有限 Web 实现，不代表正式工程迁移或视觉定稿。

玩家在当前三维工业场坪亲手放置采集器、反应器和终端仓，铺设有方向的传送带，看到晶体进入加工、催化剂进入储存；随后拆开线路使供料或出料停止，补接后恢复。此包的价值是判断这种画面是否能承载愿意继续建设的工厂操作。

## 开工十问

1. **动作**：选构件、网格放置、旋转带、查看设备、拆改回收与补接。
2. **世界变化**：空场坪形成真实生产链；连接、错向、缺口与回压影响物品移动和加工。
3. **产品方向**：直接服务生产 / 物流 / 布局主循环，探索和战斗保持后续边界。
4. **感知**：目标 5–10 分钟内搭出首条产线并经历断路恢复；这是用户体验目标，不能由加速测试宣称达成。
5. **系统**：在独立 Web 试验中实现有限确定性网格模型；复用 Godot 的核心节拍、足印、端口与守恒语义，不移植完整运行时。
6. **素材**：复用本轮 Three.js、工业模型部件、配色、角色与场坪；只新增必要的真实传送带、晶体 / 催化剂与端口几何，无新依赖或外部资产。
7. **证据**：纯模型规则 / 守恒测试、真实浏览器放置与连接路径、关键状态截图，最终体验由用户评价。
8. **失败**：先区分操作、物流规则和可见性；同类两轮失败停止追加同类提示并复盘。
9. **旧实现**：借用既有三机固体链以减少变量，不恢复全部旧功能或把历史验收当本轮通过。
10. **阶段价值**：先验证愿意继续搭建的小工厂，完成后再讨论实现平台；不以扩展工程规模作为成功。

## 固定范围与规则

- 在 `tools/visual-studies/web-topdown-3d/production/` 实现，入口 `/play/`；原 `/` 视觉对照保留。画面暂定 55° 俯角与原配色，允许原有 Q / E 转角及缩放用于看清操作。
- 厂坪预供电、晶体矿点预置、构件各 1 件及 24 条带预发；起点没有被测设备、货物或产线。采集器只能落在矿点，设备不能重叠、越界或压住角色。
- 足印沿用采集器 / 仓 `2×2`、反应器 `3×3`、带 `1×1`；设备固定朝向。端口沿用采集器本地 `(1,1)` 向右 OUT，反应器 `(0,2)` 向左 IN / `(2,2)` 向右 OUT，仓 `(0,1)` 向左 IN。
- 采集 `1 crystal/s`，缓冲 50；反应器输入 2 / 输出 1，批次开始原子消耗 `2 crystal`，10 秒完成 `1 catalyst`；输出满不开始下一批。运输 `1 格/s`，每带一件，接收须满足真实格位、入口与方向。转角支持正交输入，反向对撞不接收；多路争用按轮询公平接收。
- 终端仓沿用 200 容量并只收晶体 / 催化剂；本包固定为接收终点，省略 supply / transfer 切换、核心和无线转运，不冒称与原 Godot 完整储存系统等价。
- 模型使用固定时间步，画面只呈现权威货物及进度；后台标签暂停推进，无离线产出。刷新重新开始，无游戏存档或正式 schema 改动。
- 拆除明确执行“回收构件和全部内容”，先验证随身回收容量 200，再原子回收；在制批次按 2 个晶体回收，不能吞物、复制或在失败时部分拆除。此局部交互比旧 Godot 的载货禁拆更直接，保持同一守恒原则。回收货物可明确投入选中设备的有效缓冲 / 仓，不自动注入产物或模拟成功。

## 玩家路径与画面

1. 页面直接进入空场坪，短目标提示引导在青色矿点放采集器；建造栏显示构件和剩余数。选择后出现合法 / 非法足印，错误原因可读。
2. 放反应器和仓，端口在建造时显示 IN / OUT 与方向。设备位置自由，给出可关闭的参考位置；参考只帮助第一次落位，不代替真实输入。
3. 逐格铺带，R 转向；设备选择面板说明真实库存与状态，世界货物、运行灯和加工进度能独立表现缺料 / 加工 / 出口堵塞。
4. 首件催化剂到仓后，引导拆掉一段输入带，等待反应器耗尽已有输入后真实缺料；补接并再次收到产物才完成恢复步骤。输出堵塞可自由尝试并由定向测试 / 浏览器路径复核。
5. 完成后留在当前场地继续调整；显示本次收到的催化剂与完成事实，不替用户回答“是否好玩”。

WASD 移动在建造时可用；世界点击按“活动预览 → 选择设备 / 带 → 移动”处理，UI 不穿透。Esc 逐层取消预览、关闭选择、退出建造；保留可触达按钮，键盘快捷键不是唯一入口。页面支持桌面及窄屏布局，正式评价以桌面为主。

## 验收与隔离

- 模型覆盖放置失败原子性、端口方向、直带 / 转角、争用、缺料 / 回压 / 恢复、拆改与回收容量、计时一致性、全程晶体当量守恒；预发构件数量也须守恒。
- 浏览器实际点击放设备与带，观察首件产出、拆输入后缺料、补接恢复；至少一条输出堵塞 / 恢复路径。定位可用 DOM 暴露的网格按钮 / 提示，不能写隐藏状态或用内部放置方法代替用户路径。
- 日志放 `tools/runtime-intake/check-runs/web-first-production-line/`，截图放 `assets/art-intake/2026-09-06-web-first-production-line/`，均忽略提交。不改正式 Godot Boot、存档、玩法或像素标准，不新增液气、战斗、地图、联机、部署和发布。
- 完成匹配 Node 测试、浏览器复核、`./scripts/check-repo.sh`、文档 / 文本与 diff 检查；只报告真实执行结果。玩家能否独立理解、是否顺手、是否愿意扩建由萝卜SAMA亲测，不能用测试数量代替。
