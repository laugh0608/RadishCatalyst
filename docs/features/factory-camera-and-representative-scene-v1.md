## 玩家结果与设计闸门

- 玩家能辨认角色、核心与加工设备，判断可走区域、物流口与流向；在拉远布局和近身操作之间保持空间关系。
- 同一场景先比较镜头，再增加新核心 / 代表材质，确认靠近《银河破裂者》参考的现场感；参考的是取景与品质关系，原作未披露的投影 / FOV 不作事实。
- 介质沿 Godot 3D、导入模型和真实场景，动态网格 / 端口标记只作辅助；不做整幅背景板或第二个正式游戏客户端。
- 成功证据为参数可追溯的同场景原图、原生移动 / 点击 / 建造观察、遮挡记录及性能对照；离线数学只作前置筛选。
- 失败为角色 / 关键端口长期被挡、密集设备不可辨、最小窗口标记重叠、移动或点击错位。两次同类调整仍失败，按[决策闸门](../process/development-decision-gates.md)停手归因。

本包首先新增的是观察与审阅能力，不承诺核心玩法、研究界面、完整能源链或新存档已可玩。角色现场与产线可读性服务后续经营 / 开拓循环；5–10 分钟样板应足以暴露取景与操作问题，不复活旧 ARPG 系统。

## 场景与交互边界

主板为 24×24 格局部构图，核心预留 6×6，含 12 段独立口邻带；另有 4×4 反应器密集板。两者均是几何 / 材质夹具，不是 S1 完整能源布局、真实供给新档或经营收益证据。

R1-A 使用双存档根隔离的正式 Boot 挂载独立样板，不添加正式新建世界身份或 schema 9。复用既有移动 / 碰撞、模型射线与选中轮廓，夹具不运行生产或保存世界；新核心仅几何预留、12 口标尺及六个现有物品图标的密度示例，不展示伪造库存、研究或供电。

镜头参数和审阅配置为样板数据，不写玩家世界；模型 / 材质变体在样板局部实例隔离，不能修改全局缓存材质。鼠标射线、物品屏幕定位、UI 坐标换算、WASD 与镜头朝向均需复核；换投影不改变网格、碰撞、模拟 20 Hz 或设备端口定义。

普通取景默认跟随角色，对照按钮可锁同一目标点；固定图与跟随证据分别记录。萝卜SAMA已选 C2 / span21，滚轮向上拉近 / 降低、向下拉远 / 升高，当前边界 16–28；俯角 50°、yaw=0°、vFOV=35°不随缩放改变。默认 21 格按钮仅恢复观察距离，不重置人物或切换投影。正式设置菜单随后续客户端整合接入，本轮不新增持久化、自动变焦或自由旋转。若需消隐，先记录遮挡来源，再独立确定方案，不直接搬原作 stencil 系统。
