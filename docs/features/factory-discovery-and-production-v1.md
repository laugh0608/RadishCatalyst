# Factory Discovery And Production V1

更新时间：2026-09-25

状态：设计提案，待萝卜SAMA确认实施范围。已授权整理下一包设计；以下名称、数值、地图与 schema 2 均未实施或获实机验证，不替换现行 schema 1 合同。

## 玩家结果与取舍

玩家在矿道口发现矿壳样本，回基地理解其用途并试制解壳剂，接出可重复生产的化工链；携带成果打通矿道，进入此前不能到达的区域，建设富集晶体产线，再用更充足的产出打开第二处矿道。

本包验证“我能用自己的工厂改变可行动、可建设的世界”。固定发现保证主线可达，试制确定成功，成熟工艺稳定复现；惊喜来自首次发现及其用途。本包不验证随机发现、概率试制或多分支研发的乐趣，后续须另行设计。

建议以化工制剂开路承接[发现到掌握](../design/discovery-and-industrial-reproduction.md)，暂不选需要装备、耐久、伤害和撤离规则的防护服方案。能力表现为新增“处理矿壳、开通矿道”动作及永久世界变化，不引入通用装备或技能树。名称与反应均为虚构游戏规则，不表达真实化学工艺。

## 基础电力的接续与联合设计

2026-09-25 萝卜SAMA明确提醒电力系统不可遗漏。电力是工厂经营的正式建设项；本稿预供电只承接首包验证状态，不能成为长期免费供能决定。下一项设计工作先补三维工厂基础电力专题，再与本包联合审阅，确定先行或合包顺序；未确认前不按永久预供电冻结 D2 存档与生产合同。

电力专题至少须回答以下问题，并给出可实施的首包范围：

| 设计内容 | 必须明确的玩家行为与合同 |
| --- | --- |
| 发电与自举 | 电源如何获得、启动与扩容；首套供能不依赖尚未通电的产线，缺电后有可恢复路径；燃料消耗是否纳入首包另行比较 |
| 输配电与开拓 | 电源如何连接设备、向新矿区延伸；覆盖范围、连通关系与可见线路如何表达，不把开通矿道等同于已经通电 |
| 供需与运行 | 发电能力、设备负荷、待机 / 加工耗电和不足时的分配规则；明确采集器、反应器、仓库及传送带各自是否用电，不能仅以通电图标冒充供需系统 |
| 停复电与保存 | 在制投入和进度保留，断电不偷跑、复电不重复结算；持久状态与可重建电网分开，覆盖拆电源、断网和跨进程恢复 |
| 玩家反馈与资产 | 区分缺料、回压、未接电、供电不足；明确发电 / 输电实体资产与正式入口截图、人工复测要求 |

旧二维[建造与二值电网](slice-building-placement-and-power-grid-v1.md)仅提供历史经验；其核心 / 中继和通断规则不是三维工厂的现成发电、负荷与储能系统，不整包迁入。本轮不提前冻结发电机类型、连接距离、功率数值、储能、复杂电气仿真或电力存档字段，也不为尚未确认的电力系统预埋空框架。

本稿设备数量、产能、地图可建空间与时长均须在电力方案确认后复核；下列配方速率只表达充分供电时的加工上限。新旧世界兼容提案保留，具体 schema 字段须与电力实施顺序一起确定。

## 20–40 分钟目标路径

下列时间为设计目标，包含首次阅读、搭线、往返和调整，未经过玩家计时；不能靠提高等待时间凑足时长。

| 时段 | 玩家动作与反馈 | 世界 / 生产变化 |
| --- | --- | --- |
| 0–5 分钟 | 正式 Boot 新建“勘探工厂”，接通普通晶体 → 催化剂首线；可见矿道轮廓及附近样本提示 | 第一批催化剂有明确的后续用途 |
| 5–10 分钟 | 步行到外矿道，调查并拾取保证存在的样本；看到阻挡原因、开路需 4 份解壳剂及深处矿体 | 发现信息留在工艺面板，可随时回查；不自动扣料 |
| 10–15 分钟 | 从仓取料，在空闲反应器投入样本和催化剂试制；产出 1 份解壳剂，看到性质解释与量产配方 | 首次成功成为稳定工艺；试制产物可用于第一次开路 |
| 15–22 分钟 | 将催化剂反应器输出接入另一台解壳剂反应器，再接终端仓；诊断缺料 / 堵塞，取足 4 份 | 可重复生产开拓物资，接线与吞吐决定准备速度 |
| 22–30 分钟 | 到矿道口显式使用 4 份制剂；进入内矿区，放置采集器，将富集晶体送入高收率加工线 | 矿壳消退、通道可走可铺带；真实新产线输出催化剂 |
| 30–40 分钟 | 观察原料供给变化，决定保留普通线或重接富集线；量产 8 份解壳剂打开第二段 | 新增更大可建区与两个富集矿点；保存重进后继续经营 |

顺序不是脚本强迫：可先发现再建首线，已知配方后可手工投料或另建专线。阶段提示从事实派生，不因跳过某个提示卡死。首轮目标以第一矿道、回流生产成立为核心；整包还需第二矿道证明工艺可复用。

## 固定地图与资产表达

- 建议新 `map_id=factory_discovery_yard_64_v1`、`ruleset_id=factory_discovery_v1`；坐标仍为 `[-32,31]`，不扩世界或加载第二张地图。
- 基地区建议 `x=-32…3`，内矿区 `x=8…19`，深矿区 `x=24…31`；`x=4…7`、`20…23` 为矿壳带。每条矿壳带在 `z=-2…1` 留出处理后可通行的 4×4 矿道，其余部分持续阻挡，延伸到地图边界，不能绕行。
- 普通矿点建议 `(-20,-13)`、`(-8,-1)`、`(-20,11)`；内矿点 `(10,-1)`；深矿点 `(26,-13)`、`(26,11)`。均预留采集器足印、端口和人物通道；实际布局须先通过场景审阅再冻结，不能仅用坐标表宣称可玩。
- 外矿道样本点建议 `(2,2)`，出生点沿用基础世界附近位置。普通供给仍为 8 采集器 / 16 反应器 / 8 终端仓 / 256 带，物料为零。首轮只需少量加工设备，构件制造暂不引入；电源与输电构件、初始供能条件由基础电力专题补齐，当前供给表不是含电力的完整开局清单。
- 未开通区拒绝人物进入、建造、拖带和隔墙交互。处理矿壳要求相邻可达位置；打开后地形占用与拾取一起更新。使用世界坐标、碰撞和模型规则一致校验，不只禁用按钮。

| 可见对象 | 资产来源与审阅要求 |
| --- | --- |
| 工厂、人物与场坪 | 复用正式 `client/assets/factory/` 的导入 GLB、Node3D 和原画面参数 |

## 物料、配方与成本提案

| 稳定 ID | 玩家名称 | 来源 / 用途 |
| --- | --- | --- |
| `crystal` / `catalyst` | 普通晶体 / 催化剂 | 保留原基础链，催化剂进一步用于制剂 |
| `crust_sample` | 矿壳样本 | 外矿道固定唯一拾取物；首次试制消耗，不允许复制、丢弃或销毁 |
| `crust_solvent` | 解壳剂 | 处理两处矿壳，成本分别为 4 / 8 份 |
| `rich_crystal` | 富集晶体 | 新矿点由原采集器自动开采，作为高收率原料 |

| 配方 ID | 输入 → 输出 | 加工时间 | 可用条件 |
| --- | --- | --- | --- |
| `basic_catalyst` | 2 普通晶体 → 1 催化剂 | 10 秒 | 初始可用，原规则保持 |
| `solvent_trial` | 1 样本 + 2 催化剂 → 1 解壳剂 | 10 秒 | 拾样后可选；成功后记录工艺、结束唯一试制 |
| `crust_solvent` | 2 催化剂 → 1 解壳剂 | 8 秒 | 试制成功，允许连续自动加工 |
| `rich_catalyst` | 1 富集晶体 → 3 催化剂 | 12 秒 | 试制分析同时记录，界面提示原料位于矿壳之后 |

- 试制面板先解释“矿壳可被针对性制剂处理”，明示投入、确定产物和成功后的工艺；不设置付费式反复抽取或故意失败分支。缺材料属于可纠正条件，不能扣料后报错。
- 矿源沿用首包无限开采假设；普通 / 富集采集器均每秒 1 件、缓冲 50。不借本包增加矿源枯竭、手动反复采矿或资源再生计时。
- 单台反应器无物流开销时，普通路线每分钟 6 催化剂，富集路线每分钟 15，理论上限为 2.5 倍；多件出料与回压会降低实测值。新矿不直接给升级数值，玩家须建线、选工艺、接物流才能取得回报。
- 首次 4 份制剂含试制的 1 份，总计 8 催化剂、16 普通晶体及 1 样本；基础反应器纯加工需 80 秒，试制 / 制剂合计需 34 秒，可部分并行。该计算不含路程、搭线和带上运输。
- 第二次 8 份制剂需要 16 催化剂；富集加工 6 批用 6 晶体 / 72 秒产 18 催化剂，余 2 件；制剂加工 64 秒。采用普通线也能完成，不把第一条富集产线变成隐藏硬门槛。
- 优化选择来自复用一台反应器切配方与另建专线、普通原料与富集原料、短运输与保留既有布局。暂不添加第二套同用途配方；若实测只是等计时器，先改可行动内容和瓶颈，不能用更长时间充当经营深度。

## 设备、交互与失败恢复

- 反应器一次选择一种配方；输入只接收当前所需物料且最多存一批，输出最多存本配方一批（1 或 3 件）。开批原子扣除全部输入，保存具体在制投入；输出未清空时不开下一批，每次传送仍转移一件。
- 选配方仅在无在制、输入与输出均为空时允许；面板说明剩余物料及取出操作。取消在制必须预检背包，原样返还本批投入再清空进度；不同时保留产品，也不重复解锁。试制可如此取回唯一样本。
- 新世界设备面板提供按物品“取 1 / 全部”“放 1 / 全部”；全部指本次可转移数量，显示实际数量与剩余，零空间零变更。仅能在人物距设备足印 2 格内、同一可达分区操作，不能远距调料。
- 背包和终端仓仍各总容量 200；输入、输出、背包、仓库与在途库存分列。普通材料可选放，样本不自动进入传送带或无关设备；试制用显式投料。终端仓本包仍无输出口，连续线为“采集器 → 催化剂反应器 → 制剂反应器 → 仓”。
- 拆回任意设备先检查全部缓冲、在制投入和构件的可回收性；背包不足时完整拒绝。带上富集晶体 / 制剂同样完整回收，不能仅适配旧两种物品。
- 拾样时背包已满则样本留在地面；调查记录可保留。样本只可能处于地面、背包、仓、试制输入 / 在制或已研究之一；试制产出后不再生成新样本。
- 开路为明确按钮动作，显示“消耗 4 / 8 份，永久打通”；物料必须在背包中。距离、前置矿道、库存全部满足才一次扣料并更新地形；重复点击、旧目标和隔墙操作不扣料，不按住逐帧扣除。
- 开路动作不设可中断演出时长。保存按原合同：成功存档恢复开路后的完整状态；未保存崩溃恢复上次完整状态，材料与矿壳一起回退，不补造“已经持久化”的承诺。已有坏档 / 锁 / 保存失败保护仍适用。

## HUD 与可读性

- 保留建造和设备反馈主布局；增加一张可关闭的当前工艺 / 开拓提示，展示发现来源、产物用途、背包所需 / 已有数量和可执行下一步。工艺记录可重开，不堆通用任务日志。
- 设备面板明示配方、输入缺口、逐件输出、加工进度与堵塞对象；普通线和富集线各自反馈，切配方失败给具体阻塞原因。
- 矿道选中信息区分“未调查”“制剂不足”“可处理”“已打通”。样本和矿区用模型、轮廓、空间位置与文字共同辨识；提示应引导玩家查看真实矿体，而非让玩家盯清单交材料。
- 关闭面板后恢复原建造 / 移动输入合同，点击 UI 不在世界触发拾样、处理或建造。普通尺寸、最大化、拉远与遮挡分别审阅，新增信息不得挤掉关键存档错误。

## 状态、存档与兼容提案

建议只在新建“勘探工厂”使用工厂 schema 2；原“基础工厂”及已有 schema 1 世界继续原地图、规则和保存版本。列表显式标注世界类型；不自动给旧工厂插入矿壳，也不要求用户丢弃旧档。旧二维 schema 10 入口仍隔离。此版本分流方案须随本专题确认，再更新[正式存档合同](../architecture/factory-world-state-and-save-v1.md)。

| 权威数据 | 拟增量及约束 |
| --- | --- |
| 内容身份 | 严格的 schema / ruleset / map / supply 组合；分派到已知版本 codec，不放宽旧字段检查，不把未知规则当默认世界 |
| 发现与地形 | 稳定样本 / 矿道 ID、调查事实、样本位置、试制完成、两处开启状态；第二矿道开启必有第一矿道开启，位置及建筑必须满足已开放区域 |
| 生产 | 采集器矿物类型；反应器配方、物料计数、在制投入、批次、进度与多件输出余量；传送带保留具体物品 / 批次和进度 |
| 统计 | 按物品记录矿源生成、配方完成产物和物流入仓件数；开路耗材、样本研究消耗有记录，跨存读不重复记账 |
| 派生内容 | 地形占用、端口连接、配方可用性和提示阶段由权威状态生成，不存另一套 HUD 状态机或可漂移的任务进度 |

- 原 `generated = crystal + 2*catalyst` 不适用于新世界。建议新守恒口径以普通晶体等价值计：晶体 1、催化剂 2、制剂 4、富集晶体 6；各处库存和在制投入加已消耗制剂价值，等于普通矿生成 + 6×富集矿生成。样本用唯一性与研究消耗另核对；这些是游戏记账权重，不是物理质量。
- 新配方一个批次可出三件，不能沿用“完成批数等于产物件数”或只靠最后一个入仓批次去重；以真实逐件转移更新计数，半批出料跨进程继续需完整核对。不保存无限增长的事件日志来维持守恒。
- 版本分派应复用现有 Store 的锁、候选校验和原子发布；分别保留两个明确的规则 / codec 合同，公共生产逻辑只在有真实共同职责时共享，不复制整套应用或引入通用插件框架。
- 新读写器继续原样支持 schema 1；旧程序遇 schema 2 必须拒绝且不能退回较旧备份覆盖新世界。未知未来版本、混配 ruleset、负数、非法配方 / 物料、样本复制、矿道与耗材记录矛盾均拒绝，不填默认值“修复”。
- D2 进入实现前补齐精确字段、数量上限与版本检查夹具；本提案不宣称已具备迁移工具或可用 schema 2。

## 实施分包与验收

以下是基础电力联合设计及范围确认后的建议顺序；当前只交付发现循环提案。每包完成与风险匹配的检查，正式入口和真实状态始终一致，不能把一个夹具演出当成完整玩法。

| 包 | 交付与先决条件 | 退出证据 |
| --- | --- | --- |
| D1 内容与场景定稿 | 在确认范围内落实固定地图、已有资产组合、提示与矿道前后态；先验证辨识与可走可建空间 | 正式视角原图、路径 / 足印核对；明确两态为场景预览，不冒称生产开路已实现；不通过则先修设计 |
| D2 状态与兼容底座 | 先完成基础电力联合设计与实施顺序确认，再冻结 schema 2 字段；物品 / 配方状态、按物品取放、在制回收、地形命令与版本分流 | 守恒、样本唯一、事务失败零变更、半批多件出料 / 开路存读、schema 1 原档继续和旧二维保护；不单独交付玩法完成 |
| D3 完整玩家路径 | 接通发现、试制、自动制剂、两次开路、富集回流及工艺 HUD；验证布局与实际成本 | 正式 Boot 普通新建、首开路、可见新产线、第二次开拓及关闭重进；自然操作不预注入物料或解锁；截图与输入方式分列 |
| D4 体验收口 | 处理真实玩家阻塞，记录时间、无事可做的等待和瓶颈调整 | 萝卜SAMA能解释制剂用途、试制所得、富集线回报，并用量产物再次开路；收到亲测反馈后再定下一包 |

自动检查至少覆盖：不同顺序拾样 / 建线、满包与满输出、配方切换及取消、缺料 / 回压、多件在途、矿道重复命令、隔墙建造、开路前后保存、唯一样本各位置退出恢复、失败写入 / 恢复与原文件保护。统计测试验证真实产出和耗材，不只匹配实现字段。

窗口主证据至少包含：初见矿壳 / 样本、试制条件与成功、制剂在真实带上运输、处理前后通道、富集产线与吞吐、第二矿道、关闭进程后恢复；实测时间与理论加工时间分列。自动输入和用户亲测分开，不以截图数量替代体验结论。

验证隔离根建议 `tools/runtime-intake/check-runs/factory-discovery-v1/` 与 `review-worlds/factory-discovery-v1/`（均位于 `tools/runtime-intake/` 下），截图放 `assets/art-intake/<date>-factory-discovery-preview/`。执行前按[运行时指南](../reference/godot-runtime-verification-guide.md)注入新旧两个存档根，启动 Godot / 窗口前告知。

文档 / 静态沿用仓库入口；涉及共享模拟、存档或渲染时补匹配回归，原 100 台 / 1,000 带预算不降低。既有长测作为未改动版本证据保留；是否重跑由实际性能影响决定，不把旧结果直接当新代码通过，也不为纯文档重复四档长测。Windows 与目标硬件验收保持独立待办。

## 失败判据与待确认边界

- 首次体验不能在 5–10 分钟内理解样本与生产成果用途，或开路后不能辨认新增可用空间：先改路径、表达和场景，不加更多任务。
- 制剂只能靠反复拆仓取料、唯一样本可丢失、开路后存读还原矛盾：属于功能阻断，修正后重走整条路径。
- 富集回流只是显示加成，或实际游玩主要在等材料：不宣布生产循环成立，调整布局、材料需求和瓶颈后重新亲测。
- 新增内容迫使扩到装备 / 战斗 / 新地图框架，或必须修改已有世界规则：停止扩张并重新确认范围。

本次请求确认的实施边界为：化工制剂开路这一玩家能力、固定矿区与两次开拓、三种新物品及必要的配方 / 取放交互、新世界 schema 2 与原世界不迁移、先用现有导入资产验证表达。先补基础电力专题并联合确认，再从 D1 开始；本文件不会自行把这些提案转成运行时权限或已完成事实。
