# Slice Recipe Processing V1

更新时间：2026-07-19

状态：**方向修订中（2026-07-19 实机复核）**。原"全局计数 + 反应器按 E 激活"抽象实现（包 1+2）已提交，经萝卜SAMA实机复核判定层级过抽象，**重写为"首条化工链的空间工厂自动化"arc 总览**，设计先行、分层重建；抽象实现保留为过渡参照（不回退），随资源模型改造逐步替换。切片第七个实现专题（化工链第二步、首次工业转化）。前序 [Slice Viewpoint Correction V1](slice-viewpoint-correction-v1.md) 已收口。

## 方向修订：从"记账"到"空间自动化"

**原方向（抽象实现，包 1+2）**：晶体是全局 `int` 计数，反应器按 `E` 激活后凭空运转、从全局计数扣晶体加催化剂，储存罐是抽象上限。链路能通，但把工厂抽象成了**记账**——没有电力、没有物流、没有空间摆放，玩家实机会觉得"逻辑不对"。

**修订目标（萝卜SAMA 2026-07-19 实机复核定向）**：反应器加工必须是**真正的空间化工厂自动化**，符合章程"化工自动化差异化卖点"的保真度。目标玩家路径：

```text
受损核心 →（手持合成面板）造零件 → 修复核心 → 核心 = 电源
  → 采集物资 → 造 反应器 / 地板 / 电线杆·中继 / 传送带 / 储物箱
  → 放地板 → 放反应器 → 电线杆·中继把电力送到反应器（供电才运转）
  → 入口传送带（晶体储物箱 → 反应器）→ 出口传送带（反应器 → 催化剂储物箱）
```

即：**反应器不是预置摆设按 E 就转，而是玩家造出来、放下去、接上电、接上进出料物流，才自动运转**。

## 玩家价值（空间自动化版）

- 看到：核心供电范围、电线杆·中继连成的供电网、传送带上流动的晶体与催化剂、进出料储物箱的空 / 满读法、反应器在"通电 + 有料"时运转。
- 做：修核心解锁电力 → 采集 → 合成面板造建筑 → 铺地板、放反应器、拉供电、架进出料带、两端放储物箱 → 看晶体从入口箱经带进反应器、催化剂经带进出口箱。
- 理解：这是"基地服务冒险，冒险反哺基地"里**基地侧自动化生产**的第一课——玩家亲手搭出一条会自己跑的产线，而非按一个激活键。

## 目标模型分层（依赖顺序，每层落地时拆可执行细专题）

本文是 arc 总览（阶段级）；下列层是能力域方向与跨层验收，**每层开工时另建 `slice-*-vN.md` 可执行细专题**，阶段入口只链接当前活跃层。层间有硬依赖，原则上按序推进。

### L0 资源模型改造（地基，最高优先）

- 目标：把晶体从"全局 `int` 计数"改为**空间物品 + 背包 `pocket`**（采集器产出改为各自输出缓冲）。纯数据地基，**不含机器进出料 / 中央仓库 / 储物箱 / 搬运机制**——那些属上层（核心仓库→L2、储物箱→L4、反应器进出料→L5）。
- 依赖：无（是其余各层的地基）。
- 波及：`SliceWorld` 状态结构、`SliceSaveService` schema（背包 / 采集器缓冲序列化）、`SliceHud` 背包读法。
- 验收：采集进背包（满则拒采）、采集器缓冲满暂停并可取料、修核心 / 造采集器扣背包晶体，全程无全局计数；存读还原。**已实现（包 1）**。
- 教训：初版把核心仓库 / 手动喂机器一并塞进 L0，实机复核判定抢跑了电力 / 传送带 / 放置层，已撤回重分配；机器物流一律走传送带，不做手动喂料。

### L1 手持合成面板

- 目标：玩家随身合成面板，用原料按配方造**零件与建筑**（核心修复零件、反应器、地板、电线杆·中继、传送带、储物箱）。
- 依赖：L0（配方消耗 / 产出走库存）。雏形：整备台造采集器（`WorkbenchBuildSite` + 携带态）。
- 验收：面板列出可造项与配方，材料足够可造、不足拦截，产出进携带 / 库存。

### L2 核心功能化：电力 + 中央仓库

- 目标：修复后的核心兼两职（参照《终末地》基地核心）——(a) **电源**：`电线杆 / 中继` 组成供电网并有覆盖范围，机器只有落在供电范围内才运转；(b) **中央仓库**：核心是可存取的基地中央仓库，玩家走近手动把背包物品存入 / 取出（早期基地存储，belt 上线后与传送带物流并存）。
- 依赖：L1（电线杆·中继要能造放）、核心修复态（已有）、L0（背包物品）。
- 验收：反应器在供电范围内才 tick、断电即停；供电网可视（状态高亮，非程序绘制主介质）；背包↔核心仓库存取成立并进存档。

### L3 建造与放置泛化

- 目标：把"造 + 放"从采集器专用泛化到**反应器 / 地板 / 电线杆·中继 / 传送带 / 储物箱**通用放置（朝向、多格足印、网格校验、放置预览）。
- 依赖：L1。雏形：采集器放置预览 + 晶体地网格校验 + 2x2 足印。
- 验收：各类建筑可造可放、放置约束正确、预览合法 / 非法可辨、进存档还原。

### L4 传送带物流

- 目标：**传送带**把物品从储物箱 / 机器出口搬运到机器入口 / 储物箱；物品在带上有可见流动。
- 依赖：L0（物品实体）、L3（带可放置）。
- 验收：物品沿带方向移动、到端点入库 / 入机、拐角与合流按规则，帧率无关，进存档还原。

### L5 反应器接入自动化（arc 收束）

- 目标：把反应器接到 L0–L4：**通电 + 入口带供晶体 + 出口带排催化剂**时自动加工；晶体从入口储物箱经带进反应器输入库存，催化剂经带进出口储物箱。
- 依赖：L0–L4 全部。
- 验收（arc 收束）：正式入口搭出"晶体箱 → 入口带 → 反应器（通电）→ 出口带 → 催化剂箱"完整产线并自动跑通，全程存读还原。

## 美术清单（硬闸门：全量目标须先授权美术）

## 当前抽象实现（包 1+2）的定位

- 保留在 `dev` 作**过渡参照**（不回退）：`ReactorProcessSite` 激活交互、`_tick_reactor` 帧率无关 tick、`catalyst_count` / `reactor_active` / `core_energy` 存档字段、HUD 催化剂行与三态目标行、`StorageReadSite` 只读点。
- 这些是"记账版"化工链，验证了 tick / 存档 / HUD 范式；进入 L0 后其全局计数被空间库存替换，交互与 HUD 结构可能大改。收口以 L5 空间自动化成立为准，**不以抽象实现为收口证据**。

## 边界与冻结

- 分层顺序、美术授权、资源模型改造（L0）均属**架构级升级点**：每层开工前按 [Development Decision Gates](../process/development-decision-gates.md) 做决策闸门，L0 与美术授权由萝卜SAMA拍板，执行会话不自行铺开全量。
- 不做敌人 / 战斗、任务链、立绘对话、八方向动画、viewport 重构；不迁移、不修改冻结的旧系统与旧检查；联机、多星球继续冻结。
- 不做多种产物 / 多级配方 / 副产物 / 污染排放（本 arc 只做单条晶体→催化剂链的空间自动化）；催化剂作通用货币 / 升级建造货币留后续。

## 失败退出

- 按决策闸门两次失败停手规则执行：某一层两轮实机仍不成立（供电 / 物流 / 库存逻辑穿透、读档丢状态、无对应素材硬凑色块），停手复盘该层承载结构与保真起步方案，不继续追加同类调参。
