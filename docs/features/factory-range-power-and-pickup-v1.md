# Factory Range Power And Pickup V1

更新时间：2026-10-05

## 玩家结果与授权

萝卜SAMA亲测指出“节点已在范围内，设备却不工作”及“地面样本无法交互”，并确认正式改为范围自动供电。玩家放下电源、节点与设备后即可在有效覆盖内生产；样本远处只显示模型与小图标，走近才显示名称及拾取操作。此包承接[设备交互](factory-device-interaction-v1.md)，不继续用新增说明掩盖缺失操作。

## 自动供电合同

- 延用已显示的足印中心距离：电源 / 节点之间最多 12 格，设备接入最多 6 格；半径边界包含在内。矿壳与封闭格的边 / 角阻断沿现行几何判定。电源本身也是节点，关闭只停止发电，不停止导通。
- 所有合法节点对自动形成无向图。每台用电设备只接一个可达节点：优先归属含启用电源的网络，再按中心距离、节点稳定 ID 升序选择。不按瞬时剩余容量跳网；设备不承担中继，重叠设备覆盖不合并网络。
- 建造、回收、启停电源、开通矿道和加载时重新计算连接；固定生产步不重建拓扑。开路后只有实际距离与通路满足时才自动接入，不跨封闭矿道提前供电。
- 仍为两套 120 kW 电源、12 个节点，仓与带被动运行；20Hz 比例分配、零电暂停、半批保持、物料 / 电量统计均沿原合同。范围内但所在电网无启用电源、功率不足、缺料或回压分别显示真实原因。
- 放置、选中时显示 6 / 12 格圈、受阻段与有效目标；自动世界移除手动接线 / 断线按钮，保留启停电源及查看关系。回收已有连接的节点仍先展示影响并确认，随后按同一规则改接。

## 地面样本交互

- 沿用导入矿物外形，补一个小型样本图标，去掉远处常驻大字。只有两格内且交互线未被封闭地形阻挡时，显示“矿壳样本”与 `F` 拾取提示。
- 近身可按 `F` 或点击拾取提示；直接点击地面样本 / 图标时，远处走近后拾取，近处立即拾取。沿现有移动与碰撞，不瞬移或新增通用寻路；路线受阻则明确提示靠近后操作。
- 建造 / 接线优先，不在构件落位中误拾取。切换工具、手动移动、Esc、暂停、失焦和打开面板会取消未完成的走近拾取；UI 点击不透传。
- 权威操作仍为 `survey_sample(true)`：距离与地形、背包容量、唯一性、调查事实及统计只在模型校验后提交。满包留样本在地面，拾取成功立即移除物体、图标与提示；重复输入、保存恢复不复制样本。原工艺面板保留操作入口。

## 保存、兼容与范围

新勘探世界使用[联合 schema 3](../architecture/factory-discovery-save-v3.md)。旧 schema 2 继续严格解码；从世界列表升级时明确说明规则变化，先保留独立的升级前副本，再发布自动供电存档。库存、设备位置、在制、时间、发现与统计原样保留，仅重算电网连接，不批量操作用户存档。基础 schema 1、旧二维 schema 10 与独立样板不改变规则。

复用现有 Godot / GLB 与标准 UI，图标为仓库内自有 SVG；程序几何只承担动态提示。没有新依赖、外部美术、通用掉落物系统、设备经济、额外玩法或全量新手引导。

## 验证与失败判据

1. 状态验证覆盖先设备 / 后设备、边界 / 越界、矿壳开闭、多网确定选择、设备不桥接、源启停、节点回收、缺电公平性及半批恢复；旧显式模型继续回归。
2. schema 3 严格校验、未知未来版本阻断、非规范自动图拒绝；升级保留原副本，写入 / 读回 / 发布失败不覆盖原主档，候选重建后才接受，独立进程恢复一致。
3. 正式 Boot 双根隔离空勘探世界：自然建线后不点接线即可产生原料与产品；远处图标无名称、近处显示并实际点击 / 按键拾取；完整快照保存重进，半批和样本唯一性保持。至少审阅普通 / 最小窗口、范围、生产、远近样本及拾取结果原图。
4. 改动边界内的客户端、文档、仓库检查及日志审阅通过；合成输入和玩家亲测分列，不把此包当作 D4、20–40 分钟或规模性能验收。

显示覆盖与实际接入不一致、无法直接拾取、远处仍有样本大字、输入透传、物料重复或升级丢失进度均为失败。若同类整改两次仍不能让玩家完成操作，按开发闸门停止堆叠提示并重新审视交互结构。
