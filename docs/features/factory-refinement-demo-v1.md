# Factory Refinement Demo V1

更新时间：2026-09-29

## 已确认决策

萝卜SAMA确认“圆润但更有机械结构与化工质感”，现阶段验证优先，不投入全量精细美术；记录决策并产出小 demo。接受设备面板、接口预览、范围自动供电、逐步引导的方向。

本轮范围收敛为独立交互样板：复用现有真实采集 / 物流 / 配方 / 电力分配，局部升级反应器和节点模型，复用其他资产和人物。正式世界仍沿现行规则运行；样板不读写玩家存档、不迁移 schema、不开放新玩法。统一 6 格覆盖半径仅为样板参数，正式地图平衡与版本合同后续再定。

2026-09-29 萝卜SAMA试玩反馈“感觉还行”，并要求提交工作区。记录为样板方向初步认可；不推断完整首程、美术定稿或修正版自动点击问题已经验收。后续建议优先把设备面板与接口提示接入正式勘探工厂，继续控制资产投入。

## 玩家结果与操作路径

- 进入一个预置采集器、电源、仓库的空物料小场地；明确这是首线交互样板，不冒充空世界新手流程。
- 选择反应器，鼠标预览外形、足印、输入 / 输出格，点击放置。
- 选择节点，移动时看覆盖圈及被覆盖对象，放置后自动接电；可以停复电检查状态变化。
- 按提示从采集器出口向反应器入口逐格铺带，再接至仓库。保留自由放置、方向切换、回收与重置，提示按实际连接事实推进。
- 点击设备查看可视化输入 / 进度 / 输出和供电信息；生产数据来自真实模拟，不用定时假进度。达到首件入仓后允许继续操作。
- 当前动作、具体操作与完成反馈同时可见；错误操作显示原始模型原因。

## 实现介质与投入边界

使用 Godot 4、既有 Node3D / GLB 资产和标准 Control UI。离线工具制作两件有圆角、壳体 / 结构分层、法兰与管路的自有 GLB 小样；运行时不以程序几何替代设备，动态几何只用于接口、范围与选中提示。无外部资产、依赖安装、贴图生产、人物绑定和动画重做。

样板代码集中于 `client/scripts/prototypes/factory_refinement/`，启动入口位于 `tools/factory-content/`，不挂入正式新世界菜单。通过隔离 Boot 启动并挂载样板；这证明 Boot 和样板加载，不代表正式工厂已接入新规则。生产模型用现有发现模型，样板适配层在拓扑变化时派生连接，继续由现有电力分配器执行生产；禁止把派生规则存进旧规则世界。

供电节点和电源中心距离 6 格内自动连通；设备中心在覆盖内自动接入，重叠时优先启用电源所在网络，其次距离、稳定 ID。设备不作为中继；封闭矿壳仍阻断连接。范围、接入和高亮使用同一判断。拆除 / 电源启停后重算，保留有限电量和按比例降速。完整旧世界升级、多网大规模性能与发现全链不属于本样板验收。

## 当前样板的具体限制

设备面板仅查看库存 / 进度 / 供电，提供电源启停与回收；未实现正式近身取放、配方切换或操作暂停合同。建造卡为文字卡，缩略图位于选中设备面板；传送带逐格点击，不是正式拖铺。回收直接执行，尚无受影响设备清单和二次确认；这些完整整改建议不能记为样板已交付。人物与大部分资产沿用，模型动画未精修。

无窗口最终 32 项通过；首轮窗口 32 项通过，修正版自动点击未命中与后续链式失败保留，最终版完整窗口复验未完成。手动样板已获方向初步认可；正式集成仍须排查点选 / 布局并复核实际输入路径，不能用该反馈消除工程待办。

## 开工闸门与验证

玩家新增动作是看预览规划、放节点自动接入、点选面板诊断；世界变化是实际连通和生产状态，服务首条化工线可理解性，5 分钟内应能感知。复用现有规则和素材，仅需样板内适配，不复活旧系统。目标是降低首程理解门槛，不增加正式系统复杂度。

成功证据：正式 Boot 隔离启动、样板有窗口截图、真实按钮 / 场地点击路径、首件自然生产入仓、断电停止 / 恢复，定向覆盖边界与顺序检查；截图审阅与用户亲测分别记录。自动检查不等于玩家体验通过。

失败判据：接口难以分辨、覆盖与真实接入不一致、面板数据不对应设备、引导不能指出当前阻塞，或两件小样仍明显无法表达方向。失败时优先修复结构或缩小样板，不追加全套资产。用户关闭不自动重开，不抢焦点。
