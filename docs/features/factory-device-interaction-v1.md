# Factory Device Interaction V1

更新时间：2026-10-05

## 目标与授权

萝卜SAMA确认开始正式设备面板与接口提示首包。承接[亲测整改提案](../design/factory-playtest-refinement-proposal.md)与[低投入交互样板](factory-refinement-demo-v1.md)，本包服务 D4 体验整改，不提前宣布联合包收口。后续已确认的自动电网、直接拾样与 schema 3 升级见[范围供电与拾取](factory-range-power-and-pickup-v1.md)。

玩家在放置设备前能判断传送带接入位置；选中后看懂输入、加工、输出及阻塞，并在设备操作入口完成既有取放、配方和取消操作。首条产线的可理解性直接服务“发现 → 试制 → 稳定制造 → 开拓”的主循环，进入工厂后的 5–10 分钟内即可感知。

## 正式交互与边界

### 查看与操作

- 勘探工厂选中设备后，右侧详情持续展示真实状态；查看不暂停、不移动人物。反应器展示输入、配方、批次进度和输出，采集器展示采集缓冲，仓库展示分物料库存与容量。
- 生产条件与供电条件同时保留；缺料显示缺口，在制显示已投入材料，回压显示输出仍待取出；接口信息指出相邻接带格与连接对象。电源 / 节点显示真实电网及 6 / 12 格范围；schema 3 自动接电，旧 schema 2 保留显式图解码与回归。
- 设备详情提供“取放 / 配方”入口，打开设备操作窗口后暂停生产，与现行工艺窗口合同一致。窗口内复用相同设备摘要，按物品提供取 1 / 全部、放 1 / 全部，以及反应器切配方、取消在制。
- 远程可查看，取放 / 切配方 / 取消仍需人物位于设备足印两格内且同一可达区域；权限不足明确说明。输入输出未清空、在制、满包、配方未解锁等结果由原模型命令校验并完整反馈，不伪造成功或隐式代操作。
- “工艺、物料与矿道”保留调查、拾样、开路与既有设备操作入口；两个入口使用同一操作组件与命令，不复制库存或配方规则。
- 打开操作窗口停止未提交拖铺、清除移动按键与目标；关闭恢复原显式暂停状态。UI 点击不得透传为建造、移动或世界选择；滚动布局保证设备动作与关闭按钮可达。

### 放置、拖铺与接口

- 基础工厂与勘探工厂共用建造预览，复用正式导入模型，辅以合法 / 非法足印。按 10 月 5 日亲测反馈，去除端口悬浮文字：建造 / 铺带时以接带格和朝向箭头提示位置，选中查看时只在接口边缘显示小箭头，设备模型保持主体。输入箭头指向设备、输出箭头离开设备，颜色为辅助；详细输入 / 输出说明保留在设备面板。
- 接口位置来自物流所用的 `Model.port`；箭头服从现行固定朝向。选中设备显示自己的接口，拖铺时显示邻近设备接口；已选建造设备显示预览接口及邻近接口。镜头旋转 / 缩放不改变端口位置。
- 勘探工厂放置电源 / 供电节点、选中节点及旧规则接线时显示范围：中心半径 6 格青色实圈用于设备，12 格金色虚圈用于节点互连。受封闭矿区 / 矿壳阻挡的圈段变灰；仅对通过实际距离与遮挡校验的目标描边。非法落位显示红圈并取消目标描边；取消或切换非电力构件后清除。底部图例按世界规则说明自动接电或显式接线，不加入场景文字。
- 显示层不新增实体、不消耗构件、不写入状态或存档，不加入设备旋转、自动修路或自动接线。提示节点随选择 / 位置 / 拓扑变化更新，避免每个生产步重建模型和提示。
- 基础 schema 1 工厂补齐共用模型 / 端口预览，保留原设备操作与详情；旧二维 schema 10 不变。本包不修改 schema 字段、生产规则、权威命令、供给预算及世界版本。

## 实现与投入

沿用 Godot 4、现有 GLB 和标准 Control 组件；设备摘要由模型状态派生，复用于右侧详情与操作窗口。动态几何仅用于足印、方向、端口及接线距离提示。无需新增通用系统、依赖、外部资产或人物 / 全量设备美术；不因旧代码存在而复活二维系统。

独立样板提供方向参照，其只读面板、逐格点击、直接回收和 6 格自动供电不移植为正式规则。正式电源回收确认、真实拖铺及近身操作保持有效。

## 验证与退出证据

1. 定向状态 / UI 检查覆盖缺料、半批、停复电、输出回压、满仓、远程拒绝、成功取放、取消返料与配方切换；核对真实模型和显示一致，失败操作零变更。
2. 正式 Boot 在双根隔离空勘探世界中放置设备、真实拖铺并自然生产；通过真实控件 / 场地输入检查设备选择、操作窗口、输入隔离和恢复生产。测试准备、合成输入与用户亲测分别记录。
3. 从 Boot 默认基础工厂及另选勘探工厂分别检查三类物流设备的放置前外形 / 接口、非法位置、取消及邻近拖铺提示；审阅正式视角、已连接产线、缺料 / 缺电 / 回压面板原图，检查普通窗口、最小窗口与缩放 / 镜头旋转。排查已有样板点击未命中问题，不能仅依据按钮信号通过。
4. 保存并在独立 Boot 恢复同一世界，核对库存 / 在制 / 配方及既有保存合同。按影响执行发现、电力、视图与时钟回归；文档 / 仓库 / 客户端静态检查和 `git diff --check` 必须通过。
5. 本包工程完成后交由萝卜SAMA复核“能解释阻塞并恢复生产”；未取得反馈前不记为完整玩家体验通过，不把本包扩大为 D4、20–40 分钟或规模性能验收。

失败判据：接口与实际接入不一致、操作影响错误设备、UI 透传、权限或暂停规则改变、关键控件不可达，均属未完成。若连续两次同类视觉 / 交互整改仍不能帮助理解，按[开发闸门](../process/development-decision-gates.md)停手归因，调整布局 / 交互结构或收敛范围，不继续叠加装饰与提示文字。

## 后续顺序

正式范围供电与直接拾样已按接续专题实施；之后按最终操作补完整逐步引导，再回空世界复测完整发现循环。物料专用图标、精细资产、Windows / 目标硬件与工程规模仍单列。

10 月 5 日工程首包已完成：状态 / UI 43 项，正式 Boot 空世界写入 178 项，独立恢复 20 项通过；最小窗口、操作反馈、回压、接口及恢复原图已审阅。用户亲测尚未完成。详细批次、失败归因、输入来源和回归结果见 [W41 周志](../devlogs/2026-W41.md)；当前阶段以 [Current Plan](../planning/current.md) 为准。

同日亲测暴露默认基础工厂预览遗漏，已去除与显式电网的错误绑定，补齐 schema 1 的模型、端口与邻近铺带提示。修正版状态 54 项、正式 Boot 两种世界预览 90 项通过，保留前轮工程证据；这次修正版仍需玩家复核，不能将前轮勘探通过扩展为默认入口已覆盖。

随后亲测指出端口悬浮文字破坏观感，已按上文的无文字端口方案移除，选中时取消接带方框。最新状态 54 项、双世界窗口 124 项通过；复核包含已放置的三台设备、选中仓库、近景与建造预览。观感是否接受仍以萝卜SAMA反馈为准。

接续亲测指出放置节点缺少范围，已补 6 / 12 格接线距离、受阻圈段与可连接目标描边；该轮状态 89、双世界窗口 166 项通过。之后亲测再次确认应自动供电，同时要求可直接拾样，现由接续专题承载其规则与存档变化；历史范围显示证据仍保留。
