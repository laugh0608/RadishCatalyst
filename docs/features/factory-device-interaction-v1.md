## 正式交互与边界

### 查看与操作

2026-10-08 萝卜SAMA亲测指出：点到样本后走近即拾取、屏幕中心偏离角色导致设备附近 F 不可用、文字列表没有实现三张终末地参考图的背包 / 设备信息结构。本轮沿现有专题调整交互与布局，替代旧中心射线和自动拾取合同；前序工程证据保留，不视为新体验已通过。

- 样本走近只提示，不自动进入背包。远处点样本只走到近处并停下，随后须按 F 或再次近身点击；Esc、WASD、失焦、暂停和切工具取消走近意图。沿用两格、遮挡、容量和唯一性校验。
- 设备交互以角色位置为依据，收集足印两格内且无遮挡的设备 / 样本；优先最近目标，距离相同按稳定 ID 排序，Tab 切换附近候选，F 操作当前高亮对象。有效的手动候选保持到离开范围或拆除；普通走近时随位置更新。镜头转动 / 缩放 / 定位不改变候选权限。近身鼠标点击直接打开，远处只选择 / 提示走近，不远程操作或传送人物。
- HUD 明示目标名称、F 和多目标切换，目标设备用既有描边高亮；移除作为交互依据的屏幕中心点。建造、铺带、旧接线和面板打开时不竞争交互键。
- 唯一设备主面板采用物品图标格；背包按物料聚合，格子显示图标、名称和数量，容量明确为 200 件，不引入槽位 / 堆叠上限。点击格子选择物品，再执行放入 / 取出 1 或全部；选择本身不移动库存。不引入拖放或无线仓储。
- 反应器以输入物品格 → 现有设备模型预览 / 加工进度 → 输出物品格为主体，下方为配方和选中物品操作；在制明确区分，不能直接取走。采集器显示采集缓冲；仓库用库存与背包分栏；电力与带保留专用状态。规则 / 接口细节可回查，关键阻塞、数量、进度和主操作不藏在长文字列表中。
- 增加背包查看入口（I / HUD），使用同一物品格展示与容量，不绑定远程设备。设备 / 背包面板内产线、物流、时钟、统计与自动保存继续；面板只阻断场地输入。关闭保持原暂停偏好；失焦只清理场地输入，生产继续；保存失败及确认弹窗仍暂停，工艺回查继续保留完整步骤和原暂停合同。
- 取放、配方、取消、启停、旋转与回收仍走现有权威命令，执行瞬间校验，失败不伪造成功；刷新不重置未提交配方或当前物品选择。普通 / 最小窗口可见主操作与错误反馈；目标拆除 / 近身失效关闭设备操作。
- 10 月 17 日的[物流附件原位改装](factory-conveyor-routing-v1.md#belt-replacement)属于建造操作：三类附件替换普通带及附带货物回收沿建造范围，不受两格近身取料限制；手动取料、设备回收与准入口配置仍须近身，不能将这项建造便利扩展为面板远程操作。
- 适用于勘探工厂 schema 2 / 3 / 4 / 5；基础 schema 1、旧二维和独立样板保持边界。不改配方、生产调度、供给、电网、存档字段或迁移；沿用 Godot Control、现有 GLB 与自有 UI 图标，不导入参考截图素材或外部依赖。

本轮所需证据：状态检查覆盖角色候选 / 遮挡 / 切换、靠近不拾取与取消、物品格选择 / 实时取放 / 守恒 / 权限；正式 Boot 新隔离批次复核鼠标 / F / Tab、背包 / 仓库 / 反应器、最小窗口、自然生产及独立半批恢复，并审阅原图。失败判据为误拾取、走近仍无法选择、操作错对象、界面无法辨认库存 / 在制或主按钮不可达；按开发闸门归因，不用额外文字补丁替代结构。结果进入 W41，用户理解反馈仍待验；后续 A 已按独立明确授权实现，不把旧亲测待办重复作为开工门禁。

### 放置、拖铺与接口

- 基础工厂与勘探工厂共用建造预览，复用正式导入模型，辅以合法 / 非法足印。按 10 月 5 日亲测反馈，去除端口悬浮文字：建造 / 铺带时以接带格和朝向箭头提示位置，选中查看时只在接口边缘显示小箭头，设备模型保持主体。输入箭头指向设备、输出箭头离开设备，颜色为辅助；详细输入 / 输出说明保留在设备面板。
- schema 1 / 2 / 3 的机器接口来自物流所用的 `Model.port`；schema 4 / 5 使用 `Logistics.ports` 与实际调度共用端口，附件箭头随 dir 旋转。普通带沿自身模型呈现方向。选中设备显示自己的接口，拖铺时显示邻近设备接口；已选建造设备显示预览接口及邻近接口。镜头旋转 / 缩放不改变端口位置。
- 勘探工厂放置电源 / 供电节点、选中节点及旧规则接线时显示范围：中心半径 6 格青色实圈用于设备，12 格金色虚圈用于节点互连。受封闭矿区 / 矿壳阻挡的圈段变灰；仅对通过实际距离与遮挡校验的目标描边。非法落位显示红圈并取消目标描边；取消或切换非电力构件后清除。底部图例按世界规则说明自动接电或显式接线，不加入场景文字。
- 显示层不新增实体、不消耗构件、不写入状态或存档，本提示层不新增机器旋转或自动修路；附件空载旋转和范围自动接电分别由对应权威模型处理。提示节点随选择 / 位置 / 拓扑变化更新，避免每个生产步重建模型和提示。
- 基础 schema 1 工厂补齐共用模型 / 端口预览，保留原设备操作与详情；旧二维 schema 10 不变。本包不修改 schema 字段、生产规则、权威命令、供给预算及世界版本。

## 实现与投入

沿用 Godot 4、现有 GLB 和标准 Control 组件；设备摘要由模型状态派生，只在统一设备主面板展示。动态几何仅用于足印、方向、端口及接线距离提示。无需新增通用系统、依赖、外部资产或人物 / 全量设备美术；不因旧代码存在而复活二维系统。

独立样板提供方向参照，其只读面板、逐格点击、直接回收和 6 格自动供电不移植为正式规则。正式电源回收确认、真实拖铺及近身操作保持有效。

## 验证与退出证据

1. 定向状态 / UI 检查覆盖缺料、半批、停复电、输出回压、满仓、远程拒绝、成功取放、取消返料与配方切换；核对真实模型和显示一致，失败操作零变更。
2. 正式 Boot 在双根隔离空勘探世界中放置设备、真实拖铺并自然生产；通过真实控件 / 场地输入检查设备选择、操作窗口、输入隔离和恢复生产。测试准备、合成输入与用户亲测分别记录。
3. 从 Boot 默认基础工厂及另选勘探工厂分别检查三类物流设备的放置前外形 / 接口、非法位置、取消及邻近拖铺提示；审阅正式视角、已连接产线、缺料 / 缺电 / 回压面板原图，检查普通窗口、最小窗口与缩放 / 镜头旋转。排查已有样板点击未命中问题，不能仅依据按钮信号通过。
4. 保存并在独立 Boot 恢复同一世界，核对库存 / 在制 / 配方及既有保存合同。按影响执行发现、电力、视图与时钟回归；文档 / 仓库 / 客户端静态检查和 `git diff --check` 必须通过。
5. 本包工程完成后交由萝卜SAMA复核“能解释阻塞并恢复生产”；未取得反馈前不记为完整玩家体验通过，不把本包扩大为 D4、20–40 分钟或规模性能验收。

失败判据：接口与实际接入不一致、操作影响错误设备、UI 透传、违反本节近身 / 持续生产合同、关键控件不可达，均属未完成。若连续两次同类视觉 / 交互整改仍不能帮助理解，按[开发闸门](../process/development-decision-gates.md)停手归因，调整布局 / 交互结构或收敛范围，不继续叠加装饰与提示文字。
