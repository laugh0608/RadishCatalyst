# Demo Industrial Module Task Rhythm V1

更新时间：2026-06-19

## 用途

本文定义首版 Demo 工业模块职责与任务节奏第一包。它承接 `Demo Playable Content Substance V1`，把计划内 5 个核心工业模块从“已有设备读法”推进到玩家在 HUD、建造点、设备面板、处理结果和前哨整备中能读到职责与下一步。

## 玩家价值

玩家回到基地时，应知道当前材料应该去哪里、哪个设备负责哪段转换、处理完成后会变成补给、模块、污染处理收益还是核心站准备，而不是只看到一串配方或日志说明。

## 与整体规划的关系

- 映射 `Demo Definition V1` 的工业基建模块、资源 / 生产链、UI / HUD 和任务节奏规格。
- 承接 `Demo Industrial Tech Spine V1` 与 `Demo Device Panel Operation Readability V1`：前者说明工艺主干，后者说明设备操作，本专题补齐模块职责和阶段节奏。
- 归属 `Demo Playable Content Substance V1`，仍处于可玩内容实质补强阶段，不切到验收、试玩准备或集中修 bug。

## 当前已有基础

- 前哨核心、基础反应器、污染过滤器、基础储存箱和出发整备台已存在。
- 修复凝胶、抗污染药剂、基础零件、过滤模块、污染浆液和核心稳压缓冲包已有生产或补给路径。
- HUD、设备面板、交互提示、结果日志和 Godot 运行时检查已有可复用接入点。

## 本轮范围

- 新增 `DemoIndustrialModuleTaskRhythmFormatter`，集中表达 5 个核心模块职责和当前任务节奏阶段。
- HUD 摘要能显示当前模块职责与下一步动作。
- 建造点提示能说明基础储存箱、出发整备台、污染过滤器和地基对任务节奏的作用。
- 基础反应器 / 污染过滤器设备面板、处理提示和处理日志能说明产出去向。
- 前哨核心与出发整备台提示能说明回基地补给、模块装配和下一趟外勤关系。
- 建造与加工成功反馈写入 `module_task`，让结果日志能显示任务节奏，而不是只显示状态完成。
- 新增 `demo_industrial_module_task_rhythm_check.gd` 与默认检查入口，覆盖 HUD、建造、设备面板、处理提示、结果日志和前哨 / 整备台提示。

## 当前不做

- 不新增第 13 区域。
- 不扩第二星球、第二章节或独立支线任务网。
- 不做完整科技树、完整电网、管线、物流、自动化工厂、完整背包、完整装备栏、死亡系统、结算页、联机入口、发布流程或最终美术包。
- 不新增长期存档字段；本包只复用现有世界、角色、库存、建筑和任务状态。

## 玩家操作路径

```text
回前哨 -> 看 HUD 当前模块职责 -> 在建造点补储存箱 / 整备台 / 过滤器 -> 用反应器或过滤器处理材料 -> 看结果日志产出去向 -> 回前哨核心补给或去整备台装配 -> 下一趟外勤
```

## 运行时、存档与数据边界

- 运行时只新增窄职责 formatter 和专项检查，不改资源、配方、设备数量或区域数量。
- 不新增保存字段；任务节奏由既有 `base_structures`、`quest_state`、`inventory` 和 `equipment` 推导。
- 检查覆盖真实 HUD / 提示 / 日志输出，不只检查文档存在。

## HUD / 场景 / 对象反馈

- HUD 使用“模块职责 / 任务节奏”两行说明当前工业阶段和下一步。
- 建造点直接说明该建筑接入哪段循环。
- 设备面板和处理提示说明当前配方产物接到哪个模块或外勤准备。
- 前哨核心说明补给回合落点，出发整备台说明模块装配责任。

## 验收条件

- 5 个核心模块均有职责覆盖：前哨核心、基础反应器、污染过滤器、基础储存箱、出发整备台。
- 任务节奏覆盖储存箱接入、整备台接入、过滤模块原料 / 组装 / 装配、污染过滤器建造、污染处理、核心缓冲包准备和下一趟外勤。
- HUD、建造提示、设备面板、处理提示、结果日志、前哨核心和整备台提示都有玩家可见输出。
- 默认客户端静态检查和 Godot 运行时检查包含本专题专项检查。

## 风险与后续决策

- 本包仍是第一版职责和节奏读法，不代表首版 Demo 已达到试玩候选质量。
- 若玩家仍不理解设备价值，后续应优先补场景对象、设备造型、交互顺序或任务断点，不继续堆长日志文案。
