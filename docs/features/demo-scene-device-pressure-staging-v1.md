# Demo Scene Device Pressure Staging V1

更新时间：2026-06-19

## 用途

本文定义场景设备与危险边界现场编排第一包。它承接 `Demo Playable Content Substance V1`，把已完成的战斗读法、核心空间、工业模块、初步美术和外勤任务差异推进到玩家能在现场判断的设备位置、危险边界、对象尺寸和操作顺序。

本专题只作为明日开发范围建议和边界，不代表首版 Demo 进入验收或试玩准备。

## 玩家价值

- 玩家进入外勤现场时，能从设备、资源和危险的相对位置判断这一区域要做什么。
- 玩家处理晶体、污染沉积或核心准备对象时，能看出对象状态与回基地处理设备之间的关系。
- 玩家在承压区域中能区分普通敌压、污染压力和核心守卫压力，不只靠 HUD 文案解释。
- 玩家完成一次现场处理后，能知道下一步是继续推进、回基地加工，还是先补整备。

## 与整体规划的关系

- 覆盖 `Demo Definition V1` 的核心场景完成度、工业基建模块、资源 / 生产链、战斗压力、污染与防护、UI / HUD 和初步美术规格。
- 承接 `Demo Core Scene Playable Space V1`：四个核心区已有空间角色，本包补设备与危险现场编排。
- 承接 `Demo Initial Art Identity V1`：对象已有现场身份，本包补对象尺寸、状态层级和任务位置关系。
- 承接 `Demo Field Task Differentiation V1`：任务差异已有 formatter 与状态，本包把差异落到现场操作顺序。

## 当前已有基础

- 12 区域封顶、核心稳定站终点、资源采集、污染处理、设备面板、出发整备台和战斗现场 HUD 已存在。
- 核心空间、初步美术、工业模块职责和外勤任务差异第一包已落地。
- 当前不足是这些第一包仍偏“能读到”，还需要在代表现场形成设备、危险、对象和任务节奏的同屏关系。

## 本轮范围

- 在既有 12 区内选择基地、晶体矿脉、污染边界和核心稳定站代表现场，不新增区域。
- 补齐代表设备、资源对象、危险边界和敌压点的现场编排数据或运行时表现。
- 让晶体、污染沉积和核心准备对象在场景中体现尺寸、处理状态、回收去向和附近压力。
- 把设备面板、HUD、对象提示和战斗反馈连接到同一套现场编排口径。
- 新增专项检查，覆盖代表现场、12 区封顶、HUD / 对象 / 设备反馈和关键状态读写。

## 当前不做

- 不新增第 13 区域，不扩第二星球、第二章节或支线任务网。
- 不新增资源、配方、敌人类型、完整背包、完整装备栏、死亡系统、结算页或联机入口。
- 不做最终美术包、大规模换皮、完整地图重绘或过场动画。
- 不用纯日志、长说明或只检查字段替代真实 HUD / 场景 / 对象反馈。

## 玩家操作路径

```text
出发整备 -> 进入代表现场 -> 读设备 / 资源 / 危险边界 -> 处理对象或战斗承压 -> 回基地加工 / 整备 -> 推进核心准备
```

本包改善的是玩家在现场做判断的过程：目标不只是知道“下一步是什么”，而是能看出为什么这一步发生在这里。

## 运行时、存档与数据边界

- 优先复用 `WorldState.map_objects`、`WorldState.base_structures`、`CharacterState.inventory`、敌人状态和既有任务状态。
- 不新增长期存档字段；若必须记录现场状态，优先挂在既有对象实例状态上。
- 新增运行时 metadata 只服务场景表现、HUD 读取和专项检查，不作为新的长期系统。

## HUD / 场景 / 对象反馈

- 场景：用位置、尺寸、色块层级、状态条和边界表现设备职责与危险压力。
- HUD：只显示当前现场决策所需的生命、防护、补给、资源处理去向和承压差异。
- 对象提示：显示处理状态、回基地设备、风险来源和下一步动作。
- 战斗反馈：把敌压、污染压力和核心守卫压力接入命中反馈与状态标签。

## 验收条件

- 代表现场能同时读到设备、资源对象、危险边界和敌压点的关系。
- 晶体、污染沉积和核心准备至少各有一条现场操作顺序能回到设备处理或整备判断。
- HUD、对象提示、设备面板和战斗反馈使用一致的现场编排口径。
- 专项检查确认不新增区域、不扩规格外系统，并覆盖代表玩家路径。

## 风险与后续决策

- 风险：只把已有提示换个入口，玩家仍需要读长文案理解现场；本包必须落到场景、对象、HUD 和设备反馈。
- 风险：把一个代表现场扩成 12 区平均加厚；本包只做首版 Demo 必达路径的代表现场。
- 完成后再判断是否继续补第二个代表现场，或回到 `Demo Playable Content Substance V1` 评估是否具备重新启动验收专题的条件。
