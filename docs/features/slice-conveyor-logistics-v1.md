更新时间：2026-07-25

状态：配方加工 arc 的 **L4 传送带物流**可执行细专题。开工闸门、L4-A 货物素材和包 1 直线储物箱物流的实现 / 自动 / 正式入口视觉证据已完成；下一步包 2 转角、端点与拓扑视觉。承接 [L3 建造放置 + 扩展供电网](slice-building-placement-and-power-grid-v1.md)，反应器进出料与催化剂加工仍归 L5。

## 玩家结果

玩家能亲手合成并铺设传送带和储物箱，把背包晶体装进源箱，看见单件晶体沿方向明确的带面连续移动，经直段、转角与合流进入目标箱。带路堵塞时货物停住而不丢失；保存、退出并重新载入后，箱内与带上货物都从原状态继续。

首个正式入口闭环：

```text
采集晶体 → 合成地板 / 传送带 / 储物箱
  → 铺一条源箱舱口到目标箱舱口的直线带
  → 在源箱操作面板装入晶体
  → 晶体逐格可见移动 → 目标箱库存增加
  → 堵住目标箱 → 带上排队 → 保存 / 重启 / 载入后继续
```

## 专题开工十问

1. **新增动作**：玩家装料 / 取料、按方向铺带、用转角连接、把两路货流合并。
2. **世界变化**：晶体不再只存在于背包或数字库存，而成为带面上有位置和进度的世界状态。
3. **服务闭环**：把远征采集所得变为可自动输送的基地原料，为 L5 自动加工建立真实物流地基。
4. **可感知时间**：新档自然自举后，玩家可在 5–10 分钟内完成第一条短直线并看到晶体入库。
5. **系统尺度**：使用切片专用物流网、建筑定义端口和窄表现组件；不建设通用 ECS、寻路系统或工厂框架。
6. **地图与素材**：沿用现有工业地板、四向直段和四向单舱口储物箱；转角 / 合流 / 货物需要固定像素资产。
7. **成功证据**：逻辑断言、真实 `Boot` 输入路径、隔离存档重启、窗口截图和萝卜SAMA人工复核共同成立。
8. **失败处理**：货流读不清先换固定 sprite / 动画介质；状态丢失或顺序不稳先修模型，不堆 HUD 文案。
9. **旧系统判断**：不复活冻结的旧物流或全局计数实现；只复用 `Inventory`、建筑实例、占用和存档入口。
10. **切片推进**：完成后玩家已搭出会自动搬运的基地链路，直接解除 L5 反应器接入的最后前置依赖。

## 物流状态模型

### 货物与带槽

- L4 当前可运输物品白名单只有 `crystal`；机械零件与建筑套件不允许上带。`catalyst` 待 L5 真正产出并有专用 sprite 时加入同一白名单，不提前制造来源。
- 每个 1×1 传送带只有一个带槽；带槽为空，或保存一个 `{item_id, progress}`。一件货物代表库存中的 1 个单位，不在带上堆叠。
- `progress` 为该格入口到出口的归一进度 `[0, 1)`；到达出口但下游不能接收时停在出口等待，不销毁、不回退、不穿透。
- 货物所有权始终恰有一处：源库存、一个带槽或目标库存。跨边转移采用“先计划、后提交”，任何失败保持原归属。

### 方向、转角与合流

- 传送带旋转值就是唯一输出方向；输出目标为相邻正交格。运行时不旋转像素图，只选择审定固定帧。
- 一个带格可接收从后、左、右三侧指向自己的上游；不接受来自自身输出侧的反向输入，避免两格往返歧义。
- 单上游与本格输出同轴为直段，垂直为转角；两条或三条有效上游同时存在时为合流。
- 多上游争用同一空槽时按稳定源 `instance_id` 轮询；接收带保存 `merge_cursor`，防止固定方向长期饿死。布局不变时结果与节点遍历顺序无关。
- 环形带允许存在；无空槽时形成稳定回压，不做自动丢弃、瞬移、路径搜索或死锁破解。

### 储物箱端点

- 建筑定义新增可旋转物流端口：本体内端口格 + 舱口朝向；外部连接格是端口朝向相邻的工业地板格。
- 相邻传送带输出指向舱口时，储物箱为输入端；相邻传送带输出背离舱口时，储物箱为输出端。单舱口同一时刻只接一格带，不另设隐藏端口。
- 输出端在相邻带槽为空时从箱内取 1 件白名单物品；首包默认按 `crystal`、`part` 稳定顺序取料。输入端只在容量足够时接收。
- 玩家靠近储物箱按 `E` 打开同一建筑操作面板，可按键把背包内晶体 / 零件全部存入或取出；容量受限转移必须守恒。机器仍禁止手动喂料。

## 模拟与表现

- 物流更新归世界权威逻辑所有，表现层只读取快照；单机按本地权威，未来 Host / 专服可复用同一命令和状态边界。
- 更新使用 `_physics_process(delta)` 与固定顺序的两阶段提交；速度以“格 / 秒”定义，不能按渲染帧累加整数像素。
- 第一版速度定为每秒 1 格。正式检查比较不同渲染帧率下相同模拟时长的库存、带槽和进度结果。
- 带上货物使用独立 `Sprite2D`，沿入口边到出口边插值，并参与带面局部层级；转角必须沿折线路径移动，不能斜穿格心。
- 空带方向、转角、端点和合流依靠固定像素资产 / 组合帧表达；允许选择已入库 overlay sprite，不允许运行时 `draw_line`、箭头、色块或强转 sprite 作为主读法。
- HUD 近距提示只显示“源箱 / 目标箱、库存、堵塞”等短状态；常态不显示全图物流线、吞吐数字或调试拓扑。

## 调整、拆除与一致性

- 带槽有货时禁止调整或拆除，提示“先清空传送带”；储物箱沿用非空禁止拆除，允许带内容移动并保留同一实例状态。
- 改变相邻带、储物箱位置或旋转后，同帧重建派生端口 / 拓扑；不保存邻接边、直段 / 转角 / 合流分类或世界坐标。
- 放置、调整与拆除仍走 L3 管线；L4 只订阅建筑拓扑变化，不新增第二套占用或建造系统。
- 自动存档只能在完整提交之后观察状态；不得保存“源已扣、目标未加”的半事务。

## schema 5

- `SliceSaveService` 升至 schema 5；schema 2–4 继续可读，旧传送带迁为空槽、`merge_cursor = 0`，不改旧库存与建筑 ID。
- 传送带定义白名单新增 `cargo` 与 `merge_cursor`。`cargo` 为空对象，或 `{item_id, progress}`；物品 ID 必须在 L4 白名单，进度有限且位于合法范围。
- 储物箱继续只保存既有 `inventory`；物流端口、相邻关系、货物世界位置和视觉分类均由建筑定义与存档状态派生。
- 坏档候选含未知货物、非法进度、额外字段、重复占用或不合法建筑状态时整份候选失败并尝试备份，不静默丢货。

## 素材硬闸门

统一遵守 [Pixel Art And Grid Standard](../reference/pixel-art-and-grid-standard.md)：32px 网格、高斜角俯视、左上光、限定色板、固定帧与整数归一。

- **L4-A 货物（已完成 2026-07-25）**：从已审定晶体簇确定性分离中央单晶，输出 `10×12` RGBA `cargo_crystal.png`，SHA-256 `e47cae97c2d145a31b36a31d42747132f789af6b2a0d422a784d614c42a879bd`；四向 32px 带面联系表确认货物、带板方向与琥珀输出端可同时辨认。
- **L4-B 拓扑**：以 L3-C 四向直段为不可变主体，离线派生转角、端点和双 / 三路合流的固定 sprite 或透明 overlay；运行时只选帧，不程序画轨道。
- **硬判据**：32px 实景下方向和转弯无需文字可读；货物与琥珀滚筒、青色状态像素不混淆；多件连续移动不闪烁、不斜穿；主体足印和左上光不漂移。
- 本专题建立不调用图像生成。确定性派生与审阅可由后续素材包执行；若需生成，必须单独取得萝卜SAMA授权并使用独立批次 / manifest。
