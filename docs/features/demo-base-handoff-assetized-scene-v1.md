# Demo Base Handoff Assetized Scene V1

更新时间：2026-06-29

## 用途

本专题收束「晶体工作面 -> 回基地入料 -> 反应器 -> 仓储 -> 整备」中的基地交接段。目标是在首版 Demo 可玩纵切里，用专用资产化小工作面表达反应器、仓储和整备之间的连续物料交接。

## 玩家价值

- 玩家回到基地后，不需要先读长任务文字或路线图，就能看到物料进反应器、产物入仓储、供给交给整备台。
- 反应器、仓储和整备台应像同一组设备在接力，而不是多个 UI 面板各自亮起。
- 低保真可以接受，但画面主体必须是设备、托盘、料斗、供给线和锁定反馈。

## 与整体规划的关系

- 属于 `Demo First Playable Slice Assembly V1` 的可玩纵切装配。
- 继承 `Demo Playable UI And Art Pass V1` 的画面证据要求。
- 从 `Demo First Screen Assetized Scene V1` 复用已有低保真设备资产，不新增资源、配方、任务、区域或存档字段。

## 当前已有基础

- 晶体采集工作面 #2 / #3 已基本成立，本专题不再追加第三个同类晶体美术包。
- 第一工业路径层已经能读到回收清单、投料桥、仓储供给清单和整备锁定反馈。
- 新实机截图显示基地交接仍被大范围框、远端路线和旧路径焦点抢读。
- 2026-06-29 新 #2 截图仍处在晶体 / 污染边界语境，未触发基地交接专用工作面；不能作为本专题通过证据。

## 决策闸门结论

- 问题：基地交接连续性围绕同类截图反复修正后仍未成立。
- 已尝试：在 `DemoFirstIndustrialPathVisualLayer` 与交接 art pass 内追加清单、料斗、供给线、锁扣灯、短轨和透明度收束。
- 失败证据：玩家仍先看到大区域框、长路线和旧路径焦点，而不是设备交接件。
- 根因判断：同一程序路径层同时承担外勤路线、基地设备、交接反馈和背景压暗，阅读责任过多。
- 本轮决策：换介质并降范围，新增只服务基地交接的小工作面；旧路径层保留状态来源和远近切换，但不再继续做同类微调。

## 本轮范围

- 新增专用基地交接资产层，固定在前哨基地的反应器、仓储和整备台附近。
- 用既有 SVG 设备资产和本地绘制的托盘、料斗、供给线、锁扣灯构成画面主体。
- 按现有 `WorldState`、`CharacterState`、库存和设备状态决定当前交接阶段。
- 自动检查覆盖资产 manifest、基础形状、状态形状和视觉复核检查点。

## 当前不做

- 不新增第三个晶体资产包。
- 不新增基地新区域、敌人、任务、资源、配方或存档字段。
- 不提前推进污染处理或核心稳压段，直到基地交接截图能成立。
- 不继续沿旧路径层追加同类线框、透明度和提示调参。

## 玩家操作路径

1. 玩家采集晶体或收取采集器输出。
2. 回到基地收料口，看到返回物料被收进反应器入口。
3. 基础反应器加工中时，画面主体转为反应器料斗和加工反馈。
4. 产物可用时，仓储供给位亮起并把物料送向整备台。
5. 整备台锁定反馈亮起，表示可用于后续外勤整备。

## 运行时、存档与数据边界

- 读取现有库存、基础反应器状态、基础仓储和整备台结构状态。
- 不写入新状态，不改变保存格式。
- 专用层只改变场景表现，不改变交互结果和任务推进。

## HUD / 场景 / 对象反馈

- HUD 保持现有资源链口径。
- 场景主体改为设备资产和短距离物料交接件。
- 对象 marker 仍作为辅助反馈，不承担主要读法。

## 验收条件

- 基地交接 #2 / #3 截图中，玩家第一眼能看到反应器、仓储和整备台之间的物料交接。
- 回收清单、投料桥、仓储供给清单和整备锁定反馈像设备上的交接件，而不是漂浮 UI 噪声。
- 旧大框、长路线和远端工作点不再抢过基地设备主体。

## 验证计划

- 执行 `./scripts/check-client.sh`。
- 涉及 Godot 场景和脚本接入时执行 `./scripts/check-client.sh --with-godot`。
- 文档更新后执行 `./scripts/check-docs.sh`、`./scripts/check-text-files.sh` 和 `git diff --check`。
- 代码验证通过后，请继续提供基地交接 #2 / #3 实机截图做最终判断。
- 若截图目标、交互对象或小地图仍在晶体 / 污染边界语境，先修复复测位或状态触发，不进入下一段。

## 风险与后续决策

- 若专用工作面仍读成 UI 噪声，应继续降到单个设备交接口截图，不进入污染处理 / 核心稳压段。
- 若截图成立，再按同样原则推进污染处理和核心稳压段的场景化连续性。
