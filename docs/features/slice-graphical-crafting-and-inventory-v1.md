# Slice Graphical Crafting And Inventory V1

更新时间：2026-07-29

## 目的

把第一可玩切片的手持合成面板从“纯文字配方表 + 数字键记忆”升级为图形化基地整备界面。玩家打开面板后，应能直接看见可制造对象、产量、材料、可制作状态、已有建筑套件、当前放置对象和背包容量，不依赖开发者口头说明。

本专题是 [第一可玩切片全链串通](slice-first-playable-journey-v1.md) 的当前可执行表现层子专题；功能全链、配方、库存和存档继续沿用既有权威实现。

## 开工五问

1. **玩家结果：**玩家用鼠标即可理解并完成“查看材料 → 制作 → 选中已有建筑 → 进入放置”，并能从物品格确认制作结果和背包余量。
2. **实现介质：**复用现有晶体、催化剂、机械零件、工业地板和六类建筑像素资产；使用 Godot 容器、配方卡、物品格、短标签、状态色和按钮构成面板。
3. **成功证据：**正式 `Boot` 入口覆盖材料充足、材料不足、已有套件和当前放置对象；配方卡与背包格无截断、重叠或错误图标，鼠标与快捷键路径结果一致。
4. **失败判据：**仍需阅读长文字表或记住数字键；点击后不知道是制作还是选中；材料不足、背包已满和已有套件无法区分；图形界面复制出第二套配方或库存规则。
5. **文档落点：**本专题保存组件与交互契约，W31 周志记录实现和验证，规划入口只保留当前状态和下一步。

## 玩家路径

1. 玩家按 `B` 打开“随身制造”。
2. 左侧配方区按固定卡片显示物品 / 建筑图标、名称、单次产量和材料消耗。
3. 每张卡片直接显示“可制作”“缺少材料”或“背包空间不足”，制作按钮只在权威规则允许时可用。
4. 建筑卡片在已有套件时提供明确的“选中已有”按钮；选中后关闭面板并进入既有鼠标放置流程。
5. 右侧背包以固定物品格显示三类资源和六类建筑套件，空格仍保留图标身份和 `0` 数量。
6. 顶部继续显示当前旅程规则；底部提示 `B` / `Esc` 关闭与数字键快捷制作。

## 组件契约

### 配方卡

- 图标与名称共同表达产物，`×N` 单独表达单次产量。
- 材料消耗使用物品短名与数量，不把整张配方退回长句。
- 主按钮固定为“制作”；数字键 `1..7` 与该按钮完全同义。
- 建筑卡片另设“选中已有”；`Shift + 数字键` 与该按钮完全同义。
- 当前正在放置的建筑使用选中描边和“放置中”状态，不用隐藏数字变化表达。
- 材料不足或空间不足时禁用制作按钮，并显示具体阻塞原因。

### 背包格

- 固定展示晶体、催化剂、机械零件和六类建筑套件。
- 每格显示图标、短名和当前数量；不直接遍历私有库存字典，不改变物品 ID。
- 顶部显示总占用 `current / capacity`；容量仍按所有物品数量计算。
- 当前放置对象对应格使用选中态，帮助玩家把制作结果与世界放置关联起来。

### 反馈与输入

- 鼠标点击是完整主路径，数字键只作为稳定快捷方式。
- 制作成功后面板保持打开并刷新全部卡片 / 背包格；建筑制作继续进入既有放置态，但面板保持关闭的现有行为。
- 选中已有建筑不扣除材料或套件，进入放置后仍由既有确认动作扣除。
- `B` 与 `Esc` 均可关闭面板；打开面板继续关闭仓库、充能确认和设备操作等互斥前台。

## 权威状态与边界

- 配方与产量只读取 `SliceRecipes.RECIPES`。
- 制作、扣料、容量判断和进入放置只调用 `SliceWorld.craft()`；界面可读取同一规则生成按钮状态，但不得自行扣料。
- 背包数量和容量只读取 `Inventory`；不新增面板缓存、装备槽或快捷栏状态。
- 建筑定义与图标只读取 `SliceBuildingCatalog`；工业地板图标使用既有 tile 源区域。
- 不改配方、容量、物品 ID、自动铺地、放置规则、旅程阶段、schema 7 或存档目录。

## 实现包

### 包 1：配方卡与背包格

- 重建 `SliceCraftPanel` 场景结构，接入七张固定配方卡和九个固定背包格。
- 接入鼠标制作、选中已有、当前放置、材料不足和容量不足反馈。
- 保留 `B`、数字键与 `Shift + 数字键` 兼容路径。
- 更新现有合成 / 旅程专项，锁定图形组件身份、按钮状态与权威库存同步。

### 后续候选

- 如果包 1 人工确认后仍有明显草稿感，再单独决定筛选、分类、详情浮层或面板动效。
- 设备操作面板统一不并入本专题；世界 3/4 体积感继续作为架构级视觉专题。
