# Slice First Playable Journey V1

更新时间：2026-07-27

状态：**活跃，包 1 已完成，包 2 待实施**。承接已收口的基地、建造供电、物流反应器、多世界存档和首次外勤战斗专题，第一次从真实新档验证 20 到 40 分钟完整切片，而不是继续增加同层功能。

## 专题目的

现有专题已经分别证明六个玩家动词和关键系统可运行，但此前的正式入口证据按包拆分，后段路径会从 L5 保留世界开始。它们不能证明不了解项目的玩家能从新档自然走到切片终点。

本专题只解决一个问题：

**玩家能否从真实 `Boot → 新建世界` 出发，在没有状态注入和开发者口头指导的情况下，修复前哨、建立首条化工链、完成首次外勤并把关键样本交回基地。**

## 玩家结果

完成后，玩家应在一段连续体验中：

1. 从启动列表创建并进入新世界。
2. 采集晶体、制造修复零件并让前哨核心恢复运行。
3. 放置工业地板、供电、采集、储存、传送和反应器设备，产出 2 份催化剂。
4. 把催化剂交给核心完成工具充能，理解工业成果为何服务外勤。
5. 前往同图远征区，经历攻击、闪避、受击或撤离，击败唯一敌人并拾取关键样本。
6. 返回基地交付样本，获得抗蚀内衬与 `120` 最大生命的固定成长。
7. 在自然节点退出并重新载入后，仍能继续且不会卡死。

六个既定动词——移动、采集、战斗、建造 / 放置、加工、交互——必须在这条路径中自然发生；本专题不新增第七个动词。

## 决策闸门十问

1. **玩家新增什么动作？** 不新增动作；新增的是把六个已有动词组成可独立完成的一条旅程。
2. **世界发生什么变化？** 核心从损坏到修复，自动化链从无到有，工具从未充能到可战斗，敌人与样本进入完成态，角色最大生命从 `100` 提升到 `120`。
3. **如何服务基地与冒险闭环？** 基地产出的催化剂解锁战斗，外勤样本又永久强化角色，形成第一次双向回路。
4. **5 到 10 分钟内如何感知？** 每段都要出现清楚的工程、冒险或成长变化；完整路径必须在 20 到 40 分钟内结束。
5. **是否需要通用系统？** 包 1 不新增系统。若证据显示引导阻断，包 2 优先使用现有权威状态派生固定阶段目标，不复活旧通用任务链。
6. **能否复用现有地图和素材？** 能；限定为当前单基地 + 单远征区和现有像素资产，不新增地图或素材类别。
7. **成功证据是什么？** 自动断言、真实 `Boot` 有窗口输入链、关键节点截图、保留存档、萝卜SAMA人工复核，最后再由不了解项目的朋友盲测。
8. **失败怎么办？** 先按路径、理解、节奏、视觉或存读分类；只修阻断项。连续两次同类实机失败时停手升级，不堆提示或调参。
9. **是否复活旧系统？** 否；不复活旧 `GameRoot`、旧任务链、旧三槽存档、旧地图或旧 HUD。
10. **是否更接近切片完成？** 是；这是章程五条完成定义此前缺失的端到端证据。

## 权威路径与状态

路径固定为：

```text
Boot
→ StartupMenu 新建世界
→ 新档采集与手持合成
→ 修复核心
→ 建造供电、采集、物流和反应器链
→ 自然产出 2 catalyst
→ 核心首次充能
→ 晶体区唯一敌人
→ key_sample 拾取
→ 核心交付
→ corrosion_lining / 120 生命
```

`SliceSaveService` schema 7、多世界目录、现有世界状态和静态定义仍是唯一真相源。完整路径不得用测试注入直接写入最终库存、建筑、战斗或交付状态；允许测试脚本通过正式输入加速等待，但不得绕过玩家动作和权威规则。

## 实现包

### 包 1：真实新档全链基线与缺口审计

- 不修改玩法结果，先从真实 `Boot → 新建世界` 运行完整路径。
- 记录各阶段到达时间、交互次数、资源收支、自然保存点、失败恢复和需要猜测或口头解释的位置。
- 至少在化工链运行中或外勤前完成一次“保存返回 → 完全重启 → 载入继续”。
- 在核心修复、产线运行、工具充能、样本携带、样本交付五个关键节点抓图；多图先合成联系表。
- 输出按 `P0` 卡死 / 崩溃、`P1` 无法理解或超时、`P2` 打磨观察项分类的缺口清单。
- 一次性驱动脚本默认放 `/private/tmp`；只有形成稳定回归价值后才进入仓库。

包 1 出口：全链能够完成并形成可信时长基线，或准确定位阻断位置；不以“测试脚本跑完”代替视觉和路径判断。

2026-07-27 包 1 完成：真实 `Boot → StartupMenu → 新建世界` 无最终状态注入，依次完成 25 个有限晶体自举、37 个可再生晶体采收、31 次放置、自然产线、加工中重启续跑、2 催化剂取料与充能、三次鼠标攻击、样本拾取和核心交付。253 项断言通过；全程记录 84 次交互、101 次按键、48 个合成产物及约 390.7 秒最低生产等待。最终 schema 7 保存 `delivered / 120`、31 栋建筑和三份备份；隔离根为 `/private/tmp/radishcatalyst-first-playable-journey-package1/`，六张原图和联系表位于 `assets/art-intake/2026-07-27-first-playable-journey-package1-preview/`。

包 1 缺口分级：

- `P0`：无；完整路径、一次完全重启续跑、最终保存和世界摘要均成立。
- `P1` 理解：修复核心后 HUD 只显示“首次充能：催化剂 0/2”，没有把采集器、供电、工业地板、储物箱、传送带和反应器组成一条产线的下一步告诉新玩家；自动路径依赖已知布局，不能作为无人指导证据。
- `P1` 可读性：主要资源、目标与战斗 HUD 没有稳定底板或描边，在浅色基地 / 晶体地上对比不足；关键通知本身有描边，不是同一根因。
- `P2` 节奏：84 次交互、101 次按键和 31 次放置存在重复劳动风险；自动化使用传送和加速 tick，不能判定真实 20 到 40 分钟，留给包 2 人工计时，不在包 1 调配方或资源。

### 包 2：只修阻断路径、理解与节奏

- 只处理包 1 证明会阻断完成定义的 `P0` / `P1`。
- 优先修根因：权威状态、交互优先级、资源预算、空间路径和目标派生；不靠长说明或连续弹窗遮盖问题。
- 如需阶段目标，使用紧凑 HUD 和已有状态派生固定序列；不建立通用任务图、剧情系统或教程框架。
- 把“修核心后到首次充能”拆成由现有状态派生的短目标：先建立通电采集，再搭供电反应器与双端物流，最后取得 2 催化剂；配方 / 放置面板只补完成当前动作所需的一行规则。
- 给现有资源、目标、生命和战斗 HUD 增加同一套紧凑半透明承载底板或等效高对比处理；不借机做 HUD 换皮。
- 每个可分割修正执行匹配专项；玩家可见修正必须从真实入口复核。

包 2 出口：内部新档路径能在 20 到 40 分钟内稳定完成，无口头指导、不可逆卡死和崩溃。

### 包 3：完整验收与陌生玩家盲测

- 从干净世界完成一次正式入口全链，保留主档与三份备份。
- 萝卜SAMA先复核关键节点、时间、HUD、读档和完成态。
- 内部基线通过后，再交给一位不了解项目且不预设自动化经验的朋友，无人指导完成盲测。
- 只记录试玩者是否理解目标、为何出门 / 返回、是否愿意继续以及最想要什么；不在试玩过程中即时改规则。

包 3 出口：章程五条完成定义全部有证据。无论继续、调整或停止，第一轮产品可行性结论都能成立。

## 成功与失败判据

成功必须同时满足：

- 陌生玩家从新档在 20 到 40 分钟内完成整条路径。
- 玩家能用自己的话说明正在做什么、为什么出门、为什么回基地。
- 全程由正式像素场景、设备、角色、敌人和 HUD 表达，不依赖 debug 色块、流程图地图或长说明。
- 至少一次中途退出 / 载入后可继续，零不可逆卡死、零崩溃。
- 试玩者能回答是否愿意继续以及最想要什么。

以下任一情况视为未通过，不继续增加内容：

- 需要开发者口头提示才能找到目标或完成设备链。
- 正常操作稳定超过 40 分钟，或资源重复劳动掩盖了闭环。
- 存读、交互优先级、空间阻挡或资源预算造成不可逆卡死。
- HUD 继续加字仍不能让玩家理解路径。
- 同一类问题连续两次采用同类修正仍未通过实机复核。

## 边界

- 不新增敌人、Boss、装备词条、技能树、地图、化工配方或建筑类别。
- 不做立绘对话、八方向动画、viewport 整数重构、HUD 换皮或视觉打磨清单。
- 不做联机、角色 / 世界拆档、发布、打包或试玩分发平台建设。
- 不删除旧运行时层，不做与全链阻断无关的重构。
- 包 2 内部全链与人工计时通过前，不进入朋友盲测。
