# Slice Device Conveyor Docking Visual V1

更新时间：2026-08-12

状态：**反应器权威端口已按批准路线修正为 `local y=2`；同排正确连接态的 `12×24px` 收紧层经完整 Godot、正式 `Boot` 双状态证据与萝卜SAMA人工复核通过。下一步继续独立治理核心排序与覆盖。**

## 目的

统一设备短接口与玩家铺设传送带的连接视觉，让玩家同时看懂“这是设备自有端口”和“这里已经被真实传送带接通”，又不让整格带面遮住设备主体。

本专题承接 [世界设备家族接入 V1](slice-world-device-family-integration-v1.md) 的逻辑端点和 [视觉层级与色彩分离 V1](slice-visual-hierarchy-and-color-separation-v1.md) 的设备材质合同。它治理接驳几何、局部覆盖与排序，不改变传输、回压或物料语义；像素量测证明端口格错误时允许修正权威几何。

## 触发证据与根因

- 未连接底图已经恢复 batch06 / batch09 V1 的短方形接口；核心与反应器空口状态可读。
- 连接态当前把完整 `32×32px` 终端传送带提升到设备上层。局部接口确实被覆盖，但带面、侧框和下沿也越过设备白壳、悬臂或基座，形成“传送带挡住设备”。
- 因此问题不是单一 `z_index`，而是设备视觉锚点、端口外伸、连接格距离、终端带有效长度、局部遮挡范围和世界 y-sort 共同作用。
- 自动拓扑和物流专项通过只能证明连接成立；它们不能证明覆盖范围自然。2026-08-11 的连接态截图作为失败基线保留，不视为视觉通过。

## 玩家结果

1. 设备单独放置时，只显示属于设备的短接口、固定框、接驳颈和承重肩。
2. 方向正确的真实终端带接入时，只覆盖短接口需要插合的外段；设备白壳、主体、悬臂和基座不被整格带面压住。
3. 空格、普通经过带和方向错误时不显示连接覆盖。
4. 角色、货物、状态灯和供电线继续按原世界层级显示，不因端口覆盖跨越角色或设备主体。
5. 核心、反应器、采集器和储物箱使用同一接驳语法，但允许各自记录不同的纹理局部端口锚点。

## 冻结边界

- 逻辑端口格、`connection_distance`、传输方向、回压、source phase、足印、碰撞和 schema 8 默认冻结；已批准例外只有反应器双端从 `local y=1` 修正到 `local y=2`。
- 只有像素量测证明现行逻辑连接格无法表达自然接缝时，才升级讨论连接距离；不能为了遮图方便先改物流规则。
- 已批准设备主体、32px 网格、相机、光向和限定色板不重画、不缩放、不旋转。
- 未连接短接口是设备底图真相；连接态是运行时派生视觉，不保存到存档。

## 待审计几何

每类设备至少记录：

- 足印世界边界与 sprite 原点 / offset。
- 左右短接口 Alpha 包围盒、外伸长度、有效高度和与连接格的交叠像素。
- 终端带主体、顶面、侧框与封口的可见包围盒。
- 设备 y-sort 锚点、传送带 y-sort 锚点、角色可站区域和货物层级。
- 未连接、正确连接、方向错误、调整预览和重载后的派生状态。

首轮代表只量测修复核心与反应器；合同成立后再复核采集器和储物箱，不用四类设备同时试错。

## 方案闸门

| 方案 | 判断 |
| --- | --- |
| 整格终端带统一提升层级 | 已否决；覆盖接口的同时遮住设备主体。 |
| 为设备制作左 / 右 / 双侧连接主体变体 | 可表达精确遮挡，但会扩张主体资源和状态组合，暂不优先。 |
| 保持终端带原 y-sort，增加只覆盖接口的局部接驳盖片 / mask | 反应器跨错误网格行的两版已否决；端口纠正后，同排 `12×24px` 连接态收紧层已人工通过。核心仍需独立复核。 |
| 调整设备位置、传送带长度或连接距离 | 只在 P0 量测证明现有几何合同不可能成立时升级，不作为默认第一步。 |

优先方案不是预先批准的实现；P0 必须先给出像素表、局部剖面和至少两种候选对比，再由萝卜SAMA确认。

## 实施包

### P0：只读量测与失败复盘

- 清点历史短口、终端带四向素材、设备 offset、端口格和连接距离。
- 以现行失败截图标出“应覆盖区域”和“禁止覆盖区域”，输出核心 / 反应器像素坐标表。
- 不修改正式 PNG、GDScript、场景、端口逻辑或存档。

### P1：局部接驳候选

- 在忽略提交的 `assets/art-intake/` 只做确定性局部候选；不生成新设备主体。
- 同屏比较空口、正确连接和方向错误；必须同时保留设备身份、带面连续和白色固定框。
- 候选获人工确认前不接客户端。

### P2：运行时接入

- 连接覆盖只由统一端点拓扑派生，不在 `SliceWorld` 增加按设备 ID 拼贴的业务分支。
- 普通带保持世界 y-sort；局部覆盖必须限制在批准的接口区域，并在调整、拆除、旋转、重建和重载同帧刷新。
- 不新增持久字段。

### P3：正式入口与人工闸门

- 正式 `Boot` 保留核心 / 反应器的空口、正确连接、方向错误和角色邻近四类状态。
- 原图与接口局部图逐张核对：主体遮挡、带面接缝、HUD、角色、货物和状态灯。
- 自动检查通过但任一设备仍像“带子穿过机器”时，本专题不通过。

## 2026-08-12 P0 结论

- 核心纹理为 `144×128px`。左右终端带分别与主体产生 `495px` Alpha 重叠；若只允许覆盖外侧短口板，左侧仅 `126px / 25.5%`、右侧仅 `93px / 18.8%` 合法，其余会压住白色固定框、承重肩或底座。
- 固定核心 root 的 y-sort 锚点是 `320`，左右终端带锚点是 `352`；因此仅撤销终端带 `z_index = 1` 仍不能恢复自然排序，核心需要单独治理视觉排序锚点，但不移动逻辑端口或世界位置。
- 反应器纹理为 `176×88px`。`connection_distance = 2` 的左右终端带与真实短口 Alpha 重叠均为 `0px`，纵向存在 `11px` 透明断缝；整格提层不能建立接缝。
- 现行 endpoint topology 已能在统一 rebuild 中区分正确连接、方向错误与空口；调整、拆除、核心修复和重载也已有同帧刷新入口，不需要新增持久状态。
- 完整设备变体仍需要先解决排序，并会把核心、反应器、储物箱和采集器扩成约十四张主体帧，违反主体冻结且增加漂移风险，判为不优先。
- P0 推荐把“局部盖片 / mask”收紧为“端点驱动、跟随设备排序面的左右局部转接片”：核心只覆盖外侧短口板，反应器用局部转接片跨越 `11px` 断缝；左右片可组合，不复制主体。
- 若后续进入 P2，预计只触及四张局部资产、终端带排序、统一端点视觉快照、窄 docking visual 组件、现有 rebuild 转交点、固定核心视觉排序壳及核心 / 反应器专项；不扩张物流模拟或 `SliceWorld` 设备分支。
- 若获确认，P1 只在忽略提交的 intake 中为核心 / 反应器制作四张确定性小片并比较空口、正确连接、方向错误，不接客户端；若仍无法避免遮挡或穿角色，再升级讨论反应器端口格。
- 获确认前不修改正式 PNG、`slice_conveyor.gd`、核心排序、逻辑端口、`connection_distance`、足印、碰撞、schema 8 或现行检查。

## 2026-08-12 P1 候选

- 候选没有调用图像生成；以锁定核心 V5 / 反应器 V10 托盘态与当前短口态做确定性差分，两组主体左右各裁 `4px` 后逐像素对齐，变化只落在四个 `12×24px` 局部片。
- 首版误把“还原 V10 托盘”当成“接上真实终端带”：带面截止 `y=52`、局部片从 `y=58` 开始，仍有 `5px` 空行和 `7px` 最近像素距离，已由萝卜SAMA截图否决并撤回通过判断。
- 修正版把反应器局部片上移到 `y=46`，虽然制造了 Alpha 连续桥，但萝卜SAMA第二张截图确认终端带仍在端口上一格；第二次 AI 通过判断同样撤回。
- 根因是数据与资产网格不一致：反应器逻辑端口为 `local y=1`，左右连接格落在世界第 9 行；PNG 短口实际位于第 10 行，正好相差一个 `32px` 网格。局部片只能画折颈，不能满足“同一水平线”。
- 两次失败停手后，萝卜SAMA批准把反应器端口格改到 `local y=2`；`connection_distance = 2`、传输语义、足印、主体、碰撞和 schema 8 均不变，该步骤不接入任何跨排桥片。
- 权威目录与放置 / 反应器 / 物流精确合同已同步；专项新增旧中排必须断链的回归断言。萝卜SAMA进一步指出同排正确连接仍略显疏，确定性比较据此选择左右各一张 `12×24px` 托盘延伸片，不移动整格传送带。
- 收紧层由 `SliceLogisticsGrid` 的统一端点拓扑派生并附着到反应器排序面；只在正确 `input / output` 端点显示，旧中排、空口、普通经过带、方向错误、调整排除与重载重建均会清除或重算，不新增持久字段。
- 完整 `check-client --with-godot` 通过，其中反应器专项为 `145` 项；正式 `Boot` `39` 项保留两套 schema 8 世界：旧第 9 行明确 `unconnected / straight` 且无收紧层，新第 10 行明确 `connected / sink + source endpoint` 且左右收紧层可见。
- 两张 `3024×1701px` 截图确认左右带面、箭纹与短口同轴，间距缩短且未遮挡主体、端框、状态灯、HUD 或角色。复测档位于 `tools/runtime-intake/review-worlds/reactor-port-row/`，截图位于 `assets/art-intake/2026-08-12-reactor-port-row-preview/`；萝卜SAMA于 2026-08-12 确认这版通过，反应器分面收口，核心仍按独立几何继续专题。
