# Slice Ranged Weapon And Industrial Ammunition V1

更新时间：2026-08-13

状态：**P0 决策闸门与 P1 目标稿 V3 的枪械身份已获萝卜SAMA确认；原生尺寸 V1 / V2 / V3 均已否决，同类删臂拼接路线停止，等待架构级换介质确认，未授权客户端实现。**

## 玩家结果

核心首次充能后，玩家可以继续使用无弹药切割器立即外勤，也可以多运行一小段现有晶体—催化剂产线，把机械零件与催化剂加工成一把前哨脉冲步枪和一组晶体脉冲电池。外勤时玩家用 `1 / 2` 在切割器与步枪之间切换，左键使用当前武器，`Space` 闪避；HUD 同时说明当前武器、射击余量和补给缺口。

本专题要证明的不是“项目有了一把枪”，而是：

```text
基地继续生产晶体与催化剂
→ 玩家制造步枪和消耗电池
→ 外勤获得更安全但有限的远程选择
→ 电池耗尽后切割器仍能兜底，回基地补给有明确价值
```

## P0 专题开工十问

1. **新增动作：**核心充能后制作步枪 / 电池，按 `1 / 2` 切换，左键近击或远射。
2. **世界变化：**不新增地图或敌人；现有裂晶爬兽可被有飞行过程的脉冲弹命中，弹体、命中和耗弹均在世界与 HUD 可见。
3. **基地—冒险闭环：**步枪和电池都消耗现有机械零件与催化剂；远程安全距离以持续补给为代价，切割器始终无弹药可用。
4. **感知时长：**核心充能后的 5–10 分钟内可继续生产、制作、出发、射击、耗尽并切回切割器。
5. **系统范围：**只实现一把固定步枪和一种固定电池；不建设通用武器树、装备栏、词条、装填系统或伤害类型框架。
6. **现有范围：**沿用现有地图、敌人、鼠标瞄准、闪避、制造面板、分类库存、HUD 与 schema 8；只新增步枪 / 弹体 / 命中所需像素资产。
7. **成功证据：**自动断言、正式 `Boot` 制造与交战路径、同帧原生截图 / 录像和萝卜SAMA人工判断共同成立。
8. **失败处理：**若远射主体不可读或只是无形扣血，先换资产 / 表现介质；若远程彻底消除风险，则调整射程、伤害和消耗，不追加敌人血量或弹药系统层级。
9. **旧系统关系：**不复活旧 `GameRoot`、`J` 攻击、旧装备 JSON、旧快捷补给或旧敌人注册表。
10. **切片推进价值：**第一次把“基地工业产物”转为可主动选择、可耗尽、可回补的外勤战斗能力，而不是只延长基地数字链。

## 决策闸门五问

1. **玩家结果：**玩家能在近战稳定兜底与远程有限补给之间做出明确选择，并理解为什么要继续运行基地。
2. **实现介质：**固定像素步枪覆盖层、脉冲弹与命中 sheet；场景节点负责弹体移动和碰撞，HUD / 数据规则负责武器、余量和阻塞。程序绘制只允许调试辅助。
3. **成功证据：**基地制造态、步枪交战态、无弹药态、保存重载态至少四个正式入口状态；击中、射失、切换、UI 阻断与存档均有断言。
4. **失败判据：**步枪只读成文字 / 伤害射线、弹药与基地无关、数字键和制造互相抢输入、远程让现有敌人失去威胁，或重载复制 / 丢失玩家财产。
5. **文档落点：**本文件定义可执行范围；规划入口只链接当前状态；实现、失败与验证写入 W33 周志。

## 冻结功能合同

### 首把武器身份

- 名称：**前哨脉冲步枪**。
- 稳定物品 ID：`weapon.pulse_rifle`；装备类、唯一上限 `1`、不可进入传送带物流。
- 定位：通用探索用中距离单发武器，不是狙击枪、霰弹枪、自动步枪或特殊弹药发射器。
- 获得：核心首次充能后在现有制造终端显示配方；`机械零件 ×4 + 催化剂 ×1 → 前哨脉冲步枪 ×1`。
- 唯一性按背包与核心仓库合计判断；已有一把时配方显示“已制造”，不能重复消耗材料。
- 步枪必须在随身背包中才能选择；存入核心后不视为装备，不另建装备栏或 `equipped_weapon` 存档字段。

### 工业供弹

- 名称：**晶体脉冲电池**。
- 稳定物品 ID：`ammo.pulse_cell`；外勤补给类，随身与核心各按 `200` 上限管理。
- 配方：核心首次充能后显示；`机械零件 ×1 + 催化剂 ×1 → 晶体脉冲电池 ×8`。
- 每次成功发射立即消耗 `1`，射失同样消耗；没有命中退款、自动回收或无限备用弹。
- V1 不做弹匣与手动装填；电池数量就是可射击次数，避免增加需要持久化的半弹匣状态。
- 电池与步枪均可在背包和核心仓库间手动转移；V1 不进入储物箱、传送带或无线回库白名单，自动供弹留给后续独立判断。

### 战斗数值

| 能力 | 伤害 | 距离 / 时序 | 消耗与定位 |
| --- | ---: | --- | --- |
| 切割器 | `20` | 现行前伸与 `0.45s` 总周期不变 | 无弹药，3 击击败 `60` 生命裂晶爬兽 |
| 脉冲步枪 | `12` | 弹速 `720px/s`、最大 `320px`、每发约 `0.38s` 周期 | 每发 1 电池，5 发击败同一敌人 |
| 闪避 | 不变 | `96px / 0.18s`、冷却 `0.8s` | 与两种武器共用，继续中断未发动攻击 |

- 步枪用安全距离换取更低单发伤害与工业消耗，不提高敌人生命、不改变敌人蓄势 / 伤害 / 撤离规则。
- 一发弹体只命中第一个合法敌人一次；离开射程或碰撞后销毁。发射时锁定当帧瞄准方向，不追踪目标。
- 没有暴击、散布、穿透、击退、状态异常、弱点、爆炸或友伤。

### 输入与优先级

- 世界无阻断 UI 时：`1` 选择切割器，`2` 选择步枪，左键使用当前武器，`Space` 闪避。
- 制造面板开启时，数字键继续只属于配方；新增两项排在既有七项之后，可用 `8 / 9` 或鼠标制作，不切换武器。
- 建造放置、核心仓库、设备面板、确认层、暂停和系统界面继续阻断攻击、闪避和武器切换；关闭后必须重新按下左键。
- 没有步枪时按 `2` 保持切割器并给一条短提示；有枪但无电池时允许保持步枪选中，左键只给“电池耗尽 / 按 1 切割器”反馈，不生成弹体。
- 当前武器选择是会话态，载入世界默认切割器；这不会创造或丢失玩家财产。

### HUD 与制造界面

- 敌人 HUD 出现时，底部战斗操作条从“工具攻击 + 闪避”扩为两格武器与一格闪避：`1 切割器`、`2 步枪 · 电池 N`、`Space 闪避`。
- 当前武器依靠钢蓝细底边、文字和位置共同表达；无弹药用局部琥珀短状态，不能把整条 HUD 染成警告色。
- 玩家状态行只保留核心充能、当前武器状态与生命；不把射程、伤害、弹速或配方说明常驻 HUD。
- 制造面板在核心未充能时不显示两项新配方；充能后出现“装备 / 外勤补给”分组，现有七项顺序和 `1–7` 键义不变。

## 状态与存档边界

- 继续使用 schema 8；步枪和电池作为稳定物品 ID 写入既有 `pocket.contents` / `core_storage.contents`，不新增根字段或 schema 9。
- schema 2–7 迁移结果自然缺省为 `0`；旧 schema 8 也因没有对应键而保持 `0`，不赠送、不删除已有财产。
- 每次制作和发射都通过权威 Inventory 事务改变数量并触发现有自动保存；存档失败必须报告，不回补已经在内存中成立的射击。
- 不持久化当前武器、攻击阶段、弹体位置、冷却、瞄准方向、命中特效或临时 HUD 文案。
- 枪在核心、弹在背包等分离状态允许保存；只有枪在随身背包且电池余量大于零时才能实际发射。

## 实施包

### P1：资产目标与选定

- 先完成同一素材类别中的步枪持握覆盖层、脉冲弹、枪口和命中 sheet 目标；保持现行人物 `64px` 高度、四向瞄准与像素标准。
- 素材选定前不接客户端；图像生成调用遵守独立会话、每轮 `3` 次停手和 manifest 规则。
- 出口：世界比例、四向锚点、弹体轨迹和命中读法经萝卜SAMA批准。

2026-08-13，萝卜SAMA确认 P0 功能合同，允许进入 P1；本次授权只覆盖同一素材类别的目标候选生成、落盘和 manifest，不自动授权客户端接入。

同日完成 P1 首轮 `3 / 3` 图像生成：V1 因重画整个人物且比例失控淘汰；V2 超过 7 分钟无返回，清点确认没有落盘候选；V3 成功分离四向枪体、手臂、弹体和命中特效，推荐作为方向锚点。V3 仍是放大概念板，不能直接裁成正式 sprite；下一步停在萝卜SAMA人工判断，获批后再做基于现有工程师 `48×64px` 锚点的确定性原生尺寸重投影。

萝卜SAMA随后批准目标稿 V3 并点名进入原生尺寸重投影。V1 因重复枪体、idle 手臂冲突和弹体过宽否决；V2 因误读运行时 `flip_h` 语义、背向发射与肩线贴枪否决；V3 虽修正方向和高度，仍因删臂矩形破坏人体、分离手臂没有肩—肘—腕—双手受力链而否决。三版属于同一局部拼接介质，触发两次失败停手规则；当前建议换为侧向源 / 朝上 / 朝下三组完整人物持枪帧，不再从 idle 人物挖空合成。换介质属架构级升级点，等待萝卜SAMA确认，不接客户端。

### P2：工业供弹与库存财产

- 接入两个物品、分类、配方、充能解锁、唯一武器阻塞、背包 / 核心转移与 schema 2–8 兼容检查。
- 正式 `Boot` 覆盖未充能隐藏、充能后制造、重复制造阻塞、转入 / 取回核心和重载数量一致。
- 出口：玩家能完成“继续生产 → 制造步枪 / 电池 → 带上外勤”的基地路径；本包不伪造射击完成。

### P3：远射、输入与 HUD

- 接入资产、弹体、伤害、耗弹、`1 / 2` 切换、UI 输入互斥与战斗 HUD。
- 正式 `Boot` 覆盖射失耗弹、五发击败、无弹药切回切割器、闪避中断、撤离与保存重载。
- 彩色、低饱和、灰阶与原生窗口共同检查人物、弹体、敌人、余量、当前武器和危险预警；人工通过后专题才收口。

## 不做

- 新敌人、敌潮、Boss、地图、任务、教程、掉落表或区域门槛。
- 第二把枪、特殊弹药、自动 / 连发、蓄力、装填、武器升级、词条、耐久、装备栏或技能树。
- 自动供弹、弹药传送带物流、新生产设备、有限电力、负荷、储能或 schema 9。
- 复活旧 Demo 战斗 / 装备系统，或用程序线、矩形、无形射线作为正式远射主读法。

## 验收

- 玩家无需说明即可看出当前使用切割器还是步枪、还剩多少次射击，以及无弹药后如何继续战斗 / 回基地补给。
- 步枪弹体、命中和射失都在世界中可见；射击不会穿过 UI、重复命中或免费造成伤害。
- 一组 8 电池足以击败当前敌人但不是无限资源；远程提高安全选择而不替代无弹药切割器。
- 制造、转移、射击、保存重载和 schema 2–8 迁移不复制、不吞没步枪或电池。
- 完整 `check-client --with-godot`、正式入口、原生截图 / 录像和萝卜SAMA人工路径全部通过。
