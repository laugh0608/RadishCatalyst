# Godot First Production Line Demo V1

更新时间：2026-09-08

状态：独立 Demo、定向检查和窗口截图复核完成，交给萝卜SAMA亲测；正式迁移未批准。

## 决定与玩家结果

先在既有独立 Godot 3D 工程复现已认可的 [Web 三机产线](web-first-production-line-v1.md)，直接比较画面、操作手感与流畅度，再决定正式技术路线。本决定优先于旧规划与技术评估中的“停止追加 Demo / 等待正式迁移确认”。

玩家从空厂坪移动、放三台设备、拖铺有方向的固体带，看到真实催化剂入仓；拆开输入后耗尽余料而缺料，补接后新批次再次入仓，亦可尝试输出回压、拆回和投入回收物。

## 开工十问

1. 动作：与 Web 一致的移动、放置、拖铺、选取、旋转带、拆回和投入，不新增玩法。
2. 世界：拓扑决定物流、缺料 / 回压与恢复，库存和画面货物来自同一状态。
3. 价值：用同一生产循环比较技术承载能力，为正式路线选择提供体验证据。
4. 感知：目标在 5–10 分钟亲手接通并经历恢复，实际时长与感受由用户评价。
5. 系统：独立 GDScript 有限网格模型，固定步长；不接正式二维运行时。
6. 素材：复用 Web 本地自制几何与配色，导出 glTF 供 Godot 使用；相机、实体端口与弯道按相同尺寸重建，不安装依赖或引入外部资产。
7. 证据：定向规则与跨实现状态对照、真实独立入口输入链、窗口截图和小场景帧时间记录；用户亲测单独验收。
8. 失败：区分投影、几何、状态和输入问题；同一可见问题两轮同类修正失败即复盘，不扩大画风探索。
9. 旧实现：保留原视觉 Main 与 Web `/play/`；旧 Godot 的近身 E、建造倍率、供电与仓库模式不移植。
10. 阶段：得到可直接亲测的同规则比较，完成后讨论正式路线，不提前引入持久化或大型工厂实现。

## 固定范围

- 工程 `tools/visual-studies/topdown-3d/`，新场景 `production/Production.tscn`。现有启动脚本增加 `--production` 与定向验证参数，默认旧视觉入口保留。
- 造型、场坪、角色沿用 Web 本地几何；默认正交俯角 50°、偏航 25°，同方向暖光、低饱和青灰与琥珀配色。设备边缘常显一枚连接台箭头；不显示场地常驻名称文字，详情在面板。
- 规则以 Web `production/model.mjs` 为本包真相源：20×13 建造区、预供电、各一台设备 / 24 段带；采集器 / 仓 2×2、反应器 3×3，矿点和输入 / 输出固定格位与方向完全一致。
- 采集 1 晶体/秒，缓冲 50；原子消耗 2 晶体、10 秒生成 1 催化剂，输入 2 / 输出 1；带每格一件、1 格/秒、正交转角、不反向对撞、争用轮询；终端仓容量 200，回收箱容量 200。
- 拆回前完整校验容量，回收构件与全部内容，在制批次按 2 晶体回收；失败无部分变更。载货带不直接旋转。投入只接收合法物料，不计为带运入仓。
- WASD / 方向键按屏幕方向移动，建造时可走；点空地移动。实体不能压人或重叠，带可跨越。拖铺跨格补齐、回拖缩短、障碍停止、整段原子提交；Esc、失焦、离开场地 / UI 撤销预览。Q / E 转角、滚轮缩放，R 转带向，按钮可完成主要动作。
- 输入缺口 → 真实缺料 → 补接后的新批次入仓构成恢复，不以旧在途产物或回收投入冒充。观察 / 建造不自动变倍率。
- 失焦或手动暂停停止模拟，无后台补产；关闭 / 确认重开重置。没有游戏存档，正式 `client/` 与 schema 不变，不引入液气、多人与额外规则。

## 验证与交接合同

- 纯规则覆盖合法 / 非法放置、拖铺原子性 / 回拖 / 跨格 / 障碍、真实端口与八种转角、汇流公平、计时一致、缺料 / 回压 / 恢复、拆回容量与晶体当量 / 构件守恒。共享输入序列比较 Web 与 Godot 的状态结果。
- 独立 `Production.tscn` 从空场坪启动，通过实际输入事件完成放三机、拖铺折线、选择 / 拆带、缺料、补接和新产物入仓；不直接改隐藏状态冒充操作路径。另以定向夹具覆盖难以在一次亲测内达到的满仓边界。
- 窗口截图复核空场、端口 / 拖铺、50° 运行、真实弯道货物、断路和恢复、旋转视角与人物遮挡；入口替代仅限本独立 Demo，不运行或替换正式 Boot。
- 记录本机引擎、渲染器、窗口分辨率和局部运行帧时间样本。该证据仅适用三机与最多 24 带，不代表大型工厂、Windows 目标机或长时性能通过。
- 日志与测试夹具位于忽略目录 `tools/runtime-intake/check-runs/godot-production-line/`，交互日志位于 `tools/runtime-intake/review-worlds/godot-production-line/`；截图位于 `assets/art-intake/2026-09-08-godot-production-line-preview/`。
