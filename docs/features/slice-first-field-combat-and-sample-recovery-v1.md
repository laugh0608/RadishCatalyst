## 玩家路径与战斗规则

1. 玩家在现有空间产线取得 2 份催化剂，到已修复核心按 `E`，明确确认消耗后完成首次充能；充能是永久外勤许可，不是攻击弹药。
2. HUD 把目标切为“前往东侧晶体区调查活动迹象”，不新增地图或传送切换。
3. 裂晶爬兽只有警戒、追击、蓄势近击、恢复、回巢和败亡六类可读状态；离巢过远会回到固定锚点并恢复满生命，避免无限风筝。
4. 角色到鼠标世界坐标的向量是连续瞄准方向，并量化为现有上 / 右 / 下 / 左四种角色画面；移动动画按速度播放、朝向按鼠标选择，因此允许侧移和后退，不借机扩八方向素材。
5. 鼠标左键按下立即发动一击；持续按住时只在上一击恢复结束后续攻，松开停止后续攻击。攻击矩形沿连续瞄准向量放置，一次挥击只命中同一敌人一次。
6. `Space` 优先沿当前 `WASD` 移动输入闪避；无移动输入时沿鼠标瞄准方向。闪避提供短暂无敌并中断尚未发动的后续连攻，不取消已经进入生效段的命中。
7. 鼠标不负责点击移动或拖动镜头，当前相机继续跟随角色；“视野方向”在本专题中指角色观察与武器瞄准方向。
8. 玩家生命归零后自动撤离到核心旁，恢复到 `50/100`（交付后 `60/120`）；基地、库存、核心充能和已交付进度不丢失，敌人与未拾取样本按下述状态恢复。
9. 敌人首次败亡只生成 1 份晶腺样本。样本不进入有容量上限的普通背包，使用任务持有态，避免背包满导致关键物丢失。
10. 玩家拾取样本后回到核心按 `E` 交付；核心分析后永久安装抗蚀内衬，把最大生命从 `100` 提升到 `120` 并回满生命。本专题到此结束，不展开技能树。

首轮平衡值是验收起点，不是通用数值系统：

| 项目 | 首轮值 |
| --- | --- |
| 玩家攻击 | 左键按下立即攻击、按住按恢复节奏续攻；沿连续鼠标方向；`20` 伤害；约 `0.12s` 前摇、`0.10s` 生效、`0.23s` 恢复 |
| 玩家闪避 | 约 `96px / 0.18s`；无敌 `0.22s`；冷却 `0.8s` |
| 敌人 | `60 HP`、追击速度约 `80px/s`、警戒 `220px`、离巢 `320px` |
| 敌人攻击 | 蓄势 `0.4s`、伤害 `20`、恢复 `0.8s` |

## 受击、撤离与样本状态

权威遭遇状态只取以下五值：

```text
locked -> hostile -> dropped -> carried -> delivered
```

- `locked`：核心未充能，敌人不进入可战斗状态；充能后转 `hostile`。
- `hostile`：保存玩家当前生命和敌人当前生命；暂停保存 / 返回后读档保留双方生命，但敌人从锚点 idle 恢复，不保存半段蓄势。
- `dropped`：敌人已败亡，样本位于固定掉落点；退出重进仍在原处，不重复生成敌人或样本。
- `carried`：样本随该世界角色持有；撤离、暂停返回和重启不丢失，不在地图重复生成。
- `delivered`：敌人不复活，样本不再掉落，最大生命收益由该状态派生。

撤离发生在 `hostile` 时，敌人回满并保持 `hostile`；发生在 `dropped` / `carried` 时不回滚样本进度。攻击段、敌人 AI 子状态、闪避冷却、无敌帧、蓄势剩余时间和临时 HUD 文案均不落盘。

## HUD 与交互优先级

- 常驻增加紧凑生命条 / 数字、充能状态和当前目标；不复制旧大面板。
- 敌人在警戒范围内才显示名称、生命和“追击 / 蓄势 / 恢复”短状态；敌人离开范围即收起。
- 闪避冷却只以短图标 / 色态反馈，不增加体力系统。命中、受击和无敌使用 sprite 帧、短闪与轻量动态高亮，不用程序几何作主画面。
- 撤离反馈只说明原因、保留项和下一步；核心交互严格按“交付样本 → 首次充能 → 核心仓库”处理，避免一次 `E` 同时触发多个动作。
- 合成、仓库、建筑操作、放置、暂停或确认面板在前台时禁用攻击与闪避；UI 先消费鼠标事件，世界层只响应未被 UI 消费的左键，关闭前台 UI 后必须重新按下才可攻击，既有 `Esc` 关闭 / 返回优先级不变。

## 存档 schema 7

新增并严格校验：

```text
player_health: int
field_encounter:
  state: locked | hostile | dropped | carried | delivered
  enemy_health: int
```

- `player_max_health` 由 `state == delivered` 派生为 `120`，否则为 `100`；敌人是否存在、样本位置和收益同样由状态派生，避免互相矛盾的布尔字段。
- `core_energy` 继续沿用现有字段；首次充能阈值改为 2，既有值不向下改写。schema 2–6 缺省生命 `100`，再按核心能量迁为 `locked` 或 `hostile`。
- `locked / hostile` 的敌人生命须为 `1–60`，后三态须为 `0`；玩家生命须落在当前派生最大值内。候选不满足映射时不得静默改值。
- 所有战斗伤害、败亡、拾取、交付和撤离完成后自动保存；普通 AI tick 不写盘。候选生命越界、未知状态或状态 / 敌人生命矛盾时整份候选失败并按既有备份链回退。
- 不拆角色档 / 玩家档，不跨世界共享强化，不修改多世界目录所有权。
