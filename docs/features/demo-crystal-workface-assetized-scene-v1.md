# Demo Crystal Workface Assetized Scene V1

更新时间：2026-06-28

## 用途

本文定义默认路径晶体采集工作面的资产化重建范围。目标是停止在同一程序绘制层里继续叠线、遮罩、透明度和焦点框，改用低保真资产 / 场景节点建立“当前矿脉 -> 采集器 -> 输出托盘”的可操作工作面。

本专题仍属于「首版 Demo 可玩纵切装配第一版」和 UI / Art 执行线，不是新区域、新资源链、试玩验收或最终美术包。

## 玩家价值

玩家进入晶体段后，不读任务文字也应能判断：

- 这里是晶体采集工作面，不是全图规划线框。
- 当前矿脉是可采集对象。
- 采集器正在把晶体送到输出托盘。
- 输出托盘是可拿取产物的地方。
- 玩家站位、短物料流和设备体积说明当前操作关系。

## 与整体规划的关系

- 服务 [Demo First Playable Slice Assembly V1](demo-first-playable-slice-assembly-v1.md) 的第一次晶体外勤和回基地入料。
- 承接 [Demo Playable UI And Art Pass V1](demo-playable-ui-and-art-pass-v1.md) 的晶体段失败复盘。
- 复用 [Demo First Screen Assetized Scene V1](demo-first-screen-assetized-scene-v1.md) 与 `DemoDefaultPathAssetLanguageArtPass` 已建立的低保真资产语言。

## 触发复盘

问题：晶体段 #2 / #3 连续多轮实机截图仍无法第一眼读成可操作采集工作面。

目标：当前矿脉、采集器机体、输出托盘、局部地面和短物料流成为画面主体。

已尝试方案：降低旧路线 / 旧矩形 / 非当前晶体线稿；追加当前矿脉、采集器机头、托盘、短流、局部暗面、机台甲板和 focus ring 降权。

实机失败证据：自动检查通过后，新截图仍主要读成线框矿区、标签、焦点框和几何叠层；托盘、矿脉和设备没有从旧线稿里脱离。

根因判断：继续在 `DemoCrystalResourceVisualLayer` 上用 `draw_line`、`draw_rect` 和半透明 polygon 叠加，只会产生新的流程图层，不能建立低保真游戏工作面。

决策：换介质 + 拆专题。

下一步玩家可见结果：用资产 / 场景节点重建一个窄范围晶体采集小场景。

不再继续的做法：不再追加透明度调参、旧线稿降权、焦点框压低、标签位置微调或同层几何遮罩包。

验证方式：自动检查只证明接线；通过必须依赖 #2 / #3 实机截图确认主体成立，#1 / #4 只做回归观察。

## 本轮范围

1. 采集工作面资产介质：
   - 建立当前矿脉、采集器机体、输出托盘、局部矿面和短物料流的低保真资产 / 场景节点。
   - 资产必须有体积、材质色、端口和用途关系。
   - 程序绘制只保留动态反馈和轻量高亮。

2. 晶体 focus 内旧层退场：
   - 晶体 focus 范围内旧线框矿区、远端路线和规划矩形不再承担主体表达。
   - 非当前晶体生态只作为背景环境或直接退场。
   - 交互 label 和 focus ring 只辅助当前目标，不覆盖玩家和设备。

3. 输出托盘可拿取读法：
   - 托盘需要显示边框、容器深度、晶体 / 颗粒产物和短入料口。
   - 玩家靠近时能从场景判断“这里拿输出”，文字只作确认。

4. 回归保护：
   - 不主动改基地交接段、污染段、核心站和资源链。
   - #1 作为基地回归对比，#4 观察污染段是否被间接影响。

## 当前不做

- 不新增区域、任务、资源、配方、敌人、设备或存档字段。
- 不重画完整晶体区、完整 12 区地图或最终美术。
- 不把自动检查全绿当作视觉通过。
- 不继续在旧程序绘制层上追加同类降噪包。

## 玩家操作路径

```text
进入晶体矿脉 -> 看见当前矿面和采集器 -> 手采或确认采集器输出
-> 拿取输出托盘 -> 带回基地入料
```

## 运行时、存档与数据边界

- 资产和呈现层不进入存档。
- 继续读取现有任务、库存、采集器和交互对象状态。
- 不迁移稳定数据 ID。
- 若需要新 helper，只能负责资产呈现或视觉切换，不承载玩法状态。

## HUD / 场景 / 对象反馈

- HUD 继续承担当前目标和按键确认，不解释完整工作面。
- 场景主读法来自矿面、采集器、托盘和短物流。
- 当前交互高亮必须低于设备 / 托盘主体，不得再次变成黄框主视觉。

## 验收条件

- #2 截图不读文字也能识别当前矿脉、采集器和输出托盘。
- #3 截图里输出托盘像可拿取产物，不靠横向 label 解释。
- 玩家、托盘和采集器之间不被旧晶体线稿、路线或大框穿透。
- #1 基地回归不明显变坏，#4 污染段不被间接破坏。
