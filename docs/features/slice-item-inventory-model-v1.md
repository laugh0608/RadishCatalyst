# Slice Item Inventory Model V1

更新时间：2026-07-19

状态：配方加工 arc 的 **L0 资源模型改造** 可执行细专题。**纯数据地基**：把资源从全局 `int` 计数改成"空间物品 + 背包"。包 1 已实现（2026-07-19，25 项运行时断言全过）。原计划的包 2（核心仓库 / 机器进出料 / 手动搬运）经萝卜SAMA实机复核判定**抢跑了上层机制**，已撤回并重分配到对应层（见下"移出 L0 的能力"）。arc 总览与层状态见 [Slice Recipe Processing V1](slice-recipe-processing-v1.md)。

## 定位

L0 只做一件地基事：**晶体从全局计数改为背包 `pocket` 里的空间物品**（采集器产出改为各自输出缓冲）。它不引入任何"机器喂料 / 中央存储 / 物品搬运"机制——那些都属上层：核心中央仓库与电力属 L2，储物箱属 L4（传送带两端），反应器进出料与催化剂属 L5（传送带喂料）。L0 是 L1–L5 的共同前提，纯逻辑、不依赖新素材。

## 玩家价值（地基层）

- 看到：背包晶体计数（带上限）、采集器输出缓冲存量——晶体是"实物、有位置、背包装得下才拿得走"。
- 做：采集晶体进背包（满则拿不动）→ 用背包晶体修复核心 / 在整备台造采集器 → 采集器自动攒进缓冲 → 走近按 E 把缓冲取进背包。
- 理解：资源不再是一个总数，而是分布在世界里、要靠玩家（之后靠传送带）搬运的实物。这是工厂自动化的第一性认知，也是后续电力 / 放置 / 传送带的地基。

## 数据模型

- **物品 id**：字符串常量 `"crystal"`（`"catalyst"` 等在其产出层引入），集中定义避免散字符串。
- **`Inventory`**（`RefCounted`）：`Dictionary` item_id→count + `capacity`（0 = 无限）；`add` / `remove`（返回实际量）、`count` / `total` / `is_full` / `to_dict` / `from_dict`。
- **归属（L0 范围内）**：玩家背包 `pocket`（上限 30）；每台采集器 1 个输出缓冲（上限 10）。其余容器（核心仓库、反应器进出料、储物箱）在各自层引入。

## 交互（L0 范围内）

- 采集簇：采集 → `pocket.add("crystal", 产量)`，背包空间不足则拒采并提示。
- 采集器：产出进自身输出缓冲（满则暂停）；走近按 E 取料 缓冲 → 背包。
- 核心修复 / 整备台造采集器：消耗背包晶体（逻辑不变、源改背包）。
- 反应器：暂惰性（不产出、不喂料）——其运转属 L5，由供电 + 传送带进出料驱动，不做手动激活 / 手动喂料。

## 数值草案（可调）

- 背包容量 `30`；采集器输出缓冲 `10`；采集器造价 `5 晶体`；核心修复 `10 晶体`；采集器产出 `10 秒 / 1`。
- 亚周期产出进度不入存档（读档从 0 重计，同既有口径）。

## 存档 / schema

- `SliceSaveService` schema `2`：序列化背包 `pocket` 与各采集器 `[{cell, buffer}]`，保留 `core_repaired` / `harvested_clusters` / `collectors` / 玩家坐标等。旧 schema 1（抽象原型档）不迁移、按新档重开（切片期单份原型可接受）。

## 范围

### 包 1：库存模型 · 背包 · 采集侧（已实现 2026-07-19）

- `Inventory` + 背包 + 采集器输出缓冲；采集簇→背包、采集器→缓冲→（E）背包；核心修复 / 造采集器改走背包晶体；HUD 背包读法；schema 2。
- 出口（已达成）：采集进背包、背包满拒采、采集器缓冲满暂停并可取料、修复 / 造采集器扣背包晶体，存读还原背包与采集器缓冲；运行时 25 项断言全过、实机截图留档。

**L0 到此为止**（原包 2 已撤回）。收口 = 包 1 实机确认后回填 arc 层状态表 L0 = 已收口。

## 移出 L0 的能力（重分配，防再次抢跑）

- **核心 = 电力 + 中央仓库**（参照《终末地》基地核心：修复后既供电、又是可存取的中央仓库，背包物品可存入核心仓库或留在背包）→ **L2 核心功能化（电力 + 中央仓库）**，含背包↔核心手动存取。
- **反应器进出料 + 催化剂产出 + 核心充能** → **L5 反应器接入**：反应器经供电 + 入口 / 出口传送带自动进出料，**不做手动喂料**。
- **储物箱** → **L4 传送带物流**：放在传送带两端（一端喂晶体、一端收催化剂）。

## 不做

- 不做核心中央仓库、电力、建造放置、传送带、催化剂、充能（均属上层）；不做任何"手动按键给机器装 / 取料"（机器物流一律走传送带）。
- 不生成新素材；不迁移、不修改冻结旧系统与旧检查。

## 验收与移交

- L0 收口 = 包 1 实机（采集 → 背包 → 修核心 / 造采集器 → 采集器缓冲取料，存读还原）经萝卜SAMA确认；回填 arc 层状态表、同步三入口、记周志。
- 下一层 L1（手持合成面板）或 L2（核心功能化：电力 + 中央仓库）由萝卜SAMA择序。
