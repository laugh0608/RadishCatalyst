# Demo Base First Screen Asset Quality Pass V1

更新时间：2026-07-01

## 用途

本专题接续 [Demo Base First Screen Raster Art Pack V1](demo-base-first-screen-raster-art-pack-v1.md)，用于 2026-07-02 推进基地首屏资产质量。

`Raster Art Pack V1` 已把主介质从程序色块 / SVG 线稿切到 PNG 分件，但截图对比确认仍明显低于目标参考：地表像大块贴片，设备像扁平图标，视角、光照和尺度没有形成统一工业基地画面。

## 玩家价值

- 新档第一眼应读成可操作的异星化工前哨，而不是素材测试场或流程图。
- 玩家应能从地表、金属平台、核心设备、反应器、储存、整备台、管线和污染 / 晶体边缘判断场景用途。
- 画面质量提升必须直接服务“我在基地里修复和启用设备”的行动理解。

## 本轮范围

1. 首屏资产质量提升：
   - 重新调整浅色岩地材质，减少整块平板感，补碎石、磨损、色温变化和局部阴影。
   - 强化前哨核心、基础反应器、储存和整备台的体积、朝向、接地阴影和材质差异。
   - 统一设备、管线和平台的斜俯视尺度，避免 sprite 像贴在地图上的图标。
   - 保持晶体 / 污染只作为右侧边缘上下文，不抢基地主读法。

2. 运行时装配收束：
   - 继续使用 `DemoBaseFirstScreenSceneLayer` 承载首屏。
   - 保持首屏层只在 `region.outpost_platform` 启用，不覆盖晶体区。
   - 旧 `Polygon2D` / 程序几何只承担端口、高亮、状态灯和检查辅助。

3. 复测证据：
   - 用默认新档首屏截图判断首屏是否更像 2D / 2.5D 工业科幻 ARPG 场景。
   - 自动检查只证明资产路径、shape、区域门禁和运行时接线没有断裂。

## 当前不做

- 不导入整张参考图作为背景。
- 不新增区域、任务、资源、配方、敌人、存档字段或完整最终美术管线。
- 不推进污染处理、核心稳定站或全地图重绘。
- 不把 HUD 文案、目标箭头、检查字符串或透明度调参当作主要交付。

## 玩家操作路径

```text
新档进入前哨基地
-> 看到更完整的岩地、平台、设备和管线工作面
-> 靠近前哨核心
-> 执行现有恢复交互
-> 通过设备和局部反馈确认基地正在恢复
```

## 验收条件

- 默认首屏不再主要像平面贴片或 debug 地图。
- 核心、反应器、储存和整备台能通过体积、材质和位置区分用途。
- 地表和平台能提供接地感，玩家、设备和管线属于同一空间。
- 首屏层不会在晶体区工作面出现。
- 玩家仍能完成一次现有首屏交互。

## 验证计划

- `./scripts/check-client.sh`
- 涉及资产生成或 Godot 导入时执行 `./scripts/check-client.sh --with-godot`
- 文档改动执行 `./scripts/check-docs.sh`、`./scripts/check-text-files.sh` 和 `git diff --check`
- 收口时用一次默认首屏实机截图做观感复核。
