# Slice First Journey Guidance And Exploration Map V1

更新时间：2026-08-15

状态：**P1—P3 已实现并通过自动、正式 Boot、逐图与萝卜SAMA人工确认；专题收口。**

## 玩家结果

新玩家进入前哨后，不依赖开发者说明即可依次理解“打开随身终端 → 查看机械零件配方 → 去东侧寻找晶体 → 采够 9 个晶体 → 制造 3 个机械零件 → 返回核心修复”。右下小地图始终说明玩家在哪，并把任务情报与真实探索分开：进度只给方向和模糊搜索区，走过的地形才永久揭开。

## 触发证据与根因

- `SliceJourneyGuidance` 已生成“按 B 合成”的 `rule`，但 `SliceHud` 只显示 `goal`；新档因此只知道要造零件，不知道如何打开制造入口。
- B 实际打开同一“制造 / 背包”随身终端且默认进入制造页；若只称“背包”，会教错现行界面心智。
- 当前 `SliceHud` 没有小地图；旧 `PrototypeHud` 地图属于废止的 12 区纵切，不得搬回当前单基地 + 单远征区切片。
- 当前地图为固定 `2560×768px`，基地在西、晶体地在东；纯行走揭雾不能解决开局找路，纯进度解锁又会抹掉探索感。

## P0 决策闸门

1. **玩家动作：**按 B 查看配方、移动探索、按 E 采集、制造零件并修复核心。
2. **世界变化：**迷雾记录玩家走过的粗格；任务进度逐步公开基地、晶体信号与返回核心标记。
3. **闭环价值：**首次采集不再是盲走，玩家能理解资源为何外出、配方为何回到终端与核心。
4. **感知时长：**新档前 3–8 分钟持续可见，修复核心后退出强教程，只保留正常地图。
5. **系统范围：**首程派生器、制造面板事件、HUD 小地图、存档与检查；不建设通用任务图或完整世界地图。
6. **现有范围：**复用现行配方、库存、晶体簇、玩家位置、核心修复与深钢 HUD；不生成新素材。
7. **成功证据：**正式 Boot 覆盖首次打开、配方发现、晶体搜索、采集、制造、修复和半途重载；原图与去色图确认 HUD 不遮挡。
8. **失败处理：**若小地图仍像调试色块、任务一次塞满全部说明或重载丢雾，停止加提示并回到信息层 / 存档设计。
9. **旧系统关系：**不复活旧 Demo 区域数据、`PrototypeHud`、通用任务链或旧 `SaveService`。
10. **推进价值：**直接修复陌生玩家首个硬阻断，并为之后的晶体区、战斗目标和区域推进建立导航底座。

## 首程状态

| 阶段 | 当前任务 | 完成条件 |
| --- | --- | --- |
| 打开终端 | `按 B 打开随身终端` | 制造 / 背包终端首次打开 |
| 查看配方 | `选择机械零件，查看制造配方` | 玩家实际选中机械零件卡 |
| 寻找晶体 | `前往东侧晶体信号区，采集晶体（N/9）` | 随身晶体达到 9；显示模糊晶体搜索区 |
| 制造零件 | `按 B 制造机械零件（N/3）` | 随身零件达到 3；再次聚焦零件配方 |
| 修复核心 | `返回前哨核心，按 E 完成修复` | `core_repaired == true`；显示核心标记 |

- 首程目标用一行行动句 + 一行短规则，不用长教程弹窗。
- 打开终端后默认选中并强调机械零件；材料区必须显示 `3 晶体 → 1 机械零件`，任务总需求显示还差多少晶体。
- 玩家已有晶体、零件或已修复核心时从权威状态跳过不再适用的阶段；两个首次查看旗标只防止空档重载倒退。

## 混合迷雾合同

- 小地图位于右下安全区，宽屏呈现当前 `2560×768px` 世界；显示玩家位置 / 朝向、当前区域、任务搜索区、核心与已发现目标，不显示所有资源或全图长标签。
- 固定 `64px` 探索格组成 `40×12` 位图。新档默认揭开基地起步区；玩家移动时揭开当前位置周围粗格，已揭开格永久保留。
- 进度情报可以穿过迷雾显示模糊方向 / 搜索区，但不会直接揭开地形或精确晶体节点；进入附近后才显示精确目标。
- 修复核心后结束强教程，地图继续保留玩家、已探索地形和当前外勤目标；完整大地图、缩放、图层筛选与自定义标记延期。

## schema 9

- schema 9 在现行根字段上新增 `first_journey_flags` 与 `explored_map_bits`；旧 schema 2–8 继续只读迁移并在世界完整重建后发布。
- `first_journey_flags` 只含 `terminal_opened`、`part_recipe_inspected` 两个布尔值；不持久化当前教程阶段，阶段仍由旗标 + 库存 + `core_repaired` 派生。
- `explored_map_bits` 是固定 480 位的 Base64 位图；不保存玩家图标、任务 marker、当前区域名或迷雾动画。
- 旧档迁移按既有库存 / 核心状态推导两个旗标，并至少揭开基地起步区与存档玩家附近；不得把未知路径伪造成已探索。
