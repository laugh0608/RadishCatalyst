# Slice Building Placement And Power Grid V1

更新时间：2026-07-25

状态：配方加工 arc 的 **L3 建造放置 + 扩展供电网**可执行细专题，2026-07-21 经萝卜SAMA确认 L2 收口后建立。承接已收口的 [L2 核心功能化](slice-core-functionalization-v1.md)，把采集器专用放置泛化为建筑共同能力，并让修复核心通过电线杆 / 中继把电力送到基地设备。L3-A 至 L3-E 五类素材硬闸门均已收口，下一步进入实现包 1，尚未实现玩法代码。

## 专题十问

1. **玩家新增动作**：在随身建造面板制造建筑套件，选择地板、采集器、反应器、电线杆 / 中继、传送带或储物箱，移动预览、按 `R` 旋转、按 `E` 放置、按 `Esc` 取消；靠近已放设施可调整或拆除。
2. **世界明确变化**：空地被铺成工业地板，设备按网格落位；中继接入核心后亮起并扩展电网，断连设备明确掉电。
3. **服务基地—冒险闭环**：远征带回的晶体炼成机械零件和建筑套件，扩建基地后采集器获得持续供电，后续反应器与物流获得空间承载。
4. **5–10 分钟可感知**：L2 修核心后，玩家能铺第一段地板、放下一台设施和一座中继，并亲眼看到设施在接电前后切换状态。
5. **通用系统边界**：建立切片专用的数据驱动建筑定义、放置控制器、通用实例与二值供电图；不建立旧纵切级万能 `BuildSystem`、完整电力负载模拟或 ECS。
6. **现有介质**：复用已定稿的采集器、反应器和储存设备作为风格参照；地板、中继、传送带及必要方向 / 状态变体必须先走像素素材硬闸门，不用占位色块补缺。
7. **成功证据**：真实 `Boot` 人工路径、有窗口输入自动验证、供电前后与非法预览截图、schema 4 重启读档断言。
8. **失败处理**：放置读法失败先修素材、预览层级和短原因反馈；供电理解失败先修中继状态灯与连接反馈。连续两轮失败则按闸门换介质、拆包或降范围，不叠 debug 图形。
9. **旧系统关系**：不复活冻结的旧 `BuildSystem` / `WorldState` / 旧仓储电网；只把当前切片的采集器专用链迁入新边界。
10. **切片推进价值**：把“修核心”变成可扩张的基地空间能力，为 L4 传送带物流和 L5 通电反应器提供真实布局与供电地基，而不是只增加工程完整度。

## 玩家路径与操作

```text
采集晶体 → 合成机械零件 → 修复核心
  → B 制造并选择地板套件 → R 旋转 / E 连续铺设 / Esc 取消
  → 制造并放置设备 → 制造中继并接入核心直供
  → 设备由断电切为通电
  → 调整或拆除中继 → 电网重算，断连设备掉电
  → 重启载入，布局、库存和供电结果一致
```

- `B` 打开随身合成 / 建造面板；建筑配方产出套件并立即选中对应放置项。已有套件也可从同一面板直接选中。
- 放置态用玩家朝向确定目标格，`R` 顺时针旋转 90°，`E` 提交一件；同类套件仍有余量时保持连续放置，耗尽时退出。
- `Esc` 只取消当前预览，不消耗套件、不改变世界；切换建筑类型也不得吞掉已制造物品。
- 非放置态靠近设施按 `E` 打开短操作面板：`[1] 调整位置`、`[2] 拆除`、`Esc` 返回。调整进入带原位置保留的预览，取消时原样恢复。

## 建筑配方与物品模型

建筑先成为 `Inventory` 中的普通套件物品，提交放置时才消耗；不再使用 `carrying_collector` 这类每建筑一个布尔值。`SliceRecipes` 增加 `output_count` 与建筑定义引用，配方和物品 ID 保持稳定：

| 建筑 | 套件物品 ID | 首版配方 | 单次产出 | 足印 | 供电角色 |
| --- | --- | --- | --- | --- | --- |
| 工业地板 | `building.floor` | 晶体 1 | 4 | 1×1 | 被动承载 |
| 晶体采集器 | `building.collector` | 机械零件 2 | 1 | 2×2 | 用电设备 |
| 基础反应器 | `building.reactor` | 机械零件 4 | 1 | 3×3 | 用电设备；L3 不加工 |
| 电力中继 | `building.power_relay` | 机械零件 1 | 1 | 1×1 | 电网节点 |
| 传送带 | `building.conveyor` | 晶体 1 + 机械零件 1 | 4 | 1×1 | 被动设施；L3 不搬运 |
| 储物箱 | `building.storage` | 机械零件 2 | 1 | 2×2 | 被动设施；L3 不接物流 |

- 机械零件仍为晶体 3 → 1；以上是 L3 首轮验收数值，不引入新原料。
- 建筑套件占背包总容量 1 格 / 件；地板和传送带的批量产出必须先检查完整容量，禁止扣料后只收到部分产物。
- 中央仓库允许存取所有已登记套件；建筑配方仍只从背包扣料，不隐式跨仓库消费。
- L3 只让所有设施可造、可放、可调整、可存读；传送带搬运属于 L4，反应器加工与机器进出料属于 L5。

## 通用网格放置规则

### 定义与实例

- `BuildingDefinition` 是单一规则源：`building_id`、套件 ID、场景 / tile、基础足印、允许旋转、地表要求、是否阻挡、供电角色、供电端口格、状态 schema。
- `BuildingPlacementController` 只维护当前定义、旋转、目标原点、预览和校验原因；不负责设备生产、电力传播或存档写盘。
- `SliceBuildingInstance` 保存稳定 `instance_id`、`building_id`、`origin_cell`、`rotation` 和该建筑状态；采集器缓冲等行为由窄组件承担。
- `SliceWorld` 继续拥有世界状态与自动存档，但只编排注册表、放置控制器和电网，不再为每种建筑添加携带布尔值、ghost 和生成分支。

### 原点、旋转与足印

- 世界、玩法、碰撞和存档统一使用 32px 网格；`origin_cell` 为旋转后足印包围盒左上格，旋转值只允许 `0 / 1 / 2 / 3`，分别代表顺时针 `0° / 90° / 180° / 270°`。
- 旋转先变换定义中的占用格和供电端口偏移，再以新的包围盒左上格吸附；长宽互换不能改变预览中心或跳格。
- 地板、传送带和中继为 1×1；采集器与储物箱为 2×2；反应器为 3×3。对称设施仍保存旋转，方向性端口在 L4 / L5 直接复用。
- 高斜角设备不能用运行时任意旋转 sprite 冒充方向素材；方向性设备按定义选择已审定方向帧。无方向差异的对称设施可让四个旋转值映射同一帧。

### 地表、碰撞与预览

- 工业地板可铺在地图内、未被地板覆盖且不属于晶体地的可建岩地；地板不阻挡移动。
- 采集器维持“完整足印均为晶体地”的专属规则，不要求工业地板。
- 反应器、中继、传送带和储物箱的完整足印必须已有工业地板；支撑设施存在时禁止拆除其下方地板。
- 所有阻挡设施不得越界、重叠核心 / 资源簇 / 玩家 / 其他阻挡足印；地板和设施分别维护占用层，不能靠一次固定 62×62 物理查询推断全部规则。
- 预览必须使用目标建筑的真实 sprite / tile；合法为青色半透明，非法为警示红，并在 HUD 只显示最先命中的短原因：越界、需晶体地、需工业地板、已有占用、玩家阻挡、超出电网连接距离。
- 允许显示足印格高亮、选择描边、状态灯和中继连接脉冲；不得用纯色矩形、程序线框网络或范围圈代替建筑与地板素材。

## 调整、拆除与返还

- 调整设施保留原 `instance_id` 与内部状态；进入调整时原位置暂存，提交新位置后一次性替换并触发存档，取消或非法退出则恢复原位。
- 拆除采用二次确认；成功后返还 1 个对应建筑套件，地板 / 传送带也各返还 1 件。L3 不引入磨损与拆除损耗，鼓励玩家纠正布局。
- 背包无空间时禁止拆除并提示“背包空间不足”，不得把返还物丢在地上或静默销毁。
- 采集器缓冲非空、储物箱非空时禁止拆除；移动可保留内容，但目标位置必须合法。反应器在 L5 后有输入 / 输出 / 加工中状态时采用同一“先停机并清空”门控。
- 地板上有设施时禁止调整或拆除。拆除 / 移动中继允许造成下游断电，但提交前明确提示受影响设备数，提交后立即重算。

## 扩展供电网

### 图模型与传播

- 修复核心是唯一源节点，核心直供半径沿用 6 格；不保存额外 `core_power_online`。
- 中继中心落在核心 6 格直供内，或距任一已通电中继不超过 6 格，即与电网连通；新中继若没有上游连接，预览非法。
- 从核心对中继邻接图做可达遍历；可达中继亮起并各自提供 4 格设备供电半径。中继之间只按中心格欧氏距离判断，不做穿墙、电缆长度或容量模拟。
- 每次核心修复、建筑载入、中继放置 / 调整 / 拆除后从源头完整重算；不靠增量补丁维持旧 `powered` 布尔值，避免断连后残留假通电。
- 电网只做二值“通电 / 断电”，不做发电量、耗电量、优先级、过载、蓄电或棕断。

### 设备供电判定

- 建筑定义提供随旋转变化的 `power_port_cell`；端口格中心处于核心直供或任一已通电中继 4 格覆盖内，则设备通电。没有端口的被动设施不查询电网。
- L3 用采集器作为首个真实消费者：通电时维持既有 10 秒 / 1 晶体，断电时暂停且不积累离线 tick；重新通电后从保留的当前 tick 进度继续。
- 反应器在 L3 只显示“已通电待接物流 / 断电”，不得恢复旧按 `E` 激活或加工；其生产由 L5 接入。
- 地板、传送带和储物箱在 L3 为被动设施；传送带是否搬运由 L4 决定，不因本层先放下就产生物品。

### 玩家可见反馈

- 通电中继显示稳定青色状态灯和短连接脉冲；失去上游后灯灭并出现警示红故障灯。设备使用同族青灯 / 灭灯状态，不整体涂成纯色块。
- 靠近设备的 HUD 提示包含“通电”或“断电：未接入核心电网”；反应器通电时明确写“待接进出料（L5）”，避免误读为已经生产。
- 调整中继预览应标出将掉电的设备数量；提交断连后相关设备状态同帧刷新，采集器停止产出。
- 常态不显示覆盖范围圈；只有选择中继进入放置 / 调整态时，允许短时边缘化覆盖提示作为动态高亮，建筑 sprite 和状态灯仍是主读法。

## 存档 schema 4 与旧档兼容

- `SliceSaveService` 从 schema 3 升到 4，新增 `buildings` 与 `next_building_serial`；所有地板和设施统一序列化：

```text
{instance_id, building_id, origin_cell:[x,y], rotation, state:{...}}
```

- `state` 只按建筑定义白名单读写：L3 采集器保存 `buffer` 与当前 tick 进度，储物箱保存 `inventory`；反应器 / 传送带不提前保存 L4 / L5 状态。
- 不保存可推导的供电状态、邻接边或覆盖结果；载入全部建筑后统一重建占用索引与电网，再刷新设备状态。
- schema 3 / 2 继续可读：旧 `collectors` 按数组顺序迁为 `building.collector`、旋转 0、保留格坐标与缓冲；`carrying_collector=true` 转成背包内 1 个采集器套件；schema 2 仍按 L2 规则以空核心仓库迁移。schema 1 继续不支持。
- 迁移不得因新供电规则删除旧采集器；不在电网内的旧采集器保留原位但读为断电。重复 ID、未知建筑、非法旋转或重叠数据应使该存档候选读取失败并尝试备份，不静默丢建筑。

## 素材规格与批次拆分

统一遵守 [Pixel Art And Grid Standard](../reference/pixel-art-and-grid-standard.md)：32px 网格、960×540 相机、高斜角俯视、左上光、限定色板、设备足印与体量一致。生成会话与审阅 / 归一 / 接入分离；本专题建立时不生成图片。

### L3-C 开工闸门

1. **玩家结果**：玩家在放置 / 旋转预览中无需文字即可辨认传送带朝上、右、下、左的输出方向。
2. **实现介质**：同图四帧的固定网格像素 sprite，归一为四个 32×32 方向帧；不用程序旋转、UI 箭头或流动物品补方向读法。
3. **成功证据**：首轮通过主体 / 投影硬判据，四帧缩至 32px 后在工业地板联系表中方向清楚、足印一致、光向与共享色板同族。
4. **失败判据**：斜向或等距足印、四帧不是同一设备、方向在 32px 下混淆、出现物品 / 转角 / 合流等任一项即失败；首张先修提示词，两轮同类生成仍失败则触发路线复盘。
5. **文档落点**：全局风格以 [AI Art Prompt Library V2](../reference/ai-art-prompts.md) 为真相源，具体约束以 [L3 Building Art Prompts](../reference/l3-building-art-prompts.md) 为真相源；专题保留验收边界，候选与失败记录进批次 manifest，归一和视觉结论进周志。

### L3-D 开工闸门

1. **玩家结果**：玩家在放置 / 旋转预览中无需文字即可辨认反应器琥珀出料口朝上、右、下、左，暗青入料口固定在对侧。
2. **实现介质**：以现有定稿反应器为唯一母版，同图像素级复制四次后只添加端口；每帧恰好一个琥珀出料口和一个带青色缺口的暗青入料口，不运行时强转、不重画四台主体。
3. **成功证据**：首张通过主体不变量与端口基数方向硬判据，缩小后在工业地板联系表中四向清楚、主体无状态漂移、光向与共享色板同族。
4. **失败判据**：主体 / 青色顶腔 / 状态灯漂移、端口没有作为严格对置的一对一起旋转、出现固定第三端口、端口斜向或被遮挡、四向在 96px 下混淆、出现货物 / 管网 / 传送带 / 加工状态任一项即失败；首张先修提示词，不沿失败提示继续生成。
5. **边界**：本包只为 L3 旋转和未来 L5 预留静态进出料端口，不实现机器进出料、加工或催化剂 tick。

### L3-E 开工闸门

1. **玩家结果**：玩家在放置 / 旋转预览中无需文字即可辨认储物箱的单个双向物流舱口朝上、右、下、左。
2. **实现介质**：以现有四罐 `2×2` 储存设备为唯一身份，同图四帧只改变一个暗青双向舱口的位置；舱口带青色缺口与小型琥珀锁扣，不使用反应器式输入 / 输出双端口、运行时强转或四台不同主体。
3. **成功证据**：首张通过主体、舱口基数与四向顺序硬判据；归一到 `87–96px` 后在工业地板联系表中四向清楚，储罐数量、填充条、状态灯、开合与光向不漂移。
4. **失败判据**：主体 / 储罐数量 / 填充条漂移、每帧不是恰好一个舱口、顺序错误、舱口斜向 / 遮挡、出现固定第二端口、四向在目标尺寸混淆、出现货物 / 传送带 / 管线 / 开盖 / 容量状态动画任一项即失败；首张先修提示词，不沿失败提示继续生成。
5. **边界**：储物箱在 L3 仍为被动设施；只预留未来 L4 的双向物流连接，不实现搬运、输入 / 输出优先级、库存可视化动画或空 / 满状态差分。

| 批次 / 独立生成会话 | 内容 | 目标规格与验收 |
| --- | --- | --- |
| L3-A 地板 | 工业地板 terrain sheet | 32px 单格；含中心、边、外角、内角和少量无方向接缝变体，能组成连续平台，不把 128px 宏块整张压成单格 |
| L3-B 电力 | 电线杆式中继同图断电 / 通电双态 | 1×1 窄底座、细高直立杆体，视觉高 48–64px且总高至少为底座宽 1.5 倍；青灯 / 灭灯清楚，黄黑警示条同族，屏幕轴对齐、无斜向偏航，缩小后不靠文字识别 |
| L3-C 传送带 | 四向直段方向帧 | 1×1；输送方向可读但不生成流动物品、转角或合流行为，后者归 L4 |
| L3-D 反应器方向 | 现有反应器的四向端口变体 | 3×3、约 96px；保持现有剪影与状态灯，仅为旋转和未来 L5 端口补齐方向帧 |
| L3-E 储物箱方向 | 现有储存设备的四向端口变体 | 2×2、约 87–96px；空 / 有料读法可预留但 L3 不接物流 |

- 采集器现有 98×95px 素材继续用于 2×2；本层把它视为无方向对称设备，四个逻辑旋转映射同一帧，L4 若增加输出口再开独立方向素材包。
- L3-B 主体原型必须是类似电线杆的细高直立中继，不是矮胖变电箱、平台机器或反应器；底座前缘水平、杆体竖直居中，任何斜向下偏航、倾斜杆体或正立面主导稿直接判废，不进入缩小审阅。
- L3-C 主体必须是低矮 `1×1` 直段传送带，同一结构只按基数方向旋转；任何斜向足印、四台不同机器、文字 / UI 方向标记、物品、转角、合流或分流直接判废，不进入归一审阅。
- L3-C 于 2026-07-25 以 V1 通过首张硬判据和 32px 审阅；统一 `384×384` 源窗口经 `12×` 整数块降采样输出上 / 右 / 下 / 左四个 32×32 帧，共享 17 色，并在工业地板联系表中确认输出端和方向无需文字可辨。
- L3-D 四帧按琥珀出料口朝上 / 右 / 下 / 左排序，暗青入料口固定在对侧；现有反应器主体、青色顶腔、状态灯与机位是不可变身份，不能用四台近似新设计冒充方向帧。
- L3-D V1 于 2026-07-25 判废：主体相较定稿被增高并重设计，琥珀出料口虽大致四向变化，青色入料口却固定屏幕下缘或缺失；V2 虽修正端口对与四向顺序，四台主体仍被分别重绘，未满足像素不变量。
- L3-D 经萝卜SAMA路线复盘改为确定性离线派生：以同一份 `96×90` 运行时反应器为不可变主体，只在四个受控连接位覆盖一对琥珀出料 / 青色缺口入料模块；四帧遮掉端口区后的主体像素指纹相同，工业地板联系表确认四向无需文字可辨。运行时仍使用四张固定 sprite，不做强转或程序绘制。
- L3-E 使用单个双向物流舱口，不复制反应器的输入 / 输出双端口；四帧固定按舱口朝上 / 右 / 下 / 左排序。现有四罐 `2×2` 储存主体、储罐数量、填充条、状态灯、开合状态、比例和机位是不可变身份。
- L3-E V1 / V2 的单舱口基数与四向顺序均通过，但两次都把四罐 `2×2` 主体重构成三罐三角布局，已触发两次失败停手规则；经萝卜SAMA确认不生成 V3，改以同一份 `87×88` 运行时主体确定性派生。四帧每帧只覆盖一个受控舱口区，遮掉四区后的主体像素指纹一致；目标尺寸与工业地板联系表确认单舱口按上 / 右 / 下 / 左可读，运行时只使用四张固定 sprite。
- 每个素材类别默认使用独立图像生成会话，默认每轮至多 3 次、每次 1 张；每轮结束或切换类别前先停手，只有经萝卜SAMA分别明确授权才能在原会话继续。切换后的新类别使用独立批次、manifest 与首轮计数，候选落盘、审阅和联系表规则仍以 `AGENTS.md` / `CLAUDE.md` 为准。
- L3-A / B 是供电网玩家可见实现的硬闸门；L3-C / D / E 是“所有列举设施均可旋转放置”的硬闸门。素材未过审时不得以色块、程序贴图或单帧强转冒充完成。
