# Demo First Playable Slice Assembly V1

更新时间：2026-06-24

## 用途

本文定义首版 Demo 从“系统与读法已存在”转入“20 到 30 分钟可玩纵切装配”的阶段范围。

本专题不是新增大系统，也不是试玩验收。它负责把既有基地、外勤、加工、污染、战斗、核心稳定站、HUD 和叙事内容收束成一条玩家可跑、可看懂、可复述的 Demo 路径。

## 玩家价值

玩家跑完本纵切后，应能明确感到：

- 我在一座受损异星化工前哨中行动。
- 基地加工让我能走得更远。
- 外勤采集和战斗会反过来恢复基地。
- 污染、敌人和核心稳定站不是独立任务点，而是同一条基地稳定工程。
- Demo 结束时前哨暂时恢复，但星球异常仍有更深原因。

- 基地、晶体、污染和核心稳定站已有低保真视觉层和截图定位入口。
- HUD、设备面板、交互提示、快捷补给和完成反馈已有运行时接线。
- 玩家、敌人和关键设备已有第一版语义轮廓，能从剪影、端口、状态灯和材质色区分用途。
- 采集、入料、加工、储存 / 整备、污染过滤、浆液回流和核心写入已有第一版场景关系标记，能从短流线、端口和状态节点读出设备接力。
- 启动核心、第一工业路径、污染边界和核心写入已有本地目标焦点框，近距离只用短连线提示当前工作面。
- 核心循环已有节奏短读法和短路径压缩，把外勤输入、基地加工、整备收益、污染承压和核心写入串进 HUD 摘要、加工反馈、目标焦点和主路径检查。
- 叙事节拍已有第一、二包，把前哨事故、晶体输入、基地恢复、污染信号、核心稳定和结尾钩子压成 HUD `现场记录`、关键对象描述、任务完成短反馈，以及基地 / 污染 / 核心站默认场景证据。
- 2026-06-27 已补污染短挑战到核心写入交接：短挑战结果、过滤输出、核心稳压材料、核心站入口端口、写入能量、恢复波和结尾异常探针能在污染边界与核心稳定站读成连续接力。
- 自动检查和 Godot 运行时检查已覆盖大量数据、场景和主路径回归。

当前不足不是“路径是否存在”，而是默认画面仍容易读成开发图层、任务表和检查结果。启动界面第一印象壳已完成，下一步接到新游戏进入后的基地首屏：把前哨平台、玩家工程战斗员、核心 / 反应器 / 储存 / 整备台、地面材质、阴影、断供痕迹和局部动作反馈推到低保真游戏画面，不把完整路径体感复核、读法整理、UI 字段整理或设备面板字段整理作为当前主线。

## 本轮范围

1. 纵切路径装配：
   - 启动界面进入新游戏或读取默认槽位。
   - 新档进入前哨核心。
   - 第一次晶体外勤。
   - 回基地入料和基础反应器加工。
   - 建出或启用采集 / 过滤设备。
   - 带着整备收益进入污染边界。
   - 用一次短战斗验证准备价值。
   - 进入核心稳定站完成小高潮。
   - 给出 Demo 结尾钩子。

2. 玩家视角收束：
   - 默认隐藏开发基线、GM 控件和长调试日志。
   - 每一步只保留当前目标、关键状态、可操作对象和结果反馈。
   - 视觉问题优先按核心路径解决，不再平均治理 12 区。

3. 内容降噪：
   - 后段相位井、前线行动台、窗口复盘、高压窗口和同构回访只保留兼容，不作为本轮玩家路径主内容。
   - 若既有长链条影响首版理解，优先压缩、隐藏或后置，而不是继续解释。

## 当前不做

- 不新增第 13 区域、第二星球、长期科技树、完整装备栏、完整背包、死亡结算页或发布流程。
- 不新增复杂电网、管网、物流仿真或随机成功率。
- 不把 formatter、专项检查、长目标文案或截图点微调作为本专题主体。
- 不进入集中修 bug 或公开试玩准备；本专题完成后再做验收判断。
- 默认画面明显像游戏前，不进入完整路径体感复核。

## 玩家操作路径

```text
前哨核心恢复
-> 晶体矿脉手采
-> 回基地入料
-> 基础反应器加工
-> 采集 / 过滤设备接管重复产出
-> 整备获得药剂 / 模块 / 补给收益
-> 污染边界短挑战
-> 核心稳定站写入
-> Demo 结尾钩子
```

## 运行时、存档与数据边界

- 优先复用现有任务、物品、配方、设备、敌人、区域和存档字段。
- 允许为纵切演示新增窄职责运行时入口或场景状态，但必须服务玩家路径。
- 不迁移稳定数据 ID；旧链条先作为兼容和后续内容保留。
- 如果压缩任务展示，不删除底层数据，优先通过主线入口、HUD 和场景可见性控制。

## HUD / 场景 / 对象反馈

- HUD：目标、生命 / 防护 / 补给、关键材料、快捷物品、设备警告和危险状态必须优先于开发信息。
- 场景：基地、晶体、污染、核心稳定站四个核心区必须能在 2 秒内被识别。
- 对象：前哨核心、基础反应器、污染过滤器、储存箱、出发整备台、采集器、核心写入设备要有用途关系。
- 反馈：每次采集、加工、建造、整备、战斗和核心写入都要有短反馈，说明玩家能力或基地状态如何变化。

## 验收条件

- 一名未参与开发的试玩者能从新档跑完 20 到 30 分钟纵切，不需要开发者解释当前应该做什么。
- 玩家能复述“基地让我走得更远，远征让我把基地建得更强”。
- 首屏、基地交接、污染边界和核心稳定站不再主要表现为 debug 色块、长标签或全图路线。
- 自动检查只作为回归证据；最终通过必须结合实机跑通和截图 / 录像观感。
