## 玩家结果与范围

玩家先学会能完成目标的基本生产，再通过材料 / 发现取得新工艺，最后选择测控优化。核心等级只开放一层研究机会，节点提供具体效果；当前功率 / 故障 / 库存诊断从开局可见。

首个基础整合内容包含核心 I–II、下表 7 节点。X2 与 III 档四节点属于后续开拓 / 测控包的完整设计表，不在首包提供可付费占位节点，也不提前保存未知控制字段。所有稳定 ID 使用英文，短号只作设计标识。

X1 检查 `sample_taken` 真实发现事实，**研究不消耗唯一矿壳样本**；该样本仍由 R02 试制消耗。R01 在 X1 后可生产，所以 X1 的研究成本不能含催化剂。当前 `first_expansion_placed` 不再作为新整合世界的电芯 / G 解锁条件；旧 E2 / V8 条件不改。

## 等级与后续节点

核心 II：B1 / M1 / X1 已完成后，从 I 可生产的 2 构件包升级；等级升级不自动研究 E1 / M2 / M3。核心 III 的成本在开拓 / 测控包细化，不要求先有 PWM 或未解锁储能。

| 短号 / ID | 设计前置 | 后续能力与成本来源 |
| --- | --- | --- |
| X2 `frontier_tools` | II，B1 / X1 / E1；实际矿壳试制完成 | R13 / R14、固定支路；成本由现有板 / 载体 / 溶剂 / 电芯组成，数量待开拓布局与回报核算 |
| E2 `grid_buffer` | III，E1 | 独立储能设施；材料成本、容量 / 功率须从充放任务倒推，新建为空 |
| C1 `timed_dispatch` | III，M1 | 按周期限量 / 比例调度；现有被动分流与基础准入口不因研究被收回 |
| C2 `storage_feedback` | III，E2 / C1 | 储能阈值 / 回差、信号控制；由普通工艺可取得的材料支付 |
| C3 `load_management` | III，C2 | 非关键负载组与停复机控制；能源链可保持关键负载 |

III 档提供组合工具，不设一个免费自动最优发电按钮。后续成本表、作用目标、冲突仲裁和持久字段须进入对应内容 / 存档版本；首包不因长期总图含有这些节点而实现空系统。

## 研究命令与失败原子性

1. 玩家近身打开核心研究页，选择节点；展示核心等级、前置、发现条件、成本、库存缺口及效果，允许按效果反查。
2. `research(node_id)` 在权威命令边界重新校验当期节点存在、未完成、核心 / 前置 / 事实和核心整笔库存。校验与扣料 / 增加已研究集合 / 研究消费事件同一事务提交。
3. 首包材料提交后即时完成，无异步计时 / 进行中状态；关闭面板或选择取消不扣料。重复已完成命令明确拒绝，不扣第二笔。
4. 效果由等级和已研究集合派生，不保存另一份可分歧的“已解锁配方列表”。未知效果 / 配方在定义校验阶段失败，不能完成研究却没效果。
5. 保存失败保留已提交内存状态并暂停 / 重试，沿原文件协议处理；不能因重试再次消费。保存成功前不得宣称已持久化。

锁定节点只有满足条件才能放置 / 配方配置 / 装配；研究集合非法不能通过“加载时补前置”修复。首包升级和研究无撤销 / 洗点，界面明确一次性材料用途。后续若支持撤销，需单独退款与实体合法性合同。

## 无循环与材料可达性

除科技 DAG 外，还检查材料生产图、设备可用、核心升级前置和事实路径：

- I 的直炼 / 直接烧结可完成 B1 / M1 / X1；组装后完成 II，不依赖电芯、矿渣或后续资源。
- E1 的板 / 载体 / 催化剂可由 I 获取；首次 G 的 3 包也可提前制作。能源投产之后不强制反复切配方打断供料。
- M2 成本的炭粉由 M1 得到；M3 的矿渣由 M2 得到。回用不作为取得首个载体的前置。
- 每个唯一发现 / 一次试制只有一个实际材料消费去向；解锁检查与统计不得重复领取或伪造完成事实。

纸面直接路线到核心 II、E1、G、一台额外炉和一台额外组装机，加首颗电芯：9 构件包用于升级 / G / 两机，研究另需 11 板 / 4 载体 / 1 催化剂，总净原料为铁矿 60、晶体 43、炭矿 1。按实际初始零物料、无重复领取核算，不包含 M2 / M3、铺带额外制造、尾货与采集缓冲；自然首次时长另验。

## 教学与反馈

按实际问题安排目标：先板 / 载体用途，再粉体 / 样本，再燃料供电，再工艺取舍；优先显示当前能推进的节点，已完成节点可追溯消耗与效果。等级升高后基础路线仍能工作，替代工艺有各自用途。

研究页不能要求读外部攻略，基本数值 / 下游用途可反查。未知节点只在后续内容设计中出现，不通过问号墙承诺未实现技术。主线与效率支线清楚标识，不把 C1–C3 当普通主线考试。

## 验证与失败退出

检查 DAG / 唯一 ID / 已知效果、成本非负整数、所有前置与材料在对应版本可达；旧档不自动得到研究。状态覆盖缺一件材料、未拾样、等级不足、重复 / 未知命令、扣料失败和成功后存读。

正式 Boot 从零材料完成 I→II→E1，另走联产 / 回用；唯一样本试制仍可完成。人工检查玩家能理解为什么研究、解锁后能做什么、是否愿意选择分支。若节点只增加等待或无新操作，调整效果 / 成本；若材料 / 事实循环则阻断实施。
