## 授权、玩家结果与介质

萝卜SAMA在范围供电 / 拾取亲测通过后，确认继续推进正式首程引导和当前版本完整发现循环。本包承接[发现生产](factory-discovery-and-production-v1.md)，帮助玩家从空工厂理解每次行动的用途，并把生产成果用于开路、新资源用于改善生产；不改变配方、供给、近身权限、schema 3 或阶段退出条件。

玩家进入 5–10 分钟内可看到当前短目标、真实进度、缺口及一个具体操作入口。复用左侧目标卡、现有设备 / 工艺 / 统计面板与镜头定位；不添加世界悬浮文字、通用任务系统、奖励、自动建线、自动扣料或玩家位置传送。全部步骤和完成事实可回查，关闭提示后仍可自由生产。

## 首程与事实

| 步骤 | 玩家行动与用途 | 完成依据 |
| --- | --- | --- |
| 首条产线 | 采集器 → 基础反应器；供电、铺带，准备试制用催化剂 | 累计产出至少 2 催化剂；已试制的存档视为已有基础 |
| 矿壳样本 | 发现矿壳用途，点击图标 / F 拾样 | 既有 sample_taken |
| 首次试制 | 在空闲反应器选择矿壳试制，投入 1 样本 + 2 催化剂 | 既有 trial_completed；在制显示加工 / 供电阻塞 |
| 第一矿道 | 选择解壳剂量产，将 4 份带到外矿道西侧使用 | 既有 passages.outer；世界持有与背包携带分别展示 |
| 富集回流 | 在已开区域采矿、选富集催化剂配方，获得一批 3 件的回报 | 累计 consumed.rich_crystal > 0；属于推荐提升路线 |
| 第二矿道 | 扩大制剂供给，携带 8 份打开深处空间 | 既有 passages.inner；普通线也可完成，不强迫富集路线 |
| 继续经营 | 回查流程、统计和已开放区域，保存后继续 | 两段已开，不重复派发样本 / 试制 |

状态派生优先承认已完成的试制 / 开路事实；样本先拾不会跳过必要材料准备，也不会要求重新拾样。带、缓冲、仓储、背包及在制明确区分，不用总持有量冒充已携带。已完成阶段不因暂时缺料或拆设备倒退；当前阶段的阻塞由现有设备反馈解释。

## 提示与操作边界

- 左卡只给当前目标、用途、数量 / 进度和具体下一步；建造入口只选择工具，不代放设备；定位只移动镜头，查看设备不改变状态，写操作仍需近身。
- 按当前世界重新求取操作目标，目标被拆除时重算，不使用过期实体引用。需要取料时优先指出实际持有物料的仓 / 设备，途中过料或多处不足时可打开统计检查。
- 试制的样本已在输入 / 在制时不再要求从背包重复投入；错误配方、残留输入 / 输出、未接电、无启用源、缺电和回压给出对应的原操作入口。
- 全部步骤在既有工艺面板回查，沿其暂停和关闭恢复合同；设备统一面板不被教程长文挤占，按[设备交互](factory-device-interaction-v1.md)在近身打开并继续生产。基础 schema 1 与独立样板保持各自提示。
- 不保存独立教程进度；现有发现与统计足以重建，因此加载 / 升级不增加字段或迁移。收起 / 展开保持现有会话偏好。

## 验证、失败与交付

1. 状态检查覆盖空世界、样本先行、首线材料、样本多种位置、试制在制、源关闭 / 缺电 / 回压、材料分布、两次开路、替代路线、目标被拆、保存恢复和只读不变。
2. 正式 Boot 新 schema 3 空世界自然完成首线、拾样、试制、量产、两次开路及富集回流；停复电 / 缺电诊断与独立进程全快照恢复。合成输入与用户首次游玩分列，无材料 / 解锁 / 人物位置注入或时间加速。
3. 开窗前告知，双隔离存档根；审阅普通 / 最小窗口的当前卡、回查、关键阶段与存读原图。最终做客户端、文档、仓库与影响内回归；证据落 W41，不宣称 D4 或 20–40 分钟体验通过。

提示完成但实际未完成、已做过的动作仍被要求重做、没有可执行入口、UI 超出窗口 / 透传或改变权威状态，均为失败。两次同类整改仍失败时停止堆文案，按开发闸门复盘交互结构。本包通过后进入用户安排的[传送带附件日程](../planning/factory-conveyor-accessories-roadmap.md)。
