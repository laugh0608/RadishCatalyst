# Slice Handheld Crafting Panel V1

更新时间：2026-07-21

状态：配方加工 arc 的 **L1 手持合成面板**可执行细专题，已于 2026-07-21 经萝卜SAMA实机确认收口。承接 [L0 库存模型](slice-item-inventory-model-v1.md)（背包空间物品）；下一层进入 [L2 核心功能化](slice-core-functionalization-v1.md)。arc 总览与层状态见 [Slice Recipe Processing V1](slice-recipe-processing-v1.md)。后续 L3 已把面板扩为七项配方，全链包 2 又增加当前规则行；面板仍是纯文字原型，2026-07-27 人工反馈已把图形化建造 / 背包列为独立 `P2` UI 候选。

## 定位

arc 第二层：给玩家一个**随身合成面板**——用背包里的原料（晶体）按配方合成**零件 / 建筑**。它把 L0 起始场景撤下的**采集器**作为第一个可造物拿回来（造出后用既有携带 + 放置逻辑放到晶体地），并按目标链路引入"合成零件修复核心"。纯逻辑 + 原型文本 UI，**不依赖新素材**。

## 关键取舍（已定档 2026-07-19）

1. **核心修复方式**：改为消耗合成的"机械零件"（贴合目标链路"采集物资 + 合成面板制作零件，修复受损核心"）。备选"直接消耗晶体"不采用。
2. **第一批配方范围**：机械零件 + 采集器两项。反应器 / 储物箱 / 电线杆 / 传送带 / 地板等建筑类配方需 L3 放置泛化 + 美术，本层不做。
3. **面板形态**：极简文本面板（一个合成键开关，数字键选配方合成，原型级）；像素 UI 换皮留后续。

## 玩家价值

- 看到：按合成键弹出随身面板，列出可造项、配方与材料是否足够；造出的零件进背包、造出的采集器进携带态。
- 做：采集晶体 → 开面板 → 合成机械零件 → 用零件修复核心；再合成采集器 → 放到晶体地自动采集。
- 理解：原料不是终点——玩家用采集来的晶体亲手合成出功能物件，这是"自己动手把基地建起来"的第一步。

## 数据模型

- **物品 id**：新增 `"part"`（机械零件）；`"crystal"` 已有。
- **配方表**：集中定义的 `Recipe` 列表，每项 `{id, 显示名, 产物, 消耗{item:数量}, 类型}`；类型区分"进背包的物品"（零件）与"进携带态的建筑"（采集器）。避免散字符串 / 魔法数。
- 复用 L0 的 `Inventory`（背包）与采集器携带 / 放置逻辑（`carrying_collector` + `try_place_collector`）。

## 交互

- **合成键**（新增输入动作，如 `craft_menu`）：开 / 关随身面板。
- 面板列出配方；材料足够可造、不足置灰并提示缺料；数字键（或选中 + 确认）触发合成。
- 数字键语义固定为“制作对应配方”；制作失败但已有套件时才回退为选中，`Shift + 数字键`可无消耗地显式选中已有建筑套件。为其他设备制作工业地板后恢复原设备预览，支持连续制作两批，把 1 个余量补到反应器需要的 9 个地板。
- 合成产物：零件 → `pocket.add("part", n)`（背包满则拒造并提示）；采集器 → 进携带态（复用 `try_craft_collector`，改为按配方消耗）。
- 核心修复（取舍 1A）：`CoreRepairSite` 改为消耗背包"机械零件"；面板与核心提示口径同步。

## 面板形态

- 原型 `CanvasLayer` 文本面板（与现有 `SliceHud` 同级、同原型文本风格），开关式；不新建像素 UI 素材、不做图标。像素 UI 口径留后续 HUD 换皮专题。

## 数值草案（可调）

- 机械零件：`3 晶体 → 1 零件`。
- 采集器：`2 零件`（或等价晶体）→ 1 采集器（携带态）。
- 核心修复：`3 机械零件`（取舍 1A）；若取舍 1B 则维持 `10 晶体`。

## 存档 / schema

- 背包已按 L0 序列化任意物品（含 `part`），采集器携带 / 放置态已在存档内——**L1 无需升 schema**（`part` 作为背包物品自然进档）。
- 面板开 / 关是运行时 UI 态，不入存档。

## 范围（2026-07-19 一并实现）

三包因配方相互依赖（采集器耗零件、核心修复耗零件）一并实现：`SliceRecipes` 配方表 + `SliceCraftPanel` 随身文本面板（B 开关、数字键合成）+ `SliceWorld.craft` / `can_afford`；机械零件配方（3 晶体 → 1 零件）、采集器配方（2 零件 → 携带 → 放置，复用既有）；`CoreRepairSite` 改走 3 机械零件；HUD 增背包零件行、修复目标改零件口径。

- 出口（已达成）：开面板按配方造零件 / 采集器、缺料与背包满拒造、采集器放晶体地、核心用 3 零件修复；存档 → 重启 → 读档还原背包零件 / 采集器 / 修复态。运行时真实入口 18 项断言全过，面板实机截图留档。待萝卜SAMA实机复核收口。

## 不做

- 不做电力 / 建造放置泛化 / 传送带 / 催化剂（属 L2–L5）；建筑类配方（反应器 / 储物箱 / 电线杆·中继 / 传送带 / 地板）留 L3（需放置泛化 + 美术）。
- 不生成新素材（原型文本面板）；不迁移、不修改冻结旧系统与旧检查。

## 验收与移交

- L1 收口 = 包实机（开面板 → 造采集器 / 零件 → 放置 / 修核心，存读还原）经萝卜SAMA确认；2026-07-21 已达成。
- 下一层为 [L2 核心功能化](slice-core-functionalization-v1.md)：核心直供电源 + 中央仓库；电线杆 / 中继扩展网随 L3 通用放置落地。
