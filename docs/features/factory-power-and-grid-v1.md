## 玩家结果与首包取舍

玩家放置电源、接通首条产线，看到设备从未接电转为运转；进入新矿区后延伸供电，发现富集加工增加负荷，通过增设电源或调整连接恢复产能。生产统计应帮助玩家分清“没接上”“功率不够”“原料不足”“出口堵塞”，而不是只多一个通电图标。

前 5–10 分钟能完成接电和首线生产；20–40 分钟的发现循环中至少有一次真实扩网 / 增容。新动作是布电、断接支路与扩容，世界变化是明确的设备工作状态和产出速度。采用有限设备与图结构，不引入电气仿真框架；旧二维电网只作经验参照，不迁入核心 / 中继规则。

| 决策提案 | 首包理由与代价 |
| --- | --- |
| 封装电源，有限功率、有限预发数量 | 自举不依赖未通电的工厂；本包验证配电 / 负荷经营。长期燃料、发电机制造与能源经济仍未验证 |
| 显式接线，单台设备只接一个配电节点 | 玩家能控制支路，避免覆盖圈重叠后静默换网；需清楚的接线交互与断线反馈 |
| 缺电按比例降速，完全断电暂停 | 同网设备公平分配，低容量仍能恢复，不按实体遍历顺序饿死某台设备；需保留分数进度 |
| 只给采集器和反应器计加工功率 | 先建立可解释的真实供需；仓、带、配电节点暂为被动设施，边界在 UI 明示 |
| 电力先接通基础生产，再接发现与统计全路径 | 三者共同定义状态和存档，一次形成新规则合同；不先发布缺电力的 schema 2 再临时补迁移 |

本包不做燃料配方、储能、昼夜 / 天气、线损、线缆容量、电压、过载损坏、负荷优先级、构件制造经济或随机故障。封装电源是本阶段的内容选择，不宣称整个能源经营系统已完成，也不把无限功率作为运行默认值。

采集 / 加工速度在满功率时沿用发现生产专题的周期；待机、缺料、满输出、手动停用电源和零工作量不虚构耗电。暂不增设单台用电设备启停按钮，调配可通过断接支路或调整配方完成。

起始供给在原 8 采集器 / 16 反应器 / 8 仓 / 256 带基础上增加以上电力构件，物料仍为零。电源和节点可回收复用，总构件数守恒；拆建不恢复燃料、赠送能量或生成新构件。2 套电源共 240 kW 是本地图的有限启动装备，不支持无成本无限增殖，后续制造 / 更高级电源另包设计。

## 自举、扩建与布局核对

1. 普通新建后先放置一套电源和采集器 / 基础反应器，连接后启动。供给不要求先产出催化剂；两套电源都收回时仍能徒手重新放置，恢复不需要电力或消耗材料。
2. 普通采集器 20 + 基础反应 40 + 解壳剂 60 = 120 kW，首套电源可覆盖三台同时请求的上限；单纯缺料时实际需求更低，不能因此声称负荷满载。
3. 矿道开通后，通过节点跨越已开放通道，为富集采集器和反应器接电。原三台加富集两台同时工作时请求 220 kW；一套电源的满足率约 54.5%，接入第二套后容量 240 kW 足够。
4. 可选择把第二套电源直接带到矿区形成独立电网，或并入主网；独立电网的富余容量不能自动补给另一网。连接两个电网后才共享容量。
5. 第一富集线满功率理论产能仍为每分钟 15 催化剂；缺电速度随当步需求变化，不把 54.5% 当作整个生产周期的固定效率。物料库存、回压与制剂吞吐一起决定真实结果。

D1 布局采用节点走廊 `(1,-2) → (9,-2) → (18,-2) → (25,-2)`，穿过两段已打开的 4×4 矿道；回流带走 `z=1`，避免旧草案节点占带格。初始普通矿点向西侧分支，深矿区向南北分支；完整夹具使用 2 电源 / 10 节点 / 4 采集器 / 3 反应器 / 1 仓 / 48 带，均在预发预算内。距离、封闭地形、足印与步行网格已检查，尚不能替代真实人物碰撞、接线操作或生产吞吐验证。

## 接线、拓扑与交互

- 电源与节点合称配电节点，均按足印中心定位；节点间可建立无向连接，中心距最多 12 格。关闭电源只停止其发电能力，不拆除节点已有的导通关系。电源也可直接给附近设备供电，避免首线强迫多放一个节点。
- 用电设备须显式选择一个电源 / 节点作为接入点，中心距最多 6 格。每台最多一条接入线；改接原子替换，不允许双网重复供电。不会随距离或电网通断自动换接。
- 配电节点之间的闭环允许存在，不重复累计电源；用电设备不承担中继。相交的线不视为连接，线不占地、不挡人物，可以跨越已建设备；不模拟长度能耗。
- 两端均须位于已开放区；线段经过的逻辑格也须开放，穿过封闭矿壳的连接拒绝。边界相交采用统一的格遍历规则，擦过封闭格仍拒绝；开路后才可架设，避免从远处提前给封闭区供电。
- 接线模式选择节点后点击节点或用电设备，预览距离和受阻原因，第二次点击提交；Esc / 右键取消。接线模式与拖带互斥，操作面板点击不落地，失焦取消未提交线。
- 从任一合法接入点开始连线，在已开放世界范围内编辑，不另增加人物施工距离；该远程建造权限不放宽拾样、取放和使用制剂的近身要求。
- 选中连接可断开；删除节点或电源时列出本次会断开的连接及受影响设备。涉及现有连接则显式确认，取消零变更；无连接时沿用普通回收动作。删除后清理相关连接，原设备留在原位且显示未接电 / 无电源。
- `revision` 变更后重建受影响图；小规模可先全图重建，但不能每个模拟步重扫全世界建立拓扑。图连通分量和设备归属为派生状态，不持久化第二份网络真相。

## 20Hz 供需与停复电合同

电力和生产使用同一个模型固定步，`dt=0.05s`。以下规定用于消除同一帧内的顺序套利，不把 UI 计算结果喂回模拟。

1. 在步首快照上确定可工作设备：采集器缓冲未满；反应器已有在制，或输入齐全且输出已空。仅检查生产条件，不能先因缺电把请求负荷降为零。输入 / 输出将在步末物流阶段变化的设备，下步再重新判断。
2. 对可工作设备取剩余满速加工时间 `r_i`、额定功率 `P_i`，本步满速工作量 `w_i=min(dt,r_i)`，请求平均功率 `d_i=P_i*w_i/dt`。尚未开批的反应器按完整周期计算；非工作设备为零，避免最后不足一步仍多扣能量。
3. 每个电网取启用电源容量和 `C`、请求和 `D`。`D>0` 时满足率 `f=min(1,C/D)`；各设备获分配 `f*d_i`。无电源网和未接入设备满足率 0；`D=0` 显示待机，不伪造 100% 工作效率。
4. 获得正工作量后才允许开批并预留输入；按 `f*w_i` 推进采集 / 在制进度，达到周期时提交一次产出和物料统计。完全断电不新开批、不扣输入、不改批次序号；已有在制投入及进度保持。
5. 本步实际用电量为 `P_i*f*w_i` kJ。网络实际供电量等于用电量，不存在未实现的储能或损耗；多个启用电源按容量比例分摊实际输出。剩余容量只是未使用能力，不累计为可用电量。
6. 生产提交后执行既有逐件物流，库存转移不重复记产消；本步新入料不再反过来开第二批。暂停 / 失焦不推进生产、电量或统计时钟。

例如满步请求 220 kW、容量 120 kW 时，50 毫秒合计交付 6 kJ，各台按同一比例推进；容量恢复至 240 kW 时交付 11 kJ，其余容量对应的 1 kJ 未输出。若一台 40 kW 反应器只剩 0.01 秒工作，则满供需能量为 0.4 kJ，不按整步记成 2 kJ；首包每台每步最多完成一批，步内余时不偷偷开启下一批。

复电仅继续原进度，不补断电期间的产量。采集器与反应器断电时仍可由被动物流清空旧输出、接收允许的输入；这不代表设备正在加工。输入面板同时展示“生产条件”和“供电条件”，主状态优先显示阻止当前工作的原因，保留其他状态明细。

## 电力统计与物料统计衔接

功率用 kW，模拟能量用 kJ，累计展示可换算 kWh（1 kWh = 3600 kJ）；均为游戏参数，不承诺真实机组物理表现。精确记账以模型本步分配为准。

| 指标 | 定义 |
| --- | --- |
| 装机 / 可用容量 | 在场电源额定和 / 已启用电源额定和；未接负荷的孤立电源仍列出容量 |
| 请求负荷 | 工作条件允许时的满速需求，包含未接入或无电源的请求；不按实际分配倒算 |
| 实际供电 / 用电 | 本步分配能量除以 dt；全世界两者相等，但不能用容量替代实际供电 |
| 缺口 | 各电网 `max(D-C,0)` 加未接入设备请求；不能用全世界总容量减总需求把孤网缺口抹平 |
| 满足率 | 当前电网 `实际供电 / 请求负荷`；D=0 显示待机，缺电 0% 与未接线分开解释 |
| 配置满负荷 | 已放置的有效采集器 / 已选常规配方额定功率和，提示满开能力；不冒充当前运行请求 |

[统计专题](factory-production-statistics-v1.md)建议保留全世界近 1 / 5 / 10 分钟电力趋势；当前电网逐行显示容量、请求、缺口与设备定位。首包不保存各电网历史曲线：网络合并 / 拆分后身份会变化，用当前图划分倒推历史会误导玩家。网络编号由当前节点集合派生，仅用于当前查看，不充当永久存档 ID。

电力桶记录时长、容量×时间、请求能量、实际供电 / 用电量和缺口能量；窗口平均按真实覆盖时长计算。物料理论速度仍按充分供电计算，实际产消取完成事件；取消批次只返还物料，不返还已经用掉的电量，重载不重复计入。

## HUD、模型与资产

- 放置 / 接线时显示范围、真实已提交连接及无效原因，正常生产隐藏完整连线；这些是动态连接与选择辅助，不承担设备主体。选中设备能追到接入点及所属电源。
- 状态区分未接线、已接但无启用电源、供电不足、充分供电；与缺料 / 出口堵塞并列。电源显示启用状态、可用容量和实际输出，不使用发光程度暗示未经计算的功率。
- 原正式工厂 14 个 GLB 不含电力设备；D1 已在 `client/assets/factory/power/` 交付 `power_source` 与 `power_junction` 自有候选、来源清单和导入配置。低矮双封装电源与细杆三触点节点使用独立轮廓，均以导入 GLB / Node3D 显示。
- 先用现有导入资源组合做尺寸 / 场景草案，不能直接把反应器改名电源即算美术通过。正式候选须在原 50° 视角、普通 / 拉远和相邻设备中审阅；接线提示可程序绘制，电源 / 节点主体不可用调试几何替代。
- D1 沿用仓库已有离线 Three.js 导出工具与自有几何 / 材质帮助函数，无新增安装或外部包。候选已完成普通尺寸 / 最大化和拉远场景原图技术复核，尚未取得萝卜SAMA美术定稿反馈。后续如需新工具、依赖或外部资产，先说明具体范围；不含自动下载授权。两次同类视觉失败按[开发闸门](../process/development-decision-gates.md)复盘。

## 联合 schema 2 提案与职责

新“勘探工厂”统一接入发现、电力与有限统计历史，沿发现专题的新规则 / 地图 ID；供给 ID 建议 `factory_discovery_starter_v1`。既有 schema 1 的 25 矿点、普通 / 工程供给、预供电和读写合同保持原样；不迁移已有工厂、不改旧二维 schema 10。

| 权威数据增量 | 建议字段与校验 |
| --- | --- |
| 电力实体 | `power_source` / `power_junction` 使用现有实体稳定 ID、足印与构件计数；仅电源保存 `enabled` 布尔值，容量取规则配置 |
| 节点连接 | `power_links` 为规范化 `[小ID,大ID]` 对集合；拒绝自环、重复、无效类型、缺失节点、超距和穿越封闭地形 |
| 用电接入 | 每台采集器 / 反应器保存 `power_node_id`，0 表示未接入；非零必须是合法节点且满足距离 / 地形限制；不保存派生的网络编号或满足率 |
| 在制状态 | 配方、原投入和剩余进度沿发现包合同；采集进度同样保留分数，停电无附加债务 / 离线时间字段 |
| 电力记账 | 有限累计供电 / 用电 kJ（起始均为零且互相一致）与统计近期时间桶；不保存每帧或每条线的无限流水 |
| UI 偏好 | 统计收藏的已知物料 ID 和合法时间窗等独立于模拟；打开的临时面板、接线预览不进入世界状态 |

新快照整体校验后才发布；范围上限以本规则的构件数量、已知物品 / 配方、最近 600 个完整桶及当前桶约束。重复、非有限数、非法引用、时间桶重叠 / 超长与计数矛盾拒绝，不填默认值掩盖错误。完整字段表、浮点容差与 D2-B 支持边界已落实到[联合存档合同](../architecture/factory-discovery-save-v2.md)及版本夹具；已支持发现 / 多配方状态严格互核，未知配方与未来版本阻断回退覆盖。

保存时同时快照库存、在制、电力连接、时间与统计，加载先重建占用 / 电图再显示世界，不能先跑一帧免费生产。原子写入、候选恢复、未来版本阻断和单写入锁继续复用[现行存档合同](../architecture/factory-world-state-and-save-v1.md)；Store 复用原发布协议，codec 按身份严格分派到 schema 1 / 2。

建议将连通计算与供需分配放在窄 `factory/power_grid.gd`，由模型调用纯状态计算；统计时间桶放在 `factory/statistics.gd`，模型提交成功变化时更新；HUD / view 只读取。仅在真实职责需要时拆分，不为电力建立全局事件总线，客户端文件仍遵守 1000 行建议 / 1500 行上限。

## 失败判据与实施边界

若玩家无法判断应接线还是扩电源、两套预发电源没有带来任何布局 / 容量决策、统计把孤网缺口抹平、停复电复制产物 / 电量，或功率变化只影响图标而不影响生产，本包不通过。先调整规则、反馈与参数，不靠加入燃料或更多设备掩盖基础问题。

本提案的主要选择为：两套 120 kW 封装电源与 12 节点、12 / 6 格显式连接、按请求比例降速、带与仓不耗电、燃料 / 储能后置，以及与发现 / 统计共用新世界 schema 2。萝卜SAMA要求继续推进后按该范围完成 D1；后续按既定 D2–D4 推进，超出本包范围时重新确认。已有 schema 1 世界运行规则未更改；新建勘探工厂进入 schema 2 基础电力分支。
