# Demo Core Loop Playable V1

更新时间：2026-06-24

## 用途

本文定义首版可玩纵切的核心玩法闭环。目标不是扩系统，而是让玩家亲手完成一次“外勤带回资源，基地加工转成能力，再用能力推进危险区域”的循环。

## 玩家价值

玩家应通过操作感到：

- 出门采集不是跑腿，而是在给基地补输入。
- 回基地加工不是菜单结算，而是获得下一次外勤能力。
- 污染和战斗会验证准备是否有价值。
- 核心稳定站是这条循环的阶段性成果。

## 与整体规划的关系

- 服务 [Demo First Playable Slice Assembly V1](demo-first-playable-slice-assembly-v1.md)。
- 覆盖 [Demo Definition V1](demo-definition-v1.md) 中资源 / 生产链、工业基建模块、角色成长、战斗压力和污染防护规格。

- 第一条工业链已有手采、采集器、入料、反应器、储存、整备的视觉基础。
- 主路径能从新档推进到 Demo 完成反馈。

- 2026-06-24 第二包已落地：首轮晶体、废件、异常残留、处理点敌人、地基和污染沉积物改为一次代表动作或一轮加工可覆盖的量；配方、建造门槛、目标焦点、HUD 提示、存档样例和运行时检查已同步到短节奏。

## 本轮范围

1. 开局基地：
   - 检查前哨核心。
   - 看见基础反应器缺料或停机。
   - 明确需要去晶体矿脉。

2. 第一次外勤：
   - 手持工具采集晶体。
   - 遭遇一个低压敌人或危险提示。
   - 带着材料返回基地。

3. 回基地加工：
   - 把晶体或残骸转成基础产物。
   - 显示加工进度、产物去向和下一步用途。
   - 建出或启用采集 / 过滤设备，让重复产出由设备接管。

4. 整备收益：
   - 产出修复凝胶、抗污染药剂或过滤模块。
   - 快捷栏和 HUD 显示收益。
   - 玩家能主动使用或装备。

5. 污染边界挑战：
   - 污染造成防护压力。
   - 一场短战斗验证补给 / 模块 / 药剂价值。
   - 回收污染沉积或关键样本。

6. 核心稳定站小高潮：
   - 用既有核心站终点链路完成守卫压力、写入、复测和回流。
   - 给出 Demo 结束反馈。

## 当前不做

- 不做完整工厂自动化、电网、管网、长期科技树或随机词条装备。
- 不扩敌人种类，不新增长期成长系统。
- 不要求所有 12 区都具备同等玩法密度。
- 不把后段前线行动台和高压窗口纳入本轮核心体验。

## 玩家操作路径

```text
检查核心
-> 看见反应器缺料
-> 到晶体矿脉采集
-> 回基地加工
-> 启用采集 / 过滤设备
-> 制造补给或模块
-> 进入污染边界
-> 短战斗 / 污染承压
-> 核心站写入
```

## 运行时、存档与数据边界

- 复用现有数据 ID 和存档字段。
- 只新增支撑纵切体验的状态判断或入口。
- 如果压缩路径，不删除现有长期链条；优先通过可见任务、HUD 和场景入口控制。

## HUD / 场景 / 对象反馈

- 采集后 HUD 显示关键材料增加。
- 加工时设备面板显示输入、输出、进度和产物去向。
- 整备后快捷栏或角色状态显示能力变化。
- 污染挑战中显示防护压力和补给作用。
- 核心站完成后显示稳定结果和后续悬念。
- 核心循环节奏只用一行短状态提示当前段落，不替代场景轮廓、设备端口、任务目标或紧凑行动日志。

## 验收条件

- 从新档到核心站完成可以在 20 到 30 分钟内跑通。
- 玩家至少做过一次采集、一次加工、一次整备、一次短战斗和一次核心写入。
- 准备不足时玩家知道缺什么；准备完成后能感到通行或承压差异。
- 主路径不依赖开发者口头解释。

## 风险与后续决策

- 若纵切超过 30 分钟，优先压缩后段任务链，不新增捷径系统。
- 若循环不够有感，优先强化加工产物、HUD 和污染挑战的反馈。
