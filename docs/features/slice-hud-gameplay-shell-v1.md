# Slice HUD Gameplay Shell V1

更新时间：2026-07-28

## 目的

把第一可玩切片中“矩形底板 + 纯文字”的可读性基线，升级为可继续扩展的游戏 HUD 壳层。它仍服务当前全链，不建立通用 UI 框架，也不改变世界美术、玩法规则或存档结构。

本专题是 [第一可玩切片全链串通](slice-first-playable-journey-v1.md) 的当前可执行子专题。

## 开工五问

1. **玩家结果：**玩家能从组件位置、图标、余量条和短状态快速分辨当前任务、随身关键物资、生命 / 战斗能力、敌人状态与可执行操作；默认画面不再像调试文字面板。
2. **实现介质：**复用现有物品与角色像素 sprite，新增一个零件像素图标；用 Godot `PanelContainer`、`TextureRect`、`ProgressBar`、短标签和键帽组件组成 HUD，不用程序绘制世界视觉层。
3. **成功证据：**正式入口至少覆盖基地整备、采集器通电和外勤交战三态截图；任务、资源、生命、敌人和提示无截断，地图中心与角色活动区无大面积常驻遮挡；专项与完整 Godot 回归通过。
4. **失败判据：**仍主要靠长文字串表达状态、组件只是给旧文本换边框、战斗或基地态遮挡主体、图标与数字无法对应，或为完成 HUD 引入新的玩法 / 存档状态。
5. **文档落点：**组件契约与验收留在本专题；过程与证据写入 W31 周志；规划入口只链接当前子专题与下一步。

## 组件契约

### 任务舷窗

- 位于左上安全区，只显示阶段标签与当前一条目标。
- 任务文本继续由 `SliceWorld.current_journey_goal_text()` 从权威状态派生。
- 核心仓库不再拼到任务句末，避免任务重新退化成长状态串。

### 关键物资槽

- 位于右上安全区，固定显示晶体、催化剂和机械零件。
- 晶体与催化剂直接复用世界货物像素 sprite；机械零件使用独立小图标。
- 数字和容量按槽位表达，不用一整行分隔符文本。
- 建筑套件全集仍只在合成 / 放置上下文展开。

### 角色状态

- 位于左下安全区，使用工程师头像、生命条和数值。
- 核心充能、攻击工具和闪避只保留短状态；不显示生产统计。
- 生命条必须随 `health / max_health` 同步，不能只改文字。

### 敌人与反馈

- 敌人接近时才在上方中央出现目标条，包含敌人名称、行为态和生命余量。
- 伤害、撤离、拾取等短通知继续居中出现，不建立战斗日志。

### 上下文操作

- 位于底部中央，只在放置或存在交互目标时出现。
- 操作键使用独立键帽，提示正文负责对象、结果和阻塞原因。
- 放置输入契约仍是 `E` 确认、`R` 旋转、`Esc` 取消；鼠标放置属于包 2B，不在本专题实现。

## 实现边界

- 允许调整 `SliceHud.tscn`、`slice_hud.gd` 及直接专项断言。
- 允许新增少量稳定 UI 图标资产，不生成大幅 HUD 背景图。
- 不改配方、物品 ID、旅程阶段、战斗数值、生产节奏、schema 或存档目录。
- 不做建造 / 背包完整面板换皮，不做鼠标放置、电网范围或世界 3/4 投影修订。
- 不建立主题编辑器、响应式布局系统、通用图标注册表或动画框架。

## 实现包

### 包 1：常驻壳层

- 任务舷窗、三物资槽、角色头像与生命条接入。
- 旧 `LeftStatusPanel` / `RightStatusPanel` 整行底板退出主读法。
- 保留既有脚本公开引用，避免无关检查与调用方重写。

### 包 2：按需状态

- 敌人目标条、短通知与底部操作键帽接入同一视觉语言。
- 基地、采集和战斗三态正式入口截图复核。
- 萝卜SAMA人工确认后，本子专题才可收口并返回包 2B 决策。

## 验收

- 1920×1080 当前正式 viewport 下，五类组件不互相重叠。
- 常驻组件只占四角安全区，中心战斗与建造观察区保持开放。
- 三个物资槽都有图形身份和独立数值。
- 生命和敌人状态都有可见余量条。
- 空闲时不显示操作提示；敌人不在场时不显示敌人条。
- 正式入口截图是视觉主证据，自动断言只证明接线和状态同步。
