## 玩家路径与内容发布边界

1. 核心 I：B0 开局能力；采铁 / 晶体，直炼金属板、直接烧结载体，经核心自动供料 / 回收。研究 B1 制造构件，M1 粉碎，拾样后 X1 制造催化剂 / 试制。
2. 由 I 的材料升级核心 II，研究 E1 后制造 G、建立持续电芯链；额外炉 / 组装机由真实构件包制造，保留供给与消费账。
3. 用 M2 / M3 比较直接 / 联产 / 回用，建立有实际目标的扩建负载，观察开启 G 的容量与吞吐变化；缺料 / 满仓与缺电分开诊断。
4. 后续开拓包实现 X2 与固定支路，证明高产矿对开路后持续生产有收益；不能以四件胶囊的一次需求证明永久价值。
5. 后续核心 III / E2 / C1–C3 增加独立储能、节拍、反馈和负载控制；普通供料完成主线，PWM 不作为解锁 III 的先决条件。

首个公开可继续的新整合世界为 **基础整合内容包**：核心 I–II 与 B0 / B1 / M1 / X1 / E1 / M2 / M3 共 7 节点、R01–R12 的合法子集、核心物流与固定燃烧全部可运行后，才允许从正式菜单创建。不得发布缺能源实现的同身份半成品。X2 / 核心 III / 其余 4 节点只是后续设计，不在首包界面提供可付费但无效果的按钮。

## 开工闸门

- 玩家新增动作：核心取供料、研究 / 升级、固定燃烧扩网、后续测控与开拓；世界变化为实际设备能力、库存和可进入区域。
- 介质：既有 Godot 3D / 导入设备、核心新模型、图标与真实传送带，HUD 读取同一权威状态；不更换引擎或做独立 Web 正式版本。
- 基地价值：从发现、材料到能源 / 开拓用品，产物有消费与可感知回报；20–40 分钟是第一轮主线体验目标，按试玩校正。
- 成功证据：离线图 / 账、定向状态、正式 Boot 自然路径、窗口 / 原生操作、跨进程恢复与玩家反馈分别列出。
- 失败退出：自举循环、扣料 / 存读不守恒、无法操作阻断交付；连续两次同类玩家失败复盘，不叠提示代替修因。

## 检查与保留边界

每个子步做匹配的最小验证。必须覆盖：核心多口争用 / 回压、研究与升级重复命令、完整物料和燃料账、燃烧尾步、暂停 / 失焦 / 离线、坏档与备份恢复、旧 1–8 / 二维身份不变。自动通过不等于整段试玩成立。

当前活动亲测与正式存档不转换、不覆盖。新布局 / 核算放忽略的设计目录；后续状态 / 运行产物按运行时指南隔离。液气、多人、交易、随机地图、自动蓝图、物流桥、离线收益、全量科技与后端仍在包外。
