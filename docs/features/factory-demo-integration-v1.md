## 玩家路径与内容发布边界

1. 核心 I：B0 开局能力；采铁 / 晶体，直炼金属板、直接烧结载体，经核心自动供料 / 回收。研究 B1 制造构件，M1 粉碎，拾样后 X1 制造催化剂 / 试制。
2. 由 I 的材料升级核心 II，研究 E1 后制造 G、建立持续电芯链；额外炉 / 组装机由真实构件包制造，保留供给与消费账。
3. 用 M2 / M3 比较直接 / 联产 / 回用，建立有实际目标的扩建负载，观察开启 G 的容量与吞吐变化；缺料 / 满仓与缺电分开诊断。
4. 后续开拓包实现 X2 与固定支路，证明高产矿对开路后持续生产有收益；不能以四件胶囊的一次需求证明永久价值。
5. 后续核心 III / E2 / C1–C3 增加独立储能、节拍、反馈和负载控制；普通供料完成主线，PWM 不作为解锁 III 的先决条件。

首个公开可继续的新整合世界为 **基础整合内容包**：核心 I–II 与 B0 / B1 / M1 / X1 / E1 / M2 / M3 共 7 节点、R01–R12 的合法子集、核心物流与固定燃烧全部可运行后，才允许从正式菜单创建。不得发布缺能源实现的同身份半成品。X2 / 核心 III / 其余 4 节点只是后续设计，不在首包界面提供可付费但无效果的按钮。

## 开工闸门

- 玩家新增动作：核心取供料、研究 / 升级、固定燃烧扩网、后续测控与开拓；世界变化为实际设备能力、库存和可进入区域。
- 介质：既有 Godot 3D / 导入设备、核心新模型、图标与真实传送带，HUD 读取同一权威状态；不更换引擎或做独立 Web 正式版本。
- 基地价值：从发现、材料到能源 / 开拓用品，产物有消费与可感知回报；20–40 分钟是第一轮主线体验目标，按试玩校正。
- 成功证据：离线图 / 账、定向状态、正式 Boot 自然路径、窗口 / 原生操作、跨进程恢复与玩家反馈分别列出。
- 失败退出：自举循环、扣料 / 存读不守恒、无法操作阻断交付；连续两次同类玩家失败复盘，不叠提示代替修因。

## 联合首程复核

沿四面 S1-P 从空档建造，先用一炉烧结首批载体再切回直炼。实际拿到板材、拾样、研究、升级，再用终端仓的构件包扩建。两台组装机和两台炉并行后，电芯由三料自动合流并送入发电机。用可继续的同一份档案核对燃烧、弃能、库存、在途与研究。

定步运行通过正式模型命令建造、走动和自然生产。窗口操作覆盖 Boot 新建、定位铁矿、点选和启用发电机、暂停、保存返回与从世界目录继续。玩家复测另看能否独立发现下一步、分辨缺料与缺电，以及等待和扩建是否顺畅。遇到断路、物料不守恒、稳定供燃不足或恢复不一致时记录失败并保留正式新建门槛。

E 的平台复核沿用这条基础整合首程。Shell 与 PowerShell 共用 S1-P 布局核算、正式 Boot 检查脚本和独立的写入、继续进程。每批使用新的隔离目录，保留平台、日志、断言结果及窗口检查原图。目前按[当前规划](../planning/current.md#当前顺位)在现有 Mac 验收，正式 R2 的窗口首程及运行中产线的性能分别取证。

R2 运行中取同一基础整合新档的 S1-P 生产现场，让正常窗口时钟驱动供燃、加工与自动保存，保留帧间隔、模拟耗时、保存耗时与起止产能。窗口失焦即结束该次采样。样本后沿用正式保存返回与独立继续校验，记录与阶段性长测分列。

空档目标沿用现有定位按钮。铁矿、样本和炭矿在到达对应步骤时可定位。小地图固定朝北，显示角色、目的地、直线距离和已开放的地形。角色标记的尖端指向当前镜头下按 W 的方向。镜头继续跟随角色，玩家可关闭标记或选择下一个目标。矿道状态读取地图通行规则，定位不修改移动、生产或存档状态。复核要覆盖出生点定位离屏铁矿、转动镜头、实际行走和开路后地图更新。

已验收的隔离亲测档继续用 `sh tools/check-factory-integrated-c.sh play joint-first-run` 打开。正式新建使用独立存档根，基础整合参数为 360 kW 核心与 120 kW × 60 秒固定燃烧。完整的技术复核数据和边界记于[联合首程记录](../devlogs/2026-W45.md#integrated-joint-first-run)及[正式入口记录](../devlogs/2026-W45.md#foundation-acceptance)。

### 核心 II 发电后的扩建引导

基础整合在电芯首次点火后，目标栏和定位按钮带玩家完成一次可选扩建。混料冶炼主口的板材、副口的矿渣有不同去向。回用研究完成后，用矿渣和晶体烧结载体，再将回仓的板材和载体送入构件包组装机，最后从核心库存支付构件包。提示从当前研究、已完成配方、设备配置与实际库存推导。已有空闲构件可直接放置，样本与矿道入口仍按原条件可用。

在同一 schema 9 世界核对首次投产前、载体回仓及装配后。定位须落在当前操作需要的设备或核心，库存不足时须区分已生产、在途与现存。用真实入仓物做包并从核心扣料，独立读档后按现场恢复目标。已开通内矿道的世界保留富集矿道提示，仍可定位尚未完成的扩建步骤。核心库存混合同类物料，界面仅报告当前可用数量，材料来源在复测时沿实际流向核对。

### 核心 II 分炉后的持续生产

从已装配精炼炉的 schema 9 隔离档继续，把铁粉和炭粉送入混料炉，主口板材回核心，副口矿渣与晶体送入烧结炉，载体回核心。沿原电芯线自动供燃。两台炉选好配方后，目标与定位应能区分尚待接线的炉和已有来料、正在加工的炉。正式窗口以正常时钟运行，分别核对实际批次、两种产物入仓和发电机实际收芯；在制或在途保存后由独立进程继续并核对物料账。沿用已有配方、物流及存档字段。

<a id="foundation-mine-return"></a>

### 矿壳试制、开路与富集晶体回流

基础整合玩家可在「样本与矿道」选择当前操作的定位。追踪期间目标栏与小地图显示同一步。小地图的「返回工厂目标」结束矿道追踪，目标栏随当前库存和产线恢复对应操作。试制消耗实物样本和催化剂，完成后可用催化剂补制解壳剂。面板按背包实数提示当前矿门还差多少，区分可取成品、待加工材料和已携足药品。携足后标记对应矿门的西侧入口，走近按 F 可查看操作，确认后才扣药。开通内矿道后，引导采集富集晶体、在反应器加工并将产物送回核心。配方批次与核心库存分别显示；定位按现场推导，沿用既有存档字段。

从已分炉的同一档复核试制、外门扣 4 件、内门扣 8 件和一批富集产物回仓。独立继续后实走两道门，核对原电芯线收芯补燃和全厂物料账。

<a id="foundation-rich-supply"></a>

### 富集晶体持续回流

首批催化剂送回基地后，可将反应器设在新矿旁，用传送带自动进料，经汇合器接入已有的核心回仓线。反应器多件出料时，面板应区分留待手取的成品和已接入回仓线的成品。沿用实际配方、端口和批次，不增加存档字段。

从开路后的 schema 9 序号 34 副本接线。正常窗口时钟下核对连续两批各 3 件富集催化剂进入核心，并记录原电芯线制芯、收芯与点火。以核心入口处的货物批次辨认来源，结合核心出料核对库存。在富集加工或运输途中保存，由独立进程读档，核对续产和全厂物料账。

<a id="foundation-pack-supply"></a>

### 构件包连续生产与扩建

分炉后可从回仓线分出金属板和多孔载体，持续供应构件包组装机。玩家从收货仓取两包，存入核心并在装配页支付。组装机仍在投产时，已备足的收货仓应可直接定位。沿用现有配方、分流、准入、仓储和装配规则。

从序号 40 副本接线，用自然生产的两个新批次核对 4 板、2 载体的投入、两包入仓和装配实扣。旧组装机的在制和仓内旧货分开核算。加工或运包途中保存，独立继续后核对该批与后续产量，同时验证富集回仓及原线补燃。

<a id="foundation-refinery-yield"></a>

### 新精炼炉投产与构件包产能

有待放置精炼炉时，目标栏按已配置的工艺给出用途。尚未分炉可分别配置混料冶炼和矿渣烧结；两种工艺都已配置时，若组装机等板材，可直炼铁矿补板，并到收货仓观察构件包入仓间隔。

从序号 48 的同档副本保留原线，另把已装配的精炼炉接到铁矿，直炼板材送入已有构件包供料线。沿用现有分流、配方和仓储。两组都经过相同的预热，再以等长自然生产区间比较组装机实际收到的两种材料、收货仓新增包数和相邻入仓间隔。单列开局库存、在途货与区间末缓冲。若补板后成包速度持平，依据设备缺料、阻塞或供电的实际状态解释限制。扩建组在炉内加工或板材在途时保存，独立继续后核对批次去向、富集回仓、电芯自动补燃与全厂物料账。

### 烧结载体在组装机与核心间的分配

从同一份序号 58 副本比较现行分流与优先供应构件包的布线。用收货仓实有的构件包装配分流器，在通往核心的混合带上用准入口筛出多孔载体。一支接回组装机上游，另一支并回核心线。两组使用相同预热和计量时长，分别统计组装机与核心的实收载体、成包实收和入仓间隔，单列施工支付。调整后两个计量区间都应有载体进入核心。加工中保存并独立继续，核对该包入仓、富集回仓、供燃和物料守恒。

### 混料冶炼的持续供渣

沿用序号 68 的载体分流，按批次核对混料炉两种粉料进机、矿渣排出和烧结炉收渣。按实测停因调整一处供料，与同档原线各自然预热 80 秒、计量 160 秒。按收货仓实收比较成包数和最长入仓间隔，同时核对核心实收载体、富集催化剂、原电芯线补燃及在途与库存变化。矿渣在途或烧结途中保存，独立继续后核对该批去向与全厂物料账。

<a id="foundation-pack-receipts"></a>

### 扩建后的构件包实收

基础整合的「生产统计 → 构件包」显示最近 1、5 或 10 分钟内全厂终端仓经物流自动收到的包数。沿用存档中已结束的模拟秒。首次采样前显示「暂无样本」，有样本且没有到货时显示 0 包。仓库和背包的现有库存仍单列。

首次取包、存入核心、支付装配和放置新炉沿用原目标。分炉后，若已装配的炉投入直炼补板、板材通向在用的构件包组装机、组装机接到收货仓，且近 5 分钟已有至少两包自动入仓，目标转为核对扩建收益。目标栏可直接打开构件包统计，也可沿小地图到这条线的收货仓核对现存。读档后按设备、线路和实收记录重算。开发验收对读首次装配前、已付待放置和供渣对照期末的隔离档。

这条扩建线的收货仓无剩余仓位时，目标栏标明仓满，提示到仓取出物料，并提供原有的仓库定位和实收统计。仓位按所有在库物料合计，现存包数单列。满仓持续到最近 5 分钟没有实收时，仍可定位该仓。腾出仓位后按现场状态重新判断目标。

<a id="foundation-west-carrier"></a>

### 富集供燃与核心西口改送载体

从成品档序号 10 的同一快照派生两组。原线照常生产，另一组停用普通催化剂反应器，保留富集回仓与原电芯线，将核心西口的多孔载体实送至构件包组装机。施工使用现有构件和实际回收料，单列转存与库存。按等长生产区间比较收货仓新增包数、组装机等料、催化剂收支和自动补燃。沿输送带与设备缓冲核销旧料，待初始载体的影响消退后再判断持续收益。改线档独立继续时复核实收与物料账。

在改线档的隔离副本上，从核心「接口」关闭西侧出料并应用，观察库存留存以及组装机消耗在途载体后的入仓节奏。保存并独立继续，从同一接口重新启用，观察释放留存的短时增产和恢复后的持续入仓。用核心库存、目标栏的收货仓现存与同一时间范围的构件包统计核对玩家可见结果，逐段记录期间实收。若控件显示与实际出料不符，或无法从界面辨别切换效果，记录具体操作和画面。

<a id="foundation-direct-carrier"></a>

### 复用直接烧结炉补充构件包载体

从西口恢复供料后的序号 52 派生原线与改线。用普通晶体给已有直接烧结炉供料，把新烧结的载体送往构件包组装机。保留矿渣烧结、富集回仓和电芯供燃，施工实付与旧载体单列。两组按相同模拟区间核对新批次、组装机等料、收货仓实收、供燃和物料账。若增加的包只来自旧料，或供电、供料不足以维持生产，按实际瓶颈记录。改线副本经正式 Boot 保存并独立继续，核对加工和运输中的货物。

### 从核心库存给构件包组装机补板

从直接烧结炉已投产的序号 56 派生两组，先把收货仓等量的成包转入核心，留出相同仓位。原线照常，补板组用已有出料口、分流、准入和汇合把核心板材送入原组装线。单列施工支付和在途物料。按相同预热与计量区间比较组装机实收板材、单独等板时间、收货仓自动实收与入仓间隔，同时核对核心板材净变化、载体、富集回仓和电芯供燃。若仅消耗起始库存，记录可维持的条件。运输或组装途中保存，独立继续后核对批次与物料守恒。

### 在回仓分流之后给组装机补板 <a id="foundation-plate-return"></a>

从序号 60 的同一快照派生原线与改线，优先用现有构件把核心板材接到 #259 的进料侧。按相同预热和连续两个 80 秒区间，比较 #260 实收、最长入仓间隔和核心发出的板材回流数量。两段均实收 8 包、最长间隔维持 10 秒、板材回流下降且原电芯线持续自动补燃，才计为改线有效。记录施工回收、期初期末在途、组装机的板材和载体来源，核对持续生产及中途存档独立继续。

### 扩建产线停产诊断与恢复 <a id="foundation-pack-diagnosis"></a>

序号 64 的三份独立副本起点均为 #260 现存 163 包。修正前分别中断 #259 的两路进板、载体汇合口，或让成品出口的准入口停止接收。运行 100 模拟秒后，缺板和缺载体两组均停在 166 包，出料受阻组停在 163 包。设备面板能读出还需 2 块金属板、1 件多孔载体或主输出已停止接收。三组最近 1 分钟实收均为零，统计设备行仅显示「缺少配方原料」或「等待取出输出」。缺板和出料受阻时目标回到核心装配，缺载体时仍指向收货仓。

目标栏应定位持续缺料的组装机，显示开下一批实际缺的材料；成品积压时说明受阻的出料段，并可定位检查。满仓优先提示到仓取货。保留构件包统计入口，修复后可到同一收货仓核对连续入包。用同档在途供料、成品正常运输作为反例，以正式 Boot 窗口和独立继续复核诊断、恢复和实际入仓间隔。沿用 schema 9 既有配方、物流和存档字段。

扩建线的组装机用一个配方周期判断持续缺料。按这台机器的完工时间和可达进料线上的实物判断；读档初期可用最近一个周期全厂均未成包的历史确认停顿。设备面板和统计设备行显示下一批缺件数。成品占住机内输出时，沿已占用的下游槽检查能否排空；目标可指向停止接收的准入口、断开的出料口或满仓。修复后定位回到收货仓，最近 5 分钟的历史不足时可先等下一包到仓。[窗口与读档验收](../devlogs/2026-W48.md#foundation-pack-diagnosis)

### 扩建组装机失电与手动停机 <a id="foundation-pack-power"></a>

序号 64 的 #259 正在加工批次 #2995。移除唯一覆盖它的配电节点 #5，或在副本中手动停下 #259，两组经过 70 模拟秒均停在 8.25 / 10 秒，#260 保持 163 包。修正前的目标均回到核心提示装配精炼炉。断电组面板显示请求 40 kW、实供 0 kW，同时仍标「运行」，统计设备行写「有在制，可推进」。手停组面板正确显示停机与进度保留。

扩建线失去供电时，目标定位受影响的组装机，说明如何恢复覆盖或同网电源。设备面板与统计按实际供电说明在制状态。手动停机时保留玩家选择，提供就地启用入口的指引，其他仍在工作的扩建线优先。复电或手动启用后，原批次应继续加工、入仓，独立续档应能核对后续连续收货。沿用现行供电、物流与存档规则。

Mac 正式 Boot 已验收。断电时目标指向 #259 并显示配电覆盖距离，手停时指向同一台设备并提示就地启用。两组均在原批次恢复至 8.40 秒时保存。独立继续后 #260 首先收到批次 #2995，随后三包每 10 秒送达。首程定步回归另覆盖有节点但无电源的孤网。[窗口与读档记录](../devlogs/2026-W48.md#foundation-pack-power)

### 扩建组装机同网欠供时的降速 <a id="foundation-pack-brownout"></a>

从序号 64 的同一份档派生两组，原线保持发电，欠供组只停用同网电芯发电机 #113。最初 80 模拟秒两组 #260 均从 163 收到 171 包。满供组相邻入仓均为 10 秒，欠供组为 10.15～10.55 秒，其中 662 / 1,600 个定步获部分供电，组装机始终能加工。批次 #3000 请求 40 kW、实供 38.3 kW 时，一个定步推进了 0.04787 秒。修正前，目标跳回核心装配并失去构件包实收入口。设备面板标「运行」，统计显示「有在制，可推进」，两处供电栏均已有 95.7% 的实供比例。

当扩建组装机有加工需求且获部分供电时，应说明它在降速加工，保留收货仓定位、库存和统计入口。满供时恢复常规实收指引；等料待机、完全失电、出料受阻及满仓仍按各自现场原因提示。以同网部分供电的实测进度和收货记录复核，不用瞬时比例预报下一包的到仓时间。

正式 Boot 两组均在第 125,352 步保存，当时 #2995 正在运输、#3000 正在加工。独立续产 35 秒，均按序收到这两批，随后又收两包。欠供、满供交替期间，定位持续指向 #260。欠供组在面板重新启用 #113 后又收三包，相邻间隔均回到 10 秒。[对照、回归与窗口证据](../devlogs/2026-W48.md#foundation-pack-brownout)

### 富集矿区独立供电对照 <a id="foundation-mine-power"></a>
