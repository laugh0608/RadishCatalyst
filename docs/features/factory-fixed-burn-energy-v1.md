## 玩家结果与边界

核心提供足够启动完整能源链和部分其他生产的固定功率；玩家制造工业电芯并持续喂入 G，增加可用容量，扩大真实产线。低负载继续燃烧可造成弃能，玩家之后用储能 / 控制减少浪费；普通连续供料不要求 PWM。

基础整合包只包含核心源、固定燃烧 G、既有消费者和待机。独立储能、节拍 / 反馈、负载组属于后续包，不能给首包免费隐形蓄电或自动最优调度。

## G 的状态与操作

- 默认新放 G 为手动停机，避免接上燃料即意外燃烧；明确启用后，接入任一实际电网且有完整燃料 / 剩余燃烧量即按额定释放能量，当前负载为零也继续。
- 完整电芯只在开始燃烧时原子扣 1；已激活部分保存整数 `burn_remaining_ticks`，候选范围 `0..1,200`（显示为 0..60 秒）。暂停世界 / 离线 / 手动停机不推进；恢复从剩余值继续，不退回完整电芯。
- 接网的孤立 G 自成电网，启用有料时也燃烧，能量可全部弃掉；不因无消费者自动节流。拆除接线 / 远离核心不成为免费暂停；玩家应使用本机停机。
- 拆回停机后提示剩余燃料将损失；确认后未激活电芯完整退回，激活余能计入 `discarded_kj`。接收容量不足整次失败；重放 / 存读不能刷新一颗电芯。
- 禁止双网重复供电。G 关闭仍是导通节点；核心和配电节点沿 12 格互连 / 6 格消费者接入的自动图与遮挡判定，核心按足印中心作为源节点。

## 20 Hz 预算与能源账

消费者沿 V8 运行 / 待机单步预算与统一满足率；供电端改为固定燃烧。每个 0.05 秒步按起点库存 / 拓扑规划，在本步先计算消费请求，再结算各源实际释能与分配；拓扑查询 / HUD 不消耗燃料。

对单台 G，在步内最多使用现有余时与需要激活的下一颗完整电芯补满 `dt`；每段释放 `120×实际燃烧秒数`。尾步没有下一颗时只释放余时对应能量，不伪造整步满发。完整扣料 / 余时 / 激活次数 / 释能由同一步提交。

首包不含储能时，电网每步令需求为 `D` kJ、全部 G 固定释能为 `G`：先让已释放 G 能量供负载 `min(D,G)`；核心实际供能 `min(max(D-G,0), 核心容量×dt)`；剩余 G 能量进入 `spill_kj`。这项分配避免把可调核心先用满后再额外浪费燃料，但不改变 G 的燃烧速率。

未满足的需求保持缺口，消费者按同网满足率减速。多 G 实际释放与分担按额定 / 本步实际释能比例计算，合计一致；不同网络不能互抵。可用容量按启用源与当前燃料的本步可用能力派生，不把空 G 铭牌当可用功率。

```text
燃料账：激活颗数×7,200 = 已释放 fuel_released_kj + G 内剩余燃料能 + 回收 discarded_kj
网络账：base_supplied_kj + fuel_released_kj = used_kj + spill_kj
用电账：used_kj = work_kj + standby_kj
```

`discarded_kj` 是未释放燃料的回收损失，`spill_kj` 是已经释放但未利用的电能，不能混加 / 双计。核心未用容量不进入实际供能账；运行暂停 / 离线不追账。历史桶与累计同时记真实释能、核心供能、用电 / 待机、缺口与弃能，严格恢复不沿用旧 V8 总供用必相等假设。

## 负载与恢复

起步电芯链全运行上界 220 kW，加入一炉 / 一组装上界 320 kW，核心候选足够。按现有直接电芯工艺，1 颗需铁 2 / 炭 1 / 晶体 2，纯工作能 1,960 kJ；新增待机与尾货按运行事实计，不能当成每颗固定成本。

单 G 连续满燃烧耗 1 电芯/分钟，普通炭上界 3/分钟、R12 单机上界 5/分钟；这只是输入 / 加工上界，真实带速 / 交接另扣。逐步增加有目标的材料生产至实际请求超过核心容量，再比较无 G / 启用 G 的同源产出，不能关闭核心或靠空转制造收益。

燃料耗尽只失去对应额定；核心、物流和核心出料继续，停下扩建支路，保留能源链和其原料供给即可恢复。未来负载控制不作为首包自救必需条件。必须验证冷启动、断料、低余时、全待机和从核心正常补料，不注入电芯证明成立。

## 后续储能 / PWM 合同边界

- 新建储能初始 0；容量 / 充放功率 / 效率明确，与 G 燃料分开。先实际充电才能使用预充算例。多个储能不能同一步循环充放制造收益。
- 新版总账增加储能净变化及真实损耗；低负载富余可充入，充满弃能，停发期靠有界放电补缺口。
- C1 的供料节拍与 C2 的阈值回差必须基于模拟时间；手动 / 自动共同遵循固定步边界，最小控制周期和多控制者冲突在 D2 合同冻结。
- 平均补电为 `额定×运行占比`，但稳定还须满足储能容量 / 功率、最长空窗、启动与动态负载。360 / 390 / 120 kW 的 60 开 / 180 停算例只是理想比较，不是首包隐含能力。
