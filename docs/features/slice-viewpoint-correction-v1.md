# Slice Viewpoint Correction V1

更新时间：2026-07-18

状态：已收口（2026-07-19，萝卜SAMA实机复核确认角色移动与整体呈现符合要求）。介质级视角口径修正轮（三包 + 3.5 方向性 idle 增补）；下一专题为配方加工（化工链第二步），由新会话按文档先行建立。

## 背景与定位

萝卜SAMA 2026-07-18 实机对照 Factorio 判定：现有全部世界层素材（角色 + 设备）按 2026-07-13 定档的"3/4 俯视立面"口径生成，实为斜向下 45 度立面（能看到设备正面墙体、角色正脸偏侧），与产品空间愿景（Factorio 式高机位近正俯视、顶面主导、设备如俯拍）存在系统性视角差。

这不是单张素材走样，而是介质投影口径本身需要修订。口径已改（见 [Pixel Art And Grid Standard](../reference/pixel-art-and-grid-standard.md) 投影口径节与 [AI Art Prompts](../reference/ai-art-prompts.md) 全局风格块）：**高机位近正俯视**替代"3/4 俯视立面"。本专题按新口径重出受影响的世界层素材并换装，让画面呈现与愿景一致。同时把已止血的画面填充修正（`fractional`）纳入验收基线。

## 玩家价值

- 看到：设备与角色以真正的俯拍读法呈现，工厂一屏读法接近 Factorio；画面填满窗口，无整数缩放黑边。
- 理解：这是"像素工业俯视工厂"该有的样子——设备是俯视的机器阵列，不是斜摆的建筑立面。

## 口径与影响面

### 已定档（无需再确认）

- 投影：高斜角俯视，顶面为最大可见面 + 保留一圈清晰侧壁高度带表达体积（参照 Factorio / Mindustry），明确排除平视立面与纯垂直俯视两个极端；角色为俯拍头肩主导、脚在身下可见。
- 设备族特征（2026-07-18，S1' v3 定）：底部黄黑安全警示条 + 侧壁高度带为设备族共同特征，6 台设备重出统一带。
- 画面填充：`window/stretch/scale_mode` 由 `integer` 改 `fractional`（已落地）；整数倍全屏逐像素完美，非整数倍窗口按比例填满。
- 设备足印与视觉体量匹配：不允许约 3 tile 高精灵压 1x1 足印，采集器重出时足印提为 2x2 起。

### 重出清单（世界层立体物，13 + 6）

- 设备 6：反应器 `reactor`、储存 `storage`、整备台 `workbench`、采集器 `collector`、受损核心 `outpost_core_damaged`、修复核心 `outpost_core_repaired`。
- 角色 13：静态 `engineer` + 侧向 4 帧 + 背面 4 帧 + 正面 4 帧（帧表仍是最高风险项，两轮不达标退 CC0 角色基底口径不变）。

### 不重出 / 待定

- 地面宏块 4（rock / metal_platform / crystal / polluted）：本为纯俯视，不受影响。
- 晶体簇 3（大 / 中 / 小）：无"正面墙"读法，两种机位接近；先不重出，接入新素材后实机对比再定去留。
- 立绘：UI 层，不受影响。
- 像素风格锚点 `pixel-style-anchor.png`（现为老口径 reactor v1）：需在本轮反应器新锚点（S1' v3 或 S1'' 重出版）定稿后更新为高斜角口径锚点。

## 范围（串行推进）

### 包 1：新机位锚点验证（S1' → S1''）

- 按新口径提示词生成反应器候选，验证高斜角俯视在本调色板 / 密度下成立、可归一。
- S1'（2026-07-18 首轮）：3 张候选视角修正达成、机械复核全绿，萝卜SAMA选 v3 为方向基础；但判定整体偏扁平、缺高度表达。根因是首轮提示词把相机推到近垂直俯视（near-overhead）压平了侧壁高度带，属口径二次校准（非失败闸门，为修正轮首次锚点尝试）。黄黑警示条经萝卜SAMA定为设备族特征。
- S1''（2026-07-18 完成）：按二次校准口径重出高度增强版 3 张，审阅全绿（三张均为高斜角俯视 + 清晰侧壁高度带 + 黄黑条，96px 剪影可读、色域同族）。萝卜SAMA定稿 `v2`（反应窗平嵌顶面、侧壁带约 40%、基础设备体量最标准）为新锚点，已入库替换 `assets/reference/pixel-style-anchor.png`；`v1`（塔式体量）留档作未来大型建筑参考，`v3`（细节密）留候选。包 1 收口，包 2 解锁。
- 出口：萝卜SAMA确认新锚点定稿，更新 `pixel-style-anchor.png`；两轮仍扁平或倒退立面则复盘投影俯角（升级架构会话）。
- 生成会话由萝卜SAMA执行（图像会话稳定性约束不变）；审阅 / 归一 / 换装由执行会话承接。

### 包 2：设备重出与换装（已收口 2026-07-18）

- S3'' 三张一次过（家族一致 / 双态同机 / 剪影 / 色域全绿），6 张设备精灵归一同名换装入库（`tools/normalize_slice_pack2.py`），采集器足印提 2x2（前方 2 tile 网格交点锚定 + 四格晶体地 + 62x62 占用校验）。
- 运行时断言全过 + 三张实机截图留档；萝卜SAMA实机确认收口（存在不阻碍的小瑕疵，记入打磨清单随后收集）。
- 遗留观察：储存为四连（原口径三连，判可接受）；核心与反应器形体相近（靠位置 / 体量 / 齿冠区分，留人工点修观察）；核心区金属平台地块与设备自带底板叠加读法略重（摆位打磨项）。

### 包 3：角色重出、换装与收口（当前，含 3.5 方向性 idle 增补）

- 角色 4 张超单会话 3 张上限，拆两个生成会话（交接副本已备妥）：S4'' 静态 + 侧向帧表 → 审阅定稿后 S7'' 背面 + 正面帧表（挂 S4'' 定稿作角色参考）。
- 实施记录：首轮背面达标、静态与侧向斜向不达标；二轮（S4''-R）侧向达标、静态两轮闸门触发上报；裁决后 S4''-R2 修参考链正面一次过，静态取正面帧派生。13 张帧表与派生静态已归一换装，运行时四方向断言全过。
- 3.5 增补（2026-07-18 萝卜SAMA实机复核裁决）：停止移动后朝向丢失且 idle 为迈步姿态——生成三向站立帧（S5'' 段，朝向词沿用已验证模板）+ `SlicePlayer` 方向性 idle（`idle_down` / `idle_side` + 翻转 / `idle_up`，按 facing 选择），随包 3 收口；这是本专题第二处代码改动（原"方向选择逻辑不变"边界作此扩展）。
- 出口：真实入口实机路径截图，角色俯拍读法、四方向行走正确、停止后保持朝向且为站立姿态；填充 + 视角一并复核，记入当周周志；站立帧单张两轮闸门不变。

## 成功证据

- 正式入口实机：设备与角色为高机位俯拍读法，画面填满窗口，与 Factorio 空间读法方向一致。
- 全部换装为同名替换，场景结构与系统代码基本不动（采集器足印一处调整除外）。
- `sh ./scripts/check-client.sh` 通过；`--import` 与运行时路径复核按需执行。

## 失败退出

- 按 [Development Decision Gates](../process/development-decision-gates.md) 两次失败停手规则执行。
- 新机位锚点两轮仍无法在本调色板 / 密度下成立可读，停手复盘投影口径（可能需要在"近正俯视"与"3/4"之间取折中档），升级萝卜SAMA。

## 不做

- 不改系统逻辑（循环 / 存档 / 建造 / 产出）；素材同名替换 + 两处角色代码改动（采集器足印 2x2、方向性 idle）之外不动代码。
- 不做八方向斜向帧（2026-07-18 萝卜SAMA裁决：记后续"角色八方向动画"专题，对角朝向生成风险高、待朝向词库更成熟后攻）；对角移动维持四向帧裁决。
- 不新增设备种类、不做敌人 / 战斗素材（视角定档后另起）。
- 不动地面 tile 与立绘；不做 viewport 整数重构（留后续 HUD 换皮专题）。
- 不迁移、不修改冻结的旧系统与旧检查。

## 状态 / 存档 / HUD / 检查

- 素材为同名替换，存档 / 场景引用 / 检查引用不变；无 schema 变更。
- 采集器足印 1x1 → 2x2 需同步场景足印与 `SliceWorld` 放置校验（占用查询尺寸），属本专题唯一代码改动。
- 只要求 `check-client` 静态通过与无导入错误，不新建检查脚本文件。

- 收口后素材前置解除，敌人 / 新设备素材生成与后续玩法专题（配方加工 / 立绘对话 / 敌人战斗）由萝卜SAMA择序。
