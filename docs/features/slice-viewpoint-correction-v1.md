# Slice Viewpoint Correction V1

更新时间：2026-07-18

状态：当前唯一活跃功能专题；介质级视角口径修正轮，2026-07-18 由萝卜SAMA实机提出并定档。属最高级别决策产物落地，前序切片系统层专题（首屏 / 晶体区 / 循环 / 存档 / 建造）全部已收口。

## 背景与定位

萝卜SAMA 2026-07-18 实机对照 Factorio 判定：现有全部世界层素材（角色 + 设备）按 2026-07-13 定档的"3/4 俯视立面"口径生成，实为斜向下 45 度立面（能看到设备正面墙体、角色正脸偏侧），与产品空间愿景（Factorio 式高机位近正俯视、顶面主导、设备如俯拍）存在系统性视角差。

这不是单张素材走样，而是介质投影口径本身需要修订。口径已改（见 [Pixel Art And Grid Standard](../reference/pixel-art-and-grid-standard.md) 投影口径节与 [AI Art Prompts](../reference/ai-art-prompts.md) 全局风格块）：**高机位近正俯视**替代"3/4 俯视立面"。本专题按新口径重出受影响的世界层素材并换装，让画面呈现与愿景一致。同时把已止血的画面填充修正（`fractional`）纳入验收基线。

## 玩家价值

- 看到：设备与角色以真正的俯拍读法呈现，工厂一屏读法接近 Factorio；画面填满窗口，无整数缩放黑边。
- 理解：这是"像素工业俯视工厂"该有的样子——设备是俯视的机器阵列，不是斜摆的建筑立面。

## 口径与影响面

### 已定档（无需再确认）

- 投影：高机位近正俯视，顶面主导、正面墙体几乎不可见、明确排除平视与侧立面；角色为俯拍头肩主导、脚在身下可见。
- 画面填充：`window/stretch/scale_mode` 由 `integer` 改 `fractional`（已落地）；整数倍全屏逐像素完美，非整数倍窗口按比例填满。
- 设备足印与视觉体量匹配：不允许约 3 tile 高精灵压 1x1 足印，采集器重出时足印提为 2x2 起。

### 重出清单（世界层立体物，13 + 6）

- 设备 6：反应器 `reactor`、储存 `storage`、整备台 `workbench`、采集器 `collector`、受损核心 `outpost_core_damaged`、修复核心 `outpost_core_repaired`。
- 角色 13：静态 `engineer` + 侧向 4 帧 + 背面 4 帧 + 正面 4 帧（帧表仍是最高风险项，两轮不达标退 CC0 角色基底口径不变）。

### 不重出 / 待定

- 地面宏块 4（rock / metal_platform / crystal / polluted）：本为纯俯视，不受影响。
- 晶体簇 3（大 / 中 / 小）：无"正面墙"读法，两种机位接近；先不重出，接入新素材后实机对比再定去留。
- 立绘：UI 层，不受影响。
- 像素风格锚点 `pixel-style-anchor.png`（现为老口径 reactor v1）：需在本轮首个新设备定稿后更新为新机位锚点。

## 范围（串行推进）

### 包 1：新机位锚点验证（S1'）

- 按新口径提示词生成反应器候选（挂原锚点作家族参考但视角以新口径为准），验证高机位近正俯视在本调色板 / 密度下成立、可归一。
- 出口：萝卜SAMA确认新机位锚点定稿，更新 `pixel-style-anchor.png`；不达标两轮则复盘口径（升级架构会话）。
- 生成会话由萝卜SAMA执行（图像会话稳定性约束不变）；审阅 / 归一 / 换装由执行会话承接。

### 包 2：设备重出与换装

- 按新锚点重出其余 5 设备，归一入库，同名替换 `client/assets/sprites/slice/` 对应文件；采集器足印在场景与代码提为 2x2。
- 出口：基地 + 晶体区实机截图，设备为俯拍读法且家族一致；`check-client` 静态全绿、`--import` 无报错。

### 包 3：角色重出、换装与收口

- 重出静态 + 三方向帧表，归一（复用 `character_directions` 归一 job），换装；方向选择逻辑不变。
- 出口：真实入口实机路径截图，角色俯拍读法、四方向行走正确；填充 + 视角一并复核，记入当周周志。

## 成功证据

- 正式入口实机：设备与角色为高机位俯拍读法，画面填满窗口，与 Factorio 空间读法方向一致。
- 全部换装为同名替换，场景结构与系统代码基本不动（采集器足印一处调整除外）。
- `sh ./scripts/check-client.sh` 通过；`--import` 与运行时路径复核按需执行。

## 失败退出

- 按 [Development Decision Gates](../process/development-decision-gates.md) 两次失败停手规则执行。
- 新机位锚点两轮仍无法在本调色板 / 密度下成立可读，停手复盘投影口径（可能需要在"近正俯视"与"3/4"之间取折中档），升级萝卜SAMA。

## 不做

- 不改系统逻辑（循环 / 存档 / 建造 / 产出）；本专题只换素材与投影 / 缩放呈现口径。
- 不新增设备种类、不做敌人 / 战斗素材（视角定档后另起）。
- 不动地面 tile 与立绘；不做 viewport 整数重构（留后续 HUD 换皮专题）。
- 不迁移、不修改冻结的旧系统与旧检查。

## 状态 / 存档 / HUD / 检查

- 素材为同名替换，存档 / 场景引用 / 检查引用不变；无 schema 变更。
- 采集器足印 1x1 → 2x2 需同步场景足印与 `SliceWorld` 放置校验（占用查询尺寸），属本专题唯一代码改动。
- 只要求 `check-client` 静态通过与无导入错误，不新建检查脚本文件。

## 验收与移交

- 专题收口以"正式入口实机截图（设备 + 角色俯拍读法 + 画面填满）+ 视角前后对比"判定，记入当周周志。
- 收口后素材前置解除，敌人 / 新设备素材生成与后续玩法专题（配方加工 / 立绘对话 / 敌人战斗）由萝卜SAMA择序。
