## 当前最高优先级

1. 冻结 demo 区域数量：当前算基地共 11 个区域，只允许再补 1 个关键区域到 12 个；之后不再横向加区域。
2. 给 12 个区域做职责分层：核心区域、功能区域、过渡区域，不平均铺开内容。
3. 扩大和重排 3 到 4 个核心区域，让它们不再像任务节点房间，而是有资源、危险、路线和回访价值。
4. 继续做 UI 可读性 baseline：第一包已收束主 HUD 标题、目标追踪、运行时提示和完成反馈区域口径；下一包聚焦资源摘要、基地摘要和角色状态。
5. 收束 demo 主线终点：围绕修复核心设备、完成第一套稳定生产链、击败阶段守卫或打开稳定通道选一个明确目标。

## 区域策略

- `核心区域 4 个`：基地、早期资源区、主要危险区、demo 终点区。优先扩面积、目标密度、资源和战斗节奏。
- `功能区域 4 个`：承载特定资源、设备材料、风险类型或回访目标。
- `过渡区域 4 个`：承载连接、氛围、少量采集和路线变化，不追求完整玩法密度。

参考《银河破裂者》的空间感，但不照搬大地图模板。现阶段只要求外出区域有可探索余量、资源点、危险压力和回基地理由。

## UI 策略

UI 当前进入必要开发项，不作为纯美术打磨处理。优先级：

1. 主 HUD：生命、防护、当前目标、当前区域、关键资源。
2. 地图 / 区域提示：玩家知道自己在哪、要去哪、为什么去。
3. 基地状态摘要：当前可制造 / 可升级、缺什么、升级收益。
4. 角色状态摘要：工具、攻击、防护、抗性、已生效模块。

已完成第一包：主 HUD 不再显示 `Prototype` 标题，高频目标提示和任务完成反馈已切到封锁遗迹、裂相脊、回声台地、盐壳浅滩、碎晶沟谷、风蚀管廊、锁相框架、锚定桥等新区域口径。

不做完整菜单、设置页、背包大重构、完整装备栏、动画过场或大规模美术替换。

## 节奏规则

个人开发阶段只做足以判断方向的完成度。一个阶段达到退出条件后，必须及时进入下一阶段；不允许因为 `P2` / `P3` 细节、局部读法、文案密度或状态字段洁癖无限打磨。

只让这些问题阻塞阶段：

- 崩溃
- 主线卡死
- 坏档
- 任务无法完成
- 关键资源断档
- UI 完全无法判断下一步

其他问题进入 backlog 或后续 polish。
