## 当前最高优先级

1. 优先把已有数据占位变成可操作内容：基地基建设施、场景对象、互动反馈、存档来源和 HUD / 面板收益需同时接入。
2. 近期开发包按基地平台、晶体 / 污染核心区、核心稳定站三类主线场景推进；地图只扩既有 12 区域，不新增第 13 区。
3. 玩法增加聚焦基地服务外勤、外勤反哺基地：基建补给、装备 / 药剂承压差异、处理副产去向和回基地理由必须体现在操作中。
4. 可读性审计退为配套验证；不再把试玩记录、提示清单或静态护栏作为主要开发产出。

## 区域策略

- `核心区域 4 个`：基地、早期资源区、主要危险区、demo 终点区。优先扩面积、目标密度、资源和战斗节奏。
- `功能区域 4 个`：承载特定资源、设备材料、风险类型或回访目标。
- `过渡区域 4 个`：承载连接、氛围、少量采集和路线变化，不追求完整玩法密度。

参考《银河破裂者》的空间感，但不照搬大地图模板。现阶段只要求外出区域有可探索余量、资源点、危险压力和回基地理由。

## UI 策略

UI 当前进入必要开发项，不作为纯美术打磨处理。优先级：

1. 主 HUD：生命、防护、当前目标、当前区域、关键资源。
2. 地图 / 区域提示：玩家知道自己在哪、要去哪、为什么去。
3. 基地状态摘要：当前可制造 / 可升级、缺什么、升级收益。
4. 角色状态摘要：工具、攻击、防护、抗性、已生效模块。

已完成第一包：主 HUD 不再显示 `Prototype` 标题，高频目标提示和任务完成反馈已切到新区域口径。已完成第二包：HUD 左侧聚合当前目标和关键资源，右侧聚合基地摘要和角色状态；关键资源按当前任务、配方输入和建造消耗推导，基地摘要显示可制造 / 待制造项、缺料、完成后产物或设备加工状态，并已通过人工读法复核。玩家可见命名第一包已收束。首小时可读布局第一轮已让当前交互 / 攻击目标才显示名称并高亮，HUD 小地图改为紧凑错行标签；第二轮已拉开基地制造出口、晶体区三条资源 / 战斗线和污染边界安全施工带 / 危险场，不改完整 UI 架构。设备面板第一版已覆盖基础反应器和污染过滤器的状态、当前配方、输入 / 产出 / 副产、完成去向、下一步和操作提示。HUD 重排第一包已把常驻信息压缩到边缘，交互提示居中贴底，日志改为短条；污染过滤器药剂完成后的短条、HUD 目标、沉积物提示和门前压力点已读成同一条回访链。

不做完整菜单、设置页、背包大重构、完整装备栏、动画过场或大规模美术替换；但 HUD、设备面板、缺料提示、当前目标和补给反馈这类功能型 UI 可随玩法链继续调整。核心稳定站按首版 demo 终点处理；不重构 `base_action_state`，不新增第 4 个行动台分支。

## 冻结范围

- 前线行动台、候选、窗口复盘、高压窗口和 `base_action_state` 保持冻结，只修 `P0` / `P1`。
- 不新增同构短行动、窗口分支、随机成功率、新货币、队员或完整 loadout；允许首版 demo 级装备 / 模块效果第一包。
- 不继续沿相位井后段横向堆同构内容包；新增内容优先投到基地、核心区域扩面和可操作设施。
- 不继续用提示、闸门、坏档校验或 HUD 护栏作为默认主线任务。
- 不迁移稳定数据 ID；旧 ID 先作为存档、任务和数据兼容层保留。

## 节奏规则

个人开发阶段只做足以判断方向的完成度。一个阶段达到退出条件后，必须及时进入下一阶段；不允许因为 `P2` / `P3` 细节、局部读法、文案密度或状态字段洁癖无限打磨。

只让这些问题阻塞阶段：

- 崩溃
- 主线卡死
- 坏档
- 任务无法完成
- 关键资源断档
- UI 完全无法判断下一步

其他问题进入 backlog 或后续 polish。本阶段主要工作是 Demo 可玩内容建设，优先交付场景 UI、地图扩面、基建设施和玩法压力；不新增第 13 区域、不扩行动台和高压窗口，不提前做完整长期成长系统。
