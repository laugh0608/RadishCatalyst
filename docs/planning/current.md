## 边界与冻结

- 多世界目录与 schema 9 是当前运行基线；schema 2–8 只经冻结旧合同迁移，世界完整重建后才发布 schema 9，备份来源恢复不会轮转覆盖唯一有效候选。不复活旧 `SaveService`、旧 `GameRoot`、旧三槽存档或旧地图。
- 视角修正轮遗留项在案：八方向动画（候选专题）、viewport 整数重构、打磨清单（核心区底板叠加等观察项）。
- 新专题不做敌潮、复杂 Boss、技能树、联机或无关重构；立绘对话、八方向动画、viewport 重构与发布继续冻结。HUD 只在 UI 视觉定稿子专题批准的范围内推进。
- 远程武器不重开近战 V1；已收口专题只包含固定脉冲步枪与电池，不新增敌人、地图、武器树、装填或自动供弹。当前武器、弹体和攻击阶段保持会话态，也不进入 schema 9。
- 破损核心仅派生 V5 同族 `144×128px` 双态；修复态、位置、足印、碰撞、逻辑和 schema 8 冻结。
- 首程小地图只服务当前固定切片；不复活旧 `PrototypeHud` / 12 区纵切，不新增全屏地图、扫描器、精确未发现资源或通用任务图。schema 9 只保存两个首次查看旗标与 480 位探索图。
- 不复活旧通用任务链；若包 1 证明存在引导阻断，优先从现有权威状态派生固定阶段目标。
- 陌生玩家盲测重新冻结，直到萝卜SAMA确认画面、建造 / 背包和设备交互不再以明显草稿层作为主读法。
- 视觉专题不修改 32px 网格、960×540 相机、基础状态语义、左上光、高斜角投影或设备主体尺度；已批准例外只有中继从 `48×66px` 调整为 `48×76px`，以及 2026-08-11 把误烘焙传送带外段的核心 / 反应器运行时画布恢复为 `144×128px` / `176×88px` 短接口态。已否决的统一明度标尺不得回到正式归一管线。
- 核心 / 反应器未连接短口底图是当前基线；连接态完整终端带上层覆盖已被人工否决。反应器端口已从中排修正到底排，核心与反应器分别经独立正式入口复核后共用端点派生的窄局部接驳片；`connection_distance`、足印、碰撞、schema 8 与其他设备端口继续冻结。
- 已获批双目标稿和五张锁定设备继续作为像素与关系真相源；不得重画、重生成、缩放、旋转或从正式素材派生第二套主体。
- 现行客户端已使用逐类 profile、schema 9、固定正面设施与统一运行时端点；采集器右侧输出、储物箱模式端口和修复态核心左 `IN` / 右 `OUT` 均已启用。核心仍是地图固定设备，专属视觉排序壳、端点与相邻终端带关系均由运行态派生，不进入存档。
- 当前 `SlicePowerGrid` 仍是二值可达图；在独立电力专题确认容量、需求、分配、过载与存档边界前，不提前向中继或设备面板伪造负荷数值。
- 设备面板核心仓库包 2 暂停，待视觉专题和电力专题边界稳定后再决定是否继续。
- `SliceWorld` 当前仍低于 1500 行硬上限；设备展示快照不得重新把按类型 UI 分支堆入世界编排器。
