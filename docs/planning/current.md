## 当前主线

按专题三包串行：

1. 包 1 建造与放置：整备台消耗晶体制造采集器，携带态 + 放置预览 + 网格校验，落地生成设备节点。
2. 包 2 自动产出与存档还原：采集器计时产出入世界计数，`collectors` 进存档、读档按坐标重建续产。
3. 包 3 全循环验证与收口：建造扣费 / 非法放置拦截 / tick 产出 / 存读还原断言，截图，周志收口。

建造链路、放置约束与数值草案（制造 5 晶体、产出 1/10 秒草案）以专题文档为准，关键取舍待萝卜SAMA确认后实现。

## 边界与冻结

- 只做专题内三包；配方 / 第二资源 / 加工链是化工链第二步专题，储存罐功能化、设备拆除与升级、敌人与战斗、任务链、立绘对话均不做。
- 存档沿用 `SliceSaveService` 追加可选 `collectors` 字段，schema 不升版；不迁移、不修改冻结的旧系统与旧检查。
- 不生成新素材（采集器用库存 `collector` 精灵）；放置预览用允许的动态高亮表达。
- 冻结保留旧场景、旧视觉层与旧检查，不删除、不修改；联机、多星球、试玩准备与发布继续冻结。
