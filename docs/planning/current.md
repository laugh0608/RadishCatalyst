## 边界与冻结

- 不增加第二只敌人、后续剧情、新地图、新建筑、新配方、Boss、技能树、联机或完整有限电力。
- Demo 完成继续从既有 `field_encounter.state == delivered` 派生；schema 10 只新增 `equipped_weapon_id`，其他 UI 状态保持会话态。
- 采集器容量、存档校验和面板必须共用同一常量；保存防抖必须在制造、放置、拆除、交付、暂停与退出等关键点强制落盘。
- 传送带和地板为可通行地表层；设备按“基座足印阻挡、上部轮廓参与排序”处理，不以整张透明画布充当碰撞。
- UI 只移植参考图的状态分离、容器并排、直接操纵、强层级和可诊断结果，不复制角色编队、复杂成长、移动端按钮或完整工业简报。
- `SliceWorld` 不得继续增长；新行为先确定权威所有者，不通过更多按类型分支兜底。
- 陌生玩家盲测、试玩分发、打包和发布继续冻结，直到本专题 S0 全链退出条件通过。
