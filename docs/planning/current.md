# Current Plan

更新时间：2026-10-17

## 当前阶段

**Demo 生产内容扩展与快速玩法验证。** 萝卜SAMA已明确要求扩大物品、设备和合成链，以更丰富的生产关系验证玩法；本轮先完成关系方案，再分批实现可玩的完整链条。当前活跃专题为[生产内容扩展 V1](../features/factory-production-expansion-v1.md)，具体内容与数值仍属提案，不写成已经实现。

原发现 / 电力 / 统计联合包 D3 工程退出已获批准，D4-P / S 开发机工程验证已完成；旧 D4-U / X 与其他保留项继续登记，**不作为内容扩展设计或开发的前置门槛**。Windows 验证继续暂缓，不将暂缓或本轮优先级变化记为验收通过。

产品方向仍以 [Production-Centered Direction](../product/production-centered-direction.md) 为准：化工生产经营为核心，探索提供资源与目的，生产成果反哺开拓。旧二维切片与历史证据保留，旧试玩整改 S0 暂缓。

## 当前主线与下一步

1. **关系方案**：[生产内容扩展 V1](../features/factory-production-expansion-v1.md)提出 15 种物品、14 个加工配方、3 类新增加工设备与电芯发电机；成品分别用于制造构件、供电和开拓高产矿点。[终末地产线研究](../reference/endfield-production-planning-study.md)记录用户提供的两份资料、源码版本与取舍。
2. **E1 材料与扩建**：确认方案后先交付新矿源、粉碎 / 精炼 / 组装、直接与副产物回用工艺；玩家能做出构件包并实际扩建一台机器。
3. **E2 能源循环**：生产电芯并用其支持新增负载，能处理断料和恢复。
4. **E3 开拓回报**：生产开拓用品、打开固定支路，把更高产的原料接回既有工厂。

每批按“完整可玩用途 → 短试玩 → 调整”推进；不先堆大量无用途的物品，也不把旧包逐项精细验收排在内容开发之前。物料、存读和关键操作仍做与变更风险匹配的检查；具体范围见专题，不例行重跑历史完整自然流程或四档长测。

## 本轮边界

- 本轮授权是研究并落地方案、切换规划；不包含直接实现尚未确认的具体配方、制造经济、发电或地图 / 存档变更。方案明确后按 E1–E3 开发，不需要先补完旧 D4。
- 设计范围包括新固体原料 / 中间品 / 成品、专用加工设备、构件制造、消耗电芯供电和固定开拓回报；这些从原“新增设备 / 经济另包”进入当前设计讨论范围，但不是运行时已解冻实现的事实。
- 现行默认新世界、供给、存档与 6 / 12 格供电规则保持。提案建议新内容独立身份及新存档版本；旧世界不静默换配方、矿点或供给。普通实体预算与制造来源需在实现合同中明确。
- 沿现有 Godot 3D、导入 GLB、既有风格和自有图标，资产随内容批次做够用版本。精细美术不作为本轮前置，不以程序几何代替正式设备画面。
- 液气管网、种植 / 交易、通用科技树、仓库自动出料、物流桥、自动蓝图、战斗扩展、多人、随机地图、多星球、离线收益及 1,000 台 / 10,000 带仍在本包外；不因参考资料包含就自动纳入。
- 不自动安装依赖、下载资产包、打包、发布或推送。外部参考只作设计研究，不迁入整仓代码或游戏资产。
