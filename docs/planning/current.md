萝卜SAMA已审阅并确认首包方案，明确要求开始推进。授权覆盖正式工程接入、旧二维世界保留、工厂独立存档和 P1–P3 扩建 / 规模实施。画面认可不等于美术定稿、完整生产亲测或大工厂性能通过。

## 当前边界

- 保留已认可的设备造型、50° 视角、配色、光照、单枚接口箭头、拖铺与真实弯道；本阶段只修影响辨识或操作的问题，精细美术留待后续。
- 首包提案先保持三种设备与固体带，建设多条产线并保存成果；预供电、预发构件继续用于验证，不混入旧切片电力 / 仓储规则。
- 64×64 场地、普通构件数量、100 台设备 / 1,000 带工程负载和工厂 schema 1 已获确认，按新专题逐包实现和验证。
- 保留正式 `client/` 的旧入口、旧世界和回归证据。新工厂独立存档，不自动转写 schema 10；未决定旧世界导入或删除旧内容。
- 本机旧三机与小窗口采样不能证明高分辨率、多产线或 Windows 性能；Windows 目标硬件仍待指定。

## 当前不做

- 不批量精修 / 重做模型、角色、材质或全部 UI，不重新发起美术介质对照。
- 不增加设备种类、液气、经济解锁、战斗、多人、随机地图、多星球或离线收益。
- 不用一次性样件代替正式入口与跨进程存读验证，不把工程负载世界冒充完整经营循环。
- 不恢复陌生玩家盲测、分发、打包、发布、上传或推送；不安装依赖或引入外部资产。
