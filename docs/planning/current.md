- 不修改客户端、玩法、场景、HUD、存档、检查或素材；不启动新的图像生成与接入会话。
- 不借暂停期整理工程、删除旧层、补检查或推进“顺手可做”的功能。
- 允许只读分析仓库与历史证据、比较产品形态和生产管线，并在萝卜SAMA确认后更新复盘结论。
