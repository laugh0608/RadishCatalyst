## 当前最高优先级

1. 从 `S0` 新档做一次首版 demo 冷启动审计，确认玩家能连续抵达 demo 完成反馈。
2. 审计重点只看 `P0` / `P1`：崩溃、坏档、主线卡死、任务无法完成、关键资源断档、UI 完全无法判断下一步。
3. 对照 `docs/planning/milestone-review-checklist.md` 记录闭环、存档、静态数据、工程结构、任务引导和范围风险。
4. 审计中发现的 `P2` / `P3` 文案密度、局部拥挤、地图标签重叠或数值手感问题，只进入后续 polish，不阻塞阶段判断。
5. 不因为冷启动审计继续扩行动台、高压窗口、区域、系统或长期成长线。

## 区域策略

- `核心区域 4 个`：基地、早期资源区、主要危险区、demo 终点区。优先扩面积、目标密度、资源和战斗节奏。
- `功能区域 4 个`：承载特定资源、设备材料、风险类型或回访目标。
- `过渡区域 4 个`：承载连接、氛围、少量采集和路线变化，不追求完整玩法密度。

参考《银河破裂者》的空间感，但不照搬大地图模板。现阶段只要求外出区域有可探索余量、资源点、危险压力和回基地理由。

## UI 策略

UI 当前进入必要开发项，不作为纯美术打磨处理。优先级：

1. 主 HUD：生命、防护、当前目标、当前区域、关键资源。
2. 地图 / 区域提示：玩家知道自己在哪、要去哪、为什么去。
3. 基地状态摘要：当前可制造 / 可升级、缺什么、升级收益。
4. 角色状态摘要：工具、攻击、防护、抗性、已生效模块。

已完成第一包：主 HUD 不再显示 `Prototype` 标题，高频目标提示和任务完成反馈已切到新区域口径。已完成第二包：HUD 左侧聚合当前目标和关键资源，右侧聚合基地摘要和角色状态；关键资源按当前任务、配方输入和建造消耗推导，基地摘要显示可制造 / 待制造项、缺料、完成后产物或设备加工状态，并已通过人工读法复核。

不做完整菜单、设置页、背包大重构、完整装备栏、动画过场或大规模美术替换。核心稳定站先按最小 demo 终点处理：读取锚定桥稳定窗口和高压窗口归档状态，复用短战斗节奏设置阶段守卫，写入稳定数据后给出 demo 完成反馈；不重构 `base_action_state`，不新增第 4 个行动台分支。

## 冻结范围

- 前线行动台、候选、窗口复盘、高压窗口和 `base_action_state` 进入冻结期，只修 `P0` / `P1`。
- 不新增同构短行动、窗口分支、随机成功率、新货币、队员或完整 loadout。
- 不继续沿相位井后段横向堆内容包。
- 不继续用提示、闸门、坏档校验或 HUD 护栏作为默认主线任务。

## 节奏规则

个人开发阶段只做足以判断方向的完成度。一个阶段达到退出条件后，必须及时进入下一阶段；不允许因为 `P2` / `P3` 细节、局部读法、文案密度或状态字段洁癖无限打磨。

只让这些问题阻塞阶段：

- 崩溃
- 主线卡死
- 坏档
- 任务无法完成
- 关键资源断档
- UI 完全无法判断下一步

其他问题进入 backlog 或后续 polish。

## 阶段退出条件

- `S0` 新档能连续跑到核心稳定站 demo 完成反馈，或已明确记录阻塞点。
- 存档保存 / 读取、开发基线和自动检查没有掩盖冷启动问题。
- 玩家能理解出门、回基地制造 / 升级、再推进更危险目标的原因。
- 未发现未处理的 `P0` / `P1`；`P2` / `P3` 不阻塞进入下一阶段。
