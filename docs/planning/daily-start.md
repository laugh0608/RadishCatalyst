- 不生成素材、不接入候选、不启动 Godot、不修改客户端或玩法数据。
- 不以工程整理、删旧层、补检查、修小问题或新设计包制造“仍在推进”的假象。
- 可以只读分析仓库、历史截图、失败批次和可选生产方式；形成决策前不自行选择新介质。
- 后续任何恢复开发的建议都必须先说明个人可持续性、AI 能力边界、成功证据和失败退出条件。
