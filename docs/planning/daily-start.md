## 下一事项（2026-08-31）

下一批只推进包 4C 的三类常用设备反馈，不改玩法状态或扩整套机器音频：

1. **玩家结果：**采集器、储物箱和中继仅看世界主体即可区分有电 / 无电与本类最重要的运行或阻塞事实，形状、分段或节奏至少提供颜色之外的第二通道。
2. **权威状态：**只读取三类设备现有供电、缓冲、模式、容量与连接事实；若某一“阻塞”无法由现有权威事实可靠判断，先收窄状态矩阵，不在表现层猜测或新增重复字段。
3. **复用边界：**复用 `SliceDeviceFeedbackState` 的纯派生与边沿原则、`SliceFeedbackAudio` 的 `SFX` 路由，以及各设备自己的视觉节点；不把设备类型分支堆入 `SliceWorld`，不先造通用动画框架。
4. **音频范围：**只有能改变玩家判断的离散边沿才增加短电子提示；待机动画不鸣叫，不增加常驻机器噪声，首次观察和读档恢复继续静默。
5. **成功证据：**专项锁定三类设备的权威谓词、视觉第二通道、边沿去重和存档不变；正式 `Boot` 在 16:9 / 16:10 下逐图覆盖代表状态，并回归 4B 八态、静音和读档不重放。

推荐落地顺序：

1. 先审计采集器缓冲 / 生产、储物箱模式 / 容量、中继供电 / 连接的现有字段和刷新入口，冻结每类最小状态矩阵与边沿；不为了视觉制造第二份运行态。
2. 分别在设备自身节点内完成持续视觉，优先复用 4B 的状态构件语法，但只抽取三个设备确实共同需要的窄助手。
3. 持续视觉逐图成立后，再决定哪些离散边沿值得复用或新增短提示；总线、静音、冷却和读档静默继续沿 4B 合同。
4. 以专项和两种比例正式 `Boot` 收口 4C；三类设备成立后回到整改专题 S0 新档全链，不直接切入 A04、A05、A09。

包 4 不扩完整有限电力、工业总览、传送带拖铺、无线回传语义或新内容层。五问已冻结为保持 16:9 内容画幅与非 16:9 上下黑边，HUD 只在内容安全区内排版，不扩相机可见范围。

## 防跑偏规则

- 不把“样本交付后没任务”解释为立即扩第二段剧情；先给明确 Demo 完成态与自由建设入口。
- 不用接驳贴片、长提示或更大碰撞掩盖空间合同错误；先统一设备基座、外接格和地表规则。
- 不照搬《终末地》的体量、移动端 HUD、角色编队或完整工业简报，只借用信息架构原则。
- 不在旧布局上先批量生成动画或音频；代表设备必须逐个通过世界画面人工复核。
- 玩家可见目标以正式 `Boot`、实机截图与人工路径为主证据，自动检查只兜底。
