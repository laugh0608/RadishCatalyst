## 当前不做

- 不继续扩前线行动台、候选、窗口复盘、高压窗口或 `base_action_state`，除非出现 `P0` / `P1`。
- 不继续横向新增区域；首版 demo 到 12 个区域封顶。
- 不平均扩 12 个区域；先集中做核心区域。
- 不新增随机成功率、新货币、队员、完整 loadout、完整背包重构或大规模美术替换；允许首版 demo 级装备 / 模块效果第一包。
- 不把完整发布准备、大规模 polish 或静态审计作为当前阶段目标；当前优先交付玩家可操作的内容增量。

## 节奏规则

个人开发阶段只做足以判断方向的完成度。阶段达到退出条件后及时进入下一阶段；不因局部读法、文案密度或状态字段洁癖无限打磨。

只让这些问题阻塞阶段：

- 崩溃
- 主线卡死
- 坏档
- 任务无法完成
- 关键资源断档
- UI 完全无法判断下一步
