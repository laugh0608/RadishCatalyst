## 世界画面基线

- 清晰、克制的异星工业现场；设备轮廓、端口、真实物流流向、角色和障碍易辨认。
- 正式路径保持角色跟随，远处定位与人物位置区别明确；建造时显示逻辑网格、占地与接口。主视角的俯角、正交 / 透视、观察距离和转角 / 缩放范围待样板确认，现行正交 / 50° 只记录实现事实。
- 设备以导入 GLB / Node3D、地表 / 场景和自有图标构成主体；高亮、范围、状态灯与选择描边作为动态辅助。
- 青灰工业设备、浅色地表、蓝绿异星资源，少量琥珀 / 红用于警示；具体色值由新代表场景验证，不直接套旧像素色板。
- 核心有区别于加工设备的轮廓和可读输入 / 输出口。等级通过明确结构或局部模块变化表现，不扩大已建核心碰撞与端口而挤毁玩家产线。
- 金属板、炭粉、催化剂、燃料电芯与储能设施使用不同轮廓 / 图标，避免把燃料余时与储能电量混为一物。

官方资料已确认原作以固定高度俯视相机、面向该观察尺度的模型 / 法线细节、材质光照及局部遮挡揭示共同形成画面；公开的约 25 米高度不能直接当作本项目参数。具体来源、未知投影 / FOV 边界、水平朝向与尺度的验证分工见[银河破裂者视角研究](../reference/riftbreaker-camera-and-visual-study.md)。本项目是否需要局部消隐须另经样板判断，不因查到原作实现就直接新增系统。

样板必须同时观察普通移动、密集产线、近身设备、建造网格 / 端口，以及正常 / 最小窗口。若更接近参考的构图造成人物或接口长期被遮挡，需调整相机与场景组织；不能只加轮廓和常驻文字遮盖问题。本轮只更新设计状态，未调客户端镜头或启动 Godot。

## 资产定稿方式

先在同一代表场景核对核心、一种加工设备、传送带 / 端口、角色、地表和面板，再锁定模型单位、原点、足印、接口、材质 / 光照与缩放规范。沿已有可编辑资产管线补齐功能，不让程序方块承担正式设备主体。

最终模型精细度、角色动画和完整量产资产范围未冻结；不新开介质对照或全资产重做。图像生成 / 素材落盘遵循[工作流](../process/image-generation-and-review-workflow.md)，新增外部资产 / 工具仍需按项目授权。

## UI 的共同原则

核心指标常显，详情按需展开；玩家看到的对象、高亮和实际操作目标一致。基础故障、功率、库存和下一步去向从开局可见，科技解锁控制能力，不锁住必要信息。

世界标签、物品格、用途、端口和流向共同解释生产。面板以本项目名称 / ID / 图标为准，参考游戏只提供读法，不复制页面或素材。玩家无需阅读开发文档才能理解物品用途。

## 信息层级

| 层级 | 内容 |
| --- | --- |
| 常显 | 当前目标、核心等级、电网可用容量 / 请求 / 实际用电 / 缺口、暂停状态、当前选中与可交互对象 |
| 对象面板 | 设备原料 / 在制 / 输出、运行 / 待机 / 停机、连接；核心库存和各口配置；研究前置 / 成本 / 实际解锁效果 |
| 规划与诊断 | 配方上下游、产率 / 消耗、共享库存变化、弃能、近期曲线；后期储能 / 控制波形和最低电量 |

核心仓库存量与研究扣料只显示真实账；确认按钮应能解释缺什么和会消耗什么。未提交的配置与已应用配置分开；失败保留现场和清楚原因，不以默认值伪装成功。

## 能源表现

- 核心显示基础供电能力，发电机显示启用、燃料、额定功率、剩余燃烧时间和实际释能；低负载仍燃烧时显示弃能去向。
- 可用容量不等于当前发电 / 用电；暂停、缺燃料、断网和手动停机有不同原因。
- 储能在后续支线显示容量、当前电量、充放功率和趋势；燃料电芯不使用同一套“电池百分比”指代储能。
- 新旧世界面板按各自规则解释；V8 的按需补电不能显示成新版固定燃烧。

## 输入、可访问性与验证

沿鼠键、WASD、近身设备、鼠标 / Tab / F 同一焦点的既有边界；面板遮挡、建造 / 拖铺、失焦和取消需一致处理。暂停同时停止移动与生产，失焦仍生产的现行规则明确提示。

文字 / 图标 / 形状共同表达状态，避免仅靠颜色。普通与最小窗口、拉远、密集设备和关键中文必须可读；核心端口密度不能依靠常驻大段文字解释。

玩家可见结果按正式 Boot、有窗口原图与人工路径验证；静态或 headless 仅证明对应工程层。美术定稿不由单张概念图或一次自动截图代签。
