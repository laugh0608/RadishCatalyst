# Worldbuilding Premise

更新时间：2026-11-01

## 当前世界观基线

2026-11-01 萝卜SAMA确认[整合基线](../planning/demo-consolidation-proposal.md)。本篇定当前产品前提；当前玩法与实现范围见 [Current Plan](../planning/current.md)及[整合总合同](../features/factory-demo-integration-v1.md)。

**玩家是一名异星工业开拓员，负责让一座前哨恢复运转，调查当地高价值却难以直接利用的资源与催化现象，通过化工生产扩大安全行动和开发能力。**

## 玩家与前哨

玩家具备现场操作、工程建设、采样和分析能力。角色能亲自勘探、取样、建线与排障；世界观允许未来外勤战斗，但本阶段不把完整战斗职业或 ARPG 成长当成玩家身份的必要部分。

核心是前哨的库存、基础供能、研究和工程进展入口。核心等级表示已建立的工业能力；升级后能使用新工艺 / 设备 / 控制工具，不用神秘能量或永久增加免费电力解释一切。

最初由有限起步供能与设备恢复材料生产，随后制造燃料和设备，形成可持续扩建能力。故事目标应能对应玩家实际操作与世界变化。

## 异星为何需要化工

- 原料有利用价值，也有杂质、活性、矿壳、腐蚀或其他环境条件，取得后不总能直接使用。
- 样本与现场观察帮助玩家理解资源，工艺将发现变成可以重复制造的能力。
- 材料、能源与开拓用品使此前受限的行动成为可能，新资源再改善既有工厂。
- 工艺的副产物、能耗和布局成本形成选择；未来流体、反应条件与环境治理继续沿此关系展开。

“异星催化”同时表达物质转化与玩家改变星球的过程。具体化学名称与反应可以为游戏可读性作虚构，不把专业公式考试作为理解门槛。

## 首个 Demo 的叙事承载

同一小区域内表现前哨、初始矿点、可识别障碍与资源回报。主要目标是恢复 / 扩建生产、掌握工艺和取得实际有用的新供给；开路后必须有生产用途，不能只以动画或一次交货表示回报。

叙事通过核心目标、配方用途、环境物件和少量现场说明呈现。角色、地形、设备和端口优先可读；完整剧情树、过场、配音和大规模角色叙事不随本次整合纳入。

## 长期空间与待定事项

异常生态、污染反馈、遗迹与失联前哨可提供工艺线索、风险和开拓目的；多区域 / 多星球应改变资源与工艺条件，而不只换色。它们是长期题材空间，不是当前已实现系统。

战斗体量、敌人谱系、生态模拟、污染扩散、工业事故惩罚、最终主线真相及多星球结构继续按专题确认。当前不要求先设计完整历史年表，也不把早期“工程战斗员 / 大量秘境”设想当成交付清单。

## 一致性判断

每项世界观内容应说明：玩家会遇到什么问题、能用什么生产或现场行动应对、结果怎样改变下一步。无法落到操作的设定可保留为背景，不用它扩张当前开发范围。
