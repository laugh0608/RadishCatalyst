# Project Definition

更新时间：2026-09-05

## 一句话定义

RadishCatalyst / 异星催化是一款以异星化工生产经营为核心的工业科幻游戏：玩家探索资源，建立固体、液体和气体参与的生产线，用产物强化开拓能力、开发新区域并逐步扩建工厂与改造星球。

本轮方向变化与待定项以 [Production-Centered Direction](production-centered-direction.md) 为优先真相源。其他尚未同步的旧产品、设计和功能文档按后续任务逐项评估。

## 核心体验

玩家应持续获得四类紧密相连的体验：

1. 到未知区域寻找资源、场地与需要解决的环境问题。
2. 俯瞰布置设备，接通可观察的真实物流和化工产线。
3. 从产出、缺料、堵塞和副产物中判断问题并调整布局。
4. 用生产出的材料、装备和工具扩大探索范围，再把新收获带回工厂。

生产、物流、布局和经营结果是核心。探索为生产提供目的与边界；战斗及完整 ARPG 体量尚未决定，不作为默认承诺。

## 体验支柱

- **可操作的化工工厂：**设备、接口、物流、物态和加工结果在空间中真实连接，并能被玩家观察和调整。
- **生产驱动的开拓：**更深区域需要由工厂提供工具、装备、补给和环境处理能力。
- **有差异的异星条件：**资源、地貌、污染和环境约束改变工艺与布局，而不只是更换画面颜色。
- **可积累的工程成长：**每次扩建、试制和排障都为后续生产与探索留下价值。

长期愿景可扩展到多星球；近期只用一个小区域和一段完整工厂操作验证核心乐趣。

## 视图与交互

- 常态为固定高斜角主视图，追求轻度 2.5D 观感和清楚的工业空间关系。
- 建造时允许拉远，并显示网格、足印、接口和物流流向，降低建筑遮挡。
- 近期优先复用现有像素资产和 Godot 实现；是否更换美术介质、改用 3D 或增加第二观察角度尚未决定。
- 基地信息应帮助玩家判断设备为何运行、为何停机，以及调整后发生了什么。

## 目标玩家与范围

目标玩家喜欢布置、接通、观察和优化生产系统，也希望生产成果能支持亲自开拓异星区域。项目不要求玩家掌握专业化工公式，但应让固液气处理、反应、分离、储运和环境治理形成可理解的工业差异。

既有战斗、任务、存档、物流和设备反馈实现继续保留。旧 20–40 分钟 ARPG 切片验收与正式证据是历史基线，不是当前生产方向的验证目标。

## 长期结构

- 单机和稳定本地存档仍是基础能力。
- 多人协作、专用服务器、账号、云存档、交易和完整 Mod 平台属于后续可选能力。
- `wiki/` 承载玩家知识，`official-tools/` 承载查询与规划工具；结构化游戏数据长期应能被三者复用。
- 现有 Godot / Windows 桌面基线与既有平台交付承诺保留；Web 只待同范围对照评估，本轮不据方向调整迁移、重写或解冻新平台路线。

## 当前验证焦点

先定义一个可操作工厂片段：设备放置、真实物流接通、观察产出与堵塞、调整布局。冻结操作画面目标和玩家成功／失败标准后，再决定用现有 Godot 实现验证，还是追加同范围 Web 对照。

随机消耗工业资源以增加期待感是待探索诉求。工业研发、试制和勘探是候选表达；关键能力确定获得、随机结果具有取舍、投入累积有价值是评估建议，具体系统尚未冻结。
