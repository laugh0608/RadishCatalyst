# Project Definition

更新时间：2026-11-01

## 一句话定义

RadishCatalyst / 异星催化是一款有角色现场探索的工业科幻自动化经营游戏。玩家研究异星资源、建立化工产线，以材料、能源与开拓用品扩大生产和行动能力，再把新区域的资源与样本带回工厂。

2026-11-01 萝卜SAMA已确认[整合设计基线](../planning/demo-consolidation-proposal.md)；产品方向见 [Production-Centered Direction](production-centered-direction.md)，具体阶段与授权只见 [Current Plan](../planning/current.md)。

## 核心体验与玩家

- 主动建线、分配物料、排查瓶颈、比较工艺并观察改善，是主要乐趣。
- 探索提供资源条件、样本、场地与环境问题；生产成果使新行动成为可能。
- 从一次发现到可解释、可复现的生产能力，是工程成长；核心等级与科技分支组织学习过程。
- 基础方案可直观完成主线；效率、占地、副产物、能源和测控提供进阶取舍。玩家无需预先掌握专业化工或电力知识。

目标玩家愿意学习自动化并喜欢亲自开拓异星。战斗体量、完整角色成长、多人和多星球是后续决定，不作为当前 Demo 承诺。

## 已确认基线

| 维度 | 决定 |
| --- | --- |
| 玩法 | 生产经营为核心，材料制造 → 能源扩容 → 开拓回报，主线外保留可选优化空间 |
| 世界观 | 工业开拓员恢复异星前哨，通过工艺和现场行动理解异常资源与催化现象 |
| 视图 | Godot 3D / 网格建造；已选 C2 透视正向、默认 21 格、角色跟随，滚轮调距离 / 高度；旧正式世界尚未接入，见[视觉方向](visual-and-ui-direction.md) |
| 美术 | 克制、清楚的风格化工业科幻 3D；导入模型、物品图标及场景为主体，状态辅助服务识别 |
| 技术 | Godot 4.x / GDScript、20 Hz 权威模拟、派生视图、版本化独立存档 |
| 平台 | Windows 桌面 / 鼠键 / 离线单机为产品主目标；macOS 是当前开发验证环境，目标机证据单列 |
| 成长 | 唯一核心、多口真实仓储、等级开放研究层级；科技分支解锁实际工艺与操作 |

## 本阶段验证焦点

将已有能力整合成同一新档可继续的 Demo：核心与材料 → 研究 / 扩建 → 电芯发电 → 开拓 → 新资源反哺实际生产。第一轮主线以约 20–40 分钟为体验目标，实际时长通过试玩校正；可选测控不要求塞入首程。

判断是否成立：玩家能说清目标、瓶颈与调整原因，能看见产出 / 能力改善，保存后可继续，并愿意再扩建。工程断言、画面、自然运行与玩家体验分别提供证据，不以检查数量代签。

## 长期边界

化工的固液气、反应条件、分离、储运与环境治理逐步提供差异；当前合同只实现对应阶段的真实能力。完整科技内容、完整美术量产、战斗扩展、多人、交易和多星球分专题决定。

`wiki/` 承载玩家知识，`official-tools/` 承载查询 / 规划工具，长期复用结构化数据；Web 工具不反向要求更换正式游戏客户端。

旧二维切片、基础 / V5 / E1 / V7 / V8 与工程验证保留原规则和历史证据。新的整合设计不代表旧世界已迁移或新玩法已实现。
