## 产品方向

RadishCatalyst 是一款以异星化工生产经营为核心的工业科幻游戏。玩家探索并取得资源，建立固体、液体和气体参与的化工产线，生产材料、装备与开拓工具，以此提升探索能力、开发新区域、扩建工厂并逐步改造星球。

核心循环是：

```text
探索资源 → 建立化工产线 → 生产材料与装备 → 提升探索能力
    ↑                                      ↓
扩建工厂与环境改造 ← 开发新区域 ←───────────┘
```

生产、物流、布局和经营结果是主要乐趣。人物探索为生产提供资源、地点、问题和长期目的；战斗是否保留、保留到什么体量仍待后续验证，不默认扩成完整 ARPG，也不在本轮删除既有战斗。

长期愿景允许多星球及不同资源、环境和工艺条件；近期只在一个小区域验证生产核心是否成立。

## 体验与视图决定

- 平时采用固定高斜角主视图，形成轻度 2.5D 的空间观感。
- 建造模式允许拉远，明确显示网格、设备足印、输入输出接口和物流流向，并弱化遮挡；当前不强制切成真实正俯视。
- 当前首包沿已认可的 Godot 3D 画面与操作实施，默认 50° 视角，保留转角 / 缩放；独立 Web 版本继续作为体验参照。
- 精细模型、材质、角色动画和量产资产规范暂缓；旧像素切片与证据继续保留。正式工程已增加独立工厂入口，旧二维世界保留；边界以新首包和其架构合同为准。

参考作品只提供观察维度：借鉴《异星探险家》以工具和设施驱动开拓、《戴森球计划》的自动化物流规模、《明日方舟·终末地》的俯瞰布局、接通操作与工业气质，以及《无人深空》的星球探索愿景。项目不把这些作品的功能列表拼接成范围。

## 工厂片段验证与接续

前序工厂片段验证的问题为：

1. 放置少量设备，并从画面读懂足印和接口。
2. 用真实物流连接输入、加工和输出。
3. 观察产出、缺料或堵塞等可见结果。
4. 调整布局后确认物流和产出随之恢复或改变。

Web 与同规则 Godot 片段已完成实现 / 定向验证，当前 Godot 画面与操作获用户认可；可保存、多产线的正式工厂基础也已接入，跨进程与双线操作已有定向证据。前台持续性能及剩余玩家路径仍待收口，新增设备与经济驱动另包设计，不能把局部认可或后台稳定性扩写为整个生产经营体验通过。

此前试玩整改 S0 暂缓。既有 `delivered / 120`、schema 10、正式 `Boot`、自动检查和人工复核继续作为历史实现与回归证据，不代表本轮生产体验已验证，也不再作为当前方向的退出条件。陌生玩家盲测、试玩分发、打包和发布仍未解冻。

## 随机投入的探索边界

萝卜SAMA希望工业资源的随机消耗能够带来期待感。工业研发、试制和勘探是候选表达，尚未决定采用传统抽卡或任何具体系统。

后续方案应区分已确认方向与设计建议。当前可用于评估的建议原则是：关键能力可确定获得；随机结果提供有意义的取舍；每次投入和累计投入都保留价值。具体资源、概率、保底和产物均未冻结。

## 本轮未决定

- 是否保留战斗，以及人物成长和战斗的最终体量。
- 量产美术精细度与制作规范；Godot 3D 首包正式接入 / 独立存档合同已确认并实施。
- 是否导入旧二维世界；当前实现保留旧世界，独立新建工厂存档，不做整仓重写或 Web 正式迁移。
- 随机工业投入采用什么系统和规则。
- 面向产品的容量 / 最低配置承诺、Windows 目标硬件，以及后续内容排期；100 台 / 1,000 带是已确认工程目标，持续验收尚未完成。
