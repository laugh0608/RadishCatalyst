## 关键决策

- 修正 arc 层间依赖倒置：L2 收窄为固定核心的“直供电源 + 中央仓库”，不依赖通用放置；电线杆 / 中继的制作、放置与扩展供电网并入 L3。
- L2 复用现有核心修复态素材，不生成新素材、不使用程序绘制范围圈；L3 新素材仍需萝卜SAMA另行授权。
- 核心电源在线由 `core_repaired` 推导，不新增冗余存档布尔值；中央仓库使用通用 `Inventory`，schema 3 兼容读取 schema 2。
- 萝卜SAMA指出仓库已有正式入口自动运行与截图方案后，将 `godot-runtime-verification-guide.md` 从参考方法提升为 `AGENTS.md` / `CLAUDE.md` 硬约束：玩家可见功能必须补真实 `Boot`、输入链、有窗口截图、实际审图与周志证据，纯 headless 断言不得替代。
- 复盘一次在同一 Codex 工具调用中读取 5 张截图导致会话卡顿的失误；新增单会话默认最多 3 张图片进入上下文的统一上限，多图改用磁盘联系表审阅。
- 新增 `scripts/create-screenshot-contact-sheet.sh`，把任意数量自动化截图在磁盘压成一张带序号总览，并输出序号到原图路径映射，避免再次把整批原图送入会话。
- 2026-07-21 经萝卜SAMA明确要求，将单会话 3 张图片读取限制改为默认软上限：达到后先报告并停手，用户明确要求当前会话继续时可按每次至多 3 张追加读取。
- 2026-07-24 经萝卜SAMA架构决策，将图像生成的绝对 3 次硬上限改为分轮授权：单会话默认每轮至多 3 次，每轮结束必须先落盘、更新 manifest 并报告；只有获得当前会话继续生成的明确授权后才能追加下一轮至多 3 次，且一次授权不得解释为无限续跑。一个素材类别一个会话、生成与审阅 / 接入分离等边界保持不变。
- L3 配方产出统一为 `Inventory` 中建筑套件，放置提交时才消费，取消不损失；错放设施可调整或全额拆回套件，带内容设备与被支撑地板受门控。

- L3 存档规划升 schema 4，以稳定建筑实例统一承载地板和设施；schema 2 / 3 迁移保留旧采集器与携带套件，不因新供电规则删旧布局。
