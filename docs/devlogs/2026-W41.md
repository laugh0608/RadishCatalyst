### 失败、定位与修正

- 首次 UI 状态脚本常量名与原生 `Panel` 冲突，改名后继续；两条缺料断言漏写现有 `×` 文本，按实际合同修正。沙箱无窗口字体出现 FreeType 错误，不将其算作通过；主机重跑后最终 43 项无错误通过。
- 首次导入被沙箱阻止保存 Godot 编辑器状态；经工具授权完成主机导入及最终 UID 生成。第一次 Boot 因误用 `popup_hide` 信号初始化失败，改用 `visibility_changed`；保留日志并终止该测试进程，没有将其当作窗口通过。
- 早期窗口 b 与短探针 a 的设备按钮未命中。停止完整路径，短复现确认对话框为嵌入式 `Window`；向子窗口直接推鼠标事件不经过父视口路由，控件 hover 未更新。改为父视口坐标路由后短探针 b 15 项、窗口 c 156 项通过。
- c 原图暴露接口文字过小、操作结果埋在库存滚动末尾；增大标签并固定反馈区。随后窗口 e 与短探针 c 再现关闭按钮失效，尺寸探针确认自动换行标签缺少宽度约束，将面板撑高至 1293，返回按钮位于主窗口之外。补反馈区最小宽度后短探针 d 35 项通过，并增加主窗口可见范围断言；最终 f 完整通过。归因为控件尺寸与事件路由，未继续堆装饰或改变画面介质。
- 窗口 d 在 Boot 首屏合成鼠标点击未进入工厂；最终路径复用已有聚焦 Enter 入口。首屏鼠标驱动的偶发未命中未归因，不宣称修复；这与设备操作窗口命中问题分别记录。
- 失败批次、短探针和先前通过批次均保留；c 不作为最终布局证据，最终以 f 的 write / read 为准。样板自身的自动点击问题未复验。
