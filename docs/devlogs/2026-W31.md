## 关键决策

- C1 只证明可供比较的关键样本身份候选存在，不在生成会话中选定、去底、裁切、量化、拼联系表或接入运行时。

- 三类战斗素材硬闸门至此全部通过；萝卜SAMA随后明确授权进入 D 接入与包 1。
- 包 1 把攻击与闪避状态收进窄职责 `SliceCombatController`；`SliceWorld` 只保留库存扣料、面板装配和存档触发，不接敌人、样本或 schema 7。
- 充能一次性消耗 2 催化剂，确定性先扣核心仓库再扣背包；攻击 / 闪避在合成、仓库、建筑、放置、确认和暂停前台时禁用，关闭后必须重新按下。
- 包 2 只保存同次运行内的 `locked → hostile → dropped → carried` 转换；基地交付、永久生命收益与 `dropped / carried` 重启持久化仍统一留给包 3 schema 7。
- schema 7 只保存玩家生命与 `{state, enemy_health}`；最大生命、敌人和样本存在由单一遭遇状态派生，普通 AI tick 不写盘。
- 阶段复核不继续扩展同层战斗内容；先证明既有基地、工业、存档和外勤能力能在 20 到 40 分钟内由新玩家串成一条完整旅程。
- 里程碑清单旧有“15 到 30 分钟”口径归一为现行章程的“20 到 40 分钟”。
- 包 1 不把自动化跑通等同于无人指导通过：修核心后缺少产线短目标、主要 HUD 在浅色地面缺少稳定对比，均列为包 2 的 `P1`；高交互量先列 `P2`，等待真实计时再决定是否调节。
- 包 2 引导不保存阶段编号或任务进度；每次都从核心、通电采集器 / 反应器、建筑储物箱、背包和遭遇状态重新派生，避免建立第二套玩法真相。
- 人工反馈按层级处理：等待主导、HUD 挡视野、鼠标放置、电网范围和地板需求先列当前 `P1`；纯文字建造 / 背包列 `P2` UI 专题候选；整体 3/4 体积感不足作为介质与风格锚点升级点，不由执行会话局部调参。
- 包 2A 只调整采集周期，不改每次产出或需求；37 个可再生晶体的理论等待由 `370s` 降到 `222s`，连同反应器和物流后的正式全链最低生产等待为 `242.7s`。
- 包 2A 与包 2B 必须独立取证；2A 自动与视觉证据完成后先等待人工体感确认，不把鼠标放置实现混进同轮结果。
- HUD 同类文本底板路线停止继续调尺寸、透明度和字号；后续先复盘图标、槽位、组件层级和 HUD 安全区介质，不能继续把图形化面板简单列为 `P2` 延后。
- 生产节奏与 HUD 拆开人工复核；生产节奏提供停在核心修复、采集器通电阶段的独立世界，避免要求萝卜SAMA从新档重跑。
