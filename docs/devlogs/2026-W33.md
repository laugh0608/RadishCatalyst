## 关键决策

- 萝卜SAMA授权把远程攻击 / 枪械作为后续玩家功能方向，但不重开已收口的近战 V1，也不把尚不存在的武器或弹药字段伪装进当前战斗 HUD。
- UI 视觉专题关闭后另建远程武器可执行专题；开工前必须锁定首把武器身份、弹药与基地制造闭环、攻击 / 闪避 / UI 输入互斥、HUD、数值和存档边界。
- 切割器优先保留为无弹药基础能力；枪械首先服务“基地生产补给 → 外勤提高战术选择 → 冒险反哺基地”的闭环，不直接扩成武器树、随机掉落表或多敌种。
- 核心仓库拖拽默认选中整堆；拖动前按住 `Ctrl / Control` 时向上取整减半，拖动中每次重新按下继续对当前选中量减半，松开修饰键不恢复。容量不足时仍只移动目标栏可接收的数量，不隐藏失败或溢出。
- 元数据损坏项移入回收区后保留原始目录，但不能从游戏内直接恢复；目标稿必须明确区别于正常世界的可恢复回收，不新增尚不存在的存档修复能力。
- 首次充能的钢蓝 `A1` 只用于“确认充能 · 消耗 2 份”，取消保持中性并标明 `Esc`；核心与生产设施仍作为空间语境可见，但不能与阻断决策争夺焦点。
- P2 每包必须在静态检查后从正式 `Boot` 进入隔离复核档，完成匹配行为路径、原生截图和人工判断后再切下一面；视觉接入不得顺带改 schema、玩法、输入语义或世界资产。
