# 污染与外勤补给

更新时间：2026-05-31

## 这套机制在玩什么

污染边界段不是单纯的危险地形扣数值。它用防护消耗、敌人压力、建造前置和补给制造，让玩家理解：

```text
外出采集 -> 回基地制造 / 处理沉积物 -> 带补给再推进更危险目标
```

## 当前补给分工

| 补给 / 模块 | 默认位置 | 当前作用 |
| --- | --- | --- |
| 基础过滤模块 | 防护服模块槽 | 降低污染采集和污染敌人造成的防护压力。 |
| 修复凝胶 | 快捷栏 1 | 生命补给，支撑处理点清障、污染战斗和后续高压目标。 |
| 抗污染药剂 I | 快捷栏 2 | 防护补给，支撑深处污染采集、受扰敌人和遗迹门前压力。 |

## 处理点到门前的节奏

1. 回基地调制修复凝胶。
2. 带修复凝胶清理处理点北缘两处掠行体。
3. 清理粗糙地面，铺设基础地基，建造污染过滤器。
4. 采集首批污染沉积物，回过滤器处理抗污染药剂。
5. 带抗污染药剂回污染边界，补第二批沉积物并清理受扰敌人。
6. 沉积物和敌人压力处理完后，再推进遗迹门前压力点。

## 读 HUD 的方式

- 当前目标说明“为什么现在要回基地或再外出”。
- 关键资源会提示当前配方或建造还缺什么。
- 基地摘要会显示推荐配方、产物用途和最近完成后的下一步。
- 防护偏低时，优先看是否需要按 `2` 使用抗污染药剂；生命偏低时，优先按 `1` 使用修复凝胶。
