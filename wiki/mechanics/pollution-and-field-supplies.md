# 污染与外勤补给

更新时间：2026-06-13

## 这套机制在玩什么

污染边界段不是单纯的危险地形扣数值。它用防护消耗、敌人压力、建造前置和补给制造，让玩家理解：

```text
外出采集 -> 回基地制造 / 处理沉积物 -> 带补给再推进更危险目标
```

## 当前补给分工

| 补给 / 模块 | 默认位置 | 当前作用 |
| --- | --- | --- |
| 基础过滤模块 | 防护服模块槽 | 降低污染采集防护消耗，并缓冲污染敌人反击造成的生命 / 防护压力。 |
| 修复凝胶 | 快捷栏 1 | 生命补给，支撑处理点清障、污染战斗和后续高压目标。 |
| 抗污染药剂 I | 快捷栏 2 | 防护补给，支撑深处污染采集、受扰敌人和遗迹门前压力；高压污染点会自动消耗药剂排压。 |
| 核心稳压缓冲包 | 背包消耗品 | 终点前整备物，会在核心阶段守卫第一次回写压力中被消耗，并让核心设备写入读取回写校准。 |
| 基础储存箱 | 基地设施 | 建成后接入前哨核心；修复凝胶耗尽时回基地整备可补到 1 份，首支药剂跑通后也可补 1 份抗污染药剂。 |
| 污染浆液缓冲罐 | 基地设施 | 消耗污染浆液建造；配合基础储存箱让前哨核心可把抗污染药剂补到 2 份。 |
| 出发整备台 | 基地设施 | 建成后把背包里的基础过滤模块装入防护服模块槽，并可继续做模块校准和核心归档维护。 |

## 处理点到门前的节奏

1. 回基地调制修复凝胶。
2. 带修复凝胶清理处理点北缘两处掠行体。
3. 清理粗糙地面，铺设基础地基，建造污染过滤器。
4. 采集首批污染沉积物，回过滤器处理抗污染药剂。
5. 带抗污染药剂回污染边界，补第二批沉积物。
6. 清理受扰敌人、污染侧翼和副产回收口袋，带回额外沉积物处理药剂和污染浆液。
7. 用污染浆液和基础零件建造污染浆液缓冲罐后，回前哨核心可把抗污染药剂补到 2 份。
8. 清理门前压力点，再检查封锁入口；入口会读取模块、药剂和污染浆液状态，提示是否先回基地整理。

后续污染脊、遗迹外圈和核心稳定站会继续复用这套思路：补污染沉积物、清理受扰守卫、回过滤器处理药剂和污染浆液，再回基础反应器把副产物转成裂相坐标、零件或核心稳压缓冲包。核心归档维护接入后，归档维护回访口袋会再次要求你处理沉积、补满药剂，并从外勤出发口复测核心稳定站或回污染边界确认承压。

## 读 HUD 的方式

- 当前目标说明“为什么现在要回基地或再外出”。
- 关键资源会提示当前配方或建造还缺什么。
- 基地摘要会显示推荐配方、产物用途和最近完成后的下一步。
- 污染过滤器完成药剂后，设备面板、加工完成短条、当前目标、沉积物提示和门前压力点应读成同一条回访链，而不是五个互相独立的提示。
- 出发整备台装配成功后，HUD 基地摘要应能看出基础过滤模块已生效；如果只制造了模块但未装入，污染承压仍按未装配处理。
- 封锁入口准备提示不是开门文案。它会把基础过滤模块、抗污染药剂和污染浆液状态合成一次进门前判断，让玩家决定是否先回基地回收副产或补药剂。
- 如果药剂在门前敌人、补料守卫或核心设备写入时被自动消耗，这是当前高压排压收益，不代表任务新增了硬门槛。
- 如果污染浆液缓冲罐已建成，药剂反馈会显示当前余量和目标，例如 `2/2 -> 1/2`；低于目标时，先回前哨核心补满再进入连续高压段。
- 防护偏低时，优先看是否需要按 `2` 使用抗污染药剂；生命偏低时，优先按 `1` 使用修复凝胶。
- 修复凝胶已经用完时，先判断基础储存箱是否建成；建成后回前哨核心整备会补 1 份，没有建成就回基础反应器调制或补基础零件建储存箱。
- 如果基础反应器提示可以回收基础零件，说明污染浆液已经不只是副产物；但核心稳压缓冲包或稳相信标需要浆液时，先满足当前目标配方。
