# 交互反馈与受阻恢复

更新时间：2026-06-24

本页说明当前原型里，玩家应该怎样读懂一次操作的结果，以及操作被挡住时该往哪里恢复。

## 先看哪里

靠近对象或设备时，优先按这个顺序判断：

1. 当前目标和小地图：判断大方向，是继续现场处理、回基地制造，还是补给后再出发。
2. 当前对象提示：判断你正在对谁操作，它是可采集、可采样、可建造、可清障、可写入，还是已经完成。
3. 战斗现场面板：战斗中先看自身生命 / 防护 / 补给、敌人 HP / 威胁 / 状态和最近承压。
4. 行动状态条、底部一行摘要和 HUD 基地摘要：确认当前能对谁操作、刚才成功了什么、消耗了什么，以及这一步属于外勤输入、基地加工、整备收益、污染承压还是核心写入。
5. 设备面板或对象完成态：如果结果涉及配方、加工、副产、已处理对象或完成后回访，按 `Q` 看设备面板或重新靠近对象确认状态；设备面板顶部先读现场状态、输入输出和下一步，再看完整配方列表。

如果这些信息互相矛盾，优先相信当前目标和当前高亮对象；再用设备面板或地图确认下一步。

## 成功后看什么

一次成功操作通常会告诉你四件事：

- 结果：拿到了资源、样本、校验片、补给，或写入了某个稳定数据。
- 消耗：用了基础零件、污染浆液、修复凝胶、抗污染药剂，或触发了一次整备状态。
- 状态：对象是否已采集、已校准、已建成、已击败、已写入或已归档。
- 下一步：继续现场处理、回基地加工、回前哨补给、检查设备，或去核心稳定站复测。
- 战斗差异：命中后敌人 HP、反击造成的生命 / 防护变化、敌人威胁和当前状态。

成功后对象仍显示完成态是正常的。完成态用于告诉你这里已经处理过，读档后也不需要重复尝试。

## 受阻时怎么恢复

| 受阻情况 | 先看什么 | 恢复路线 |
| --- | --- | --- |
| 采集或采样缺前置 | 对象提示里的状态和下一步 | 先完成当前目标要求的清障、进入区域、装备模块或回基地解析。 |
| 对象已经处理过 | 对象完成态和小地图方向 | 不要反复按键，按完成态提示回基地处理产物或转向下一个区域。 |
| 建造缺前置 | 建造点提示 | 先清理地块、铺基础地基、补材料，或处理污染条件。 |
| 建造缺材料 | HUD 关键资源和设备推荐 | 回晶体矿脉区、污染边界或基础反应器补齐对应材料。 |
| 加工缺原料 | 设备面板输入栏 | 按缺口回收资源、处理污染沉积物，或保留当前目标需要的最后一份污染浆液。 |
| 设备忙碌 | HUD 进度条和设备面板 | 等当前配方完成；其他配方显示忙碌不是同时在加工。 |
| 补给无法使用 | 快捷栏、前哨核心和出发整备台提示 | 确认背包里有修复凝胶 / 抗污染药剂，必要时回前哨核心补给或先接入整备台状态。 |
| 核心设备不能写入 | 核心设备提示和守卫 / 缓存状态 | 先击败核心阶段守卫，回收核心守卫回写缓存和核心写入校验片。 |
| 战斗或污染承压过高 | 生命、防护、药剂余量和整备台状态 | 回前哨核心补满，确认基础过滤模块已装配，再带修复凝胶或抗污染药剂返回。 |
| 任务差异登记不可用 | 出发整备台提示、设备面板和对象完成态 | 先让晶体、污染或核心准备中至少两类处理结果可读，再回整备台确认。 |

## HUD、地图和对象状态互证

当前原型会尽量让同一件事出现在多个位置：

- HUD 当前目标说明为什么做。
- 小地图说明往哪里去。
- 对象提示说明现在能不能操作。
- 设备面板说明缺什么、加工什么、完成后去哪里。
- 对象完成态说明这里已经推进到哪一步。
- 战斗现场说明当前锁定敌人的 HP、威胁、状态和最近命中承压。
- 快捷补给面板说明 `1 / 2` 是否能立即补生命或防护，以及需要回基础反应器、污染过滤器还是前哨核心补齐。
- 行动状态条说明当前目标、当前可操作对象、运行提示和最近结果，帮助你不用打开调试面板也能判断下一步。
- 底部一行摘要只保留当前对象和最近动作结果；如果仍不确定原因，优先看当前对象提示和设备面板，而不是等待长日志滚动。

例如污染过滤器完成药剂后，设备面板、加工短条、HUD、污染沉积物和门前压力点都会指向同一条回访链。核心稳定站写入完成后，HUD、地图、前哨核心、出发整备台、外勤出发口和核心设备完成态都会读成 Demo 已完成后的整理与复测，而不是新的行动台方案。

## 常见误解

- “没有 `E` 是不是坏了？”
  通常不是。先看状态和下一步，当前对象可能缺前置、缺材料、正在加工或已经处理过。
- “失败提示让我回基地，是不是路线倒退？”
  不是。很多目标本来就是外勤发现缺口，再回基地制造或补给，之后带产物回来处理。
- “对象处理完还显示文字，是不是没完成？”
  完成态文字是确认记录，避免你误以为没有成功。
- “核心稳定站完成后为什么还提示复测？”
  这是完成后整理读法，用来确认补给、维护和完成态能在保存读取后继续读懂，不代表开启新章节。
