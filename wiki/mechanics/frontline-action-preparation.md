# 前线行动台与出发整备

更新时间：2026-06-13

剧透提示：本页涉及稳窗相位序校准之后的基地行动系统。

## 这套系统在玩什么

前线行动台不是远征队列，也不是自动派遣。它当前只验证一件事：你把前线反馈带回基地后，能在下一趟出发前看懂“本趟计划、携带模块、目标、风险和收益”，再决定是否确认出发整备槽。

当前完整链路是：

```text
稳窗回波 / 补给回执 / 巡线信标等前线短目标
-> 回基地基础反应器解析反馈
-> 前线行动台显示当前计划和下一候选
-> 按 E 确认出发整备槽
-> 相位回投台执行已确认计划
-> 锚定桥前线同一整备异常窗口处理结果
-> 回基地行动台归档反馈
-> 高压窗口归档后进入核心稳定站
```

## 三种计划

进入三种计划前，前线行动台会先跑三条轻量短行动：稳窗回访、补给短行动和巡线短行动。每一条都只确认一次、只读取一个前线目标，再回基地解析反馈；旧的补给 / 巡线分台只保留兼容口径，当前玩家可见入口统一是前线行动台。

| 计划 | 模块 | 你应该看懂的变化 |
| --- | --- | --- |
| 低风险补给 | `稳相垫片` | 回投时装入基础零件和修复凝胶，窗口带回稳相缓存样本，下一轮偏强化资源回收。 |
| 信息侦测 | `回波透镜` | 回投时载入路线目标和风险预告，窗口带回透镜校准读数，下一轮偏降低路线扰动。 |
| 压力清障 | `防护涂层` | 回投时装入修复凝胶和抗污染药剂，窗口先被清障扰动守卫压制，处理后带回涂层样本，下一轮偏降低防护消耗。 |

## 压力清障的特殊规则

压力清障是当前三种计划里风险最高的一条。它不是直接对异常窗口按 E 完成：

1. 在行动台确认 `压力清障` 整备槽。
2. 到相位回投台按 E 出发。
3. 到锚定桥前线后，先找到 `清障扰动守卫`。
4. 靠近守卫按 `J` 攻击，击退后再回到前线整备异常窗口。
5. 守卫未击退时，异常窗口会提示被压制，不能直接结算。
6. 守卫击退后，对异常窗口按 E，带回涂层样本和清障反馈。

## 高压窗口目标

连续两轮异常窗口反馈归档后，行动台会把三类模块收益合并成一次 `高压窗口` 目标。它不是第四种常规方案，也不会自动出发：

1. 回基地前线行动台确认 `高压窗口` 三模块联锁整备槽。
2. 到相位回投台按 E 出发。
3. 本趟会复用 `稳相垫片`、`回波透镜` 和 `防护涂层` 的归档收益。
4. 在锚定桥前线处理更危险的高压异常窗口，带回 `高压窗口稳定数据`。
5. 回行动台归档后，前线行动台链路到此收口，后续目标会转向核心稳定站，而不是继续新增行动方案。

## 核心稳定站承接

高压窗口反馈归档后，核心稳定站会开放为当前 demo 终点。此时不要继续在行动台寻找第四个计划，按当前目标从锚定桥继续向东：

1. 进入核心稳定站。
2. 确认侧向补给、核心稳压缓冲包和抗污染药剂准备。
3. 击败 `核心阶段守卫`，回收 `核心守卫回写缓存` 和 `核心写入校验片`。
4. 在 `核心稳定设备` 写入稳定数据，写入反馈会读取侧向补给、守卫回写校准和药剂排压。
5. 确认出现 demo 完成反馈后，回基地出发整备台接入核心归档维护；这属于终点回访复测，不是行动台新增计划。

## 常见误解

- “我按 E 就被传到前线，是不是系统自动决定了？”
  不是。行动台确认的是当前计划槽；确认后相位回投才执行该计划。当前计划和模块会显示在行动台、回投日志和前线窗口提示里。
- “解析反馈为什么没有立刻给完整奖励？”
  解析反馈只把下一趟整备放进行动台。补给、防护补给和测绘预告要等你确认整备槽，并在下一次相位回投时执行。
- “方案终端能不能改掉我已经确认的本趟计划？”
  不能。方案终端只替换下一计划候选，不会改写已经确认的出发整备槽。
- “处理完异常窗口以后为什么还要回行动台？”
  因为窗口结果会被归档成下一轮判断依据，例如稳相缓存样本、透镜校准读数或涂层样本如何影响下一轮补给、测绘或清障。
- “高压窗口归档以后为什么行动台没有新方案？”
  正常。高压窗口是行动台链路收口，不是第四个常规方案；下一步应去核心稳定站。
- “核心稳定站完成后为什么出发整备台又有提示？”
  这是核心归档维护。它把终点写入结果接回基础过滤模块，后续通过污染边界回访、前哨补给和外勤出发口复测读取收益。
