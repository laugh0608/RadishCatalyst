# 核心稳定站

更新时间：2026-05-27

剧透提示：本页涉及当前 demo 终点。

## 区域概览

核心稳定站是锚定桥东侧开放的当前 demo 终点区域。它不是新的长期行动台分支，也不是继续向东追加的普通相位井断面；它用于把锚定桥稳定窗口、高压窗口稳定数据和基地整备收益收束成一次明确的阶段目标。

## 进入条件

- 已完成锚定桥稳定窗口校准。
- 已完成高压窗口三模块联锁目标，并把高压窗口反馈回基地归档。
- 当前目标应指向进入核心稳定站。

开发复测时可以直接载入 `S21 核心稳定站已开放`。`S20` 仍停在测绘反馈归档后的行动台 / 高压窗口链路，不是核心稳定站短跑起点。

## 区域结构

核心稳定站当前分为四段：

1. 入口确认段：从锚定桥继续向东进入核心稳定站。
2. 侧向补给缓存：写入核心设备前可先回收一次修复资源。
3. 阶段守卫压制段：`核心阶段守卫` 会挡住核心设备写入。
4. 核心设备平台：击败守卫后，在 `核心稳定设备` 写入稳定数据。

## 推荐流程

1. 进入核心稳定站，确认当前目标切到击败核心阶段守卫。
2. 如需补给，先回收侧向的核心站补给缓存。
3. 击败 `核心阶段守卫`。
4. 到 `核心稳定设备` 交互，写入核心稳定数据。
5. 确认出现 demo 完成反馈。

## 常见卡点

- 从 `S20` 出发无法进入核心站：
  `S20` 还需要完成行动台确认和高压窗口归档链。核心稳定站短跑请使用 `S21`。
- 核心设备提示不能写入：
  先击败 `核心阶段守卫`。
- 完成后又被指回行动台或高压窗口：
  这属于阻塞问题，应记录为 `P0` / `P1`，因为核心稳定站完成后不应再开启新的行动台分支或新区域入口。
