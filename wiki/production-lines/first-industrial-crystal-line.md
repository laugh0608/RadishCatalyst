# 第一工业晶体线

更新时间：2026-06-29

## 路线

```text
手持采样晶体 / 残骸
-> 建出基础晶体采集器
-> 输出托盘收取晶体矿物
-> 回基地基础反应器加工
-> 基础零件 / 修复凝胶
-> 储存箱补给 / 出发整备台交接
```

## 读法

这条线是当前原型的第一段工业路径。它要让玩家明白：

- 前期需要自己开路和采样。
- 建出采集器后，稳定产出由设备接管。
- 输出托盘不是终点，收料后要回基地入反应器。
- 这条线应优先从局部资产化工作面读取，不从全图路线、旧规划框或长标签读取。
- 反应器产物会进入后勤设施：基础零件服务建造和校准，修复凝胶服务下一趟外勤。
- 储存箱和出发整备台让基地收益变成可带出去的补给或整备状态。
- 回基地后如果画面进入基地交接工作面，先看反应器料斗、仓储供给件和整备锁扣；它们表示资源已经从外勤产物转成基地可用产物。

## 画面线索

- 晶体区看当前矿面、采集器机体、输出托盘、短物料流和装车轨。
- 基地看收料口、基础反应器料斗、产物输出位、储存箱供给件和整备台锁扣。
- 状态灯表示设备段落：采集器等待 / 出料、收料口已装入、反应器加工、储存有产物、整备台可交接。
- 物料槽表示当前段有没有东西可收、可投或可取；短流带只连接相邻设备和端口，不是跨区导航线。
- 若目标、交互对象或小地图仍在晶体 / 污染语境，说明还没有进入基地交接工作面，先按当前目标完成对应现场步骤。
- 如果全图路线、旧色块或长标签太显眼，优先相信当前目标、高亮对象、状态灯和局部设备工作面。
