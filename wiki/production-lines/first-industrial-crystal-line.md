# 第一工业晶体线

更新时间：2026-06-21

## 路线

```text
手持采样晶体 / 残骸
-> 建出基础晶体采集器
-> 输出托盘收取晶体矿物
-> 回基地基础反应器加工
-> 基础零件 / 修复凝胶
-> 储存箱补给 / 出发整备台交接
```

## 读法

这条线是当前原型的第一段工业路径。它要让玩家明白：

- 前期需要自己开路和采样。
- 建出采集器后，稳定产出由设备接管。
- 输出托盘不是终点，收料后要回基地入反应器。
- 反应器产物会进入后勤设施：基础零件服务建造和校准，修复凝胶服务下一趟外勤。
- 储存箱和出发整备台让基地收益变成可带出去的补给或整备状态。

## 画面线索

- 晶体区看矿面、采集器工作面、输出托盘和装车轨。
- 基地看收料口、基础反应器输入台、产物输出位、储存箱和整备交接口。
- 如果全图路线、旧色块或长标签太显眼，优先相信当前目标、高亮对象和局部设备工作面。
