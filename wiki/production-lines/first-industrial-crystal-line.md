# 第一工业晶体线

更新时间：2026-07-25

## 路线

```text
手持采集晶体
-> 随身合成机械零件
-> 修复前哨核心
-> 铺工业地板与扩展电网
-> 通电采集器稳定产出
-> E 取出采集器缓冲
-> 存入源储物箱
-> 传送带搬运
-> 目标储物箱入库
```

## 读法

这条线是当前空间工厂切片的第一条自动物流路径：

- 前期手持采集提供核心修复和第一批套件所需资源。
- 采集器把晶体地变成持续产出点，但当前仍需玩家取出内部缓冲。
- 储物箱的舱口决定它是向线路发料还是从线路收料。
- 传送带自动派生直线、转角、端点和合流外观。
- 目标箱满载会让整条线路回压，清出空间后继续。
- 多只源箱可以合流到同一目标箱，并轮流获得通行机会。

当前基础反应器还不属于这条可运行产线。晶体进入目标箱后，线路的运输目标已经完成。

## 推荐布局

先从最简单的直线开始：

```text
源箱舱口 -> 4 格同向传送带 -> 目标箱舱口
```

确认能入库后再加入两个正交转角，最后尝试三只源箱合流。调试合流时让目标箱保留足够空间，避免把正常回压误判成拓扑错误。

## 常见瓶颈

- 源箱不发料：舱口外第一格方向反了，或源箱没有晶体。
- 目标箱不入库：末端没有指向舱口。
- 转角显示直线：上游没有真正指入该格。
- 整线停住：目标箱已满，或中间某格仍有货物。
- 某一路长期没有货：确认它持续有晶体，并且所有入口确实指向同一合流格。
