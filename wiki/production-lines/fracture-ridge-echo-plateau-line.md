# 裂相脊到回声台地生产线

更新时间：2026-06-08

剧透提示：本页涉及首小时之后的 Demo 中段主线。

## 用途

这条生产线说明玩家在裂相脊入口之后，为什么要多次把前线产物带回基地处理，再带着基地产物回到更深处。它的重点不是堆库存，而是让基地加工改变下一次外勤目标。

## 主线流程

```text
外圈相位守卫
-> 污染回波沉积
-> 污染过滤器处理出污染浆液
封锁回波匣 + 污染浆液
-> 基础反应器解析裂相坐标
-> 裂相脊入口门禁
-> 相位纤丝
-> 污染过滤器精炼谐振滤芯
-> 基础反应器组装裂相覆写栓
-> 裂相锁扣回收裂相样块
-> 基础反应器解析裂相路由印片
-> 裂相阵列台点亮
-> 相位导管
-> 基础反应器整理裂相读数矩阵
-> 前线回传锚点
-> 相位回投返回裂相脊后半
-> 裂相碎屑
-> 污染过滤器筛出透镜胚片
-> 基础反应器调准中继调谐镜
-> 裂相尖塔回收内层故障轨迹
-> 基础反应器解析裂相坐标印片
-> 故障残渣
-> 污染过滤器稳定故障芯
-> 基础反应器组装裂相锁钥
-> 裂相锁位带回回声定位器
-> 基础反应器解析回声路由片
-> 回声泄压阀与回声碎屑
-> 污染过滤器筛出回声稳流芯
-> 基础反应器组装回声探针
-> 回声台地读取回声芯样本
```

## 关键设备

- `基础反应器`：负责解析回波、样块、读数、故障轨迹和定位器，也负责组装裂相覆写栓、中继调谐镜、裂相锁钥和回声探针。
- `污染过滤器`：负责把相位纤丝、裂相碎屑、故障残渣和回声碎屑稳定成下一步装配件，并提供污染浆液副产。
- 当前深段回波解析也会消耗污染浆液；相位守卫后暴露的污染回波沉积应先处理，再把回波匣和浆液带回基地。
- `相位回投台`：前线回传锚点上线后，把玩家送回当前前线落点，减少裂相脊后半的重复跑图。

## 注意事项

- 缺基础零件时，先看 HUD、设备面板和加工日志；它们会优先提示阶段补给、前哨核心回收、富晶残脉或污染浆液回收线。
- 裂相锁钥不是留在背包里的装备，带回裂相锁位后会换成回声定位器。
- 回声定位器需要先回基地解析成回声路由片，回声台地才会变成明确的下一段目标。
