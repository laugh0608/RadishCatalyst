# 污染边界到核心稳定站生产线

更新时间：2026-06-15

剧透提示：本页涉及污染边界后续回访和当前 demo 终点。

## 生产线概览

这条线说明当前原型里污染治理如何一路反哺到核心稳定站终点：

```text
污染沉积物 -> 污染过滤器 -> 抗污染药剂 + 污染浆液
污染浆液 -> 基础反应器 -> 基础零件
污染浆液 + 基础零件 -> 污染浆液缓冲罐 -> 前哨核心双药剂整备
污染浆液 + 基础零件 + 继电残片 -> 稳相信标
修复凝胶 + 抗污染药剂 + 污染浆液 + 基础零件 -> 核心稳压缓冲包
核心稳压缓冲包 -> 核心阶段守卫第一次回写压力削弱
核心阶段守卫 -> 核心守卫回写缓存 -> 核心写入校验片 + 终点前补给
核心写入校验片 + 侧向补给 + 守卫回写校准 + 抗污染药剂 -> 核心稳定设备写入排压
核心稳定设备写入 -> 出发整备台核心归档维护 -> 污染边界回访过滤 -> 核心稳定站复测
核心复测读数缓存 -> 基础零件 + 修复凝胶 -> 出发整备台后勤维护确认
后勤维护复测沉积 + 核心复测受扰掠行体 -> 污染过滤器 -> 抗污染药剂 + 污染浆液
基础多用工具 + 出发整备台 -> C 战术扫描 -> 下一次敌人反击或污染采集承压下降
基础防护服 + 基础过滤模块 + 补给 -> 出发整备台防护响应 -> 下一次外勤反击承压下降
基础多用工具 + 基础零件 -> 出发整备台工具打击校准 -> 下一次外勤反击输出压制
```

## 路线分段

1. 污染边界首段：建造污染过滤器，处理污染沉积物，得到抗污染药剂和污染浆液。
2. 污染边界回访：污染侧翼和副产回收口袋提供额外沉积物与受扰守卫，让药剂、污染浆液和回基地处理理由落到实际路线。
3. 遗迹门前确认：清掉门前压力后，封锁入口会读取基础过滤模块、抗污染药剂和污染浆液状态，提示是否先回基地整备。
4. 遗迹外圈回访：污染脊沉积物和守卫提供额外补料压力，污染浆液可回收基础零件并参与稳相信标。
5. 前哨双药剂整备：污染浆液缓冲罐把过滤副产接入前哨核心，连续压力段可按 2 份抗污染药剂准备。
6. 核心稳定站整备：回污染边界补核心缓冲包沉积物，清理补料守卫，再回基地整备核心稳压缓冲包。
7. 核心阶段守卫：缓冲包会削弱第一次回写压力，并记录可被最终设备读取的回写校准。
8. 守卫后回收：核心守卫回写缓存提供核心写入校验片、基础零件和终点前补给。
9. 核心设备写入：侧向补给、守卫回写校准和抗污染药剂会形成仓促写入、局部整备和充分整备的承压差异；没有药剂仍可完成，但反冲更高。
10. 归档维护回访：核心写入完成后，出发整备台可把核心归档维护接入基础过滤模块；污染边界回访沉积、过滤器完成反馈、前哨核心补满药剂和外勤出发口复测会读成同一条回访线。
11. 后勤维护复测：核心复测读数缓存带回基础零件和修复凝胶；基地处理晶体补料并在出发整备台确认后勤维护后，污染边界后勤复测、核心站复测沉积和受扰守卫会读出维护收益。
12. 角色套件整备：战术扫描、防护响应和工具打击校准都从出发整备台或基础多用工具接入，分别服务下一次扫描目标、外勤反击防护和外勤反击输出。

## 操作重点

- 基础过滤模块、修复凝胶和抗污染药剂共同决定污染回访是否稳。
- 出发整备台先负责把基础过滤模块装入防护服，随后承接模块校准、核心归档维护、后勤维护、防护响应和工具打击校准；没装入时，后续污染压力会按未装配提示处理。
- 污染浆液缓冲罐不是完整流体网络，它只把污染浆液副产转成前哨核心的双药剂整备收益。
- 污染浆液不是废料；目标配方需要最后一份浆液时，先不要回收基础零件。
- 核心设备写入前必须先回收核心写入校验片；抗污染药剂不是硬门槛，但会明显降低写入承压。侧向补给和守卫回写校准也会被最终写入读取。
- 核心复测读数缓存不是新资源体系；它只把基础零件和修复凝胶带回基地，让出发整备台确认后勤维护。
- 工具打击校准会消耗基础零件，防护响应需要补给齐备；二者都只在下一次外勤反击触发，不会变成常驻装备栏。
