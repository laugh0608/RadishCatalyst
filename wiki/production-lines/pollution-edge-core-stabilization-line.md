# 污染边界到核心稳定站生产线

更新时间：2026-06-07

剧透提示：本页涉及污染边界后续回访和当前 demo 终点。

## 生产线概览

这条线说明当前原型里污染治理如何一路反哺到核心稳定站终点：

```text
污染沉积物 -> 污染过滤器 -> 抗污染药剂 + 污染浆液
污染浆液 -> 基础反应器 -> 基础零件
污染浆液 + 基础零件 + 继电残片 -> 稳相信标
修复凝胶 + 抗污染药剂 + 污染浆液 + 基础零件 -> 核心稳压缓冲包
核心阶段守卫 -> 核心守卫回写缓存 -> 核心写入校验片
核心写入校验片 -> 核心稳定设备写入
```

## 路线分段

1. 污染边界首段：建造污染过滤器，处理污染沉积物，得到抗污染药剂和污染浆液。
2. 遗迹外圈回访：污染脊沉积物和守卫提供额外补料压力，污染浆液可回收基础零件并参与稳相信标。
3. 核心稳定站整备：回污染边界补核心缓冲包沉积物，清理补料守卫，再回基地整备核心稳压缓冲包。
4. 核心阶段守卫：缓冲包会削弱第一次回写压力。
5. 守卫后回收：核心守卫回写缓存提供核心写入校验片、基础零件和终点前补给。

## 操作重点

- 基础过滤模块、修复凝胶和抗污染药剂共同决定污染回访是否稳。
- 污染浆液不是废料；目标配方需要最后一份浆液时，先不要回收基础零件。
- 核心设备写入前必须先回收核心写入校验片。
