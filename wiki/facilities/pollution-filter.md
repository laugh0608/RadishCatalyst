# 污染过滤器

更新时间：2026-06-03

## 定位

`污染过滤器` 是处理点扩建后的关键设施。它把污染边界采回的危险资源转成可携带补给，并把污染副产物留给后续资源链。

## 建造前置

当前原型里，建造污染过滤器前需要：

1. 带修复凝胶前往处理点北缘。
2. 清理两处处理点掠行体。
3. 清理两块粗糙地面。
4. 铺设两块基础地基。
5. 凑齐污染过滤器建造材料。

如果过滤器不能建造，先看 HUD 交互提示里的 `状态` 和 `下一步`：

- `基础地基：0 / 2` 或 `1 / 2`：继续清理地块并铺满两块基础地基。
- `缺少建造材料`：回晶体区补资源，再用基础反应器补齐过滤器材料。
- 没有 `按 E 建造`：当前还被前置或材料挡住，先按 `下一步` 处理。

## 当前作用

```text
污染沉积物 x2 + 基础溶剂 x1
-> 抗污染药剂 I x1 + 污染浆液 x1
```

第一次处理完成后，设备面板和日志会提示带药剂回污染边界补第二批沉积物并清理受扰敌人，而不是直接把玩家推到遗迹门前。

靠近污染过滤器时，设备面板应优先看当前配方、输入 / 产出、状态和下一步建议；缺料时先补沉积物或基础溶剂，不要反复按启动键。
