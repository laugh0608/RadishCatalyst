# 污染过滤器

更新时间：2026-06-24

## 定位

`污染过滤器` 是处理点扩建后的关键设施。它把污染边界采回的危险资源转成可携带补给，并把污染副产物留给后续资源链。

## 建造前置

当前原型里，建造污染过滤器前需要：

1. 带修复凝胶前往处理点北缘。
2. 清理处理点掠行体。
3. 清理一块粗糙地面。
4. 铺设一块基础地基。
5. 凑齐污染过滤器建造材料。

如果过滤器不能建造，先看 HUD 交互提示里的 `状态` 和 `下一步`：

- `基础地基不足`：继续清理地块并铺好基础地基。
- `缺少建造材料`：回晶体区补资源，再用基础反应器补齐过滤器材料。
- 没有 `按 E 建造`：当前还被前置或材料挡住，先按 `下一步` 处理。

## 当前作用

```text
污染沉积物 x2 + 基础溶剂 x1
-> 抗污染药剂 I x1 + 污染浆液 x1
```

第一次处理完成后，设备面板、加工完成短条、HUD 当前目标和基地摘要会提示同一条回访链：处理药剂 -> 带药剂回污染边界 -> 清理受扰敌人 / 门前压力点，而不是直接把玩家推到遗迹门前。

同一配方在后续任务里会分流完成去向：稳相信标阶段指向组装信标，回收深段回波阶段指向外圈回波匣和裂相坐标解析，核心稳定站整备阶段指向核心稳压缓冲包，门前压力未处理时指向带药剂回污染边界排压。

`污染浆液` 是有效副产物，不是失败结果。处理点扩建后，基础反应器会开放污染浆液回收基础零件；后续稳相信标、核心稳压缓冲包和污染浆液缓冲罐也会直接消耗污染浆液。

靠近污染过滤器时，设备面板应优先看当前配方、输入 / 产出、状态和下一步建议；缺料时先补沉积物或基础溶剂，不要反复按启动键。

当前设备面板还会显示任务差异：污染沉积不是单纯产出药剂，它会把现场承压转成 `抗污染药剂 I` 和 `污染浆液` 两类收益。药剂进入补给，浆液可能回收基础零件，也可能保留给核心稳压缓冲包、稳相信标或污染浆液缓冲罐。

过滤器加工中时，HUD 和设备面板会显示同一条进度；如果配方列表里其他配方显示设备忙碌，表示这台设备正在处理当前配方，不是多条配方同时运行。

如果药剂已经做完但封锁入口仍然没有放行，先回污染边界检查沉积物提示、受扰敌人、污染侧翼、副产回收口袋和门前压力点；这些提示应和过滤器完成反馈指向同一组待处理目标。

门前压力清掉后，封锁入口会读取污染过滤器产出的药剂和污染浆液：缺药剂时建议回过滤器补药剂，携带多余污染浆液时建议先回基础反应器回收基础零件。

如果当前目标需要深段回波解析、稳相信标、核心稳压缓冲包或污染浆液缓冲罐，先保留目标所需的最后一份污染浆液；有多余浆液时再回收成基础零件。

核心归档维护接入后，污染边界会开放归档维护回访沉积和守卫。回收这批沉积后，过滤器完成反馈会改为指向：处理成药剂和污染浆液 -> 回前哨核心补满药剂 -> 从外勤出发口复测核心稳定站或回污染边界确认承压。
