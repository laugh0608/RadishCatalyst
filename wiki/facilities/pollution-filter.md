# 污染过滤器

更新时间：2026-06-08

## 定位

`污染过滤器` 是处理点扩建后的关键设施。它把污染边界采回的危险资源转成可携带补给，并把污染副产物留给后续资源链。

## 建造前置

当前原型里，建造污染过滤器前需要：

1. 带修复凝胶前往处理点北缘。
2. 清理两处处理点掠行体。
3. 清理两块粗糙地面。
4. 铺设两块基础地基。
5. 凑齐污染过滤器建造材料。

如果过滤器不能建造，先看 HUD 交互提示里的 `状态` 和 `下一步`：

- `基础地基：0 / 2` 或 `1 / 2`：继续清理地块并铺满两块基础地基。
- `缺少建造材料`：回晶体区补资源，再用基础反应器补齐过滤器材料。
- 没有 `按 E 建造`：当前还被前置或材料挡住，先按 `下一步` 处理。

## 当前作用

```text
污染沉积物 x2 + 基础溶剂 x1
-> 抗污染药剂 I x1 + 污染浆液 x1
```

第一次处理完成后，设备面板、加工完成短条、HUD 当前目标和基地摘要会提示同一条回访链：处理药剂 -> 带药剂回污染边界 -> 补第二批沉积物 -> 清理受扰敌人 / 门前压力点，而不是直接把玩家推到遗迹门前。

同一配方在后续任务里会分流完成去向：稳相信标阶段指向组装信标，回收深段回波阶段指向外圈回波匣和裂相坐标解析，核心稳定站整备阶段指向核心稳压缓冲包，门前压力未处理时指向带药剂回污染边界排压。

`污染浆液` 是有效副产物，不是失败结果。处理点扩建后，基础反应器会开放污染浆液回收基础零件；后续稳相信标和核心稳压缓冲包也会直接消耗污染浆液。

靠近污染过滤器时，设备面板应优先看当前配方、输入 / 产出、状态和下一步建议；缺料时先补沉积物或基础溶剂，不要反复按启动键。

过滤器加工中时，HUD 和设备面板会显示同一条进度；如果配方列表里其他配方显示设备忙碌，表示这台设备正在处理当前配方，不是多条配方同时运行。

如果药剂已经做完但封锁入口仍然没有放行，先回污染边界检查沉积物提示、受扰敌人和门前压力点；这些提示应和过滤器完成反馈指向同一组待处理目标。

如果当前目标需要深段回波解析、稳相信标或核心稳压缓冲包，先保留最后一份污染浆液给目标配方；有多余浆液时再回收成基础零件。
