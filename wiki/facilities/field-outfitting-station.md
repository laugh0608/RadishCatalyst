# 出发整备台

更新时间：2026-06-19

## 定位

`出发整备台` 是基地平台的早期后勤设施。它不是完整装备栏，也不是出门前的长期 loadout 菜单；当前原型里，它把已经制造好的 `基础过滤模块` 装入防护服模块槽，并继续承接模块校准、核心归档维护、后勤维护、防护响应和工具打击校准，让基地制造结果直接改变下一趟外勤承压。

## 建造方式

当前出发整备台建造需要：

```text
基础零件 x2 + 导电废件 x1
-> 基地平台整备位
-> 出发整备台
```

如果建造提示显示缺料，先回晶体矿脉区采集晶体矿物、回收外勤残骸，再用基础反应器补基础零件。

## 当前作用

出发整备台上线后，靠近它按提示交互：

```text
基础过滤模块 x1
-> 出发整备台
-> 防护服模块槽：基础过滤模块
```

装入后，HUD 基地摘要会显示整备台收益，污染沉积采集、防护消耗和污染敌人反击都会读到模块状态。

只要基础多用工具仍在装备位，整备台上线后角色会获得 `C 战术扫描`。靠近敌人或带污染压力的采集点按 `C`，会标记目标；下一次敌人反击或污染采集会消费该标记并降低承压。模块已装入或已校准时，扫描收益会进一步提高。

模块已经装入后，整备台还会开放维护操作：

```text
晶体矿 x2 + 残骸废件 x1
-> 出发整备台
-> 基础过滤模块校准
```

核心稳定设备写入完成后，若基础过滤模块仍装在防护服中，整备台会开放 `核心归档维护`。接入后，下一趟污染采集、污染战斗和核心稳定站复测都会继续读取维护收益。

核心站复测读数带回并处理过后，整备台会再开放 `后勤维护确认`：

```text
核心复测读数缓存 -> 基础零件 / 修复凝胶
晶体补料回访 -> 基础反应器处理晶体矿
出发整备台 -> 后勤维护确认
```

确认后，核心稳定站复测沉积采集和复测守卫反击会继续降低承压。这仍然是基础过滤模块的维护状态，不是完整装备栏。

如果基础防护服、基础过滤模块、修复凝胶、抗污染药剂和满生命 / 防护都齐备，整备台可以确认 `防护响应`。它会在下一次外勤反击触发，降低生命 / 防护承压，触发后需要回前哨核心补给并回整备台复查。

如果装备基础多用工具且背包有 `基础零件 x2`，整备台可以确认 `工具打击校准`。确认会消耗基础零件，下一次外勤反击会读出工具输出压制并降低承压；触发后可继续回基础反应器加工零件，再回整备台重新确认。

当晶体加工、污染过滤或核心准备中至少两类处理结果已经可读时，整备台会开放 `任务差异登记`。确认后，晶体 / 污染 / 核心准备会按资源类型写入下一趟外勤路线；玩家可以从 HUD、设备面板和对象反馈判断该回基础反应器、污染过滤器，还是先整备核心稳压缓冲包。

## 读提示方式

- 建造前：HUD 会说明建成后可装配基础过滤模块。
- 缺少模块：交互反馈会提示先回基础反应器制造基础过滤模块。
- 装配成功：反馈会说明模块已装入防护服，并把污染边界推进目标接上。
- 可校准：提示会显示晶体矿和残骸废件成本。
- 已校准：提示会显示污染采集和污染反击承压继续下降。
- 核心归档维护待接入：提示会显示 `E 接入核心归档维护`。
- 后勤维护待确认：提示会说明核心复测读数和晶体补料已处理，可确认下一趟复测维护。
- 战术扫描：HUD 角色状态会显示 `C 战术扫描` 是否可用；扫描命中后，战斗或采集反馈会说明标记已消费。
- 防护响应：提示会显示可确认、已待命、已触发或可复位；外勤反击触发后战斗日志会说明防护响应来源。
- 工具打击校准：提示会显示是否缺基础零件、已待命或已触发；外勤反击触发后战斗日志会说明工具校准来源。
- 任务差异登记：提示会显示晶体、污染或核心准备哪些路线已可登记；不足两类时继续补另一类外勤处理结果。
- 重复检查：整备台会提示模块已装入、已校准或维护已接入，不会重复消耗。
