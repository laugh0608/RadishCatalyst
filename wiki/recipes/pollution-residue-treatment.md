# 污染沉积物处理

更新时间：2026-06-06

## 配方

```text
污染沉积物 x2 + 基础溶剂 x1
-> 污染过滤器
-> 抗污染药剂 I x1 + 污染浆液 x1
```

## 解锁阶段

完成处理点扩建并建造污染过滤器后开放。

## 用途

这条配方是污染边界二次外出的关键：第一次处理沉积物会给抗污染药剂，帮助玩家按“处理药剂 -> 带药剂回污染边界 -> 补第二批沉积物 -> 清理受扰敌人 / 门前压力点”的顺序推进。

## 注意事项

- 抗污染药剂默认服务快捷栏 `2`。
- 污染浆液是副产物，不应被当成失败结果；后续链路会继续使用污染过滤副产。
- 如果任务还没补齐沉积物数量，设备面板会优先提示回污染边界补第二批沉积物。
- 加工中先看 HUD 进度条；需要确认输入、产出、副产和下一步时按 `Q` 打开污染过滤器面板。
- 药剂完成后仍被门前压力挡住时，先看污染沉积物提示和门前受扰敌人；它们不是新任务分叉，而是这条配方的回访用途。
