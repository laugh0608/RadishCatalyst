# 制造基础地基材料

更新时间：2026-05-31

## 配方

```text
基础零件 x1 + 晶体矿物 x1
-> 基础反应器
-> 基础地基材料 x2
```

## 用途

基础地基材料用于处理点扩建。当前任务需要清理两块粗糙地面并铺设两块基础地基，之后污染过滤器才能落地。

## 使用建议

- 如果过滤器提示缺少地基，先确认是否已经清理粗糙地面。
- 如果地基材料不足，回晶体矿脉区补晶体矿物，或检查基础零件是否已经被其他配方消耗。
