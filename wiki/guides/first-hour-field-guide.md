# 首小时外勤入门

更新时间：2026-06-23

本页面向当前原型的新玩家，说明前 15 到 30 分钟最容易漏读的基地、晶体矿脉区和污染边界关系。

## 核心思路

第一段体验不是让你立刻理解完整化工系统，而是学会一条反复会用到的路线：

```text
从基地出发 -> 手持采样晶体和残骸 -> 建出采集器接管晶体产出 -> 回基地制造 -> 带着产物再去污染边界
```

如果不知道下一步做什么，先看当前目标、左侧关键资源、右侧基地摘要和小地图方向标记；进入战斗时，再看战斗现场面板和敌人浮动标签。

## 读默认 HUD

默认可玩画面先看这几处，不需要先打开调试面板：

- 左侧当前目标说明下一步要去哪里，关键资源说明这一步缺什么。
- 右侧基地摘要会把当前段读成外勤输入、基地加工、整备收益、污染承压或核心写入，帮助你判断为什么要外出、回基地或继续推进。
- 快捷补给面板显示 `1` 修复凝胶和 `2` 抗污染药剂的数量、可用状态和回补来源；生命低先看 `1`，防护低先看 `2`。
- 底部一行摘要同时显示当前可交互对象和最近行动结果；如果需要配方输入 / 产出细节，再靠近设备按 `Q` 查看面板。
- 小地图和当前目标焦点只负责找当前工作面；看到采集器、过滤器或核心站里的短连线时，不要按跨屏导航线理解。

## 读低保真现场状态

当前原型不会用完整美术动画解释所有生产状态，先按局部工作面判断：

- 玩家用防护服轮廓和朝向读当前位置；敌人用威胁环、状态条和浮动标签区分是否正在承压。
- 前哨核心、基础反应器、污染过滤器、储存箱、出发整备台、晶体采集器和核心写入设备都有不同轮廓、材质色、状态灯或短标签；先按这些识别用途，不要把它们当作普通方块。
- 采集器、收料口、基础反应器、储存箱和整备台旁的小状态灯表示等待、有料、加工、输出或交接。
- 物料槽亮起时，代表对应原料或产物已经进入当前段；不要只看远处路线是否发光。
- 短流带只说明相邻设备或端口之间正在交接，不代表整张地图都要沿线跑一遍。
- 污染边界优先看沉积岛、过滤床、药剂输出架、浆液沉降盆和回收装车位；旧黄绿底纹只是区域背景。
- 核心稳定站优先看守卫压力残留、回写缓存、核心写入设备、复测读数面板和站内回流端口；完成后仍可看到整理和复测读法。

## 基地平台

基地平台是恢复、加工和判断下一步的地方。

- 靠近 `前哨核心` 可以恢复基础状态，并确认当前主线目标。
- 靠近 `基础反应器` 时，设备面板会显示当前配方、推荐配方、输入、产出和用途。
- 建造 `基础储存箱` 后，前哨核心整备会在修复凝胶耗尽时补到 1 份。
- 建造 `出发整备台` 后，可以把已制造的基础过滤模块装入防护服；模块没有装入时，污染区承压不会按已装配处理。
- 整备台上线后，基础多用工具会接入 `C 战术扫描`；靠近敌人或污染采集点使用后，下一次反击或采集会降低承压。
- 过滤模块、补给和基础零件齐备后，整备台还会出现防护响应或工具打击校准提示，它们都服务下一次外勤反击。
- 当晶体、污染或核心准备至少两类处理结果已经可读时，整备台会提示任务差异登记；确认后，下一趟外勤会按资源类型指向对应设备和处理路线。
- 制造完成后，日志会提示产物进入背包，以及它应该服务下一次外勤还是继续基地制造。
- 加工启动后，HUD 会显示进度条；按 `Q` 可以查看设备面板。配方列表里只有正在运行的配方显示进度，其他配方显示设备忙碌。

早期不要在基地里找完整菜单。当前原型主要通过当前目标、设备面板和基地摘要告诉你该做什么。

## 读交互提示

靠近当前可操作对象时，HUD 会优先显示这个对象的提示。先按提示里的结构判断：

- `对象 / 用途`：你正在操作谁，以及它服务采集、采样、检查、建造还是清障。
- `产物 / 样本`：成功后会拿到什么，或它会推进哪条线索。
- `状态`：当前是否已处理、缺料、被前置条件挡住或正在加工。
- `下一步`：如果不能操作，先做这里写的事，例如回晶体区补材料、清理地块、铺基础地基或回设备加工。
- `操作`：只有这里显示 `E`、`Q` 或 `R` 时，才代表当前对象支持对应按键。

## 读战斗现场

战斗中不要只看左下日志。当前原型会把关键信息放在战斗现场面板和敌人标签里：

- 自身：生命、防护和快捷补给是否还够继续承压。
- 敌人：当前锁定目标的 HP、威胁等级、承压类型和状态。
- 命中反馈：最近一次攻击造成了多少伤害，反击扣了生命还是防护。
- 威胁差异：污染敌人和核心守卫通常会带来更高生命 / 防护压力。
- 未锁定敌人时，先靠近带生命条和威胁标签的目标，再攻击。

## 晶体矿脉区

晶体矿脉区是第一批资源和低压战斗教学区域。

- 主路晶体用于获得 `晶体矿物`，回基地后可加工成 `基础零件`。
- 残骸点会给 `导电废件`，用于校准基础反应器。
- 基础晶体采集器建成后，重复晶体产出会通过输出托盘表达；托盘可收取时，先收料，再把晶体矿物带回基础反应器。
- 异常或残留点会逐步引向样本分析和污染边界。
- 基地后勤区解锁后，晶体侧路会补一批更明确的残脉 / 残骸资源，服务储存箱、出发整备台和污染边界准备。
- 小型原生敌人压力不高，但会提醒你战斗、生命和防护状态不是装饰。

当前可交互对象会显示名称和提示；如果附近有很多资源点，优先按当前目标和高亮对象行动。

当前低保真画面里，晶体矿脉区的主要线索不是整块蓝色底板，而是岛状矿面、碎矿块、富矿脊线、采集器工作面、输出托盘、残骸堆和回基地装车轨。看到这些局部工作面时，优先把它们理解成“可采集 / 可收料 / 可回收 / 会回基地处理”的路线提示。

## 回基地制造

第一次回基地不是“交任务”，而是把外勤带回来的东西变成下一次外勤能力。

常见早期制造价值：

- `基础零件`：用于过滤模块、修复凝胶和地基材料。
- `反应器校准件`：让基础反应器恢复关键处理能力。
- `修复凝胶`：用于下一次外勤续战。
- `基础过滤模块`：降低污染采集防护消耗，并缓冲污染敌人反击。
- `基础地基材料`：用于处理点北缘铺设地基，让污染过滤器能落地。
- `基础零件` 后续也可用于工具打击校准；如果整备台提示缺基础零件，先回晶体区或用污染浆液回收线补足。

如果制造目标已经完成，基地摘要通常会把你指回外出推进，不需要反复留在设备旁边。

## 污染边界区

污染边界是第一处更高风险区域。

- 安全施工带会先要求你带修复凝胶清理两处处理点掠行体，再清理粗糙地面、铺设两块基础地基并建造污染过滤器。
- 入口沉积物让你学习污染沉积物采集和防护消耗。
- 巡游污染敌人会让过滤模块和补给开始有意义。
- 污染过滤器会把 `污染沉积物 x2` 和 `基础溶剂 x1` 处理成 `抗污染药剂 I x1`，并留下 `污染浆液 x1`。
- 污染浆液可以回基础反应器回收基础零件，但后续目标配方需要它时先不要把最后一份浆液回收掉。
- 首趟药剂做完后，先把它留在快捷栏 `2`，带着药剂回污染边界补第二批沉积物，再清理受扰敌人和门前压力点。
- 污染侧翼和副产回收口袋会继续使用污染沉积斑和受扰掠行体；它们的作用是把“补药剂、拿副产、回基地处理”变成实际路线。
- 后勤维护确认后，污染边界会出现复测压力点；这段会读取整备台维护状态，清理后仍要把沉积物带回过滤器处理成药剂和污染浆液。
- 门前压力清掉后，封锁入口会读取基础过滤模块、抗污染药剂和污染浆液携带状态；如果还带着多余污染浆液，先回基础反应器回收基础零件也是合理选择。
- 更深处的污染沉积、污染残核和遗迹门前压力会带来更高生命 / 防护压力，适合在准备好过滤模块、修复凝胶或抗污染药剂后再推进。

污染不是单纯扣血墙。它会通过防护消耗、敌人压力、处理点建造和后续药剂制造一起推动你回基地准备。

当前低保真画面里，污染边界会用沉积岛、危险口袋、过滤床分区、药剂输出架、浆液沉降盆和回收装车位表达处理现场。旧黄绿大块如果仍能看到，只当作区域底纹，不代表完整可操作范围。

## 常见卡点

- 看不到谁能互动：靠近当前目标或高亮对象，当前可交互物才会优先显示名称和提示。
- 基础反应器缺料：回晶体矿脉区补晶体矿物，或找残骸点回收导电废件。
- 基础反应器显示缺料但没有 `E 启动加工`：先按“下一步”补原料；设备仍可用 `Q` 查看详情或用 `R` 切换配方。
- 配方列表里其他配方也显示设备忙碌：这是同一台设备正在加工，先等当前配方完成；不是其他配方也在同时制造。
- 污染边界消耗太快：先确认是否做出基础过滤模块、修复凝胶或抗污染药剂。
- 基础过滤模块做完但没有生效：先建造并使用出发整备台，确认 HUD 显示模块已生效。
- 按 `C` 没反应：确认已经装备基础多用工具，并且出发整备台已经建成；扫描只会锁定近身敌人或带污染压力的采集点。
- 防护响应不能确认：需要基础防护服、已装入的基础过滤模块、修复凝胶、抗污染药剂，并且生命 / 防护已通过前哨核心恢复满。
- 工具打击校准不能确认：需要基础多用工具和 `基础零件 x2`，确认后会消耗这批基础零件。
- 任务差异登记不出现：先完成至少两类外勤处理结果，例如晶体回反应器、污染沉积回过滤器、核心准备材料回反应器整备；再回出发整备台查看。
- 战斗中看不懂承压：优先看战斗现场面板的自身生命 / 防护、敌人威胁和最近命中反馈；日志只作为补充。
- 修复凝胶用完了：如果基础储存箱已经建成，回前哨核心整备可补到 1 份；还没建成就先回反应器调制或补基础零件建储存箱。
- 过滤器不能建造：先清理两块粗糙地面，确认两块基础地基已经铺好。
- 药剂做完但还没让你去门前：先补齐第二批污染沉积物并清理受扰敌人 / 门前压力点；过滤器面板、短条、HUD、沉积物提示和门前压力点会指向同一条回访链。
- 封锁入口提示你带着污染浆液：说明副产物可先回基础反应器回收基础零件；如果你准备直接进遗迹外圈，也可以确认入口继续推进。
- 建造失败：看交互提示里的失败原因，通常是地面、地基、材料或污染条件还没满足。
- 操作被挡住但不知道去哪：先看当前对象提示里的状态和下一步，再对照 HUD 当前目标、小地图方向和设备面板。
- 不知道当前处在循环哪一步：看右侧基地摘要的短状态；外勤输入通常要采集或回收，基地加工要回设备处理，整备收益要确认模块或补给，污染承压要看防护和药剂，核心写入要看守卫缓存和写入设备。
