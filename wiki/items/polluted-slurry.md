# 污染浆液

更新时间：2026-06-13

## 定位

`污染浆液` 是污染过滤产生的危险副产物。当前原型已经把它接回资源链：它既能回收成基础零件，也会成为深段回波解析、稳相信标、核心稳压缓冲包、污染浆液缓冲罐和后续多段整备包的输入。

## 当前来源

```text
污染沉积物 x2 + 基础溶剂 x1
-> 污染过滤器
-> 抗污染药剂 I x1 + 污染浆液 x1
```

裂相脊和相位井后段的多种过滤配方也会继续产出污染浆液。

## 当前用途

- `污染浆液 x1 -> 基础反应器 -> 基础零件 x2`。
- 参与深段回波解析、稳相信标、核心稳压缓冲包、污染浆液缓冲罐和后段整备件。
- 作为“污染治理副产物反哺基地”的第一条明确样例。
- 在封锁遗迹入口确认前，如果背包里仍有污染浆液，入口提示会提醒可先回基地回收基础零件。

## 注意事项

- 不要把污染浆液当成失败废料。
- 如果当前任务需要深段回波解析、稳相信标、核心稳压缓冲包或污染浆液缓冲罐，先保留目标配方所需的最后一份浆液。
- 有多余浆液且缺基础零件时，再用基础反应器回收；门前确认提示出现时也可以先回基地处理。
