# 基础过滤模块

更新时间：2026-06-15

## 定位

`基础过滤模块` 是当前原型里第一件防护服模块。它不是单纯的区域通行钥匙，而是让污染边界外勤更可控的早期 Build 选择。

## 当前来源

```text
基础零件 x2 + 过滤介质 x1
-> 基础反应器
-> 基础过滤模块 x1
```

完成样本分析后会开放对应配方。背包中有模块时，回基地建好 `出发整备台`，靠近整备台按提示可把它装入防护服模块槽。

模块装入后，出发整备台还可以消耗 `晶体矿 x2 + 残骸废件 x1` 做晶体校准。核心稳定设备写入完成后，整备台会开放核心归档维护，把终点写入结果接回模块维护。核心复测读数和晶体补料处理后，后勤维护会继续绑定在同一整备台状态上。

## 当前作用

- 降低污染沉积物采集造成的防护消耗。
- 缓冲污染敌人反击造成的生命 / 防护压力。
- 缓冲遗迹外圈相位守卫的回波反击压力。
- 接受出发整备台校准后，继续降低污染采集和污染反击承压。
- 接入核心归档维护后，下一趟污染回访和核心稳定站复测会继续读取维护收益。
- 后勤维护确认后，污染边界后勤复测、核心稳定站复测沉积和复测守卫会继续读取维护收益。
- 支撑防护响应确认；防护响应触发时，战斗日志会说明基础防护服、过滤模块和前哨补给共同降低了承压。
- 参与封锁遗迹入口门前准备判断；未装入时，入口确认会提示后续污染承压更高。
- 支撑污染边界深处、污染脊、遗迹外圈和核心缓冲补料点的回访路线。

## 使用建议

- 进入污染边界深处前，优先确认它已经装入防护服模块槽。
- 如果只制造了模块但 HUD 仍显示未生效，回基地检查出发整备台，而不是继续在基础反应器旁反复加工。
- 如果 HUD 显示模块可校准、核心归档维护或后勤维护待接入，回出发整备台处理；这些不是新装备栏，而是同一模块的维护状态。
- 如果污染敌人反击压力过高，先检查是否遗漏模块、修复凝胶或抗污染药剂。
- 如果整备台提示防护响应可确认，先回前哨核心补满生命 / 防护并备好修复凝胶、抗污染药剂，再确认响应。
- 它不替代补给；防护偏低仍应按 `2` 使用抗污染药剂，生命偏低仍应按 `1` 使用修复凝胶。
