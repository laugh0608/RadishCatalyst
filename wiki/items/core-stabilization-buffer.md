# 核心稳压缓冲包

更新时间：2026-06-08

剧透提示：本页涉及当前 demo 终点前整备。

## 定位

`核心稳压缓冲包` 是核心稳定站终点前的基地整备物。它把修复凝胶、抗污染药剂、污染浆液和基础零件合成成一次守卫战承压收益，并把守卫战后的回写校准接到最终核心写入。

## 当前来源

```text
修复凝胶 x1 + 抗污染药剂 I x1 + 污染浆液 x1 + 基础零件 x2
-> 基础反应器
-> 核心稳压缓冲包 x1
```

进入核心稳定站后会开放该配方。当前任务会要求玩家回污染边界补沉积物、清理补料守卫，再回过滤器和基础反应器完成整备。

## 当前作用

- 带回核心稳定站挑战 `核心阶段守卫`。
- 守卫第一次回写压力命中时会消耗缓冲包。
- 消耗后会降低该次回写造成的生命 / 防护承压。
- 设备会记录这次回写校准；之后写入核心稳定设备时，最终反冲还会读取这份校准并进一步降低承压。

## 注意事项

- 如果缺抗污染药剂或污染浆液，回污染边界补沉积物并用污染过滤器处理。
- 如果缺基础零件，确认是否有多余污染浆液可回收；但不要回收目标配方需要的最后一份浆液。
- 缓冲包不等于免疫后续伤害；最终写入仍会根据是否带有抗污染药剂结算一次生命 / 防护压力。
