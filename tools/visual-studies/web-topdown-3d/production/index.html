01 / 搭建

建立你的第一条产线

选择采集器，放到青色晶体矿点。

  1. 放下三种设备
  2. 收到第一件催化剂
  3. 拆开输入，观察缺料
  4. 修好线路，恢复产出

厂坪已供电，构件已备齐。从矿点开始。

WASD 移动 · 点击设备查看 · 滚轮缩放回收箱：晶体 0 / 催化剂 0

先将采集器盖住青色矿点，再放反应器和终端仓。青色口接收、金色口输出；反应器的接口位于靠前一排，带的箭头指向物料要去的方向。参考框只提示位置，所有构件都需要亲手放下。

选构件后点击厂坪放置，或用 X / Z 与“放置”按钮精确落位。R 转带向，方向键微调预览，Esc 逐层取消。拆回时货物一并进入回收箱，在制批次还原成晶体；可投入选中设备。后台标签暂停生产。

输入断开后，带上与机器内已有物料仍会继续加工；待存料耗尽才会缺料。堵住输出则逐渐形成回压，疏通后自动恢复。
